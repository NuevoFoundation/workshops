As propriedades ou características de um array são uma forma de descrever os atributos do array. Exemplos incluem: o número total de elementos, o valor em um índice específico, etc...

Aqui está uma lista das propriedades do objeto Array juntamente com suas descrições.

## Constructor()

Retorna uma referência à função do array que criou o objeto.

**Sintaxe:**
```javascript
arrayName.constructor;
```

## Index()

A propriedade representa o índice baseado em zero da correspondência na string. O índice fornece uma forma de acessar ou modificar elementos com base em sua posição no array.

### Acessar um elemento do array pelo índice:

**Sintaxe:**
```javascript
var value = arrayName[index];
```

**Exemplo:**
![#Imagem não encontrada](../../img/indexaccess.png)

### Modificar um elemento do array pelo índice:

**Sintaxe:**
```javascript
arrayName[index] = newValue;
```

![#Imagem não encontrada](../../img/indexmodify.png)

## Length() 
Reflete o número de elementos em um array.

**Sintaxe:**
```javascript
var length = arrayName.length;
```
