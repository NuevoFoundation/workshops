Os componentes que usaremos para o projeto estão listados abaixo. Certifique-se de ter todos antes de começar: 
![imagem de todos os itens](../img/materials.jpg)

1. Peças de acrílico previamente cortadas (3mm) com peças adicionais anexadas às peças #7 e #8. Isso inclui as partes para montar a caixa (lados, topo, fundo) e o "dedo".
	1. Chave de alternância (duplo polo-duplo throw "DPDT"). Esta é a "Chave Superior de 6 terminais", que está anexada à peça #7. A chave é semelhante a:
	![chave superior](../img/top-switch.png)
	2. Chave Momentânea/Limitadora (single-pole-double-throw "SPDT"). Esta é a chave inferior, que está anexada à peça #8. A chave é semelhante a:
	![chave inferior](../img/bottom-switch.png)
2. Suporte para 2 baterias (suporte para 3 baterias também serve)
![suporte de baterias](../img/2batteryPack.png)
3. 2 baterias AA (ou 3, se o suporte de baterias for para 3)
![2 baterias AA](../img/2batteries.png)
4. Placa de ensaio de 400 pontos (pode ser substituída por uma menor, se necessário)
![placa de ensaio](../img/breadboard1.png)
5. 12 fios de conexão (comprimento de 20 cm)
	1. 2 pretos
	2. 2 vermelhos
	3. 2 amarelos
	4. 3 azuis
	5. 3 verdes

	![fios](../img/wires.png)
6. Motor
![motor](../img/motor.png)
