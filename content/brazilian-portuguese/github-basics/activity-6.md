### O Desafio dos Conflitos de Merge

Imagine que você está trabalhando em um projeto com sua equipe. Você recebeu a tarefa de atualizar o site do projeto, mas ao tentar enviar suas alterações, encontra um conflito de merge. É aqui que suas habilidades serão colocadas à prova!

### Compreendendo o GitHub Issues

Antes de mergulharmos na resolução de conflitos, vamos explorar uma ferramenta crucial no código colaborativo: o GitHub Issues. Estes são mais do que apenas relatórios de bugs; são um centro de comunicação para o seu projeto.

### Quiz: Qual é o propósito das etiquetas (labels) no GitHub Issues?

Tire um momento para considerar as seguintes opções:

1. Atribuir issues aos membros da equipe  
2. Definir prazos para os issues  
3. Categorizar e filtrar issues  

Pense em como você tem usado o GitHub em seus projetos. Qual dessas funções parece mais alinhada com o propósito das etiquetas?

Quando estiver pronto(a), escolha sua resposta. Lembre-se, há apenas uma opção correta!

**A resposta correta é: 3. Categorizar e filtrar issues**

As etiquetas no GitHub Issues são ferramentas poderosas para organizar seu projeto. Elas permitem identificar rapidamente o tipo de issue (bug, melhoria, dúvida), sua prioridade ou qual parte do projeto ele afeta. Essa categorização torna mais fácil gerenciar projetos grandes com muitas issues.

### Atividade Prática: Criando um Issue

Agora que você entende o propósito das etiquetas, vamos colocar esse conhecimento em prática:

1. Vá para o repositório GitHub de um dos seus projetos.  
2. Navegue até a aba "Issues".  
3. Clique em "New Issue".  
4. Dê ao seu issue um título relacionado a um recurso que você gostaria de adicionar ou um bug que você notou.  
5. Na descrição, forneça detalhes sobre o issue. Lembre-se de ser claro(a) e conciso(a)!  
6. No lado direito, você verá opções para adicionar etiquetas. Escolha pelo menos uma etiqueta apropriada para seu issue.  
7. Envie o issue.  

Após criar o issue, anote o número dele. Você precisará dessa informação para o próximo passo.
