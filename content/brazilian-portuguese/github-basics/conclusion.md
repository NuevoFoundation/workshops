Nuvi precisa planejar e documentar a estratégia de fuga para completar a aventura.

### Tarefa:
1. Crie uma issue no repositório detalhando o que você aprendeu e quaisquer perguntas que tenha.
2. Crie um quadro de projeto com pelo menos duas colunas: A Fazer e Concluído.
3. Adicione a issue ao quadro de projeto.

### Pistas:
- Use issues e quadros de projeto para se manter organizado e acompanhar o progresso.
