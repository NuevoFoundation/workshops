## Usando o Playground

Vamos utilizar a ferramenta PlayCode para construir nosso primeiro projeto com React. Com ela, você pode editar código online.

Primeiro, precisamos entender como o PlayCode ou Playground funciona. Você pode criar arquivos e pastas para organizar seu código. Trata-se de um editor de código que atualiza automaticamente, ou seja, tudo o que você escrever será atualizado sem precisar recarregar a página. Assim, você pode ver seu progresso em tempo real.
