## Crie o Banner do seu Restaurante
Ao configurar o caixa virtual do seu restaurante, primeiro precisamos garantir que temos um banner do restaurante com o nome dele. Como queremos um banner real, e não apenas o nome em texto simples, vamos usar arte ASCII! Arte ASCII utiliza símbolos especiais, como `()`, `{}`, `*` e outras teclas para criar imagens e palavras.  
Para esta atividade, podemos usar este recurso online para converter texto em arte ASCII.

[Conversor de Texto para ASCII](https://onlineasciitools.com/convert-text-to-ascii-art)

Por exemplo, podemos converter a palavra "Restaurante" em arte ASCII. Dê uma olhada no código abaixo!

```python
print("    _   _   _   _   _   _   _   _   _   _  ")
print("   / \ / \ / \ / \ / \ / \ / \ / \ / \ / \ ")
print("  ( r | e | s | t | a | u | r | a | n | t )")   
print("   \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ ")
```
