O servidor da Nuvi está ativo e as pessoas estão entrando—mas o ajudante de tradução ainda não existe. Nesta seção, você criará o primeiro bloco de construção: um bot mínimo do Discord usando Python. Você registrará uma aplicação no Discord, gerará um token de bot, convidará o bot para um servidor que você controla, e implementará um primeiro comando para garantir que tudo funciona. Pense nisso como ativar o núcleo assistente da Nuvi antes de adicionar features de linguagem.

Nós vamos nos concentrar em:
- Criar uma aplicação Discord e um usuário bot
- Gerenciar o token do bot com segurança
- Escrever um bot Python mínimo
- Rodar o bot localmente e validar conectividade

Vamos começar!
