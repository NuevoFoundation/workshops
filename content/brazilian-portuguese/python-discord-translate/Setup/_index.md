Nuvi acaba de lançar um novo hub global no Discord, onde amigos de diferentes países estão se reunindo — mas as conversas iniciais já estão se dividindo em bolhas de idiomas. Antes de ajudar Nuvi a construir o bot tradutor que conectará todos, você precisa de um lugar confiável para escrever e executar o código. Nesta seção, você preparará seu ambiente de desenvolvimento para construir um bot do Discord com funcionalidades de tradução. Você vai instalar as ferramentas necessárias, criar ou selecionar um runtime Python e organizar uma pasta de projeto limpa, para manter segredos seguros e o código modular. Pense nisso como construir o workshop do robô antes de montar as peças do tradutor.

Vamos focar em:
- Pré-requisitos (versão do Python, pip, ambiente virtual)
- Instalando dependências principais (bibliotecas)
- Fundamentos da estrutura da pasta do projeto
