## Sua missão no campeonato

O Nuvi United chegou à partida final de um campeonato mundial de futebol imaginário. O estádio está cheio, o placar está pronto, e o time precisa de **você** para criar um programa em Python para a partida.

Ao longo de três atividades, seu programa irá apresentar os times, exibir atualizações da partida e decidir quem levantará a taça. Você pode personalizar o time, o capitão, as cores, o adversário e o placar.

Esta é uma história fictícia de codificação. Ela não utiliza times, logotipos ou resultados oficiais de torneios.
{{% /notice %}}

## O que você vai aprender

Quando o apito final soar, você será capaz de:

- criar variáveis que armazenam informações sobre o time e os placares;
- usar strings formatadas para criar anúncios da partida; e
- usar uma decisão `if`/`else` para escolher a mensagem do vencedor.

## O que você precisa

- Python 3 instalado no seu computador
- Um editor de texto, como Visual Studio Code, IDLE ou Notepad
- Cerca de 45 minutos

Você já deve saber como salvar um arquivo e executar um programa simples em Python. Não é necessário criar uma conta online ou usar serviços externos de codificação.

Como você já possui alguma noção de Python, a Atividade 1 será uma rápida revisão em vez de uma introdução inicial à programação. Ela revisa variáveis para que todos comecem com os mesmos dados do time, antes que a Atividade 2 use essas variáveis em mensagens formatadas da partida e a Atividade 3 compare as variáveis de placar para decidir o vencedor.

## Crie seu arquivo de partida

1. Abra o seu editor de texto.
2. Crie um arquivo chamado `world_cup_2026.py`.
3. Salve-o em um local fácil de encontrar.
4. Abra um terminal naquela pasta.
5. Execute o programa após cada alteração:

```text
python world_cup_2026.py
```

Em alguns computadores, o comando será `python3 world_cup_2026.py`.

{{% notice tip %}}
Para um workshop presencial, trabalhe ao lado de um colega. Após cada atividade, troquem de lugar: uma pessoa executa o código enquanto a outra verifica o anúncio da partida.
{{% /notice %}}
