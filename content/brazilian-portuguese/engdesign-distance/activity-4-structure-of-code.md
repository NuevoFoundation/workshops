Lembrando que a estrutura principal de qualquer código é seguir uma série de etapas para obter uma solução. Nossas etapas incluem inserir certos valores numéricos, selecionar uma opção entre um número dado de alternativas, etc. Qualquer decisão que você tomar em cada etapa terá resultados significativos ao final do código. Cada etapa será incorporada a um cálculo, que então fornecerá o tamanho do diâmetro com base nas suas escolhas. Além disso, nossa solução é obter um diâmetro para nosso eixo cardã e, em seguida, verificar se o tamanho do diâmetro é uma boa escolha de design.

Já existe um código fornecido para você, e sua tarefa principal é tratá-lo como uma ferramenta para determinar o diâmetro do eixo cardã com base em todas as escolhas que você fizer. As escolhas estão divididas em 5 etapas principais.

1)	Input do Fator de Segurança  
2)	Seleção de um material para o seu eixo cardã  
3)	Seleção das condições para o seu eixo  
4)	Inserir a carga que o seu eixo irá experimentar  
5)	Seleção da geometria do seu eixo  

Não se preocupe, todas essas etapas serão explicadas na próxima seção.
