你進入一個充滿漂浮看板和專案時間表的房間。一個舒心的聲音宣告：「從混亂中找到秩序，計劃你的逃脫！」

## 你的任務

1. 在你的 GitHub 儲存庫中創建一個新的專案看板。
2. 添加「待處理」、「進行中」和「完成」的欄位。
3. 創建一些議題並將它們添加到你的專案看板中。
4. 在不同的欄位之間移動一個議題。

## 指引

1. 前往你的 GitHub 儲存庫。
2. 點擊「Projects」標籤。
3. 點選「New project」並選擇「Board」作為模板。
4. 在你的看板上添加所需的欄位。
5. 在你的儲存庫中創建幾個議題。
6. 將這些議題添加到你的專案看板。
7. 將一個議題移動到看板的每個欄位中。

{{< expand "專案看板操作流程" >}}
**創建看板**
1. 前往「Projects」標籤
2. 點擊「New project」
3. 選擇「Board」模板
4. 添加欄位：「待處理」、「進行中」、「完成」

**添加議題**
1. 前往「Issues」標籤
2. 新建議題
3. 在每個議題中，點擊「Projects」並添加到你的新看板

**移動議題**
1. 返回你的專案看板
2. 拖放議題到不同欄位
3. 觀察這如何反映你的任務進度
{{< /expand >}}
