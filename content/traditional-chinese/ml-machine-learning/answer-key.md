## 第一節：什麼是迴歸？

### 練習 1 答案

**Q1：** 可以根據面積判斷形狀類型嗎？

**A：** 不可以。一個正方形 (3x3 = 9) 和一個三角形 (底 6，高 3，面積 = 6x3/2 = 9) 的面積相同，但它們是不同的形狀。

**Q2：** 什麼樣的關係決定形狀類型？

**A：** 邊的數量。這是一種直接的線性關係：3 邊 = 三角形，4 邊 = 正方形，5 邊 = 五邊形，依此類推。

## 第二節：簡單線性迴歸

### 關鍵公式

線性迴歸方程：

```
y = ax + b + ε
```

其中：
- `x` = 自變數 (工作經驗年限)
- `y` = 因變數 (工資)
- `a` = 斜率/係數 (每單位 x 的變化量導致 y 的變化量)
- `b` = 截距 (當 x = 0 時的 y 值)
- `ε` = 誤差項

### 練習 1：使用 Scikit-learn 操作

載入並視覺化數據集：

```python
import pandas as pd
from sklearn import linear_model

dataset = pd.read_csv("Experience_vs_Salary.csv")
x = dataset.iloc[:, :-1].values  # 工作經驗列
y = dataset.iloc[:, 1].values     # 工資列

model = linear_model.LinearRegression()
model.fit(x, y)
```

### 練習 2：計算斜率與截距

**答案：**
- **截距 (b)：** 25,792.20
- **係數/斜率 (a)：** 9,449.96
- **方程：** 工資 = 9,449.96 × (工作經驗) + 25,792.20 + ε

**解釋：**
- 一名無工作經驗的員工的平均工資約為 $25,792
- 每增加一年工作經驗，工資平均增長約 $9,450

## 第三節：置信區間

### 關鍵公式

```
係數範圍 = 係數 ± 2 × 標準誤差
```

### 練習 2：計算標準誤差

**答案：** 標準誤差 = **409.40**

### 置信區間計算

```
係數範圍 = 9,449.96 ± 2 × 409.40
係數範圍 = 9,449.96 ± 818.80
係數範圍 = [8,631.16 , 10,268.76]
```

**解釋：** 我們有 95% 的信心認為，每年工作經驗對工資的增長影響在 $8,631.16 至 $10,268.76 之間。

### 練習 1：檢查更多樣本

**Q：** 為什麼每次運行的截距和係數值不相同？

**A：** 每次運行都會從 10,000+ 筆數據中隨機選擇 30 條記錄作為樣本。不同的樣本會得到略有不同的結果，但值應落在置信區間範圍內。

### 練習 3：正態分佈

從多個樣本中抽取的係數值的直方圖呈現鐘形曲線（正態分佈）。這證明了這些值會圍繞真實係數聚集，其中大多數落在置信區間內。

## 第四節：模型擬合

### 練習 1：計算 R 平方

**答案：** R² = **0.973**

**解釋：** 我們有 97.3% 的信心認為工作經驗和員工工資之間存在關聯。這個模型解釋了工資變化的 97.3%。

{{% notice tip %}}
**給教師的建議：** R² 的範圍是 0 到 1。大於 0.9 的值表示非常強的關聯。如果學生得到較低的 R²，請讓他們檢查樣本大小。鼓勵學生改變 `sample_size` 變量，觀察 R² 的改變。
{{% /notice %}}
