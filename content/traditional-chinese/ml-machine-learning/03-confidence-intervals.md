# 信賴區間

前面的例子告訴我們，當你從一個較大的數據集中處理隨機樣本時，**截距**和**係數**的值會在某一範圍內變化。我們知道實際值一定介於兩個值之間，但我們並不知道它們是什麼！這就是所謂的 [信賴區間](https://www.geeksforgeeks.org/confidence-intervals-for-machine-learning/)。

當你多次運行**練習1**中的代碼時，你會發現**係數**的值每次都不同，但注意到它很少低於9000，或者很少高於10000。在此範圍內所有可能的**係數**值之間的差異是多少呢？這個值被稱為**標準誤差**。

**[標準誤差](https://www.statology.org/standard-error-regression/)** - 值偏離回歸線的平均距離。

# 示例 3：常態分佈

讓我們退一步問，在“練習2”中看到的係數或斜率中，有多大的可能性會在運行其他樣本程序時重複出現？

機器學習使用大量的統計學來確定我們獲得的值。在統計學的領域裡，有一個用來測量數值在數據中`出現概率`的圖表。這被稱為`正態分布`或`鐘形曲線`，它看起來像這樣：

|![正態分布](../resources/normal_distribution.png)|

|圖示：正態分布或鐘形曲線|

讓我們舉一個例子：見到非常矮的人有多大的可能？見到非常高的人又有多大的可能？

如果我們將這種關係和鐘形曲線聯繫起來，你會得到如下圖表：

|![正態分布](../resources/normal_distribution_height.png)|
|:--:|
|圖示：帶有人群身高的正態分布或鐘形曲線|
