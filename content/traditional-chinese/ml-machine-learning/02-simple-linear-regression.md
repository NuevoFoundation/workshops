# 何謂簡單線性回歸？

簡單線性回歸旨在找出兩個變量之間的相關性，並推導解釋依變量與自變量間關係的數學方程式。通常在進行簡單線性回歸時，我們希望能達成以下結論：

1. 變量之間是否存在**關聯性**？

    你可以確定收入與支出之間的關係、工作經驗與薪水的關係，或者濕度與溫度的關係。但舉例來說，學生的身高與考試分數之間則不存在任何關聯。

2. 我們是否可以用它來進行**預測**？

    通過回歸，我們可以訓練模型並找出是否能夠有把握地進行預測。我們能否利用查明的關聯來預測新值？

    例如：明天的溫度會是多少？今年和去年相比，我的麵包店能賣出多少產品？如果我有五年的工作經驗，我的薪水將是多少？

# 變量的角色

在簡單線性回歸中，變量可以扮演以下兩種角色之一：

1. **依變量**

    我們希望預測或預估其值的變量。我們稱它為**依變量**，因為它的值依賴於其他因素。一般用 **y** 表示此變量。

2. **自變量**

    這是我們可以控制或改變以影響依變量的變量。一般用 **x** 表示此變量。

    例如：如果一顆蘋果的價格是 $1.00，而你買了 10 顆蘋果，總花費將為 $10.00。此處的依變量是 `總花費`，而自變量則是你想購買的蘋果數量。

# 簡單線性方程數學模型

當我們使用簡單線性回歸時，我們將其稱為**線性回歸**，因為該數學模型在二維平面上表示為一條直線。我們來簡單思考一下。

直線的數學方程式是什麼？

這個方程式可能對你而言非常熟悉。如果是的話，它是直線的一般方程式。

<h1>
\[
    y = ax + b
\]
</h1>

- **x** 是自變量。
- **y** 是依變量。
- **a** 是直線的斜率。
- **b** 是截距，亦即當 **x = 0** 時 **y** 的值。

依據此方程式，我們將説明我們如何使用簡單線性回歸數學模型來計算並預測新值。

# 真實世界中的範例

在現實世界中，數據有時並不完全呈現線性關係，而可能以不同的方式表現。乍一看，數據可能似乎毫無關聯。在進行簡單線性回歸時，你需要尋找數據是否略顯線性。

假設你在一家擁有超過 10,000名員工的公司人力資源部擔任`數據分析師`。你的上司想知道員工的工作經驗年限是否會影響其薪水高低。作為`數據分析師`的你可以調閱員工資料，快速核實以下資訊：

1. 員工目前的薪水是多少？
