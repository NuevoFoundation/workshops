為了構建我們的遊戲，我們將使用 Pygame 庫，它提供了一組現成的功能，讓我們能夠用來構建 Pong 遊戲及其動畫。

## 使用 Replit

今天，我們將使用 Replit 來構建 Pong 遊戲。

如果您想回顧如何使用 Replit 請查看我們的 <a href="https://workshops.nuevofoundation.org/python-basics/repl-it/" target="_blank">Python 基礎教學</a>。

## 庫與匯入語句

仔細查看代碼的頂部。您會看到以下這一行：

```
import pygame
```

這個語句讓我們能夠匯入 Pygame 庫所提供的所有動畫與物件繪圖功能。**庫**是一個功能相關的集合，可以在 Python 語言中使用。例如，`pygame` 庫提供了一種方式來在螢幕上畫出一個矩形，而我們可以用這種功能來繪製 Pong 遊戲中所需的邊界、球以及球拍。

## 註解

以 `#` 開頭的灰色行被稱為 **註解**。這些是用簡單英文書寫的代碼備註，用來幫助解釋代碼的作用。註解會被電腦忽略；開發者通常利用註解在彼此間進行溝通，尤其是當多位開發者一起合作處理同一份代碼時。註解也能幫助在閱讀代碼時，快速了解發生了什麼，而不需要深入閱讀所有的代碼。在 `main.py` 中，我們在整個代碼中使用了註解，以指出需要對代碼進行修改的地方。
