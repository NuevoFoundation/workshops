## 視覺化隊列

想像一下，你正在為一個商業應用設計 NuevoEats，也許這個商業對象是麥當勞。

我們希望能以最高效的方式為我們的大型企業服務我們的新潛在客戶；一次一位顧客。當顧客通過 NuevoEats 應用程式下外帶訂單時，這幾乎就像是他們在我們的餐廳前面排成了一條有序的隊列，新的顧客從隊伍的後方加入。顧客下訂單時應該「排隊」，而我們則應按從前到後的順序為這些顧客服務。

在 Java 中，`Queue` 的工作方式類似。當我們聲明了一個 `Queue` 後，我們可以將新的元素添加到隊列後方，並從隊列前方刪除元素。

事實上，我們在 Java 中遇到的大多數隊列都是以這種先入先出的方式運作的——通常簡寫為 FIFO。
