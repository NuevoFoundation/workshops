## 設定 Replit!

今天你將使用 Replit 來學習 Java 的資料結構。在開始之前，如果你還沒有 Replit 帳號，你需要先註冊一個帳號。

點擊下面的按鈕來註冊 Replit 帳號——你需要一個電子郵件帳戶才能註冊。如果你已經有 Replit 帳號，也可以使用下面的按鈕登入。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">註冊 Replit</a>

<img src="../img/replit-signup.png" height="300" alt="Replit 註冊表單" />

接下來，點擊下面按鈕啟動今天要使用的 Replit 控制台。你應該會看到像下面的畫面。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/HelloWorld" target="_blank">啟動 Replit</a>

<img src="../img/replit-start-screen.png" height="300" alt="Repl 的起始畫面" />

接下來我們需要 Fork 此 Repl，也就是創建此程式的副本，這樣我們就可以自己進行修改。點擊右上方的 "Fork Repl"，然後點擊 "Fork Repl" 按鈕。

<img src="../img/replit-fork.png" height="300" alt="Fork Repl 來創建程式副本" />

Fork 完 Replit 後，你將看到類似下面的視窗：

<img src="../img/replit-window.png" height="300" alt="Replit 視窗" />

{{% notice warning %}}
每當你看到 "啟動 Replit" 按鈕時，必須按照上述步驟來 Fork 此 Repl，以完成活動。如果你在 Fork Repl 時遇到困難，請尋求協助！
{{%/notice %}}

在開始之前，我們先來了解 Replit 是如何工作的。`main.java` 檔案包含程式碼，或者說是計算機執行的指令。按下 **執行** 按鈕，即告訴計算機執行程式碼中的指令。執行程式碼的結果將顯示在下面白色屏幕中，位於 **結果** 標籤下方。

為了學習如何編碼資料結構，我們將使用 Replit 來測試你的技術。按下執行並嘗試完成以下任務吧！

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/introduction" target="_blank">啟動 Replit</a>
