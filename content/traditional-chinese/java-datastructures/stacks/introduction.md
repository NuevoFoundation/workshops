## 認識堆疊

堆疊與佇列非常相似，許多你在學習佇列時了解的概念也適用於堆疊。然而，不同於遵循先入先出（FIFO）邏輯的佇列，堆疊使用的是相反的邏輯：後進先出（LIFO，Last In, First Out）。

一個常見的例子是將堆疊想像成一疊盤子。想像有5個盤子疊在一起。如果你在上面再放上一個第6個盤子，你的盤子堆現在就是6個盤子。然而，如果你想要拿掉一個盤子呢？你不會選擇從堆疊的底部拿出盤子；相反，你會從最上面拿出一個。

這種後進先出（LIFO）的邏輯也適用於 Java 中的堆疊。
