陣列是一種資料結構，其元素以數值順序排列，每個項目都能以其位置編號來引用。在 Java 中，這些元素的類型統一（如 `String`、`int`、`double` 等），並且採用零起始索引，這表示陣列中的第一個元素索引為 `0`，第二個元素索引為 `1`，以此類推。

![image](../img/array.png)

在進一步討論陣列之前，以下是一些需要了解的重要術語：

- 陣列中項目的數量稱為陣列的 **長度**。
- 陣列中每個項目的資料類型稱為陣列的 **基本類型**。
- 陣列中某項目的位置編號稱為該項目的 **索引**。

對於本課程的需求，我們希望創建一個陣列來儲存應用程式中所有不同的餐廳。 假設我們的程式需要處理一千家不同餐廳的名字，我們需要一種方法來整理和處理所有數據。 如果沒有陣列這種資料結構，我們就必須為每一家餐廳創建一千個不同的變數，而且如果我們想做一些簡單的事情，比如列印出每家餐廳的名字，就需要寫 1000 個 `print` 語句。要完成這樣的工作將會是個極大的挑戰。

相對來說，陣列允許我們用一次性步驟完成相同的操作。陣列雖然是一個單一變數，但它可以含有全部 1000 家餐廳的名稱。

![image](../img/array2.png)

此陣列的 **長度** 是 1000，因為它包含了 1000 個單獨的名稱。陣列的 **基本類型** 是 `String`，因為陣列中的項目都是字串。第一個名稱在陣列中的位置是 **索引** `0`，第二個名稱的索引是 `1`，依此類推，直到第一千個名稱的索引為 `999`。
