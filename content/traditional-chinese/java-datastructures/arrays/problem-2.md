## 任務 2：排序陣列！

菜單中每項目成本都很雜亂！幫助我們將陣列按照從小到大的順序排序。

{{% notice tip %}}
1. 想一想如何排序陣列（有很多不同的方法可以做到）！
2. 看看範例！
{{% /notice%}}

如果我們給出以下這個陣列， 
```js javascript
int[] cost = {100,90,50,60,20,1,3};
```

那麼我們應該得到以下輸出：
```js javascript
int[] sorted = {1,3,20,50,60,90,100};
```
