## 二元樹

樹是一種特殊的資料結構，因為它是由許多節點透過邊連接而成的集合。我們並沒有像其他資料結構一樣有一個通用的初始化器來建立新的樹。為了簡化討論，我們將專注於 **二元樹**，這是一種具有嚴格規則的特定類型的樹，關於每個節點的放置位置有明確的規範。

二元樹的規則為：
* 每個節點具有正好兩個邊，分別是左節點和右節點
* 左邊的節點的值小於目前節點
* 右邊的節點的值大於目前節點

我們之前看到的樹是一個二元樹的例子。請檢視每個節點，自己檢查它們是否遵循這些規則！

## 搜尋元素

在我們探討如何用程式實現搜尋之前，先來看看二元樹是如何尋找元素的。在檢視樹中的元素時，我們總是從根節點開始，而根節點在二元樹中通常是資料的中間值。

從根節點開始後，我們檢視它的值，並問自己：「我們要找的值是小於、等於還是大於這個值？」如果值是相等的，那太棒了！我們已經找到了答案。如果我們要找的值比目前的值小，那麼我們會移動到左側節點並重複相同的問題。如果我們要找的值比目前的值大，那麼我們會移動到右側節點並重複相同的問題。

## 遍歷元素

現在我們已經概念上理解了如何搜尋元素，可以看到搜尋元素實際上就是將相同的操作重複執行。因此，只要我們將此操作正確程式化，整個搜尋演算法就完成了。

想像我們有如下定義的節點：
```js javascript
class Node {
    int value;
    Node left;
    Node right;
}
```

我們現在可以根據上一節中討論的邏輯來找到正確的元素。請看以下程式碼片段：
```js javascript
Node current = root;
if (current.value < desired) {
    current = root.right;
} else if (current.value > desired) {
    current = root.left;
}
```
我們可以看到這段程式將我們從一個步驟帶到下一個，接著我們可以使用這段邏輯在 `for` 迴圈中持續進行，直到找到我們想要的值。
