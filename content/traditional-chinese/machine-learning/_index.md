## 讓我們學習一些機器學習來評估 FIFA 電子遊戲中球員的總體評分

機器學習是一門研究*算法*和*模型*的科學，能夠使計算機識別事物、做出決策，甚至在沒有明確指令的情況下預測結果。例如，當與手機助手（如 Siri 或 Cortana）互動時，機器學習幫助將你的聲音轉換成文字，並進一步理解你的需求。是不是很神奇？

今天我們將一步步向你展示如何*教*計算機根據球員的屬性來評估足球運動員的總體評分。

讓我們開始吧！

## 一點背景知識

假設 EA Sports（FIFA 2019 的開發商）有一個公式用於計算足球運動員的 "總體" 評分。通過這個公式，我們可以輕鬆計算出任何球員的總體評分，即使他/她不在遊戲中。但問題是，我們不知道這個公式是長什麼樣的。<br>
我們知道*輸入*是球員的屬性，而*輸出*是總體評分。那麼，我們可以使用一種稱為“回歸”的方法來基於輸入/輸出來“估計”這個公式。

今天，我們將使用一個簡單的模型，稱為線性回歸。  
假設計算足球運動員總體評分的公式 \( y = f(x)\) 是  
\[
    f(x) = ax + b
\]  
線性回歸的目標是找到 \(a\) 和 \(b\)。在機器學習中，公式 (f(x)) 被稱為“模型”，而解算/估算該模型的過程被稱為“訓練”模型。一旦我們訓練了模型，就可以用它來預測新數據的目標 \(y\)。

回到我們的故事，如果我們只有一個變量 \(x\)，估算 \(f(x)\) 應該很容易。每個人都應該能用筆和紙解決這個問題。然而，當 \(x\) 是球員屬性（例如速度、力量、傳球、攔截）的長列表時，問題就變得復雜了。公式應該被重新寫成  
\[
    f(x_1, x_2, ..., x_n) = a_1 * x_1 + a_2 * x_2 + ... + a_n * x_n + b
\]  
然後，我們必須向模型提供大量高品質的數據，以使模型更接近這個“真實”的公式。讓我們開始吧！
