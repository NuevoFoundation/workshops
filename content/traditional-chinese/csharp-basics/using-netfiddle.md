### 使用 .NET Fiddle
今天，您將使用 .NET Fiddle 來學習如何用 C# 進行編程。

在開始之前，我們先來了解這個窗口是如何運作的。窗口的左側有一個選項列表。這些選項都已經為您設定好了，所以您不需要擔心它們。屏幕的中央是代碼區，也就是給電腦執行的指令。點擊 **執行** 按鈕（窗口頂部中央的三角形按鈕），您就可以指示電腦執行代碼中的指令。執行代碼的結果將在屏幕底部顯示。

### 關於 C# 的一些提示

以下是一些重要提示：
1. 每一行代碼結尾都需要加上分號 `;`
2. 在範例中可能會出現您目前還不理解的代碼。這沒關係，暫時忽略它們，專注於您現在正在進行的任務。

## 保存您的工作

如果您希望在這些練習過程中保存您的工作成果，您需要註冊一個 .NET Fiddle 帳號（如果您還沒有的話）。

點擊下方按鈕即可註冊 .NET Fiddle 帳號——註冊時需要提供一個電子郵件地址。如果您已有 .NET Fiddle 帳號，也可以使用下方按鈕登錄您的帳號。

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/SignUp" target="_blank">註冊 .NET Fiddle</a>

<img src="../images/dotnetfiddle-signup.png" height="300" alt=".NET Fiddle 註冊表單" />

接下來，您可以 *分叉*（Fork）此 Fiddle，這意味著您可以建立程序的一個副本，以便進行修改並保存自己的更改。點擊頂部的 "Fork" 按鈕。
