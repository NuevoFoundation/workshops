## 變數：命名它吧！

在第一個練習中，我們學會了使用 `Console.WriteLine()` 和 `Console.Write()` 來輸出不同的內容。

雖然直接輸出數字或句子很好，但這些內容缺乏意義。如果我們想要再次使用同一個句子或數字，就必須重新輸入。

在 C# 中，我們引入了**變數**這個概念，來存儲資料。變數可以用一個名稱來存儲一段資料。

例如，有一個名為 `myName` 的變數，被賦予了值 `"Ann"`。另一個變數可能叫作 `age`，其值是數字 `12`。

## 什麼是類型！

那麼，我們該如何在 C# 中創建用來存儲資料的變數呢？

在學習如何創建變數之前，我們需要先了解 C# 中的 **資料類型**（簡稱**類型**）。類型描述了變數存儲的內容。如果你有一個數字變數，那麼它只能存儲數字，不能是句子或符號。每個變數都對應一種特定的類型，來控制它能保存的資料種類。

例如，我們可以有一個變數 `age`，用來存儲數字 `12`。如果你試圖將文字 `"twelve"` 賦值給 `age`，這會產生錯誤，因為它只接受數字。

在 C# 中，想要存儲整數數字的變數類型是 `int`。我們用以下程式碼來聲明一個名為 `age` 的 `int` 變數，並賦予它值 `12`：

```
int age = 12;
```
一般而言，聲明變數的格式是：`[資料類型] [變數名稱] = [資料];`。
{{% notice note %}}
以下是 C# 中一些重要的內建資料類型：

**類型** | **描述** | **範例**
--------|-----------|----------
`int` | 整數 | `20`, `30`, `35`
`char` | 單個字符，例如符號或單個字母 | `'A'`,`'b'`, `'('`, `']'`
`string` | 一連串的 `char` | `"Hello"`, `"Bonjour"`, `"Hola"`
`bool` | 布林值，僅有 `true` 或 `false` | `true`, `false`
`double` | 小數數值 | `2.0`, `3.14`, `9.33`

{{% /notice %}}

使用我們的例子，以下是用 C# 宣告這些變數的方式：

```C#
string name = "Ann";
int age = 12;
boolean loveMusic = true;
```

最後一個變數很有意思，它只能有 `true` 或 `false` 這兩個值。我們會在本工作坊的進階章節中看到它的實用之處。

## 操作變數

接下來，讓我們看看如何操作變數。

在下面的 .NET Fiddle 框中，點擊 fork 並嘗試輸入以下程式碼，然後**執行**：

```C#
int age = 10;
Console.WriteLine(age); // 輸出 10
age = 12; // 將 12 賦值給變數 age
Console.WriteLine(age); // 輸出 12
```
