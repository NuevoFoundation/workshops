## 數學運算：算術運算子

在上一個練習中，我們學習了變數以及如何將值分配給特定類型的變數，例如：

```C#
int age = 3;  // 宣告名為 age 的變數，其類型為 int，初始值為 3
age = 4;      // 將 4 指派給變數 age
```

觀察上面的程式碼，本質上是在變數 `age` 的值上加 1。

在 C# 中，我們可以直接使用 **算術運算子** 來對變數進行數學運算，例如：`+`，`-`，`*`，`/`，`%`。
例如，我們可以使用加法運算子 `+` 對 `age` 加 1：

```c#
int age = 3;  // 宣告名為 age 的變數，其類型為 int，初始值為 3
age = age + 1;// 在 age 上加 1
```

{{% notice note %}}
以下是 C# 中的算術運算子：

**運算子** | **描述** | **範例**
------|------|--------
`+` | 加法 | `1 + 1 = 2`
`-` | 減法 | `2 - 1 = 1`
`*` | 乘法 | `3 * 3 = 9`
`/` | 除法 | `9 / 3 = 3`
`%` | 求餘數（模數） | `10 % 4 = 2`

**注意**：如果除法運算的兩個操作數都是整數，結果也將是整數。例如，`10 / 4` 的結果是 2，而不是 2.5，因為餘數被丟棄。若其中一個操作數是 `double`，結果將是 `double` 型別。

**注意**：使用求餘數運算子（`%`）可以取得除法運算中的餘數。

{{% /notice %}}

{{% notice tip %}}
加法（`+`）運算子在字串中可作為連接運算子。例如：

`String name = "Patric" + "k";` 與 `String name = "Patrick";` 是相同的。
{{% /notice %}}

## 比較：關係運算子

接下來，我們學習如何使用 **關係運算子** 比較數字。

就像在數學中，我們可以使用 `>`，`<`，`>=`，`<=` 比較數字。例如：`(3 > 2)` 的結果為 `true`，也就是布林值。

{{% notice note %}}
以下是 C# 中的關係運算子：

**運算子** | **描述** | **範例**
------| ------| ------
`==` | 等於 | `(3 == 3)` 的結果是 `true`
`!=` | 不等於 | `(3 != 3)` 的結果是 `false`
`>` | 大於 | `(3 > 2)` 的結果是 `true`
`<` | 小於 | `(3 < 2)` 的結果是 `false`
`>=` | 大於或等於 | `(3 >= 2)` 的結果是 `true`
`<=` | 小於或等於 | `(2 <= 2)` 的結果是 `true`

注意：`==` 和 `!=` 只能用於相同類型的數據。例如：
```csharp
int x=3; 
double y=3.0; 
x==y; // 這會產生錯誤，因為 x 和 y 是不同的類型。
```

{{% /notice %}}

{{% notice tip %}}
使用 1 個等號（`=`）是對變數賦值。使用 2 個等號（`==`）是比較兩個元素的值。

```csharp
age = 3;  // 設定 age 值為 3
age == 3; // 檢查 age 的值是否為 3
```
{{% /notice %}}
