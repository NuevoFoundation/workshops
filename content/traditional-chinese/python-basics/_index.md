## 概覽

歡迎來到 **Python: 基礎** 課程，在這裡您將學習一種被廣泛使用的高階程式語言，通過它可以向計算機下達指令，創建有趣的程式！

Python 是由 Guido van Rossum 在 1985-1990 年間創建的高階程式語言。

{{% notice info %}}
高階程式語言之所以被稱為高階，是因為它距離計算機中央處理器 (CPU) 原始執行的程式碼還有幾個步驟。高階程式碼是為人類使用設計的，比低階程式碼更容易理解。高階程式碼會被轉換成低階語言，這些低階語言只能被特定的 CPU 理解和執行。為了使程式碼能夠運行，每一行用高階語言編寫的程式碼都必須先被翻譯成機器語言，然後才由計算機執行。
{{% /notice %}}

如今，Python 被全世界的開發者廣泛使用。具體來說，Python 被用於開發網站、軟體組件和應用程式，或者用於數據科學、人工智慧以及機器學習技術。

在本課程中，我們將涵蓋該語言的所有基本功能。
