在建立 Python 程式時，我們可以使用 `#` 加入單行註解來添加一些備註。**註解** 是程式碼的一部分，但不會影響程式的執行。在 `#` 符號後的任何內容都被視為註解，程式會忽略它們。加入註解是為了讓讀者理解程式碼的作用。註解可以讓程式的維護更加簡單，也有助於發現程式中的錯誤。

如果在撰寫程式碼時，您希望添加一些筆記來幫助理解程式，就使用 `#` 符號來創建註解。

```python
# 這是我的第一行程式碼
print("Hello, World!")
```

![螢幕截圖顯示註解 This is my first line of code.](../../img/comments.png "如何在 Python 中撰寫註解的範例圖片")

請注意，如果您移除了 `#` 符號，程式碼將無法正常執行！

![螢幕截圖顯示移除註解前的 # 導致程式執行錯誤](../../img/comments_wrong.png "錯誤撰寫註解的範例圖片")

試著在您的第一行程式碼上方加上一個註解，然後執行程式。您將看到電腦會忽略您的註解。
