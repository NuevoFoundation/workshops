現在我們已經知道了打印語句、變數以及從使用者讀取輸入的基本知識——我們可以結合這些超棒的技能來使用條件語句。條件語句讓計算機可以根據表達式的**值**來做出**決策**。在現實中，我們經常使用條件語句來做決策！例如，如果外面正在下雨，那麼我會使用雨傘。在這個例子中，我評估了外面的天氣，因為正在下雨，我做出了使用雨傘的後續決定。

你能想到日常生活中你會用到哪些條件語句嗎？

# If 語句

我們先從最簡單形式的 if 語句開始！看看這個現實中的例子，你會發現使用了一些詞彙，而這些詞彙也適用於程式中的語句。**如果**外面正在下雨，那麼我會使用雨傘。`if` 告訴我們需要做一個決定。外面在下雨嗎？這個問題就被稱為表達式。如果正在下雨，那麼我會使用雨傘。這是當表達式為真的時候執行的語句。

```python
if (expr):
    statement
```

如上所示，這裡有三個不同的部分：

1. If – 這告訴計算機根據括號中的表達式來做出決定
2. Expr – 這代表我們正在評估的表達式。如果這個表達式為“真”，那麼計算機將進入 if 語句並執行語句。
3. Statement – 當表達式為“真”時，計算機將完成的內容

```python
x = 0
y = 5

if (x<y):       # 真
    print('yes')
if (y<x):       # 假
    print('yes')
if (x == 10):   # 假
    print('yes')
```

讓我們分解上面的例子，決定為什麼某些語句是真或是假。

我們給出了兩個變數 `x` 和 `y`，它們分別賦值了一個數值。在第一個 if 語句中，我們測試 `x` 的值是否小於 `y` 的值。由於 `0` 小於 `5`，所以這是真！所以，第一個 `if` 語句將打印 "yes"。

然而，我們可以看到 `y` 並不小於 `x`，因此它被評估為“假”。那麼 if 語句內部的內容將不會執行。同樣的，對於測試 `x` 是否等於 `10` 的 if 語句也是如此。我們看到 `x` 等於 `0`，所以這個表達式為“假”，if 語句內的內容不會執行。

# Else 語句

現在我們已經知道如何使用 if 語句來有條件地執行單條或多條語句，讓我們看看我們還可以用 `else` 做些什麼！

有時，你需要評估某個條件以便決定如何行動，如果它是“真”，那麼執行某個行動，但如果它是“假”，我們則執行另一個行動。以下是 `else` 語句最簡單的形式。

```python
if (expr):
    statement1
else: 
    statement2
```    

這與 `if` 語句非常相似！然而，在這裡，如果 `if` 語句為“假”（不真實），程式將自動執行 `else` 語句中的 `statement2`。

一個現實中的例子是，如果我餓了，我會吃飯。否則（換句話說，我不餓），我就不吃飯。讓我們看看用 Python 表現出來是怎樣的！

```python
if (hungry):
    eat
else:
    dont_eat
```
