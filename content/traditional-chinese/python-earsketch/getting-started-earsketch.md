[EarSketch](https://en.wikipedia.org/wiki/EarSketch) 是由喬治亞理工學院開發的一個免費教育編程環境。我們今天將使用 EarSketch 創作音樂。

1. 要創作音樂，點擊下面的按鈕，在新分頁中打開 Earsketch。

<a class="my-2 mx-4 btn btn-info" href="https://earsketch.gatech.edu/earsketch2/" target="_blank">啟動 Earsketch</a>

2. 打開網頁後，您可能會看到如下歡迎畫面。點擊 "skip" 按鈕跳過導覽，我們將在以下步驟中介紹所有必要的操作。

<img src="../img/screenshot-skip-tour.png" height="400"/>

3. 現在，讓我們開始吧。點擊左側功能表上的 *Scripts* 圖標，然後選擇 *+ New Script*。

<img src="../img/screenshot-new-script.png" height="400"/>

4. 輸入 *myjam*（或您想要的任何名稱）作為腳本的名稱，並保持編程語言為 *Python*。點擊 *Create* 按鈕創建您的腳本（即放置您的代碼的文件）。

<img src="../img/screenshot-new-myjam.png" height="200"/>

## 推薦給教師 — EarSketch 概述

在開始課程之前，請先了解一下 EarSketch 的概況。熟悉如何在用戶界面中來回導航是很重要的。

左側屏幕的 `Content Manager` 是您瀏覽 EarSketch 各項功能的主要操作區。

1. 導覽列的第一項是 `Sounds` 集合。這是所有 EarSketch 預載音效的集中地。在音效瀏覽器中，您可以根據藝術家、音樂風格或樂器來篩選顯示的音效。

<img src="../img/screenshot-navigation-sound-browser.png" height="400"/>

2. 導覽列的下一個圖標是 `Scripts` 面板。這裡是我們撰寫代碼的地方。

<img src="../img/screenshot-navigation-script.png" height="400"/>

3. 導覽列上的最後一個圖標是 `API Browser` 面板。*應用程序編程接口*（*API*）是一組您可以立即使用的代碼！當您打開它時，每個 API 都有詳細的解釋。

<img src="../img/screenshot-navigation-api-curriculum.png" height="400"/>

在右側，您將看到 `Curriculum` 指南。如果您想了解有關 EarSketch 的更多信息，可以探索當您點擊它時出現在窗口右側的這一部分。在本次練習中，我們將跳過該部分。
