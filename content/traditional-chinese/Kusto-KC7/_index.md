### 歡迎新加入的網絡防禦者！
*--- 威脅情報適用於每個人*
使用真實的威脅數據學習網絡安全。
**KC7 是一款教您學習真實世界網絡安全技能的遊戲**
> KC7 模擬多個網絡威脅行為者對某虛構公司的入侵，教您使用真實數據識別對手在網絡殺傷鏈七個階段的活動。

到了您第一天工作的末尾，您應該能夠：  
- 使用 Kusto 查詢語言 (KQL) 在 Azure Data Explorer (ADX) 中操控數據  
- 使用多個數據集來回答目標問題  
- 在日誌中找到網絡活動，包括：電子郵件、網頁流量和伺服器日誌  
- 使用多種技術來追蹤 APT (高級持續威脅) 的活動  
- 使用第三方數據集來發現有關攻擊者的信息  
- 建立威脅情報報告  
- 提出公司可以採取的保護措施建議  

如果您是培訓師，請在進入工作坊之前從 **T3：培訓師導引** 部分開始。如果您是學員，請繼續進入 **活動 1：登錄與網絡環境設置**。

{{% notice warning %}}
請勿使用 Firefox 瀏覽器進行此工作坊。
{{% /notice%}}

{{% notice warning %}}
請注意，與其他編碼語言一樣，KQL 對大小寫敏感。在使用 Azure Data Explorer (ADX) 時請記住這一點。然而，網絡防禦者遊戲的記分板對大小寫不敏感。
{{% /notice%}}
