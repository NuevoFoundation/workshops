## 開始

今天活動的目標是學習 C# 技巧，並運用新學到的知識來創建一個猜字遊戲！讓我們開始設定這個遊戲。

今天你將使用 .NET Fiddle，一個專門為幫助您學習、建構和運行 C# 程式碼的在線工具。

{{% notice tip %}}
在開始之前，如果您尚未擁有一個 .NET Fiddle 帳號並希望稍後保存您的工作，可以選擇註冊一個 .NET Fiddle 帳號。

點擊以下按鈕註冊 .NET Fiddle 帳號 - 您需要一個電子郵件帳號才能註冊。如果您已經有一個 .NET Fiddle 帳號，您也可以使用下方的按鈕登入您的帳號。

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/SignUp" target="_blank">註冊 .NET Fiddle</a>

<img src="./media/dotnetfiddle-signup.png" height="300" alt=".NET Fiddle 註冊表格" />

{{% /notice %}}

接下來，通過點擊下方按鈕啟動今天活動中要使用的 .NET Fiddle 控制台。您應該能看到下方畫面。

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/lMl7j4" target="_blank">啟動 .NET Fiddle</a>

<img src="./media/guessTheWordActivity-start.png" height="300" alt="Fiddle 的開始畫面" />

{{% notice tip %}}
如果您已成功登入，可以選擇 fork 此 Fiddle，這意味著您可以製作程式的副本，以進行自己的更改並保存。點擊頂部的 "Fork" 按鈕。

<img src="./media/dotnetfiddle-fork.png" height="300" alt="Fork 一個 Fiddle 來創建程式副本" />

fork 之後，您將看到類似以下的視窗：

<img src="./media/guessTheWordActivity-fork.png" height="300" alt=".NET Fiddle 視窗" />

{{% /notice %}}

我們將忽略此畫面上的部分細節，但會介紹一些基本資訊。如果在 `main.cs` 文件中包含程式碼，這些程式碼或指令是供電腦執行的。而該程式碼的結果會顯示在右側，稱為 **控制台**。

現在如果您按下 **執行** 按鈕，您會發現什麼都沒有發生！您的任務是幫助 Nuvi 完成這個遊戲的程式碼！

任何位於 **活動** 部分的活動都將在此瀏覽器標籤中完成。您將自行完成這些活動，但當您困住時可以尋求幫助。
