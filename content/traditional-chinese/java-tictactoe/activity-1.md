在這個活動中，我們將創建一個程式，用來印出遊戲板和遊戲提示，如下面的輸出所示：

```
<<<~  井  字  棋  ~>>>
* 選擇數字 1 - 9 放置你的棋子
* 玩家: 'X' 電腦: 'O'

 1 | 2 | 3 
---+---+---
 4 | 5 | 6 
---+---+---
 7 | 8 | 9 
請輸入你的行動 (1-9): 2
 O | X |   
---+---+---
   |   |   
---+---+---
   |   |   
請輸入你的行動 (1-9): 
```

## 主類別與主方法

在起始程式碼中，我們有一個類別 `Main` 和方法 `main()`。程式會在我們點擊 `Run` 按鈕時，從 `main()` 方法開始執行。

```java
public class Main {
  public static void main(String[] args) {
  }
}
```

## print 陳述

在 `main()` 方法中，使用 print 陳述來輸出遊戲的歡迎語和規則！

```
<<<~  井  字  棋  ~>>>
* 選擇數字 1 - 9 放置你的行動
* 玩家: 'X' 電腦: 'O'
```

## 變數與陣列

在這個遊戲中，我們需要追蹤每個遊戲板上 9 個位置的符號狀態。

因此，我們需要在程式中儲存 9 筆資料。我們可以使用大小為 9 的陣列來儲存這些數據。

根據規則，遊戲板上的 `"X"` 表示玩家的行動，`"O"` 表示電腦的行動，而 `" "` 表示空位。

為了實現這一點，我們可以宣告一個名為 `board` 的陣列變數，初始值為 `" "` 的陣列元素（即 `{" ", " ", " ", " ", " ", " ", " ", " ", " "}`）。

## 顯示遊戲板

現在我們有了變數 `board` 來儲存遊戲板上的符號狀態，接下來嘗試使用 print 陳述來印出一個空的遊戲板（如下所示）。

注意每個遊戲板由五行組成，因此合理的做法是使用五個 print 陳述各自輸出遊戲板的每一行。

每一個 9 個方格都是長度 3 的字串，中央字符對應儲存在 `board` 陣列中的符號。

完成此步驟後，程式應該能輸出下方的結果。

```
<<<~  井  字  棋  ~>>>
* 選擇數字 1 - 9 放置你的行動
* 玩家: 'X' 電腦: 'O'

   |   |  
---+---+---
   |   |  
---+---+---
   |   | 
```

## 方法

由於我們將在整個遊戲過程中需要多次輸出遊戲板，因此最好將第四步編寫的程式區塊移動到一個方法中。

這個方法應該接受一個 `String[]` 作為輸入並印出當前的遊戲板。該方法應該寫在 `main()` 方法之外。

讓我們撰寫具有以下標頭的方法：

```java
public static void printBoard(String[] curBoard);
```

## 呼叫方法

在 `main()` 方法中呼叫 `printBoard()`，讓它列印具有標籤位置的初始遊戲板。您可以透過建立另一個 `String 陣列`，內容為 `"1", "2", ..., "9"` 來實現。

加入一行程式碼來印出 `請輸入你的行動 (1-9): `

```
<<<~  井  字  棋  ~>>>
* 選擇數字 1 - 9 放置你的行動
* 玩家: 'X' 電腦: 'O'

 1 | 2 | 3 
---+---+---
 4 | 5 | 6 
---+---+---
 7 | 8 | 9 
請輸入你的行動 (1-9): 
```
