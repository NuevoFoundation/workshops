## 讀取並處理輸入

在 Java 中，一種高效獲取使用者輸入的方法是使用 `java.util` 套件中的 `Scanner` 類別。為了使用此類別及其所有方法，我們需要在檔案頂部添加以下這行代碼進行 `import`。

```java
import java.util.Scanner;
```

## 錯誤處理

在 Java 中，我們可以通過將可能引發錯誤的代碼放在 `try-catch` 區塊中來處理潛在錯誤。

在 `try` 區塊中，放置可能引發錯誤的代碼。

在 `catch` 區塊中，放置當執行 `try` 區塊的代碼出現錯誤時的處理指令。這樣可以防止程式崩潰。
例如：

```java
try{
   // 嘗試的代碼區塊
} catch(Exception e){
   // 處理錯誤的代碼區塊
}
```

執行你的程式並輸入非數字的資料，現在你的程式應該不會崩潰了！

## Try 區塊

在 `try` 區塊中，我們接收使用者輸入的數字。然而，不是所有的輸入都是有效的，因為我們只應接受棋盤上的有效位置。

使用 if 語句檢查數字輸入是否有效。（提示：訪問 `board` 陣列以檢查輸入是否有效）。

如果無效，打印以下陳述：`位置無效；請重新輸入你的移動（1-9）: `。

## Catch 區塊

在 `catch` 區塊中，我們知道玩家輸入了非數字的內容。首先，我們需要通過刪除 `Scanner` 中的這個無效輸入來忽略它。我們通過在創建的 `Scanner` 對象上調用方法 `next()` 來做到這一點。之後，還應打印以下陳述通知玩家重新輸入一個移動：`位置無效；請重新輸入你的移動（1-9）: `。

通過點擊 `Run` 測試你的程式，你應該可以看到如果輸入了非數字內容或輸入的數字不在 1 到 9 之間，程式會顯示訊息：`位置無效；請重新輸入你的移動（1-9）: `。

## 多重輸入

現在我們有了一個接受單次輸入並評估是否有效的程式，我們希望玩家可以重複執行直到遊戲結束。

為了不斷提示使用者輸入下一步移動，我們將整個 `try-catch` 區塊放在一個 `while` 循環中。此 `while` 循環的條件為 `true`，意即程式將持續執行循環直到收到停止指令。

注意，我們在每次迴圈結束時調用 `printBoard(board)` 並提示玩家，如下所示：

```java
while(true){
    // 在此處插入 try-catch 區塊

    printBoard(board);
    System.out.print("Enter your move (1-9): "); 
}
```

## 處理無效輸入

當使用者輸入無效內容時，我們不希望程式調用 `printBoard(board)` 並打印 `Enter your move (1-9): `。

換句話說，我們希望程式執行 `while` 循環的下一次迴圈。

我們在代碼中加入 `continue;` 表示讓程式跳回去並從 `while` 循環的頂部再次執行。
