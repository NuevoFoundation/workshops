## 使用 Replit

今天您將使用 Replit 學習如何用 Java 編碼。在開始之前，如果您尚未註冊 Replit 帳戶，您需要先註冊。

點擊下面的按鈕註冊 Replit 帳戶——註冊需要一個電子郵件帳戶。如果您已經擁有 Replit 帳戶，可以使用下面的按鈕登錄您的帳戶。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">註冊 Replit</a>

<img src="../images/replit-signup.png" height="300" alt="Replit 註冊表單" />

接下來，點擊下面的按鈕啟動今天將使用的 Replit 控制台。您應該會看到如下的畫面。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaTicTacToeStarterCode" target="_blank">啟動 Replit</a>

<img src="../images/replit-start-screen.png" height="300" alt="Repl 起始畫面" />

現在我們將執行複製程式的操作，這簡單來說就是"Fork Repl"，以便我們可以自行修改它。點擊右上角的 "Fork Repl" 按鈕，然後點擊 "Fork Repl" 按鈕。

<img src="../images/replit-fork.png" height="300" alt="複製 Repl 程式" />

進行複製操作後，您會看到如下類似的窗口：

<img src="../images/replit-window.png" height="300" alt="Replit 窗口" />

{{% notice warning %}}
每次看到“啟動 Replit”按鈕時，您都需要按照上述步驟複製 Repl，才能完成活動。如果在複製 Repl 時遇到困難，就請尋求幫助吧！
{{%/notice %}}

{{% notice info %}}

在開始之前，讓我們先了解一下窗口的工作方式。`Main.java` 文件包含代碼，這些代碼是電腦執行的指令。按下 **運行** 按鈕，您即告訴電腦執行代碼中的指令。運行代碼的任何結果都將顯示在底部窗口的 **Console** 標籤下。

{{% /notice %}}

點擊`Run`按鈕旁邊標有`open in Replit`的圖標。這將是您為井字棋程式編寫代碼的窗口。祝您玩得愉快！
