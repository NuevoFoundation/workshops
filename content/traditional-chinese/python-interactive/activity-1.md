## 創建你的餐廳橫幅
在設定你的餐廳虛擬收銀系統時，我們首先要確保擁有一個包含餐廳名稱的橫幅。由於我們需要真正的橫幅，而不僅僅是名稱的純文字表達，我們可以使用 ASCII 藝術！ASCII 藝術使用特殊符號，例如 `()`, `{}`, `*` 和其他鍵組成圖像和文字。

在這項活動中，我們可以利用這個線上資源將文字轉換成 ASCII 藝術。

[文字轉 ASCII 藝術轉換器](https://onlineasciitools.com/convert-text-to-ascii-art)

舉例來說，我們可以將「Restaurant（餐廳）」這個單詞轉換為 ASCII 藝術。看看下方的代碼！

```python
print("    _   _   _   _   _   _   _   _   _   _  ")
print("   / \ / \ / \ / \ / \ / \ / \ / \ / \ / \ ")
print("  ( r | e | s | t | a | u | r | a | n | t )")   
print("   \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ ")
```

記得將此文件保持開啟狀態，因為我們會在之後的活動中回到這裡，每個活動都會基於前一個活動進一步建構。最後，整個餐廳的收銀系統都將在這份文件中設置完成。
