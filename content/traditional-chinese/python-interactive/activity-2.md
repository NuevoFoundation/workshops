## 如何建立和儲存你的菜單
現在我們已經為你的餐廳設計了一個橫幅，接下來讓我們考慮如何去組織你的菜品資訊。還記得之前你決定過要在餐廳賣哪些食物與飲料嗎？現在我們需要弄清楚如何儲存這些資訊。我們需要儲存每道菜的名稱、價格和描述。

為了做到這一點，我們可以使用 Python 的字典來追蹤這些資訊。

我們將建立一個字典，其中的值是列表！  
透過這種方式，我們可以同時獲得菜品的價格和描述。如果我們用列表或其他容器作為字典中的值，那麼就會產生一個**巢狀字典**。由於我們需要同時存儲價格和描述資訊，所以必須按照特定的順序在列表中存儲它們。

以下是我們將要使用的結構：
{item : [price, description]}  
當我們在建立**巢狀字典**時，確保遵循這一結構，可以保證日後存取價格和描述時更加簡單。

以下是範例巢狀字典，但請記住在建立你的菜單時要應用上面提到的結構！
```python
#結構
#{word:[meaning, partOfSpeech, pronounciation]}
smallDictionary = {'toy':['小孩玩耍的物品', '名詞', 'toi'], 'walk':['以慢速規律的步伐前進，一次抬起一隻腳，依序而行', '動詞', 'wok']}
```

回到之前的 `Replit` 連結，加入程式碼來將你的菜單儲存在名為 `dictMenu` 的變數中。請記住將 `dictMenu` 設為全域變數 —— 不要將它放在 `main()` 函數中，而是將它放在程式碼的頂部，這樣所有函數都可以存取它。  
提示：你的價格應該是 `float` 類型，而描述應該是 `string` 類型。
