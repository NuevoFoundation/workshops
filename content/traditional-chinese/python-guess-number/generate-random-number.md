Python 包含一個名為 `random` 的庫，能幫助您生成隨機數字。在程式的開頭寫上 `import random`，並使用 `randint` 函數，就可以在指定的範圍內生成一個數字。

以下的程式碼將生成一個介於 1 到 10 之間的隨機數字：
```python
    random.randint(1,10)
```
