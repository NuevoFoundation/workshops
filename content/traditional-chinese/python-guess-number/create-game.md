## 接收使用者輸入

這個遊戲將使用你在 Python 基礎部分學到的一些概念。
你需要了解如何使用以下概念。如果你對任何一個概念不熟悉，請回到相關部分進行複習。
- <a href="../../python-basics/conditional-statements-loops/loops/" target="_blank">While 迴圈</a>
- <a href="../../python-basics/basics/writing-to-console/" target="_blank">在控制台輸出文字</a>
- <a href="../../python-basics/basics/reading-from-console/" target="_blank">從控制台接收輸入</a>
- <a href="../../python-basics/conditional-statements-loops/conditional-statements/" target="_blank">條件判斷</a>
- <a href="/python-guess-number/random/" target="_blank">隨機數</a>

你需要編寫這個遊戲，使它能夠隨機生成一個數字。

接著，程式將不斷要求使用者在控制台輸入猜測值，並與程式隨機生成的數字進行比較。

做好重複任務的最佳方式是什麼？你猜對了，那就是使用迴圈！
你可以使用 `while` 迴圈來完成這項任務。

在 `while` 迴圈內，你可以使用條件判斷來檢查玩家是否猜對了。如果猜錯了，你可以提供一些有幫助的提示，讓他們知道應該嘗試猜更低還是更高。
