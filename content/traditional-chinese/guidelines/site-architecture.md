# 網站建置方式

工作坊子域的內容是使用 Hugo 的 [DocDock](https://docdock.netlify.com/) 主題所建置的。[Hugo](https://gohugo.io) 是一款具有多種優勢的靜態網站生成器：

1. **內容作者** 可以專注於使用 Markdown 編寫內容，而無需關注網站實現或 CSS/頁面樣式設計。工作坊內容會 *自動魔法般* 地添加到左側內容表及工作坊主頁。Hugo 在本地運作表現出色（例如：在飛機上），且是最快的靜態網站生成器，可在不到 2 秒內建置整個工作坊網站。  
2. **學生** 能享受到各個工作坊一致的使用者體驗，內建的無障礙功能、多語言支援、響應式設計（支持從手機到桌面設備）、自動鏈接至 GitHub 存儲庫，以及透過 Azure CDN提供的全球快速網站效能。  
3. **Nuevo 開發團隊** 能通過下列功能輕鬆建置及自定義工作坊頁面，包括自定義頁面範本、[內建頁面控制功能，例如警示、註解、按鈕、警告等](https://workshops.nuevofoundation.org/guidelines/formatting/)、自定義控制元件（例如：Nuevo 頁面標頭）、iframe 互動性、自定義元數據、自動跨頁鏈接、頁面主題化、自動生成網站地圖、內建圖示，以及利用 GitHub Actions 和 Azure DevOps 進行建置與部署的內建自動化功能。
