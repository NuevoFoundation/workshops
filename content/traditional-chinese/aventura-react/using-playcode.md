## 使用 Playground

我們將使用 PlayCode 工具來建立我們的第一個 React 專案。在這裡，你可以在線編輯程式碼。

首先，我們需要了解 PlayCode 或 Playground 的運作方式。你可以建立檔案和資料夾來組織你的程式碼。這是一個自動更新的程式碼編輯器，因此無論你寫什麼，都會即時更新而不需要重新整理。你可以實時看到你的進展。
