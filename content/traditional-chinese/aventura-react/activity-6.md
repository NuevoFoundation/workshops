### 下一步做什麼？

現在你已掌握 React 的基本原理，可以繼續探索：

- **新增旅程的停靠點：** 為哥斯達黎加的其他地點（例如 Manuel Antonio 國家公園或 Río Celeste）創建一個新組件。
- **改善設計：** 在你的 `style.css` 中嘗試使用新的顏色、動畫或圖片。
- **學習更多 React：** 前往 [官方 React 文檔](https://react.dev/learn)，探索像 `useEffect`、頁面導航，以及如何將你的應用程式發布到互聯網上的概念。
- **分享你的作品：** 向你的朋友和家人展示你的應用程式。你現在是一位 React 程式設計師了！
