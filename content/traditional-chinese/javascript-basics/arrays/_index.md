## 什麼是陣列？

陣列簡單來說就是一組值的集合。它是一種特殊的變數，可以同時存放多個值。

例如，考慮一個名為 fruits 的陣列，這個陣列中可以包含像蘋果、橘子、芒果等值，並且這些值全部集成在一個變數中。

## 如何建立一個陣列

以下的語句展示了創建陣列的兩種不同方式，但結果相同。

<b>語法：</b>
```javascript
var arrayName = new Array(element0, element1, ..., elementN);
var arrayName = Array(element0, element1, ..., elementN);
var arrayName = [element0, element1, ..., elementN];
```
