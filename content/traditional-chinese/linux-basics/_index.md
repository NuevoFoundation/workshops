**操作系統**（OS）是介於您與電腦硬體之間的一種軟體。每個電腦都必須至少有一個 OS 才能運行其他程式，比如您的瀏覽器！操作系統幫助您與電腦進行溝通，而不需要懂得如何使用電腦語言。

Microsoft Windows 是您可能最熟悉的家庭用操作系統。另一個常見的操作系統是 Apple 的 macOS。Linux 是另外一個操作系統！由於其多功能性，它受到開發人員的廣泛喜愛。有很多選擇可以使用，但今天我們將使用基於 Linux 的操作系統，名為 Kali Linux。這是一個深受安全專家和駭客喜愛的操作系統！

Windows、macOS 和 Linux 之間最大的區別在於它們最擅長的用途。Windows 是多媒體和遊戲的理想選擇！macOS 位於 Windows 和 Linux 之間。儘管它也擅長多媒體處理，但並不支持全部的遊戲。而 Linux通常更適合程序開發和主機伺服器。
