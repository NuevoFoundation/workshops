# 附錄

## 詳細解釋元件 

想像我們的電路像是一場戲劇。在正式演出之前，我們需要一個地方來練習。而此時，麵包板（Breadboard）便派上用場了。
+ 麵包板是一種簡單的平台，我們可以用它來建造臨時的電路，以進行測試和調試，這樣就可以在最終設計完成並永久焊接（接合）之前進行修正。
+ 麵包板讓我們能輕易地添加、移除或重新排列元件。下面左邊的圖像是一個麵包板的圖片。
+ 右側的圖片展示了插孔如何彼此連接。
+ 麵包板上，每一列編號（黃色部分）都有5個插孔。每一列的插孔（黃色線）彼此連通。
+ 右側的紅色線表示這些插孔之間的共同連接，藍色線則表示另一組插孔之間的共同連接。
+ 左側的紅色和藍色線也是一樣的。但是，右側和左側的紅色和藍色線並沒有彼此相連。
+ 插入到相同共同連接的元件在電路中就是相連的。

發光二極管（Light Emitting Diode，簡稱LED）是一種小型燈，當電流通過時就會點亮。

+ LED有兩個接腳：陽極（Anode）和陰極（Cathode）。
+ 陽極比陰極長，且始終接在較高的電壓上。
![替代文字：LED圖片](../img/LED.png)

電阻器是一小片陶瓷材料，用於減緩電流的流動。

+ 電阻器有兩個接腳，但它是無方向性的。換句話說，不論哪個接腳接到較高電壓都可以。
+ 大多數電子元件只能承受一定量的電流，否則會損壞。因此，電阻器保護我們的遊戲內其他元件，確保電流處於安全的低範圍。
