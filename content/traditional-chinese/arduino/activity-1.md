## 接線我們的閃爍 LED

在此系統的初次體驗中，我們將讓 LED 開啟與關閉。透過此操作我們可以掌握電路的基礎知識，以及如何使用程式來運行並控制元件。

![替代文字：LED 的接線圖](../img/act1_LED1.png)

1. 將 LED 的長腳（正極）連接到 25J 引腳，將短腳（負極）連接到藍色 [-] 線的任意位置。
2. 將一個 220 歐姆的電阻的一腳接到 25H，另一腳接到紅色 [+] 線的任意位置。
3. 使用杜邦線的一端接到面包板紅色 [+] 線中電阻所在的同一位置，另一端連接到 Elegoo 的 5V。
4. 使用另一根杜邦線的一端接到面包板的 31Z，另一端連接到 Elegoo 的 GND（接地）。
5. 通過 USB 將 Arduino 主板插入電腦，並打開 Arduino IDE 應用程序。

{{% notice info %}}
為接線使用顏色標示是非常常見且有幫助的！這裡我們使用紅色表示正電、黑色表示負電，但色彩實際並不重要，只要你能記住哪條線代表什麼即可。
{{% /notice %}}

## 開啟 LED 範例程式碼

6. 點擊 File -> Examples -> 01.Basics -> Blink

![替代文字：如何找到 Blink 範例程式碼的圖片](../img/Blink-sample-code.png)

7. 現在點擊上傳按鈕，將程序上傳至 Arduino。

{{% notice info %}}
額外提示：注意觀察 LED 開啟與關閉的時間間隔。你覺得應該修改程式中的哪一項來調整時間間隔？
如果你說是 delay(1000) 中的數字，那你答對了！
將該數字改成其他值（別忘了再次按上傳按鈕）。
是否看到變化了？你為什麼覺得 1000 代表 1 秒？那 10 分鐘會是多久呢？為什麼？
