[EarSketch](https://en.wikipedia.org/wiki/EarSketch) 是由喬治亞理工學院開發的一個免費教育編程環境。今天我們將使用 EarSketch 創作音樂。

1. 要創作音樂，請點擊以下按鈕以在新標籤頁中打開 Earsketch。

<a class="my-2 mx-4 btn btn-info" href="https://earsketch.gatech.edu/earsketch2/" target="_blank">啟動 Earsketch</a>

2. 打開網頁後，您可能會看到如下的歡迎畫面。請按下「skip」跳過導覽——我們接下來將一步步向您說明必要的操作步驟。

<img src="../img/screenshot-skip-tour.png" height="400"/>

3. 現在讓我們開始吧。點擊左側菜單欄上的 *Scripts* 圖標，然後選擇 *+ New Script*。

<img src="../img/screenshot-new-script.png" height="400"/>

4. 輸入 *myjam*（或您想使用的其他名稱）作為腳本的名稱，並將編程語言更改為 *JavaScript*。點擊 *Create* 按鈕來創建您的腳本（即放置代碼的文件）。

<img src="../img/screenshot-new-myjam.png" height="200"/>
 
5. 最後，點擊齒輪圖標，然後選擇「Blocks mode」。此時，您的畫面應該如下所示。

<img src="../img/screenshot-setup-complete.png" height="400"/>

## 教師推薦 - EarSketch 的概覽

在上課之前，請先瀏覽一下 EarSketch 的概覽。了解如何在用戶界面中進行切換是非常重要的。

螢幕左側的 `Content Manager` 是導航使用 EarSketch 的主頁基地。

1. 導航欄的第一項是 `Sounds` 集合。這是 Earsketch 中所有預載聲音的中心位置。在聲音瀏覽器中，您可以根據藝術家、類型或樂器來篩選出現的聲音。

<img src="../img/screenshot-navigation-sound-browser.png" height="400"/>

2. 導航欄的下一個圖標是 `Scripts` 面板。我們的代碼將在此編寫。

<img src="../img/screenshot-navigation-script.png" height="400"/>

3. 導航欄最後的圖標是 `API Browser` 面板。*應用程序編程接口* 或 *API* 是一組可以直接使用的代碼！點擊打開後，將提供每個 API 的詳細說明。

<img src="../img/screenshot-navigation-api-curriculum.png" height="400"/>

在右側，您可以看到 `Curriculum` 指南。如果您想了解更多關於 EarSketch 的資訊，可以點擊該部分，在窗口右側會顯示相關內容。在這次練習中，我們將跳過這部分。
