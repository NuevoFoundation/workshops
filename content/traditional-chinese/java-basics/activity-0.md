## 使用 Replit

今天你將使用 Replit 來學習如何用 Java 編寫程式。在開始之前，如果你還沒有 Replit 帳戶，則需要註冊一個帳戶。

點擊下方按鈕註冊 Replit 帳戶——你需要一個電子郵件帳號來註冊。如果你已經擁有 Replit 帳戶，也可以使用下方按鈕登錄。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">註冊 Replit</a>

<img src="../images/replit-signup.png" height="300" alt="Replit 註冊表單" />

接下來，點擊下方按鈕啟動今天將使用的 Replit 控制台。你應該會看到以下畫面。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaBasicsTest" target="_blank">啟動 Replit</a>

<img src="../images/replit-start-screen.png" height="300" alt="Repl 的起始畫面" />

我們現在將 Fork 這個 Repl，這表示我們會建立一個程式的副本，以便我們可以對其進行自己的修改。點擊右上方的 "Fork Repl" 按鈕，然後再次點擊 "Fork Repl" 按鈕。

<img src="../images/replit-fork.png" height="300" alt="Fork 一個 repl 並建立程式副本" />

Fork Replit 後，你將看到如下所示的視窗：

<img src="../images/replit-window.png" height="300" alt="Replit 視窗" />

{{% notice warning %}}
每次你看到 "啟動 Replit" 按鈕時，你需要按照上述步驟 Fork 該 Repl 來完成一個活動。如果在 Fork Repl 時遇到問題，請隨時尋求幫助！
{{%/notice %}}

在開始之前，我們先來了解這個視窗如何運作。`Main.java` 文件包含程式碼，也就是指示電腦執行的指令。按下 **run** 按鈕（在框架頂部中間的綠色帶三角形按鈕），你就可以指示電腦執行程式碼中的指令。執行程式碼的任何結果都會顯示在屏幕底部的 **Console** 標籤下。

在「物件與類別」練習中，你需要在 `Main.java` 文件和 `Birds.java` 文件之間切換。你可以點擊右側看起來像文件的圖標來完成這件事。這將打開文件菜單，並允許你訪問其他檔案。

嘗試按下 **run** 按鈕。如果你看到 **Let's learn Java!**，說明你已經準備好。我們開始吧！
