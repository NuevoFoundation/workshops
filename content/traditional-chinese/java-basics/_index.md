歡迎來到課程 <b>Java：基礎</b>，在這裡您將學習一種廣泛使用的高階程式語言，它能向電腦傳遞指令來創建令人興奮的程式！

Java 是一種高階程式語言，由詹姆斯·高斯林和 Sun Microsystems 於 1995 年在加州開發。

<img src="images/logo.png" height="150" alt="Java 標誌，一個冒著熱氣的咖啡杯，上面寫著 Java" />

{{% notice info %}}
高階程式語言之所以稱為高階，因為它與電腦中央處理器（CPU）執行的原始代碼有一定的距離。高階代碼是專為人類使用而設計，比低階代碼更容易理解。高階代碼會被翻譯成低階語言，而低階語言是特定 CPU 所能理解和執行的。為了讓代碼運行，每一行用高階語言編寫的代碼都必須在被電腦實施前翻譯成機器語言。
{{% /notice %}}

如今，Java 已被全球的開發者廣泛使用。Java 主要被用於開發 Android 行動應用程式、桌面應用程式、網頁應用程式，以及遊戲開發。

在這門課程中，我們將涵蓋此語言的所有基本功能。
