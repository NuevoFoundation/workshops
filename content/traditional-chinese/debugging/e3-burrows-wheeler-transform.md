Burrows-Wheeler 轉換 (BWT) 是一種用於數據壓縮的算法。它將一個字符串作為輸入，並輸出一個經過編碼的字符串，該字符串通常具有相似字符聚集在一起的特性。

## 理論

這個算法相對簡單且易於理解。

1. 獲取輸入字符串並提取其所有的旋轉變形。（見圖片）。
2. 將這些旋轉按字典順序升序排序。
3. 取排序後的變形的最後一列，這就是輸出。

![Burrows-Wheeler Transform](../resources/e3-01.png "Burrows-Wheeler 轉換的三個步驟")

在上圖中，我們使用字符串 `banana` 作為示例。`\0` 是一個符號，用於表示字符串的結束（類似於 C 語言中的空終止符字符），但字典順序上是**最大的**字符。

一種高效實現 BWT 的方法是使用一種稱為後綴數組（suffix array）的數據結構。為了創建後綴數組，我們首先取出輸入字符串的所有後綴，並給它們分配一個編號標籤。然後，我們按字典順序對這些後綴進行排序。

![Suffix Arrays](../resources/e3-02.png "創建後綴數組的步驟")

以 `Nuevo\0` 為範例，我們首先提取它的所有後綴並列出。然後按字典順序進行排序，其中 `\0` 作為空終止符字符，仍然是最大的字符。最後，我們取每個後綴第一個字母的索引，並將這些索引放入一個數組中。例如，`Nuevo\0` 中字母 `N` 的索引是 `0`，而 `e` 的索引是 `2`。由於它們在字母順序中最小，因此依次放入數組的第 0 和第 1 個位置。

我們可以將後綴看作是 Burrows-Wheeler 轉換中的旋轉！我們需要做的就是將原先“切掉”的**前綴**附加到字符串的末尾。因此，`evo\0` 變為 `evo\0Nu` 當我們想將後綴看作一個旋轉時。然後，如果我們對所有後綴執行這一操作，我們就能得到在 Burrows-Wheeler 轉換中需要的排序旋轉。

![Suffixes to Rotations](../resources/e3-03.png "用後綴生成 Burrows-Wheeler 轉換的排序旋轉的表格")

需要注意的一個關鍵點是，我們實際上不需要存儲這些旋轉，因為後綴數組中的索引已經包含了相關信息。如果 `suffix_array[i] == 0`，那麼我們知道正在查看的旋轉是 `Nuevo\0`。如果 `suffix_array[i] == 3`，那麼正在查看的旋轉是 `vo\0Nue`。可以理解為我們將字符串右移了 `N` 位，在 `suffix_array[i] == N` 的情況下。上圖已對此進行說明。

因此，基於此，我們可以通過將 `suffix_array[i]` 減去 1，然後對後綴數組的總長取模來獲取旋轉的最後一個字符，從而獲得任何給定字符串的 Burrows-Wheeler 轉換。

## 實現

我們的實現策略是使用上述步驟：構建一個後綴數組，然後取索引，減去 1，再對字符串的長度（包括空終止符）執行模運算。

我們已經實現了後綴數組的功能，並且使用它實現了 Burrows-Wheeler 轉換。不過，由於編寫代碼時很疲倦，我們遺漏了一些錯誤。這個練習會比較棘手，因為它涉及到很多索引操作以及如何巧妙地使用這些索引。作為修復錯誤的提示，大部分錯誤集中在後綴數組的構建以及如何使用它。

{{% notice tip %}}
空終止符字符可能會影響打印字符串的方式。在本練習中，你需要逐字符打印出轉換後的字符串，因為空終止符會導致 `printf` 函數在遇到它後停止輸出。以下代碼將打印出調用 `bwt(dest, src)` 的結果，其中 `STR_LEN` 是字符串的靜態長度，**包括空終止符**。
```c
for(int i = 0; i < STR_LEN; ++i) {
    printf("%c", dest[i]);
}
```
注意，`strlen()` 返回字符串的長度，不包括空終止符。

最後一個提示：在 C 語言中，`%` **不是**模運算符！它是餘數運算符。這可能是導致某些索引出錯的原因……
{{% /notice %}}
