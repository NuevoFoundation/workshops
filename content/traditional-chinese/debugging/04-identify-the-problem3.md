## 除錯工具

程式碼除錯是一個非常普遍的常見問題，因此人們設計了專門幫助其他程式設計師更有效地進行除錯的程式。這些工具適當地被稱為 **除錯器 (debuggers)**，而且有很多能夠與 C 程式語言一起使用的除錯器。我們來看看 `gdb`，這是一種常用於命令列的除錯工具。

在我們的範例中，我們將使用 <a href="https://www.youtube.com/watch?v=SLauY6PpjW4" target="_blank">快速排序法 (Quicksort)</a>。

**快速排序法 (Quicksort)** 是一種排序資料陣列的演算法，首先在陣列中選擇一個元素作為 `樞軸 (pivot)`。

接下來，根據以下條件對元素進行排列：
- 低於樞軸的元素。
- 高於樞軸的元素。

排序完成後，相同的過程將使用樞軸作為中點，遞迴地應用於陣列的上下部分。

{{% notice note %}}
我們的快速排序法版本假設最左邊的元素為 "較大" 的元素，而分區內最右邊的元素作為樞軸。
{{% /notice %}}

[GDB (GNU 專案除錯器)](https://sourceware.org/gdb/) 是一種強大的除錯工具，允許你從命令列除錯程式。這在你無法使用圖形化使用者介面 (Graphical User Interface, GUI) 時特別有用。

了解程式的運作方式對於有效的除錯非常重要。我們的 'quicksort' 實現會透過遞迴方式執行快速排序，並在當前元素小於樞軸的條件下進行排序。另外，我們假設第一個元素為 "較大" 的元素。排序本身發生在 `partition` 函數中。

### 使用 GDB 進行除錯的步驟
#### 編譯程式
1. 打開 **Shell** 標籤並編譯程式：

```bash
make Quicksort
```

{{% notice note %}}
當程式被編譯時，會使用旗標：`-g` 和 `-Og`。第一個旗標告訴編譯器添加 **除錯資訊**，這意味著如果沒有此旗標，gdb 將無法除錯程式。第二個旗標告訴編譯器以不會影響程式執行結構的方式進行優化。沒有 `-Og` 的話，編譯器可能會將部分程式碼優化掉，因此除錯器的效果將大打折扣。

重要的是要記住第二個旗標。進行除錯時，應該 **始終** 確保編譯器對程式碼進行最小化優化，因為優化可能會大幅改變程式碼的執行方式！
{{% /notice %}}

#### 執行程式 
1. 輸入指令 `gdb examples/Quicksort`。這將開啟 GDB 的命令列介面。若要使用 `gdb` 除錯程式，可以使用 `gdb <程式名稱>`。

2. 確保 GDB 表示其正在 `Reading symbols from ./examples/Quicksort...`，不然的話你就沒有將程式附加到 GDB。

3. 你可以輸入指令 `quit` (或其任何縮寫：例如 `q` 也可以使用) 來退出 GDB，就像正常的 Shell 命令列一樣。

#### 除錯程式

為了除錯程式，我們需要從 GDB 中執行它。

1. 輸入指令 `run` (或 `r`)。這會執行程式，就像你從普通命令列運行它一樣。
```bash
(gdb) run
```

程式首先會列印出待排序的陣列內容：一個無序數字的陣列。接下來，會執行排序演算法，最後列印排好序的陣列。你可以看到陣列在排序過程中的變化！

然而，似乎排序並沒有按照預期進行。

接下來，我們使用除錯工具提供的最重要的功能之一：**斷點**。斷點指示除錯器在程式執行時，當到達具體的那行程式碼時暫停執行。這樣可以讓你即時檢查程式內部的執行情況。注意，除錯器不會執行斷點所在的那行程式碼，直到你繼續執行程式。

首先讓我們來確定所有數據排序的地方。你知道排序是在哪裡進行的嗎？
{{% expand "***解答***" %}}
排序發生在 `for` 迴圈內以及當樞軸與 "較大" 的元素交換時。
{{% /expand %}}
