布林值（Boolean）是表示真或假的陳述。不同於字串或數字，布林值儲存的是真假陳述：我所說的話是真還是假？例如，如果我問「你是一個機器人嗎？」，這個問題會產生一個真或假（true 或 false）的結果，這就是布林值。在這個例子中，因為你不是機器人（希望如此！），我們會產生 `false`。我們還可以使用數學運算符來創建布林表達式。以下是一些範例；然而，留意「等於」與「不等於」的特殊符號：

| 運算符   | 描述                   | 運算符   | 描述                         |
| -------- | --------------------- | -------- | ---------------------------- |
| `<`      | 小於                  | `>`      | 大於                        |
| `<=`     | 小於或等於            | `>=`     | 大於或等於                  |
| `==`     | 等於                  | `!=`     | 不等於                      |

如同往常，使用 `System.out.println` 來輸出您的結果：

```kotlin
System.out.println(10 < 8);
System.out.println((3 * 6) == (32 - 14));
```

## 一起練習

刪除程式碼中所有的 `System.out.println` 文本。嘗試猜測以下表達式的答案。使用 `System.out.println` 來檢查您的答案。

- 54 < (10 + 32)
- (37 / 5) == 7
- "Hello" + "World" == "Hello World"
- false == false

## 布林運算符

您還可以使用 `&&` （且）與 `||` （或）運算符將布林表達式聯接起來。例如，假設我問：「你是人類，並且 Nuvi 是機器人嗎？」這句話中的「和（and）」將兩個真假問題聯繫在一起。在這種情況下，因為你是人類是正確的，並且 Nuvi 是機器人也是正確的，因此整個結果是 `true`。以下是一個描述這些運算的表格：  

| 表達式                         | 結果      | 表達式                                   | 結果      |
| --------------------------- | -------- | ------------------------------------- | --------- |
| <code>true && true</code>   | `true`   | <code>true &#124;&#124; true</code>   | `true`    |
| <code>true && false</code>  | `false`  | <code>true &#124;&#124; false</code>  | `true`    |
| <code>false && true</code>  | `false`  | <code>false &#124;&#124; true</code>  | `true`    |
| <code>false && false</code> | `false`  | <code>false &#124;&#124; false</code> | `false`   | 

總結來說，`&&` 需要兩個布林表達式都為真，`||` 則只需要其中一個布林表達式為真。以下是更多範例：

- `(5 < 8) && (9 != 10)` 產生 `true`，因為 5 小於 8 且 9 不等於 10。
- `(6 != 2 * 3) || (8 < 2 * 4)` 產生 `false`，因為 6 不等於 2 * 3 和 8 不小於 2 * 4 兩者皆為 `false`。
