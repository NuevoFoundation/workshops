## 放置文字

現在，您將學習如何在 Phaser 中放置物件。請參考以下的 repl。

首先，讓我們看看如何放置文字！

```javascript
message = this.add.text(20, 10, "Hello World!", {
	font: "25px Arial",
	fill: "white"
});
```

這些程式碼建立了一個名為 "message" 的變數。這個變數將文字 "Hello World" 添加到我們遊戲畫面上的 (X, Y) 座標 (20, 10)。程式碼還指定了文字的顏色為白色，字體為 Arial，字體大小為 25 px。

將這行程式碼放入頁面底部的 `create()` 方法中，看看它是否出現在您的遊戲畫面中。

{{% notice note %}}

1. 在建立文字時，變數名稱並不是顯示在螢幕上的文字內容，而是以引號括起來的文字內容。
2. 這種語法也可以用來放置存儲在字串變數中的文字。

{{% /notice %}}

{{% notice warning %}}

### 幫助！我的遊戲視窗很小！

別擔心，其實遊戲視窗相對較大，但 repl 預設將其最小化。您可以通過拖動視窗之間的分隔條來擴展您的視圖。

{{% /notice %}}

## 放置背景

文字非常簡單，但當我們想在遊戲中使用自訂的圖像（幾乎總是如此）時，我們必須在 `preload()` 中先載入圖像，然後再在 `create()` 中指定其位置。

讓我們從建立背景開始。將此程式碼放入您的 `preload()` 方法中。

```javascript
this.load.image('background', 'assets/sky.png');
```

這個程式碼只是將圖像載入遊戲中。接下來，我們使用 `create()` 將這個圖像添加到遊戲中：

```javascript
this.add.image(400, 300, 'sky');
```

這行程式碼只是在座標 (400, 300) 放置圖像。試試看，看看黑色畫面是否被替換成背景！

{{% notice note %}}

座標 (400, 300) 指的是我們放置圖像中心像素的位置。這意味着 (400, 300) 是圖像的中心。我們將圖像放在這裡，以使它覆蓋整個畫面，就像背景一樣。

{{% /notice %}}

## 放置角色

接著，讓我們把角色放入我們的世界中。

`preload()` 函數中需要添加如下程式碼：

```javascript
this.load.spritesheet('dude', 'assets/dude.png', {
    frameWidth: 32,
    frameHeight: 48
});
```

由於這是一個精靈表（spritesheet），所以需要更多的語法。精靈表看起來像這樣：  
![dude](../media/example-dude.png)  
這是我們角色的精靈表。精靈表是單一角色或物件在多個位置的精靈集合。當按順序播放時，這些圖像將為我們的遊戲創建動畫（我們將在下一課中更詳細地描述這一點）。儘管對我們來說很明顯這是一系列相同角色的圖像，但電腦無法輕易地自行檢測出這一點。因此，我們需要更多語法來告訴電腦此精靈表中每個角色精靈的大小（在這裡為 32x48）。

在 `create()` 中放置這個精靈表的語法與圖像幾乎相同，但需要加上一個物理標籤：

```javascript
dude = this.physics.add.sprite(250, 200, 'dude');
```

這行程式碼建立了一個名為 "dude" 的變數，該變數將精靈表中的第一個圖像添加到座標 (250, 200)。我們還為這個精靈起名為 "dude"。

在這行程式碼中，`dude` 是我們創建的一個變數名稱。250 和 200 是我們放置精靈的 X 和 Y 座標，因此它將被放置在螢幕上的座標 (250, 200)。"dude" 是我們精靈的名稱，但在本節課中並不會用到它。

試著加入這個角色！您是否在螢幕上看到角色了？

{{% notice note %}}

1. 想要看到角色，`create()` 中的 `dude` 變數必須在背景之後建立。這是因為電腦從上到下讀取程式碼，因此如果角色是在背景之前放置，電腦會將背景放在角色之上，遮住角色，導致使用者無法看見。
2. 該角色應該是面向左側的，因為在初始放置時，精靈表中的精靈將總是顯示第一幀的圖像，而我們的角色在精靈表中的第一幀就是面向左側。

{{% /notice %}}
