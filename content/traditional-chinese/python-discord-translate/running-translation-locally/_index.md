Nuvi 的機器人可以回應，但它尚未能幫助朋友們之間互相理解。在本節中，你將安裝一個可以在你的電腦上**本地執行**翻譯的程式——不需要任何外部帳戶——使得機器人能夠成為 Nuvi 想像中的多語言橋樑。

你可以用於以下用途：
- 手動測試 `/translate` 指令
- 檢測訊息是英文還是西班牙文（`/detect` 端點）
- 自動為註冊用戶翻譯訊息（`/translate` 端點）

現在讓我們來設置翻譯引擎，以便機器人可以連接它。

---

## 1. 什麼是 LibreTranslate？
LibreTranslate 是一個免費且開源的翻譯程式（由社群開發），可以在本地運行。無需註冊帳戶，無需雲端訂閱。你輸入一種語言的文本，它返回另一種語言的文本。

為什麼這對本次工作坊有幫助：
- 隱私：你的文本保留在你的電腦上。
- 控制：你可以選擇語言並決定何時更新。
- 離線使用：下載語言數據後，它可以不接入網路地工作。
- 開源：你可以查看它如何運作，甚至參與改進。

你可以將它視為一個微型的本地網站，並且具有一個 **API**，你的機器人可以用來完成以下兩件事：
1. 檢測訊息的語言是什麼（`/detect`）
2. 將訊息翻譯成另一種語言（`/translate`）

這將驅動後續的自動翻譯功能。

### 什麼是 API？
API 就像是一個程式的菜單。它列出了可以調用的「端點」（URL）以及你能得到的結果。當你訪問 `http://127.0.0.1:5000/translate`，並提供正確的數據時，LibreTranslate 的 API 將回應已翻譯的文本。你的機器人將會**發送請求**（你的文本 + 語言選擇），並**接收回應**（翻譯後的文本）——就像點餐並收到一盤菜。
