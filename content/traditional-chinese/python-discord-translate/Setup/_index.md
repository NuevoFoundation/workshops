Nuvi 剛剛開設了一個全新的全球 Discord 中樞，來自不同國家的朋友們正陸續加入——但早期的聊天已經開始分裂成語言區隔。在你幫助 Nuvi 建立能連結大家的翻譯機器人之前，你需要一個可靠的地方來撰寫和執行程式。在本章節中，你將為開發一個具有翻譯功能的 Discord 機器人準備開發環境。你將安裝必要的工具，建立或選取一個 Python 執行環境，並組織一個乾淨的專案資料夾，以確保機密性和模組化的程式碼。把這看作是在組裝翻譯零件之前，先搭建好機器人工場。

我們將重點放在：
- 先決條件（Python 版本、pip、虛擬環境）
- 安裝核心依賴項（函式庫）
- 專案資料夾結構基礎
