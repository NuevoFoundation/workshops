Eine Antriebswelle wird bei einem fahrenden Auto zwei Arten von Belastungen erfahren: Drehmoment und Moment. Drehmoment ist ein Maß für die Kraft, die ein Objekt um seine Achse rotieren lassen kann.

[insert image]
Diese Rotationskraft stammt vom Motor, und die Antriebswelle überträgt sie auf die Räder. Ein höheres Drehmoment ermöglicht es dem Auto, viel schneller zu beschleunigen. Dieser Bereich kann irgendwo zwischen 0 und 10.000 liegen. Die Werte stammen von tatsächlichen Drehmomenten von echten Autos. Wählen Sie jedoch gerne eines der folgenden Werte als geeignetes Minimum und Maximum für das Drehmoment aus: 0, 1000, 2000, 3000, 4000, 5000, 6000, 7000, 8000, 9000, 10.000.

[insert image]

Antriebswellen erfahren auch Biegungen, durch die die Welle nach oben oder nach innen durch Kräfte gebogen wird. Diese Kräfte wirken sich ebenfalls auf die Leistung der Welle aus. Wählen Sie auch gerne einen Bereich zwischen 0 und 10.000 aus, genau wie beim Drehmoment.
