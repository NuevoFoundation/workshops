## Einführung in MATLAB

MATLAB ist eine äußerst nützliche Programmiersprache für Ingenieure. In dieser Aktivität können die Studierenden alle Schritte des Designprozesses in MATLAB einbinden, um schnelle und organisierte Lösungen für ihre Probleme zu finden. Die Lösung wird der im Programm berechnete Mindestdurchmesser sein.  
Erinnern Sie sich daran, dass der Designprozess eine Abfolge von Schritten zur Erreichung einer Lösung ist. Dieser Prozess spiegelt die Aufgabe der Studierenden wider, eine Antriebswelle zu entwerfen. Dies soll die Studierenden darüber informieren, dass der Designprozess für jedes Designprojekt nützlich ist. Der Vorteil der Nutzung von Programmierung besteht darin, dass Studierende mit nur wenigen Klicks am Computer eine Lösung für ihr Problem erhalten können und den Prozess so oft wiederholen können, wie sie möchten. Dies ist eine viel praktischere Methode im Vergleich zur manuellen Durchführung derselben Aufgaben, die mehr Zeit in Anspruch nehmen und fehleranfällig sein kann.
