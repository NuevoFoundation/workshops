Erinnern wir uns daran, dass die Hauptstruktur jedes Codes darin besteht, eine Reihe von Schritten zu befolgen, um eine Lösung zu finden. Unsere Schritte umfassen das Eingeben bestimmter Zahlenwerte, das Auswählen einer Option aus einer gegebenen Anzahl von Möglichkeiten usw. Jede Entscheidung, die Sie für jeden Schritt treffen, wird am Ende des Codes signifikante Ergebnisse haben. Jeder Schritt wird in eine Berechnung einbezogen, die dann den Durchmesser basierend auf Ihren Entscheidungen ausgibt. Außerdem besteht unsere Lösung darin, einen Durchmesser für unsere Antriebswelle zu ermitteln und anschließend zu überprüfen, ob unsere Durchmessergröße eine gute Designwahl ist.

Es gibt bereits einen bereitgestellten Code für Sie, und Ihre Hauptaufgabe besteht darin, diesen Code als Werkzeug zu behandeln, mit dem Sie den Durchmesser Ihrer Antriebswelle basierend auf allen von Ihnen getroffenen Entscheidungen bestimmen können. Die Entscheidungen sind in 5 Hauptschritte unterteilt.

1)	Faktor der Sicherheit eingeben  
2)	Ein Material für Ihre Antriebswelle auswählen  
3)	Die Bedingungen für Ihre Welle auswählen  
4)	Die Belastung eingeben, die Ihre Welle erfahren wird  
5)	Die Geometrie Ihrer Welle auswählen  

Keine Sorge, all diese Schritte werden im nächsten Abschnitt erklärt.
