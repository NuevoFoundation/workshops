## Einführung

Das Ziel der heutigen Aktivität ist es, C#-Fähigkeiten zu erlernen und dein neu gewonnenes Wissen zu nutzen, um ein Worterrate-Spiel zu erstellen! Lass uns das Spiel einrichten.

Heute wirst du .NET Fiddle verwenden, ein Online-Tool, das dir hilft, C#-Code zu lernen, zu erstellen und auszuführen.

{{% notice tip %}}
Bevor du beginnst, kannst du dich bei .NET Fiddle anmelden, falls du noch kein Konto hast, und später deine Arbeit speichern möchtest.

Klicke auf den untenstehenden Button, um dich bei .NET Fiddle anzumelden – du benötigst eine E-Mail-Adresse, um dich anzumelden. Wenn du schon ein .NET Fiddle-Konto hast, kannst du dich über den untenstehenden Button in dein Konto einloggen.

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/SignUp" target="_blank">Melde dich bei .NET Fiddle an</a>

<img src="./media/dotnetfiddle-signup.png" height="300" alt=".NET Fiddle Anmeldeformular" />

{{% /notice %}}

Als nächstes starte die Konsole von .NET Fiddle, die wir heute verwenden werden, indem du auf den untenstehenden Button klickst. Du solltest den folgenden Bildschirm sehen.

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/lMl7j4" target="_blank">Starte .Net Fiddle</a>

<img src="./media/guessTheWordActivity-start.png" height="300" alt="Der Startbildschirm eines Fiddles" />

{{% notice tip %}}
Wenn du eingeloggt bist, kannst du das Fiddle „forken“, was einfach bedeutet, dass du eine Kopie des Programms erstellst, um deine eigenen Änderungen vorzunehmen und sie zu speichern. Klicke oben auf die Schaltfläche „Fork“.

<img src="./media/dotnetfiddle-fork.png" height="300" alt="Ein Fiddle forken, um eine Kopie des Programms zu erstellen" />

Nachdem du das Fiddle geforkt hast, siehst du ein Fenster, das dem untenstehenden ähnelt:

<img src="./media/guessTheWordActivity-fork.png" height="300" alt=".Net Fiddle Fenster" />

{{% /notice %}}

Wir werden einige der Details auf diesem Bildschirm ignorieren, aber wir werden einige der Grundlagen durchgehen, die erscheinen. Die Datei `main.cs` enthält Code oder Anweisungen, die der Computer ausführen soll. Durch Drücken der **Run**-Schaltfläche sagst du dem Computer, dass er die Anweisungen im Code ausführen soll. Alle Ergebnisse der Codeausführung werden auf der rechten Seite angezeigt, der sogenannten **Konsole**.

Wenn du jetzt **Run** drückst, siehst du, dass nichts passiert! Deine Aufgabe ist es, Nuvi dabei zu helfen, den Code für dieses Spiel zu vervollständigen!

Alle Aktivitäten unter den Abschnitten **Aktivität** werden in diesem Browser-Tab durchgeführt. Du wirst diese Aktivitäten eigenständig durchführen, aber Hilfe ist verfügbar, wenn du feststeckst.
