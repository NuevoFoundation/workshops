## Verwendung von Replit

Heute wirst du Replit verwenden, um zu lernen, wie man in Java programmiert. Bevor du beginnst, musst du ein Replit-Konto erstellen, falls du noch keins hast. 

Klicke auf die Schaltfläche unten, um ein Replit-Konto zu erstellen – du benötigst eine E-Mail-Adresse, um dich registrieren zu können. Falls du bereits ein Replit-Konto hast, kannst du dich über die untenstehende Schaltfläche bei deinem Konto anmelden.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Registriere dich bei Replit</a>

<img src="../images/replit-signup.png" height="300" alt="Replit Registrierungsformular" />

Als Nächstes starte die Replit-Konsole, die wir heute verwenden werden, indem du auf die untenstehende Schaltfläche klickst. Du solltest den unten gezeigten Bildschirm sehen.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaTicTacToeStarterCode" target="_blank">Starte Replit</a>

<img src="../images/replit-start-screen.png" height="300" alt="Der Startbildschirm eines Repls" />

Wir werden nun das Repl forken, was einfach bedeutet, eine Kopie des Programms zu erstellen, damit wir daran Änderungen vornehmen können. Klicke auf die Schaltfläche "Fork Repl" oben rechts und dann auf die Schaltfläche "Fork Repl".

<img src="../images/replit-fork.png" height="300" alt="Ein Repl forken, um eine Kopie des Programms zu erstellen" />

Nach dem Forken des Replits wirst du ein Fenster sehen, das ähnlich wie das unten gezeigte aussieht:

<img src="../images/replit-window.png" height="300" alt="Replit-Fenster" />

{{% notice warning %}}
Jedes Mal, wenn du den "Starte Replit"-Button siehst, musst du die oben beschriebenen Schritte befolgen, um das Repl zu forken, damit du die Aktivität abschließen kannst. Bitte frage nach Hilfe, wenn du Schwierigkeiten beim Forken der Repls hast!
{{%/notice %}}

{{% notice info %}}

Bevor wir starten, lass uns zunächst verstehen, wie das Fenster funktioniert. Die Datei `Main.java` enthält Code oder Anweisungen, die der Computer ausführen soll. Indem du die **Run**-Schaltfläche drückst, sagst du dem Computer, die Anweisungen im Code auszuführen. Alle Ergebnisse des ausgeführten Codes werden auf dem unteren Bildschirm unter dem Tab **Console** angezeigt. 

{{% /notice %}}

Klicke auf das Symbol neben der `Run`-Schaltfläche, das `open in Replit` sagt. Dies wird das Fenster sein, in dem du den gesamten Code für das TicTacToe-Programm schreiben wirst. Viel Spaß!
