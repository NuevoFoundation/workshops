## Benutzereingaben akzeptieren

Dieses Spiel wird einige der Konzepte verwenden, die du im Abschnitt "Python Grundlagen" gelernt hast.  
Du musst wissen, wie man die folgenden Konzepte verwendet. Wenn du bei einem dieser Konzepte unsicher bist, gehe bitte zurück und wiederhole sie.
- <a href="../../python-basics/conditional-statements-loops/loops/" target="_blank">While-Schleifen</a>
- <a href="../../python-basics/basics/writing-to-console/" target="_blank">In die Konsole schreiben</a>
- <a href="../../python-basics/basics/reading-from-console/" target="_blank">Aus der Konsole lesen</a>
- <a href="../../python-basics/conditional-statements-loops/conditional-statements/" target="_blank">Bedingte Anweisungen</a>
- <a href="/python-guess-number/random/" target="_blank">Zufallszahlen</a>

Du musst dieses Spiel so programmieren, dass es zufällig eine Zahl generiert.

Anschließend wird das Programm wiederholt den Benutzer nach einer Eingabe in der Konsole fragen, und du musst diese Eingabe mit der zufällig generierten Zahl vergleichen.

Was ist der beste Weg, um wiederholte Aufgaben auszuführen? Genau, Schleifen!  
Du kannst eine `while`-Schleife verwenden, um diese Aufgabe zu erledigen.

Innerhalb der `while`-Schleife kannst du mit bedingten Anweisungen überprüfen, ob der Spieler richtig geraten hat. Wenn nicht, kannst du ihm hilfreiche Hinweise geben, ob er niedriger oder höher raten sollte.
