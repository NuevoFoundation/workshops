Python beinhaltet eine Bibliothek namens `random`, die dir hilft, Zufallszahlen zu generieren. Du kannst sie in deinem Programm verwenden, indem du `import random` an den Anfang deines Programms schreibst und die Funktion `randint` benutzt, um eine Zahl in einem bestimmten Bereich zu generieren.

Dies würde eine Zufallszahl zwischen 1 und 10 erzeugen.
```python
    random.randint(1,10)
```

Versuche, den untenstehenden Code ein paar Mal auszuführen und sieh, was du erhältst!
