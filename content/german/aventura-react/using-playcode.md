## Den Playground Verwenden

Wir werden das Tool PlayCode verwenden, um unser erstes Projekt mit React zu erstellen. Hier kannst du Code online bearbeiten.

Zuerst müssen wir wissen, wie PlayCode oder der Playground funktioniert. Du kannst Dateien und Ordner erstellen, um deinen Code zu organisieren. Es ist ein Code-Editor, der sich automatisch aktualisiert, sodass alles, was du schreibst, ohne manuelles Neuladen aktualisiert wird. Du kannst deinen Fortschritt in Echtzeit sehen.
