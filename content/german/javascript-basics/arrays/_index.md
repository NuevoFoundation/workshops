## Was ist ein Array? 

Ein Array ist einfach eine Sammlung von Werten. Es ist eine spezielle Variable, die mehr als einen Wert gleichzeitig speichern kann.  

Zum Beispiel kann man sich ein Array namens fruits vorstellen, das Werte wie Apfel, Orange, Mango etc. enthält – alle zusammen in einer einzelnen Variablen.  

## Wie erstellt man ein Array?

Die folgenden Anweisungen zeigen, wie man Arrays auf zwei verschiedene Weisen erstellen kann, wobei das Endergebnis dasselbe bleibt.

<b>Syntax:</b>
```javascript
var arrayName = new Array(element0, element1, ..., elementN);
var arrayName = Array(element0, element1, ..., elementN);
var arrayName = [element0, element1, ..., elementN];
```
