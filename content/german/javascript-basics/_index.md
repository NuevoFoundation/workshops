## JavaScript Grundlagen
 Hallo! Wenn du dies liest, bedeutet das hoffentlich, dass du JavaScript lernen möchtest 😁🥳. Egal, ob es dein erstes Mal ist, dass du programmierst, oder ob du schnell eine neue Sprache lernen möchtest – du bist hier genau richtig! Mach dich bereit, die Macht des Programmierens zu entdecken und Spaß dabei zu haben. 

## Was ist Code?

Wir können nicht lernen zu programmieren, ohne zuerst zu verstehen, was Code eigentlich ist. Denk an deine Lieblingswebsite. Wenn dir keine einfällt, nehmen wir NuevoFoundation.org. Als Benutzer musst du nur die Webadresse in deinem Browser eingeben und bevor du dich versiehst – tada! – erscheint die Website mit all ihren schönen Farben und Bildern von Nuvi. 

Einfach, oder? Nicht ganz. Hinter dieser scheinbar einfachen Interaktion stecken Hunderte – wenn nicht Tausende! – Zeilen Code, die alles zum Funktionieren bringen. Lass uns nur einen Schritt dieser Interaktion betrachten: die Suche und den Zugang zur Nuevo Foundation-Website. Es gibt Milliarden von Websites (1,7 Milliarden, das letzte Mal, als ich nachgesehen habe), wie schafft es dein Browser so schnell, die gewünschte Website zu finden? Denk kurz darüber nach...

Es gibt Leute, die das programmiert haben, und Leute, die deinen Browser programmiert haben, und die Nuvi-Website, und dieses Lehrmaterial, das du gerade liest, und ... na ja, du verstehst schon. Code ist die Art und Weise, wie wir Menschen Dinge wie Websites, Apps und Spiele entwerfen und bauen. Es ist die Sprache, mit der wir Computern sagen, was sie tun sollen. 

## Was ist JavaScript und wofür wird es verwendet?

Genauso wie es viele menschliche Sprachen gibt, gibt es auch viele Programmiersprachen. Vielleicht hast du schon von einigen gehört, wie Python oder Java. Jede Programmiersprache hat ihre Stärken und Einsatzmöglichkeiten – zum Beispiel wird CSS für die Gestaltung von Websites verwendet, Python eignet sich hervorragend für Datenwissenschaft und so weiter.

JavaScript wird manchmal als die "Sprache des Webs" bezeichnet. So ziemlich jede Website, die dir einfällt, verwendet JavaScript in irgendeiner Form. JavaScript ist besonders gut darin, das Verhalten von Websites zu steuern, beispielsweise was passiert, wenn du auf einen Button klickst oder Daten zwischen Seiten überträgst.

Das Gute daran ist, dass du, sobald du eine Sprache gelernt hast, eine andere ziemlich schnell lernen kannst, da die Grundlagen oft gleich bleiben. 

## Einrichtung der Umgebung

Umgebung? Ich dachte, das sei ein Programmierworkshop? 

"Umgebung" ist einfach, wie Programmierer ihre Umgebung für das Programmieren nennen. Du weißt, wie du Dinge wie Microsoft Word oder Google Docs benutzt, um Essays zu schreiben? Das kannst du als deine "Essay-schreiben"-Umgebung betrachten. 

Für Programmierer gibt es Anwendungen, die IDEs genannt werden, was für Integrated Development Environment steht. Das sind die Arten von Anwendungen, mit denen wir Code schreiben und ausführen können.

Für diesen Workshop werden wir playcode.io verwenden.

Sobald du playcode.io geöffnet hast, musst du ein paar Schritte ausführen, bevor wir starten können:
* Schließe alle Dateien oben links, außer __script.js__.
* Lösche alles im __script.js__-Datei.
* Schalte __live__ aus, indem du einmal auf die __live__-Schaltfläche oben rechts klickst.

Wenn du alle oben genannten Schritte korrekt ausgeführt hast, sollte dein Bildschirm so aussehen:
