# Python-Grundlagen

Um Musik zu programmieren, müssen wir ein wenig Python lernen. Keine Sorge, es wird dich nicht beißen. Python ist eine der Sprachen, die wir Menschen verwenden, um Computern mitzuteilen, was sie tun sollen. Diese Sprachen werden als "Programmiersprachen" bezeichnet. Wir werden Python-Konzepte im Laufe des Kurses lernen, aber starten wir mit einer einfachen Print-Anweisung.
