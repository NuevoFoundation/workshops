[EarSketch](https://en.wikipedia.org/wiki/EarSketch) ist eine kostenlose Bildungsprogrammierumgebung, die am Georgia Institute of Technology entwickelt wurde. Heute werden wir mithilfe von EarSketch Musik komponieren.

1. Um Musik zu machen, klicken Sie auf die folgende Schaltfläche, um Earsketch in einem neuen Tab zu öffnen.

<a class="my-2 mx-4 btn btn-info" href="https://earsketch.gatech.edu/earsketch2/" target="_blank">Earsketch starten</a>

2. Nachdem Sie die Webseite geöffnet haben, sehen Sie möglicherweise den folgenden Willkommensbildschirm. Drücken Sie "skip", um die Tour zu überspringen – wir gehen unten auf alle notwendigen Schritte ein.

<img src="../img/screenshot-skip-tour.png" height="400"/>

3. Jetzt wollen wir beginnen. Klicken Sie auf das *Scripts*-Symbol in der linken Menüleiste und wählen Sie *+ New Script*.

<img src="../img/screenshot-new-script.png" height="400"/>

4. Geben Sie *myjam* (oder einen anderen Namen Ihrer Wahl) als Namen Ihres Scripts ein und lassen Sie die Programmiersprache auf *Python* eingestellt. Klicken Sie auf die Schaltfläche *Create*, um Ihr Script zu erstellen (die Datei, in der Ihr Code platziert wird).

<img src="../img/screenshot-new-myjam.png" height="200"/>

## Empfohlen für Lehrkräfte – Überblick über EarSketch

Bitte werfen Sie einen Blick auf die Übersicht von EarSketch, bevor Sie mit der Klasse beginnen. Es ist wichtig, zu wissen, wie Sie sich in der Benutzeroberfläche hin und her bewegen können.

Der `Content Manager` auf der linken Seite des Bildschirms ist Ihre zentrale Anlaufstelle, um alles zu navigieren, was EarSketch zu bieten hat.

1. Das erste Element der Navigationsleiste ist die `Sounds`-Sammlung. Dies ist der zentrale Ort für alle vorinstallierten Sounds, die EarSketch zu bieten hat. Im Sound-Browser können Sie filtern, welche Sounds erscheinen, basierend auf Künstlern, Genre oder Instrumenten.

<img src="../img/screenshot-navigation-sound-browser.png" height="400"/>

2. Das nächste Symbol in der Navigationsleiste ist der `Scripts`-Bereich. Hier werden wir unseren Code schreiben.

<img src="../img/screenshot-navigation-script.png" height="400"/>

3. Das letzte Symbol in der Navigationsleiste ist der Bereich `API Browser`. Eine *Application Programming Interface* oder *API* ist ein Set von bereitgestelltem Code, das Sie sofort verwenden können! Wenn Sie darauf klicken, wird eine detaillierte Erklärung zu jeder API angezeigt.

<img src="../img/screenshot-navigation-api-curriculum.png" height="400"/>

Auf der rechten Seite sehen Sie den `Curriculum`-Leitfaden. Wenn Sie mehr über EarSketch erfahren möchten, können Sie den Bereich erkunden, der rechts im Fenster erscheint, wenn Sie darauf klicken. Wir überspringen diesen Abschnitt für diese Übung.
