## Das Terminal

In all unseren Aktivitäten werden wir Fähigkeiten für die **Command-Line-Interface** (CLI) üben. Es ist gut, die CLI zu lernen, da sie schneller und effizienter als eine GUI sein kann. GUI ist die **grafische Benutzeroberfläche**, die Sie wahrscheinlich hauptsächlich verwendet haben. Öffnen Sie das Terminal, das ein anderer Name für die CLI ist.  
In Kali wird diese Anwendung als "Terminal Emulator" bezeichnet.

![kali find terminal](../images/start-04.PNG?classes=border,shadow)

Nachdem Sie auf die Schaltfläche geklickt haben, sollte sich das Terminal wie im folgenden Bild öffnen. Sobald es geöffnet ist, sind Sie endlich bereit, mit den Linux-Aktivitäten zu starten!

![kali terminal open](../images/start-05.PNG?classes=border,shadow)
