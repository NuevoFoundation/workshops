Willkommen zum Kurs <b>Java: Grundlagen</b>, in dem Sie eine weit verbreitete, hochentwickelte Programmiersprache kennenlernen, mit der Computeranweisungen erstellt werden, um spannende Programme zu entwickeln!

Java ist eine hochentwickelte Programmiersprache, die 1995 von James Gosling und Sun Microsystems in Kalifornien entwickelt wurde.

<img src="images/logo.png" height="150" alt="Java-Logo einer dampfenden Kaffeetasse mit dem Schriftzug Java darunter" />

{{% notice info %}}
Eine hochentwickelte Programmiersprache wird als „hochentwickelt“ bezeichnet, weil sie einige Schritte von dem ursprünglichen Code entfernt ist, der auf der Central Processing Unit (CPU) eines Computers ausgeführt wird. Hochentwickelter Code ist für Menschen bestimmt und viel einfacher zu verstehen als Low-Level-Code. Der hochentwickelte Code wird später in eine Low-Level-Sprache übersetzt, die nur von einer bestimmten CPU wahrgenommen und ausgeführt werden kann. Damit der Code funktioniert, muss jede einzelne Zeile des in einer hochentwickelten Sprache geschriebenen Codes vor der Ausführung vom Computer in Maschinensprache übersetzt werden.
{{% /notice %}}

Heute wird Java von Entwicklern auf der ganzen Welt genutzt. Insbesondere wird Java verwendet für Android-Apps, Desktop-Anwendungen, Webanwendungen und Spieleentwicklung.

In diesem Kurs werden wir alle grundlegenden Funktionen der Sprache behandeln.
