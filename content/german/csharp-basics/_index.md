## Übersicht

Willkommen beim Kurs **C#: Grundlagen**, in dem du eine weit verbreitete, hochentwickelte Programmiersprache kennenlernen wirst, die verwendet wird, um spannende Programme zu erstellen!

Die Programmiersprache C# wurde 2000 von Anders Hejlsberg bei Microsoft entwickelt. Zum Zeitpunkt der Erstellung dieses Kurses ist die neueste stabile Version der Sprache C# 11.0, die 2022 veröffentlicht wurde.

{{% notice info %}}
Eine hochentwickelte Programmiersprache wird als "high-level" bezeichnet, da sie einige Schritte vom ursprünglichen Code entfernt ist, der auf der Central Processing Unit (CPU) eines Computers ausgeführt wird. High-Level-Code ist für Menschen gedacht und viel einfacher zu verstehen als Low-Level-Code. Der High-Level-Code wird später in eine Low-Level-Sprache übersetzt, die nur von einer bestimmten CPU wahrgenommen und ausgeführt werden kann. Damit der Code funktioniert, muss jede einzelne Zeile Code, die in einer hochentwickelten Sprache geschrieben wurde, in Maschinensprache übersetzt werden, bevor sie vom Computer ausgeführt wird.
{{% /notice %}}

C# gehört zu den beliebtesten Programmiersprachen der Welt, zusammen mit Java, JavaScript, Python und anderen. C# kann auf jedem Computer ausgeführt werden, einschließlich Windows, Mac und Linux-Betriebssystemen.
