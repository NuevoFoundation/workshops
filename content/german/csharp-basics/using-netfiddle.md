### Verwendung von .NET Fiddle
Heute werden Sie .NET Fiddle verwenden, um das Programmieren in C# zu lernen.

Bevor wir beginnen, lassen Sie uns zunächst verstehen, wie das Fenster funktioniert. Auf der linken Seite gibt es eine Liste von Optionen. Diese wurden bereits für Sie eingestellt, sodass Sie sich darüber keine Sorgen machen müssen. In der Mitte des Bildschirms befindet sich der Code, oder die Anweisungen, die der Computer ausführen soll. Wenn Sie die **Run**-Taste drücken (die Schaltfläche mit dem Dreieck in der Mitte oben im Rahmen), weisen Sie den Computer an, die Anweisungen im Code auszuführen. Die Ergebnisse des ausgeführten Codes werden unten auf dem Bildschirm angezeigt.

<img src="../images/donetfiddle-overview.png" height="300" alt=".NET Fiddle Fensterlayout" />

Nehmen Sie sich etwas Zeit, um das Tool unten kennenzulernen.

### Einige Tipps zu C#

Einige wichtige Tipps:
1. Jede Codezeile endet mit einem Semikolon `;`
2. Es gibt Code in den Beispielen, den Sie nicht verstehen werden. Das ist in Ordnung, konzentrieren Sie sich zunächst auf die Aufgabe, an der Sie arbeiten.

## Speichern Ihrer Arbeit

Wenn Sie während dieser Übungen Ihre Arbeit speichern möchten, müssen Sie sich für ein .NET Fiddle-Konto anmelden, falls Sie noch keines besitzen.

Klicken Sie auf die Schaltfläche unten, um sich für ein .NET Fiddle-Konto anzumelden – Sie benötigen ein E-Mail-Konto, um sich anmelden zu können. Falls Sie bereits ein .NET Fiddle-Konto haben, können Sie sich über die Schaltfläche unten in Ihrem Konto anmelden.

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/SignUp" target="_blank">Für .NET Fiddle anmelden</a>

<img src="../images/dotnetfiddle-signup.png" height="300" alt=".NET Fiddle Anmeldeformular" />

Danach können Sie *forken*, was einfach bedeutet, eine Kopie des Programms zu erstellen, damit wir unsere eigenen Änderungen daran vornehmen und speichern können. Klicken Sie oben auf die Schaltfläche "Fork".

Nach dem Forken des Fiddles sehen Sie ein Fenster ähnlich dem unten gezeigten:

<img src="../images/dotnetfiddle-window.png" height="300" alt=".NET Fiddle Fenster" />
