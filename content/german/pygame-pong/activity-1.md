Sie können die Begrenzung des Pong-Spiels anpassen, indem Sie die Höhe und Breite des Rechtecks ändern, das die Begrenzung darstellt.

Gehen Sie zum <a href="https://replit.com/@nuevofoundation/PongLessonStudent?v=1" target="_blank">Code</a>, der das Pong-Spiel enthält. Drücken Sie **Run**. Beachten Sie, dass die Spielbegrenzung nicht korrekt aussieht – siehe das untenstehende Bild. Lassen Sie uns das in dieser Aktivität beheben, damit die Begrenzung des Spiels besser aussieht.

![Pong-Spiel mit falscher Begrenzung](../media/width-highlight.png)

Suchen Sie im Code nach `# TODO (ACTIVITY 1)`. Befolgen Sie die dortigen Anweisungen, um das Attribut `WIDTH` der Klasse `Pong` zu ändern. Wenn Sie dies korrekt gemacht haben, wird das Begrenzungsproblem behoben. Drücken Sie **Run**, um das Ergebnis zu sehen.

{{% notice tip %}}

Versuchen Sie, die Werte für Höhe und Breite zu ändern, um die Auswirkungen unterschiedlicher Werte auf die Spielbegrenzung zu beobachten.

{{% /notice %}}
