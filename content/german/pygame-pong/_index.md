Du weißt vielleicht bereits, wie man Pong im echten Leben spielt. Wie wäre es, deine eigene Version von Pong auf deinem Computer zu bauen? In diesem Tutorial lernen wir, eine Bibliothek in Python namens Pygame zu verwenden, um Pong zu erstellen. Klingt das spannend?

![Animation eines Pong-Spiels](https://media.giphy.com/media/xThuWtNFKZWG6fUFe8/giphy.gif)

Das Ziel dieses Workshops ist es, dein vorhandenes Python-Wissen zu nutzen, um den angegebenen Code zu korrigieren, damit das Spiel funktioniert, und dabei die Pygame-Bibliothek und ihre Funktionen kennenzulernen.
