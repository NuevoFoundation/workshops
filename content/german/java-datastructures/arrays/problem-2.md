1. Du kannst eine `for`-Schleife verwenden, um durch das Array zu gehen!

## Aufgabe 2: Sortiere ein Array!

Die Kosten für jedes Element auf der Speisekarte sind kreuz und quer verteilt! Hilf uns, das Array von klein nach groß zu sortieren.

{{% notice tip %}}
1. Überlege dir eine Methode, das Array zu sortieren (es gibt viele verschiedene Möglichkeiten)!
2. Schau dir das Beispiel an!
{{% /notice%}}

Angenommen, wir haben dieses Array: 
```js javascript
int[] cost = {100,90,50,60,20,1,3};
```

dann sollten wir folgende Ausgabe erhalten:
```js javascript
int[] sorted = {1,3,20,50,60,90,100};
```
