Ein HashMap ist eine Tabelle, die eine Sammlung von Schlüssel-Wert-Paaren enthält. Es "verknüpft" zahlreiche Schlüssel mit ihren entsprechenden Werten. Ein HashMap ist einer Wörterbuch sehr ähnlich. In einem Wörterbuch möchten Sie möglicherweise eine Definition für ein bestimmtes Wort nachschlagen. Sie schauen einfach das Schlüsselwort im Wörterbuch nach und erhalten dadurch die Definition, die an dieses Schlüsselwort angehängt ist. Das Wörterbuch ordnet Wörter (die "Schlüssel") ihren Definitionen (die "Werte") zu.

HashMaps können viele verschiedene Arten von Informationen speichern. Das folgende HashMap speichert Personen als Schlüssel und ihre Bestellung als Wert.

![image](../img/hashmap.png)

Wir möchten in der Lage sein, direkt auf die Bestellung einer Person zuzugreifen, genau wie wir eine Definition in einem Wörterbuch finden würden. Indem wir "Bea" nachschlagen, gibt uns das HashMap ihre Bestellung zurück: Arepas. Im nächsten Abschnitt betrachten wir einige gängige HashMap-Methoden.
