## Aufgabe 1: Das 2D-Array ausgeben

Im folgenden 2D-Array haben wir eine Liste verschiedener Speisen. Jede Zeile enthält denselben Typ. Zum Beispiel ist Zeile 1 ein Array mit Hauptgerichten. Zeile 2 ist ein Array mit Getränken und Zeile 3 ist ein Array mit Desserts.

```js javascript
String[][] menu = {    
                    { "Hamburger", "Pasta", "Steak", "Tacos" },
                    { "Cola", "Sprite", "Pepsi", "Fanta" },
                    { "Pudding", "Eiscreme", "Mochi", "Kuchen" }
                  };
```
Verwende das, was du gelernt hast, um das Array auszugeben!
