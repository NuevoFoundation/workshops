Ein Fahrer muss sowohl eine Bestellung abholen als auch an den Kunden ausliefern. Ein Fahrer kann mehrere Bestellungen gleichzeitig abholen. Für maximale Effizienz möchte ein Fahrer so viele Bestellungen wie möglich abholen und die meisten Auslieferungen auf dem kürzesten Weg durchführen. Wenn ein Fahrer auf dem Weg ist, eine Bestellung aus einem Restaurant abzuholen, aber plötzlich ein Kunde von einem Restaurant bestellt, das sehr nah und auf dem Weg liegt, sollte ein Fahrer in der Lage sein, die Bestellung von diesem Restaurant abzuholen, um das Beste aus seiner Fahrt herauszuholen. Allgemein möchte ein Fahrer Bestellungen basierend auf der kürzesten Entfernung abholen und ausliefern. Dieses Verhalten können wir implementieren, indem wir einen Stack verwenden.
