## Darstellung eines Stacks

Ein Stack ist einem Queue sehr ähnlich, und viele der Konzepte, die Sie über ein Queue gelernt haben, können auf einen Stack angewendet werden. Im Gegensatz zu einem Queue mit der FIFO-Logik arbeitet ein Stack jedoch mit der entgegengesetzten Logik, LIFO (Last In, First Out).

Ein häufig verwendetes Beispiel, um einen Stack zu veranschaulichen, ist ein Stapel von Tellern. Stellen Sie sich 5 Teller vor, die aufeinander gestapelt sind. Wenn Sie einen sechsten Teller oben auf den Stapel legen, ist Ihr Tellerstapel nun ein Stapel von 6 Tellern. Aber was, wenn Sie einen Teller entfernen möchten? Sie würden nicht den untersten Teller aus dem Stapel nehmen; stattdessen würden Sie den obersten Teller herausnehmen.

Diese Last In, First Out (LIFO)-Logik gilt auch für Stacks in Java.
