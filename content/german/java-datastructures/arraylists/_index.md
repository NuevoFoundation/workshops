Jetzt, da die Kunden Zugriff auf alle Artikel auf der Speisekarte haben, ist es an der Zeit, ihre Bestellungen aufzugeben. Ein Kunde könnte einen Artikel zu seiner Bestellung hinzufügen, einen Artikel entfernen, einen Artikel ändern oder auf einen Artikel zugreifen wollen. Nach dem Fertigstellen der Bestellung möchten Sie eine Quittung ausstellen, die die Anzahl der Artikel, die der Kunde bestellt hat, sowie eine Liste jedes Artikels enthält, damit der Kunde zur Kasse gehen kann. Wir werden all diese Aufgaben mithilfe einer `ArrayList` bewältigen.
