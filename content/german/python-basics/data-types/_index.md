## Übersicht

In der Programmierung sind Datentypen ein wichtiges Konzept. Variablen können Daten unterschiedlicher Typen speichern, und verschiedene Typen können unterschiedliche Dinge tun.

Python hat die folgenden Datentypen standardmäßig eingebaut, in diesen Kategorien:

**Typ** | **Beispiel**
---------|-------------
Text |	str
Numerisch | int, float, complex
Sequenz | list, tuple, range
Zuordnung | dict
Mengen | set, frozenset
Boolean | bool
Binär | bytes, bytearray, memoryview
Keine | NoneType

In diesem Abschnitt konzentrieren wir uns auf Strings, Zahlen und Booleans. Los geht's!
