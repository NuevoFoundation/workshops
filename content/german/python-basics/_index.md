## Überblick

Willkommen zum Kurs **Python: Grundlagen**, in dem Sie eine weit verbreitete, hochentwickelte Programmiersprache lernen, die Computeranweisungen gibt, um spannende Programme zu erstellen!

Python ist eine hochentwickelte Programmiersprache, die zwischen 1985 und 1990 von Guido van Rossum entwickelt wurde.

{{% notice info %}}
Eine hochentwickelte Programmiersprache wird als "high-level" bezeichnet, weil sie einige Schritte vom ursprünglichen Code entfernt ist, der auf der Zentralen Verarbeitungseinheit (CPU) eines Computers ausgeführt wird. High-level Code ist für Menschen verständlich und viel einfacher zu verstehen als Low-level Code. Der High-level Code wird anschließend in eine Low-level Sprache übersetzt, die nur von einer spezifischen CPU wahrgenommen und ausgeführt werden kann. Damit der Code funktioniert, muss jede einzelne Zeile des in einer hochentwickelten Sprache geschriebenen Codes in Maschinensprache übersetzt werden, bevor sie vom Computer implementiert wird.
{{% /notice %}}

Heute wird Python von Entwicklern auf der ganzen Welt verwendet. Insbesondere wird Python für die Entwicklung von Websites, Softwarekomponenten und Anwendungen oder für die Arbeit mit Data Science, Künstlicher Intelligenz und maschinellen Lerntechnologien verwendet.

Und in diesem Kurs werden wir alle grundlegenden Funktionen der Sprache behandeln.
