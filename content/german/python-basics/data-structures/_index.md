## Überblick

Im vorherigen Abschnitt haben Sie etwas über Bedingungsanweisungen und Schleifen gelernt. In diesem Abschnitt werden wir verschiedene Datenstrukturen einführen. Eine Datenstruktur ist eine Methode zur Organisation und Speicherung von Daten und Informationen, damit ein Benutzer sie effizient nutzen kann. In Python gibt es drei Hauptdatenstrukturen, die wir in diesem Abschnitt behandeln und verwenden werden: Listen, Tupel und Sets.
