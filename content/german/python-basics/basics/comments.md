Beim Erstellen eines Python-Programms können wir Notizen hinzufügen, indem wir einzeilige Kommentare mit `#` verwenden. **Kommentare** sind die Teile des Codes, die das Programm nicht beeinflussen. Alles, was nach dem `#`-Symbol geschrieben wird, gehört zum Kommentar und wird vom Code ignoriert. Kommentare werden in den Code aufgenommen, um den Lesern zu erklären, was der Code tut. Sie können die Wartung des Codes erleichtern und auch beim Auffinden von Fehlern helfen.

Wenn du während des Schreibens von Code Notizen machen möchtest, um den Code besser zu verstehen, verwende das `#`-Symbol, um einen Kommentar zu erstellen.

```python
# Das ist meine erste Zeile Code
print("Hallo, Welt!")
```

![Screenshot zeigt den Kommentar: Das ist meine erste Zeile Code.](../../img/comments.png "ein Bild, das zeigt, wie man Kommentare in Python schreibt")

Sei vorsichtig, wenn du das `#`-Symbol entfernst, funktioniert dein Code nicht mehr!

![Screenshot des Codes zeigt das Entfernen des # vor einem Kommentar, was einen Fehler bei der Codeausführung verursacht](../../img/comments_wrong.png "ein Bild, das einen falsch geschriebenen Kommentar zeigt") 

Probiere aus, einen Kommentar über deiner ersten Codezeile hinzuzufügen und drücke „Ausführen“. Du wirst sehen, dass der Computer deinen Kommentar ignoriert.
