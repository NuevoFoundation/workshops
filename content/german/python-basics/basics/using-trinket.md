Heute verwenden wir Codebunga, um Python zu lernen. Hier ist ein Beispiel eines interaktiven Codebunga-Fensters, das du heute benutzen wirst.

<iframe title="Einstieg mit Codebunga - Codebunga" src="https://codebunga.com/embed/fcrtud9r" width="100%" height="600" frameborder="0" marginwidth="0" marginheight="0" allowfullscreen></iframe>

Bevor wir anfangen, lass uns zuerst verstehen, wie das Fenster funktioniert. Die Datei `main.py` enthält Code oder Anweisungen, die der Computer ausführt. Alles, was aus der Ausführung des Codes resultiert, wird auf der rechten Seite angezeigt. Dieses Fenster, das das Ergebnis anzeigt, nennt man Konsole.

Drücke auf **Ausführen** und sieh zu, wie deine Konsole deinen Code auf dem Bildschirm rechts ausführt! Im folgenden Beispiel weist `print` den Computer an, die im Klammerausdruck `()` stehende Textzeichenfolge in die Konsole, also den Bildschirm rechts, auszugeben. Mehr über `print` erfährst du in den nächsten Lektionen.
