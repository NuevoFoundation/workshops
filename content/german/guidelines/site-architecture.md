# Wie die Seite aufgebaut ist

Der Inhalt der Workshop-Subdomain wird mit dem [DocDock](https://docdock.netlify.com/) Theme für Hugo erstellt. [Hugo](https://gohugo.io) ist ein Static Site Generator mit einer Reihe von Vorteilen:

1. **Inhaltsautoren** können sich auf den Inhalt konzentrieren, indem sie Markdown verwenden, anstatt sich um die technische Umsetzung der Seite oder das CSS/Seitendesign zu kümmern. Workshops werden *automatisch* im linken Inhaltsverzeichnis und auf der Startseite der Workshops hinzugefügt. Hugo funktioniert hervorragend lokal (z. B. im Flugzeug), und Hugo ist der schnellste Static Site Generator, da er die gesamte Workshop-Seite in weniger als 2 Sekunden erstellt.  
2. **Lernende** profitieren von einer konsistenten Benutzererfahrung über alle Workshops hinweg, integrierter Barrierefreiheit, Lokalisierung, responsivem Design für Mobilgeräte bis Desktop, automatisierten Links zum GitHub-Repository und schneller globaler Seitenleistung mittels Azure CDN.
3. **Nuevo Dev Team** profitiert von der Möglichkeit, Workshop-Seiten zu erstellen und anzupassen, einschließlich benutzerdefinierter Seitentemplates, [eingebauter Seitensteuerungen für Hinweise, Notizen, Buttons, Warnungen und mehr](https://workshops.nuevofoundation.org/guidelines/formatting/), benutzerdefinierter Steuerungen (z. B. das Nuevo-Header), iframe-Interaktivität, benutzerdefinierter Metadaten, automatisierter Verlinkung zwischen Seiten, Seitenthemen, automatischer Erstellung von Sitemaps, eingebauter Icons und integrierter Automatisierung mit GitHub Actions und Azure DevOps für Erstellungs- und Bereitstellungsprozesse.
