# Моделди Трендөөдөн Өткөзүү

Биздин модель баалуулуктарды божомолдоо үчүн, аны трендөөдөн өткөрүшүбүз керек. Бирок, кантип муну жасайбыз, жакшысы, биз муну жасап жатабыз 😉!

Моделди трендөөдөн өткөрүү бул — маалыматтардын ортосунда жакшы байланыш бар экенин жана биздин модель ошол маалыматтарга туура келгенин текшерүү.

Биз бул жакшылыкты R<sup>2</sup> 1ге жакын кылып камсыз кылуу менен жасап койгонбуз. Эми эмне кылышыбыз керек — 10,000+ жазуулардын маалымат базасын колдонуп, трендөө жана тестирлөө маалымат базаларын түзүү. Трендөө маалымат базасы баштапкы 30дан айырмаланып кокустук үлгү болот. Техас штатынын Эль Пасо Университетине ылайык, 30% үлгү алуу так моделди түзүүнүн идеалдуу жолу деп эсептелет. Эгер бул тууралуу көбүрөөк билгиңиз келсе, бул жакка барыңыз: ([Тренддөө жана Тестирлөө Жыйнактары Арсындагы 70/30 же 80/20 Мамилеси](https://scholarworks.utep.edu/cs_techrep/1209/))

Кызматкерлердин саны көбөйгөн сайын маалымат базасы да чоңоёт жана R<sup>2</sup> мааниси өзгөрөт. Биздин модель учурдагы кызматкерлердин санына шайкеш келүүсүн камсыз кылуу үчүн, 10,000+ кызматкердин маалымат базасы көбөйгөн сайын бул процессти аткарышыбыз керек.

# Болжолдоо
