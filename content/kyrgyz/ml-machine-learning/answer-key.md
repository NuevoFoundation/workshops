## 1-бөлүм: Регрессия деген эмне?

### 1-тапшырманын жооптору

**1-суроо:** Аймак аркылуу фигуранын түрүн билүүгө мүмкүнбү?

**Жооп:** Жок. Бирдей аянты бар, бирок ар кандай фигура болгон квадрат (3x3 = 9) жана үч бурчтук (негизи 6, бийиктиги 3 болсо, аянты = 6x3/2 = 9) болушу мүмкүн.

**2-суроо:** Фигуранын түрүн кандай байланыш аныктайт?

**Жооп:** Капталдардын саны. Бул түз пропорционалдык байланыш: 3 каптал = үч бурчтук, 4 каптал = квадрат, 5 каптал = беш бурчтук ж.б.

## 2-бөлүм: Жөнөкөй Линейлик Регрессия

### Негизги Формула

Линейлик регрессиянын формуласы:

```
y = ax + b + ε
```

Мында:
- `x` = көз карандысыз өзгөрмө (Тажрыйба жылдары)
- `y` = көз каранды өзгөрмө (Маяна)
- `a` = коэффицент/ыкшамдык (x бирдикке көбөйгөндө y канчага өзгөрөт)
- `b` = баштапкы чек (x = 0 болгондо yдин мааниси)
- `ε` = ката элемент

### 1-тапшырма: Scikit-learn менен иштөө

Маалымат топтомун жүктөө жана визуалдаштыруу:

```python
import pandas as pd
from sklearn import linear_model

dataset = pd.read_csv("Experience_vs_Salary.csv")
x = dataset.iloc[:, :-1].values  # Тажрыйба графасы
y = dataset.iloc[:, 1].values     # Маяна графасы

model = linear_model.LinearRegression()
model.fit(x, y)
```

### 2-тапшырма: Ыкшамдык жана баштапкы чек табуу

**Жооптор:**
- **Баштапкы чек (b):** 25,792.20
- **Коэффицент/Ыкшамдык (a):** 9,449.96
- **Формула:** МАЯНА = 9,449.96 × (Тажрыйба) + 25,792.20 + ε

**Түшүндүрмө:**
- 0 жылдык тажрыйбага ээ кызматкер болжол менен $25,792 маяна алат.
- Кошумча ар бир жылдык тажрыйба маянага болжол менен $9,450 кошот.

## 3-бөлүм: Ишеним интервалдары

### Негизги Формула

```
КоэффицентДиапазону = Коэффицент ± 2 × СтандарттыкКата
```

### 2-тапшырма: Стандарттык катаны табуу

**Жооп:** Стандарттык ката = **409.40**

### Ишеним интервалынын эсептөөлөрү

```
КоэффицентДиапазону = 9,449.96 ± 2 × 409.40
КоэффицентДиапазону = 9,449.96 ± 818.80
КоэффицентДиапазону = [8,631.16 , 10,268.76]
```

**Түшүндүрмө:** Биз ар бир жылдык тажрыйба маянаны $8,631.16 менен $10,268.76 ортосунда көбөйтөт деп 95% ишенип айта алабыз.

### 1-тапшырма: Көбүрөөк үлгүлөрдү текшерүү

**Суроо:** Эмне үчүн ар бир аткарууда баштапкы чек жана коэффиценттин мааниси өзгөрүп турат?

**Жооп:** Ар бир аткарууда 10,000+ маалымат топтомунан 30 ар кандай кокустук жазуу тандап алынат. Ар кандай үлгүлөр бир аз айырмасы бар жыйынтыктарды берет, бирок бул маанилер ишеним интервалынын чегинде кала берет.

### 3-тапшырма: Нормалдык таралуу

Көптөгөн үлгүлөрдөн алынган коэффицент маанилеринин гистограммасы Белл-Сыяктуу Имце (нормалдык таралуу) түзөт. Бул маанилер чыныгы коэффиценттин айланасында топтолгонун көрсөтөт, жана көбүнчөсү ишеним интервалында калат.

## 4-бөлүм: Моделдин шайкештиги

### 1-тапшырма: R-Квадрат табуу

**Жооп:** R² = **0.973**

**Түшүндүрмө:** Биз 97.3% ишенип айта алабыз, тажрыйба жылдары кызматкердин айлык акысына байланыштуу экендигин. Модель маянадагы өзгөрүүлөрдүн 97.3% түшүндүрөт.

{{% notice tip %}}
**Мугалимдер үчүн:** R² 0ден 1ге чейин өзгөрөт. 0.9дан жогорку маанилер абдан күчтүү байланышты көрсөтөт. Эгерде студенттерде төмөн R² чыкса, алардын үлгү өлчөмүн текшерүүсүн өтүнүңүз. "sample_size" өзгөрмөсүн өзгөртүп, R²га таасирин байкоону сунуштаңыз.
