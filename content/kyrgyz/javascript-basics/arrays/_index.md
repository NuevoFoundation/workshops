## Массив деген эмне?

Массив – бул жөн гана маанилердин жыйындысы. Бул атайын өзгөрмө, бир эле учурда бир нече маанини сактай алат.

Мисалы, жемиштер деп аталган массивди карап көргүлө, анда алма, апельсин, манго сыяктуу баалуулуктар бир өзгөрмөдө чогуу сакталат.   

## Аны кантип түзүүгө болот

Төмөндөгү билдирүүлөр массивдерди эки башка ыкма менен түзүүнү көрсөтөт, бирок жыйынтыгы бирдей болот.

<b>Синтаксис:</b>
```javascript
var arrayName = new Array(element0, element1, ..., elementN);
var arrayName = Array(element0, element1, ..., elementN);
var arrayName = [element0, element1, ..., elementN];
```
