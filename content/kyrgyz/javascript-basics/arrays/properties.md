Массив касиеттерин же өзгөчөлүктөрүн анын мүнөздөмөлөрүн билдирүү үчүн колдонулат. Мисалдар: жалпы элементтердин саны, белгилүү бир индекстеги мааниси ж.б.

Төмөндө Array объектинин касиеттеринин тизмеси жана алардын сүрөттөмөсү келтирилген.

## Constructor()

Объектини түзгөн массив функциясына шилтеме кайтарат.

**Синтаксис:**
```javascript
arrayName.constructor;
```

![#Сүрөт табылган жок](../../img/constructor.png)

## Index()

Бул касиет саптагы нөлгө негизделген индекстин дал келишин билдирет. Index массивдеги элементтерди алардын позициясы боюнча кирүүгө же өзгөртүү мүмкүнчүлүгүн берет.

### Индекс боюнча массив элементине кирүү:

**Синтаксис:**
```javascript
var value = arrayName[index];
```

**Мисал:**
![#Сүрөт табылган жок](../../img/indexaccess.png)

### Индекс боюнча массив элементин өзгөртүү:

**Синтаксис:**
```javascript
arrayName[index] = newValue;
```

**Мисал:**
![#Сүрөт табылган жок](../../img/indexmodify.png)

## Length() 
Массивдеги элементтердин санын чагылдырат.

**Синтаксис:**
```javascript
var length = arrayName.length;
```
