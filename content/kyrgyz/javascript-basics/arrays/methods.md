Методдор массивде аткаргыңыз келген иш-аракетти билдирет. Алар массивдин жүрүм-турумун өзгөртүү же кандайдыр бир операцияларды аткаруу үчүн колдонулушу мүмкүн.

Массивдерди пайдаланууну жеңилдетүү үчүн көптөгөн методдор бар. Башкы методдорду карап чыгып, алардын кандай көрүнүшү жөнүндө түшүнүк алабыз.

{{% notice note %}}

#### Сапаттарга салыштырмалуу кандай айырмасы бар?

**Сапаттар** — массивдин өзүндө бар маалымат. **Методдор** — массив жасай ала турган иш-аракеттер.

{{% /notice %}}

## Concat()

Эки же андан көп массивдерди бириктирип, жаңы массивди кайтарат.

**Синтаксис:**
```javascript
var value = arrayName1.concat(arrayName2);
```

## Push()
Массивдин аягына бир же бир нече элементти кошуп, массивдин узундугун кайтарат.

**Синтаксис:**
```javascript
var value = arrayName.push(newElement);
```

**Мисал:**
![#Сүрөт табылган жок](../../img/push.png)

## Pop()
Массивден акыркы элементти алып салып, ошол элементти кайтарат.

**Синтаксис:**
```javascript
var value = arrayName.pop();
```

<b>Мисал:</b>
![#Сүрөт табылган жок](../../img/pop.png)

## Shift()

Массивден биринчи элементти алып салып, ошол элементти кайтарат.

**Синтаксис:**
```javascript
var value = arrayName.shift();
```

**Мисал:**
![#Сүрөт табылган жок](../../img/shift.png)

# Unshift()

Массивдин башына бир же бир нече элементти кошуп, жаңы узундукту кайтарат.

**Синтаксис:**
```javascript
var value = arrayName.unshift(newElement);
```

**Мисал:**
![#Сүрөт табылган жок](../../img/unshift.png)

## Sort()

Массив элементтерин ордунда сорттоп, массивдин өзү боюнча шилтеме (reference) кайтарат.

**Синтаксис:**
```javascript
var value = arrayName.sort();
```

**Мисал:**
![#Сүрөт табылган жок](../../img/sort.png)

# Reverse()

Массивди ордуна карата өзгөртөт: биринчи элемент акыркы болуп, акыркы элемент биринчи болот. Түздөн массивге шилтеме кайтарат.

**Синтаксис:**
```javascript
var value = arrayName.reverse();
```
