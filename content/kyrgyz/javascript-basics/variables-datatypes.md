JavaScript тилинде өзгөрмөлү түзүү үчүн 3 вариант бар.

1. `var` (бул variable сөзүнөн кыскартылган) менен мындай иретте:
```javascript
var x = 5;
var y = 6;
var z = x + y;
```

2. `let` колдонуу менен ушундай:
```javascript
let x = 5;
let y = 6;
let z = x + y;
```

3. Же `const` (бул constant сөзүнөн кыскартылган) менен мындайча:
```javascript
const x = 5;
const y = 6;
```
Бул жерде түшүнүш керек нерсе - constant өзгөрбөйт. Бул анын башында берилген маани кийин өзгөрбөй турганын билдирет.

`var`, `let`, жана `const` менен JavaScriptтеги ар кандай маалымат түрлөрүн сактоого болот. Бул динамикалык түрлөр (dynamic types) деп аталат.

JavaScriptте 8 башка маалымат түрлөрү бар:
- String
- Number
- Boolean
- Undefined
- Null
- Symbol
- Object
- BigInt

Биз эң маанилүүлөрүн талкуулайбыз: String, Number, Boolean, Undefined жана Object!

## String
Stringтер сөздөрдөн же уруунун топтомунан турушу мүмкүн.

```javascript
// String мисалдары
let animal = "Пил";
let alphabet = "abc";
let name = "Жан";
```

## Number
Сандар ар кандай өлчөмдөгү сандар үчүн колдонулушу мүмкүн (кичинелер да, чоңдор да!). Бирок, эгер абдан ЧООООҢ сандар керек болсо, анда атайын bigint деп аталган өзгөрмөгө муктаж болосуз (бирок бул башка тема).

```javascript
// Number мисалдары
let age = 16;
let weight = 7.5;
```

## Boolean
Booleanдер чындык (true) жана жалгандык (false) маанилерин көрсөтөт, демек, чындыкты айтууну же жалган сүйлөөнү билдирет.

```javascript
// Boolean мисалдары
let truth = true;
let lie = false;
let x = true;
let y = false;
```

## Undefined
Undefined дегендин мааниси өзгөрмө мааниси жок болуп жатат дегенди билдирет (себеби 0 техникалык жактан мааниге ээ!).

```javascript
// Undefined мисалы
let x = undefined;
```

## Object
JavaScriptте объект түшүнүгү бир аз татаал. Бул түзүлгөн объект болушу мүмкүн, мисалы: массивдер, даталар, шарттуу топтомдор жана башкалар, же колдонуучу тарабынан аныкталган массив; башкача айтканда, бул маалыматтардын каалаган топтому болушу мүмкүн.

```javascript
const person = {firstName:"Жан", lastName:"До"};

<!-- Массив объектиси: -->
const cars = ["Saab", "Volvo", "BMW"];

<!-- Дата объектиси: -->
const date = new Date("2022-03-25");

<!-- Колдонуучу тарабынан аныкталган объект (бул учурда биринчи жана акыркы ысымдар) -->
const person = {firstName:"Жан", lastName:"До"};
```

## Өзгөрмөнүн түрүн так билбеген учурда...
`typeof` операторун колдонуңуз! Эгер `typeof` операторун өзгөрмө менен колдонсоңуз, ал сизге анын кандай түр экенин көрсөтөт:

```javascript
typeof "Айша" // "string" деп кайтарат
typeof 0 // "number" деп кайтарат
typeof (3) // "number" деп кайтарат (жакшалар эч нерсе кылбайт)
typeof (3 + 4) // "number" деп кайтарат
```
