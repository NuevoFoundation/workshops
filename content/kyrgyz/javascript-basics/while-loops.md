`while` цикли бул – шарт туура болгон учурда бир нече аракеттерди аткарып туруучу код бөлүгү. Биз `while` деген сөз менен баштайбыз андан кийин шартты кашаалардын `()` ичине жазабыз, анан аткарыла турган аракетти (же аракеттерди) фигуралуу кашаанын `{}` ичине жайгаштырабыз. Бул төмөнкүчө жазылат:

```javascript
// While циклинин түзүлүшү
while (шарт туура болсо) {
  // аткарылуучу аракет
}
```

Эми мисалдарга өтөлү!

## Мисалдар
Айталы, биз 8 жолу аткарылган цикл түзгүбүз келип жатат.

```javascript
// 8 жолу аткарылган цикл
let i = 0; // эсептегич айныманын орнотулушу
while (i < 8) {
  i++; // циклдин кийинки жолу өтүүсүнө шарт түзүү (бул циклди кайрадан ушул бөлүктөн өткөрөт)
}
```

Шарт катары билдирүү, мисалы чейин/калп (true/false) сыяктуу маани дагы болушу мүмкүн. Мисалы, биз видеодогу ар кандай комментарийлерди окудук десек, баарын окуп бүткөнгө чейин циклди аткаргыбыз келет дейли. Бул үчүн while циклдин ичинде бир нече ар түрдүү айнымалардын болушу керек (төмөндөгү татаал "node" деген сөздөрдү убактылуу көңүлгө албай койсоңуз болот).

```javascript
const commentIterator = video.createNodeIterator(video, NodeFilter.SHOW_COMMENT) // бул видеодогу бир комментарийден башкага өтүүнүн жолу
let currentComment; // бул учурдагы комментарий үчүн орун басар

// бул while цикли "nextNode" деген нерсе бар болсо (бул "бул комментарийден кийинкиси бар" деген маанини билдирет) циклди улантат
while (currentComment = commentIterator.nextNode()) {
  console.log(currentComment.textContent.trim()); // бул учурдагы комментарийди чыгарып жатат, аны окуй алабыз!
}
```
