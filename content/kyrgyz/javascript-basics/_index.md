## JavaScript Негиздери

Салам! Эгер бул макаланы окуп жатсаңыз, анда сиз JavaScriptти үйрөнүүнү каалагандай көрүнөт 😁🥳. Бул сиздин биринчи жолу программалоо кылууңуз болсо да же жаңы тилди тез үйрөнүүнү көздөп жатсаңыз да - сиз туура жердесиз! Программалоо күчүн ачууга жана андан ырахат алууга даяр болуңуз. 

## Код деген эмне?

Кодду үйрөнмөйүнчө, код деген эмне экенин түшүнүп алышыбыз керек. Сүйүктүү веб-сайтыңыз тууралуу ойлонуп көрүңүз, эгер эсибизге түшпөсө, анда мисалы катары NuevoFoundation.org сайтына кайрылалы. Колдонуучу катары сиз жөн гана веб-даректи браузерге жазып, анан заматта - та-да! - веб-сайт пайда болот, кызгылт түстөрү жана Nuvi сүрөттөрү менен кооз.  

Оңой сыяктуу көрүнөт, туурабы? Бирок андай эмес, бул жөнөкөй көрүнгөн аракеттин артында жүздөгөн - же мүмкүндүк миңдеген! - код саптары бар. Бул өз ара аракеттешүүнүн бир гана кадамын карап көрөлү, мисалы, Nuevo Foundation сайтына издөө жана өтүү. Интернетте миллиарддаган веб-сайттар бар (акыркы жолу текшергенимде 1,7 миллиард болчу), браузериңиз каалаган сайтыңызды кантип ушунчалык тез издеп табат? Бир аз ойлонуп көрүңүз...

Мунун бардыгын коддоп жазган адамдар бар, сиздин браузериңизди коддоп жазган адамдар дагы бар, ошондой эле Nuvi веб-сайты жана сиз окуп жаткан бул программа дагы жазылган. Код - бул биз адамдар веб-сайттарды, колдонмолорду жана оюндарды түзүүдө колдонулган тил. Бул компьютерлерге эмне кылуу керек экенин айтып берүү үчүн колдонулган тил.  

## JavaScript деген эмне жана ал эмне үчүн колдонулат?

Кантип адамдарда тилдер ар түрдүү болсо, ошондой эле программалоо тилдери да көп. Балким, алардын айрымдарын уккандырсыз, мисалы, Python же Java. Ар бир программалоо тилинин өзүнүн күчтүү жактары жана максаттары бар - мисалы, CSS веб-сайттарды кооздоо үчүн колдонулат, ал эми Python маалымат илиминин тармактарында өтө жакшы колдонулат ж.б.

JavaScript кээде "вебдин тили" деп аталат. Сиз ойлогон дээрлик бардык веб-сайт JavaScriptти кандайдыр бир деңгээлде колдонот. JavaScript веб-сайттын жүрүм-турумун көзөмөлдөөдө абдан жакшы, мисалы, баскыч басылганда эмне болорун көзөмөлдөйт же беттердин ортосунда маалыматты өткөрүп берет. 

Жакшы жери, бир тилди үйрөнгөндөн кийин, башка тилди үйрөнүү абдан оңой болуп калат, анткени негизги принциптер окшош бойдон калат.

## Чөйрөнү даярдоо

Чөйрөө? Бул эмне болгон программалоо сабагы?

"Чөйрөө" - бул программисттер программалоого шарт түзүү үчүн колдонгон окшош тиркемелерди айтканда колдонулган термин. Сиз Microsoft Word же Google Docs сыяктуу колдонмолорду дил баян жазуу үчүн колдонгонсуз го? Бул "дил баян жазуу чөйрөсү" деп айтсак болот.  

Программисттер үчүн IDE деп аталган тиркемелер бар, бул Integrated Development Environment дегенди түшүндүрөт. Бул тиркемелер аркылуу биз код жаза алабыз жана аны иштете алабыз.

Бул сабакта биз playcode.io колдонабыз.

Playcode.ioну ачкандан кийин, програма башталаардан мурун бир нече кадамды аткаруу керек:
* Жогорку сол бурчта болгон __script.js__ тышкары бардык файлдарды жабыңыз.
* __script.js__ файлынын ичиндеги бардык текстти өчүрүңүз.
* Жогорку оң бурчтагы __live__ деп жазылган баскычты бир жолу басып өчүрүңүз.

Эгер жогорудагы кадамдарды туура аткарсаңыз, экраныңыз төмөндөгүдөй көрүнүшү керек:
