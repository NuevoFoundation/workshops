## Иш-аракет 1: Жаркыраган LED

### Зымдарды туташтыруу резюмеси

1. LEDдин узун учу (анод) 25J пинге, кыска учу (катод) көк [-] рельске туташтырылат
2. 25Hден кызыл [+] рельске 220 омик резистор
3. Кызыл [+] рельстен Arduino ичиндеги 5Vге туташтыруучу зым
4. Көк [-] рельстен (31Z) Arduino ичиндеги GNDге туташтыруучу зым
5. Ардуинодон USB аркылуу туташтырыңыз

### Код

Окуучулар төмөнкү баралышы керек: **File > Examples > 01.Basics > Blink**

Төмөнкү код Blink мисалынын функционалдык бөлүгүн көрсөтөт. Окуучулар жүктөгөн толук мисал кошумча комментарийлер жана автордугу менен келет.

```c++
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
```

### Негизги түшүнүктөр

- `setup()` бир гана жолу Arduino иштей баштаганда аткарылат
- `loop()` түбөлүк үзгүлтүксүз иштей берет
- `pinMode()` бир пинди INPUT же OUTPUT катары белгилейт
- `digitalWrite()` бир пинди HIGH (күйгүзүлгөн) же LOW (өчүрүлгөн) кылат
- `delay(1000)` 1000 миллисекундга (1 секунда) токтоп турат

### Кошумча кыйынчылык жообу

Бул иш-чара мындай деп сурайт: "Убакытты өзгөртүү үчүн эмнени өзгөртсө болот?" Жооп: `delay(1000)` ичиндеги санды өзгөртүңүз. Мисалы, `delay(500)` LEDди эки эсе ылдамыраак күйгүзүп-өчүрөт. 1000 миллисекунд = 1 секунд, ошондуктан 10 мүнөт = 600000 миллисекунд.

## Иш-аракет 2: Жашик (джойстик) жана сериалдуу чыгуу

### Зымдарды туташтыруу резюмеси

1. Жойстиктин GNDсы Arduino GNDге
2. Жойстиктин +5Vсы Arduino 5Vге
3. Жойстиктин VRxы аналогдук A0 пинге
4. Жойстиктин VRyы аналогдук A1 пинге
5. Жойстиктин SWсы сандык 2-пинге
6. Ардуинодон USB аркылуу туташтырыңыз

### Код

```c++
//www.elegoo.com
//2016.12.09

// Arduino пиндери
const int SW_pin = 2; // которгуч (switch) чыгарууга туташкан сандык пин
const int X_pin = A0; // X чыгарууга туташкан аналогдук пин
const int Y_pin = A1; // Y чыгарууга туташкан аналогдук пин

void setup() {
  pinMode(SW_pin, INPUT);
  digitalWrite(SW_pin, HIGH);
  Serial.begin(9600);
}

void loop() {
  Serial.print("Которгуч:  ");
  Serial.print(digitalRead(SW_pin));
  Serial.print("\n");
  Serial.print("X багыты: ");
  Serial.print(analogRead(X_pin));
  Serial.print("\n");
  Serial.print("Y багыты: ");
  Serial.println(analogRead(Y_pin));
  Serial.print("\n\n");
  delay(500);
}
```

### Негизги түшүнүктөр

- `Serial.begin(9600)` 9600 бод ылдамдыгындагы сериалдуу байланыш ачат
- `Serial.print()` текстти Serial Monitorго жиберет (Ардуино IDEде чоңойткуч иконкасын басыңыз)
- `analogRead()` аналогдук пинден 0ден 1023кө чейинки маанини окуйт
- `digitalRead()` сандык пинден HIGH (1) же LOW (0) окуйт
- `digitalWrite(SW_pin, HIGH)` 2-пинге ички тартуучу резисторду күйгүзөт, андыктан которгуч басылбаса HIGH же басылса LOW болот
- Жойстиктин борбордук абалы X=490, Y=490 чамасында болот

### Күтүлгөн сериалдуу чыгаруу

Жашик борбордук абалда болгондо, студенттер төмөнкүдөй маани табышы керек:
```
Которгуч:  1
X багыты: 490
Y багыты: 490
```

Жашикти жылдыруу X жана Y маанилерин (0-1023 диапазонунда) өзгөртөт. Жашик кнопкасын басуу Которгучту 1ден 0 ге өзгөртөт.
