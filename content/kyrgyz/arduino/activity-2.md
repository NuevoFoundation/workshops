## Джойстикти Туташтыруу

Сиз программадан (чыгуулардан) сигналдарды түзүп, аларды LEDдерди башкаруу үчүн кантип колдонууга болорун түшүнгөндөн кийин, эми система үчүн динамикалык киргизүү маалыматтарды кантип алуу керектигин карап чыгалы. Бул аракетте биз видео оюн консолдорунда колдонулган аналогдорго окшош джойстикти колдонобуз.

![Alt Text: Джойстик модулу үчүн схема](../img/act2_Joystick.png)

1. Джойстиктеги GNDти бир учу туташтыруучу зым аркылуу Elegoo'нун GND чыгышына туташтырыңыз.
2. Джойстиктеги +5Vни бир учу туташтыруучу зым аркылуу Elegoo'нун 5V чыгышына туташтырыңыз.
3. Джойстиктеги VRxти бир учу туташтыруучу зым аркылуу Elegoo'нун A0 (аналог абалы 0) чыгышына туташтырыңыз.
4. Джойстиктеги VRyни бир учу туташтыруучу зым аркылуу Elegoo'нун A1 (аналог абалы 1) чыгышына туташтырыңыз.
5. Джойстиктеги SWти бир учу туташтыруучу зым аркылуу Elegoo'нун 2 (сандык абал 2) чыгышына туташтырыңыз.
6. Arduino тактасын USB аркылуу компьютериңизге туташтырып, Arduino IDE тиркемесин ачыңыз.

## Аналогдук Кирүүлөрдү Таанып жана Басып чыгаруу
Биз кайрадан программаларыбыз үчүн үлгү коддорду колдонобуз. Бул жолу аны Elegoo вебсайтынан алабыз. Төмөндөгү кодду Arduino IDE'ге көчүрүңүз.
``` c++
//www.elegoo.com
//2016.12.09

// Arduino пиндеринин номерлери
const int SW_pin = 2; // бириктирилген которгуч чыгуучу сандык пин
const int X_pin = A0; // X чыгуучу сигналга бириктирилген аналог пин
const int Y_pin = A1; // Y чыгуучу сигналга бириктирилген аналог пин

void setup() {
  pinMode(SW_pin, INPUT);
  digitalWrite(SW_pin, HIGH);
  Serial.begin(9600);
}

void loop() {
  Serial.print("Которгуч:  ");
  Serial.print(digitalRead(SW_pin));
  Serial.print("\n");
  Serial.print("X-оӊдун белгилери: ");
  Serial.print(analogRead(X_pin));
  Serial.print("\n");
  Serial.print("Y-оӊдун белгилери: ");
  Serial.println(analogRead(Y_pin));
  Serial.print("\n\n");
  delay(500); 
}
```
7. Эми программаны Arduino'га өткөрүп берүү үчүн "жүктөө" түймөсүн басыңыз.
8. Экрандын жогорку оң бурчунда жайгашкан “Serial Monitor” деген түймөнү басып, консоль терезесин ачыңыз.

9. Джойстикти кыймылдатканыңызда X жана Y маанилери кантип өзгөрүп жатканын байкаңыз.
