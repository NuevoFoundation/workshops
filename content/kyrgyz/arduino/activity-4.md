## Байланыш схемасы

LEDдерге сигналдарды чыгарып берүү боюнча жакшы түшүнүк алганыңыздан кийин, текстти жөнөкөй дисплей менен чыгарып көрүп көрөлү. Дисплейдин жарыктыгын чектөө үчүн 1 гана резистор (5K) колдонулат. Төмөнкү схемага ылайык, инструкциясыз эле туташтырып көрүңүз.

![Alt Text: Elegoo жана LCD дисплейдин байланыш схемасы](../img/LCD-wiring.png)

## Код:
``` c++

/*
  LiquidCrystal Library - Hello World

  16x2 LCD дисплейди колдонууну көрсөтөт. LiquidCrystal
  китепканасы Hitachi HD44780 айдоочу менен шайкеш келген бардык LCD дисплейлер үчүн иштейт.
  Алар абдан көп кездешет, жана аларды 16-пин интерфейстери менен таанууга болот.

  Бул скетч LCD'ге "Hello World!" текстин чыгарат
  жана убакытты көрсөтөт.

  Схема:
 * LCD RS пини сандык пинге 7ке
 * LCD Enable пини сандык пинге 8ке
 * LCD D4 пини сандык пинге 9ка
 * LCD D5 пини сандык пинге 10ке
 * LCD D6 пини сандык пинге 11ге
 * LCD D7 пини сандык пинге 12ге
 * LCD R/W пини жерге (ground)
 * LCD VSS пини жерге (ground)
 * LCD VCC пини 5Vке
 * 10K резистор:
 * учтары +5Vке жана жерге (ground)
 * борбору LCD VO пинине (pin 3)

 Китепкана башында 2008-жылдын 18-апрелинде кошулган

// китепканада кодду кошуңуз:
#include <LiquidCrystal.h>

// интерфейс пиндеринин номерлери менен китепкананы инициализациялаңыз
LiquidCrystal lcd(7, 8, 9, 10, 11, 12);

void setup() {
  // LCD'нин колонналар жана саптар санын орнотуңуз:
  lcd.begin(16, 2);
  // LCD'ге билдирүү басып чыгаруу.
  lcd.print("Hello, World!");
}

void loop() {
  // курсорду колонна 0ге, сап 1ге орнотуу
  // (эскертүү: сап 1 экинчи катар, анткени эсеп 0ден башталат):
  lcd.setCursor(0, 1);
  // баштандан бери өткөн секунддарды басып чыгаруу:
  lcd.print(millis() / 1000);
}
