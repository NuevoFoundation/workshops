### Файлдарыбызга кимдин жеткиси болушун чектей алабызбы?

Колдонуучуларга файлдарга "уруксаттарды" берүүнүн аркасында.

Уруксаттар компьютер үчүн файлдарга кимдин жеткиси бар экенин жана алар файлдар менен эмне жасай алары тууралуу чечим кабыл алуучу ыкма болуп саналат.

Linux'та колдонуучу файлдан үч түрдүү мүмкүнчүлүктөрдү сурашы мүмкүн: "окууга (read)", "жазууга (write)" же "аткарууга (execute)".

{{% notice note %}}

"Окуу" уруксаты деген колдонуучу файлды ачып, окуй аларын билдирет. "Окуу" уруксаты көбүнчө `r` символу менен белгиленет.

"Жазуу" уруксаты деген – колдонуучу файлды ачып, ага жазуу жүргүзө алат дегенди билдирет. Бул, ошондой эле, файлдын атын өзгөртүүнү же аны файл системасында башка жерге жылдырууну камтыйт. "Жазуу" уруксаты көбүнчө `w` символу менен белгиленет.

"Аткаруу" уруксаты файлды программа катары иштетүүгө аракет жасоо мүмкүнчүлүгүн билдирет. "Аткаруу" уруксаты көбүнчө `x` символу менен белгиленет.

{{% /notice %}}

### Файлдарыбыз канчалык коопсуз экенин кайдан билебиз?

Бизге белгилүү бир буйрук файлдарыбыз канчалык коопсуз экенин көрүүгө жардам бере алабы?  
Керек болсо мурунку нерселерди кайра кайталап көрүңүз!

![ls -l буйругу](../images/Act5.1.png?classes=border,shadow)

Биз уруксаттарды күткөндөй өзгөрттүкпү деп текшерүүнү улантуу үчүн ошол буйрукту колдоно беришибиз керек.

### Анда файлдарды кантип уруксаттар менен коргойбуз?

```
chmod u=rwx g=rx o=x file1
```

`chmod` буйругу файлдарыңыздын уруксаттарын өзгөртүү үчүн колдонулат ("Change Mode" дегенди билдирет) жана төмөнкү үч колдонуучулар тобу үчүн иштейт:

- файлдын <b>u</b> колдонуучусу жана ээси
- файлга жеткиси бар адамдар тобунун <b>g</b> мүчөлөрү
- <b>o</b> башкасы, же башка каалаган адам

Бул топторго төмөнкү иштерди аткарууга уруксат берүү үчүн өзгөртүүлөр киргизилиши мүмкүн:

- <b>Окуу</b>
- <b>Жазуу</b>
- <b>Аткаруу</b>.

### Өзүңүз аракет кылып көрүңүз!

Эми, файлдарыбыздын уруксаттарын өзгөртүүгө аракет кылалы. Файлга биздин тобубуздан сырткаркы эч ким жана өзүбүздөн башка эч ким кире албай турган кылгыбыз келет. Бул үчүн кантип жасайбыз?

![chmod буйругу](../images/Act5.2.png?classes=border,shadow)

#### Кызыктуу маалымат: Кыска жол!

`chmod` жөнөкөй сандык буйруктар менен да колдонулушу мүмкүн. Бул буйруктар төмөнкүдөй жазылат:

```
chmod 751 [файлдын атын киргизиңиз]
```

Сандар колдонуучуларга "окуу", "жазуу" жана "аткарууга" уруксат берүү сыяктуу маанилерди түшүндүрөт.  
Бул сандардын калганы кайсы уруксаттарды берет?

| Сан |         Мааниси          |
| :--: | :----------------------: |
|   7   | окуу + жазуу + аткаруу  |
|   6   |      окуу + жазуу       |
|   5   |     окуу + аткаруу      |
|   4   |          окуу           |
|   3   |    аткаруу + жазуу      |
|   2   |          жазуу          |
|   1   |        аткаруу          |
|   0   |     уруксат жок         |
