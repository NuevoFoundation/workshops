### Файлдарыңызды коопсуздаңыз, алар кайра бузулуп калбашы үчүн

`tar` бул архивделген файлдарды түзүү жана чыгарып алуу буйругу.

{{% notice info %}}
Архив бул бир нече файлдарды камтыган коллекция. Архив файл бир же бир нече файлдардын кысылган маалыматтарын сактайт.

`zip` бул файлдардын топтомун кысуу буйругу. Форматы: `zip [zip файлдын аты] [кысууга керек файлдардын аттары]`

{{% /notice %}}

Форматы: `tar [файлдардын аттары]`.

| белгилер (flags) | Колдонулушу                          |
| :----            | :----------------------------------  |
| -c               | архив түзөт                          |
| -x               | архивди чыгарат                      |
| -f               | берилген аталыштагы архив түзөт      |

`tar` колдонуунун жардамы менен `files` папкаңызды коопсуз кыласыз! Сиз архивди `files.tar.gz` деген аталышта түзүшүңүз керек.
