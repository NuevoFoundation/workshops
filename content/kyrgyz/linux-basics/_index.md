**Операциялык система** (OS) – бул компьютердин жабдуулары менен сиздин араңыздагы интерфейс катары кызмат кылуучу программалык камсыздоо. Ар бир компьютерде жок дегенде бир программаларды, мисалы, браузериңизди иштетүү үчүн колдонулчу OS болушу керек!. OS сизге компьютердин тилин билбестен, аны менен баарлашууга жардам берет.

Microsoft Windows үйдө колдонууга эң белгилүү операциялык система болушу мүмкүн. Дагы бир жалпы түрү Apple macOS болушу мүмкүн. Linux дагы бир операциялык система! Ал иштеп чыгуучулар тарабынан анын көп функционалдуулугу үчүн кеңири тандалат. Көптөгөн варианттар бар, бирок бүгүн биз Linux-базасындагы OS, Kali Linux дегенди колдонобуз. Бул коопсуздук адистери жана хакерлер арасында популярдуу OS!

Windows, macOS жана Linux арасындагы эң чоң айырмачылыктар алардын кайсы иштерге эң ылайыктуу болгонунда. Windows мультимедиа жана оюндар үчүн идеалдуу! macOS Windows менен Linuxтун ортосунда турат. Ал дагы мультимедиа үчүн эң сонун, бирок бардык оюндарды колдобойт. Linux адатта программалоо жана серверлерди уюштуруу үчүн жакшыраак.
