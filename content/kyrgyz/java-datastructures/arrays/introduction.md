Массивдер — бул маалымат структурасы, анда ар бир элемент сандык иретте жайгашкан жана ар бир элемент өзүнүн позиция номери менен көрсөтүлөт. Java тилинде бул элементтердин ар бири бир типте болот (`String`, `int`, `double`, ж.б.) жана нөлдөн индекстелген, демек, массивдеги биринчи элемент `0` номеринен башталат, экинчи элемент `1` менен, ошентип уланат.

![image](../img/array.png)

Массивдер тууралуу көбүрөөк сүйлөшүүдөн мурун билүү керек айрым маанилүү терминдерди карап чыгалы:

- Массивдеги элементтердин саны массивдин **узундугу** деп аталат.
- Массивдеги жеке элементтердин тиби массивдин **негизги тиби** деп аталат.
- Массивдеги элементтин позиция номери ошол элементтин **индекси** деп аталат.

Биздин максат үчүн, тиркемебиздеги ар түрдүү ресторандардын аталыштарын камтый алган массивди түзгүбүз келет. Тасавур кылгыла, биздин программа миң ар башка ресторандын аттарын иштеп чыгышы керек. Бизге бардык бул маалыматты жөнгө салыш үчүн ыкма керек болот. Массив маалымат структурасы жок болсо, бул маселени ар бир ресторан үчүн миң башка өзгөрмөнү түзүү аркылуу чечүүгө туура келет, жана ар бир ресторандын атын басып чыгаруу сыяктуу жөнөкөй нерсени аткаруу үчүн 1000 басып чыгаруу буйругу керек болмок. Бул чоң сыноо болмок. 

Ошону менен бирге, массивдер бизге ушул эле иштерди бир кадамда жасоого мүмкүнчүлүк берет. Массив жөнөкөй бир өзгөрмө, бирок анын ичинде 1000 ресторандын аты бар.

![image](../img/array2.png)

Массивдин **узундугу** 1000 болот, анткени анын ичинде 1000 жеке ат бар. Массивдин **негизги тиби** `String` болот, анткени массивдеги элементтер саптар. Биринчи ат **индекс** `0` деп аталган жерде жайгашат, экинчи ат индекс `1`де, жана ушинтип уланат, миңинчи ат индекс `999`де болот.
