## Тапшырма 2: Массивди сорттоо!

Мәзирдеги ар бир нерсеге карата баалар толук башаламандыкта! Бизге массивди эң кичинеден эң чоңго карай сорттоого жардам бериңиз.

{{% notice tip %}}
1. Массивди сорттоонун жолун ойлонуп көрсөңүз (көптөгөн жолдору бар)!
2. Мисалды караңыз!
{{% /notice%}}

Эгерде бизге төмөндөгү массив берилип жатса, 
```js javascript
int[] cost = {100,90,50,60,20,1,3};
```

анда биз төмөнкүдөй жыйынтык алышыбыз керек:
```js javascript
int[] sorted = {1,3,20,50,60,90,100};
```
