## Бинардык Арактар

Арактар - бул маалымат түзүлүштөрүнүн өзгөчө түрү, анткени алар бири-бири менен байланышы бар түйүндөрдүн жыйындысынан түзүлөт. Башка маалымат түзүлүштөрүндөй жаңы, жалпы аракты түзүү үчүн даяр баштапкы функция жок. Оңой болуш үчүн, биз өзгөчө түрдөгү **Бинардык Арактарды** карайбыз, алар түйүндөр кайсы жерде жайгашышы керектиги боюнча так эрежелерге ээ.

Бинардык арактын эрежелери:
* ар бир түйүндө так эки чети бар: сол түйүн жана оң түйүн
* сол жактагы түйүндөр азыркы түйүнгө караганда кичине
* оң жактагы түйүндөр азыркы түйүнгө караганда чоң

Мурун каралган ароо бинардык арактын мисалы болуп саналат. Ар бир түйүндү карап чыгып, анын эрежелерди сактап жатканын текшерип көрүңүз!

## Элементтерди Издөө

Код жана ишке ашырууну караганга чейин, бинардык арак элементти кантип издей турганын карап көрөлү. Арактагы элементтерди карап жатканда биз ар дайым тамыр түйүндөн баштайбыз, ал бинардык аракта маалыматтардын ортосуна жакын болушу керек.

Тамырдан баштаган соң, маанини карап чыгып, өзүбүздөн "биз издеп жаткан маани бул мааниден кичине, барабар же чоңбу?" деп сурайбыз. Эгерде маани барабар болсо, сонун! Биздин сурообуздун жообун таптык. Эгерде керектүү маани учурдагы мааниден кичине болсо, анда сол жактагы түйүнгө өтүп, ошол эле суроону кайрадан беребиз. Эгерде керектүү маани учурдагы мааниден чоң болсо, анда биз оң жактагы түйүнгө өтүп, ошол эле суроону кайрадан беребиз.

Аракетти төмөндөгү мисалдан байкап көрүңүз. Бул мурунку арактардын окшош талдоосу жана биз #9 маанисин табууну каалайбыз.

## Элементтерди Айланып Өтүү

Эми элементтерди издөөнү концепциялык жактан түшүндүк, жыйынтыкта издөөлөр кайталана турган бир эле операция экени айдан ачык. Бул деген, эгер биз операцияны туура программага киргизсек, анда бүтүндөй издөө алгоритмин жазып чыгууга болот.

Төмөндө келтирилгендей аныкталган түйүндөрдү элестетиңиз:
```js javascript
class Node {
    int value;
    Node left;
    Node right;
}
```

Эми биз жогорудагы бөлүмдө айтылган элементти табуу логикасын колдонсок болот. Төмөнкү код бөлүгүн карап көрүңүз:
```js javascript
Node current = root;
if (current.value < desired) {
    current = root.right;
} else if (current.value > desired) {
    current = root.left;
}
```
Бул код бир кадамдан кийинкисине өтүүгө мүмкүндүк берет. Андан соң, биз бул логиканы каалаган маанини тапканга чейин `for` циклде колдоно алабыз.
