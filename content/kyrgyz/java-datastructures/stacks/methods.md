## Стектер

Стек кезекке окшош. Болгону алардын методдорунун аталыштары жана элементтерди алуу ыкмалары айырмаланат.

Стек түзүүдөн мурун, бизге `stack` классын `import` кылуу керек болот. Жумушту жеңилдетүү үчүн, бардык класстарды китепканадан импорттоо үчүн `*` колдонсок болот. Бул төмөндөгүдөй көрүнөт.

```js javascript
// Мында stack классын жана башка класстарды импорттойбуз
import java.util.*;
```

Стекте колдонсо боло турган бир нече методдор бар. Эгер кызыгып жатсаңыз, интернеттен бул методдор тууралуу көбүрөөк маалымат издеп таба аласыз. Бирок, азырынча биз эң маанилүү методдорду гана түшүндүрөбүз: `push()`, `peek()` жана `pop()`.

## Стек түзүү

```js javascript
Stack driver = new Stack();
```

<hr>

## Элементтерди кошуу

Стекке элемент кошуу үчүн, `push()` методун колдонсо болот. Бул `push()` операциясы стекке элементти үстүнө жайгаштырат.

```js javascript
push(1);
push(2);
push(3);

// Элементтери бар стек түзүлөт [3, 2, 1]
```

<hr>

## Элементтерге жетүү

Стектин эң үстүндөгү элементти алуу же биринчи элементти көрүү үчүн, `peek()` методун колдонсо болот. Алынган элемент стекке өзгөрүүсүз калат, ал өчүрүлбөйт.

```js javascript
stack.peek();

// 3тү кайтарат
// Стекте [3, 2, 1] бар
```

<hr>

## Элементтерди өчүрүү

Стектен элементти алып таштоо үчүн, `pop()` методун колдонсо болот. Бул метод аркылуу элемент стектин үстүнөн алынат жана өчүрүлөт.

```js javascript
stack.pop();

// 3тү кайтарат
// Стекте [2, 1] бар
```

<hr>

Бул үч негизги методду түшүнгөндөн кийин, мисал карап көрөлү.

```js javascript
import java.util.*;
public class Driver {
    public static void main(String []args) {
        // Стектин демейки инициализациясы
        Stack stack = new Stack(); 
  
        // Элементтерди кошуу 
        stack.push("Burger King"); 
        stack.push("Subway"); 
        stack.push("Jack in the Box"); 
  
        // Стектеги элементтерди басып чыгаруу 
        System.out.println(stack); 
    }
}
```

Натыйжа:

```js javascript
["Jack in the Box", "Subway", "Burger King"]
```
