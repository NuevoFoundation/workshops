HashMap — бул ачкыч-маани жуптарын камтыган таблица. Ал ар түрдүү ачкычтарды тиешелүү маанилерге "карталап" байланыштырат. HashMap сөздүккө абдан окшойт. Маселен, сиз кайсы бир сөздүн аныктамасын билгиңиз келсе, сөздүктө ошол ачкыч сөздү издеп, анын жанына тиркелген аныктаманы ала аласыз. Сөздүктө сөздөр (ачкычтар) алардын аныктамаларына (маанилерине) карталанат.

HashMap ар кандай түрдөгү маалыматтарды сактай алат. Төмөндө көрсөтүлгөн мисалда адамдар ачкыч болуп, аларга тиешелүү буйрутма маанилери көрсөтүлгөн.

![image](../img/hashmap.png)

Биз сөздүктөн сөздү тапкандай эле, бирөөнүн буйрутмасын түздөн-түз табууга мүмкүнчүлүк алгыбыз келет. "Беа" деп издегенде, HashMap анын буйрутмасы: «Арепа» экенин кайтарат. Кийинки бетте биз HashMap'тын кээ бир кеңири колдонулган ыкмаларын карап чыгабыз.
