## Тапшырма 1: Hashmap колдонуу аркылуу маалыматтарды уюштуруу

Бул туулган күн! Кардар 20дан ашык адамга чоң туулган күн кечесин өткөрүүдө! Ар бир адам өз буйрутмасын берген. Бардык буйрутмаларды иреттүү сактоо үчүн, сиз `String` түрүндөгү hashmap түзүүнү чечтиңиз. Туулган күндүн кыздын аты Изабелла, бирок анын аты тизмеде жок болуп жатат. Изабелланын эмне буйрутма кылганын таба аласызбы?

{{% notice tip %}}
1. Hashmap ыкмаларын эстей аласызбы?
2. Төмөнкү буйрутма үлгүсүнө карап көрүңүз!
{{% /notice%}}

```js javascript
// Hashmapтин учурдагы үлгүсү
HashMap<String, String> order = new HashMap<String, String>();

// ачкыч, маани
order.put("Justin", "Sprite");
order.put("George", "Coke");
order.put("Sam", "Fanta");
order.put("Eva", "Coke");
order.put("Olivia", "Coke");
...
```
