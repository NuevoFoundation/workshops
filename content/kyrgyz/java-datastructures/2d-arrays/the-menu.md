## Ресторан маалыматын сактоо

Келгиле, мурун массив бөлүмүндө түзгөн ресторан массивибизди эстейли. 

![restaurant](../../arrays/img/array2.png)

Көрүнүп тургандай, бул массив колдонмобуз үчүн ар кандай ресторандарды камтыйт. Эми, ар бир ресторанды өзүнүн меню элементтеринин массивин камтый тургандай кылып даярдайлы. Эгер туура жасалса, биздин массивдин `0`-элементинде, "Burger King", өзүнүн тиешелүү меню элементтерин камтышы керек. Бул төмөнкүдөй көрүнүшү мүмкүн:

![burgerkingarray](../img/2darray2.png)

Көрүнүп тургандай, `0`-элемент биздин Burger King массиви болушу керек. 1D массивдер сыяктуу эле, бул массивдин элементтерине нөлдөн баштап кол салабыз. Эгер биз Whopper заказ кылгыбыз келсе, анда жөн эле `Restaurant[0][0]` деп чакырабыз. Бул биздин Burger King массивибизди жана ошол массивдеги биринчи элементти, тагыраак айтканда, Whopper'ди чакырат. Эгер массивге картошка фри кошкубуз келсе, анда `Restaurant[0][2]` деп чакырабыз.

Суроо: Эгер биз апельсин тоогун заказ кылгыбыз келсе жана ал Panda Express массивинин 10-элементинде болсо, аны кандайча чакырууга болот?

Эгер сиз `Restaurant[2][9]` деп жооп берсеңиз, анда туура айттыңыз! Panda Express үчүнчү массив `[2]`, ал эми апельсин тоогу онунчу элемент `[9]`.
