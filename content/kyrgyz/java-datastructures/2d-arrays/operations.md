2D массивдар кадимки массивдар сыяктуу эле иштейт, жана массивдерге колдонгон көптөгөн түшүнүктөрдү же ыкмаларды көп өлчөмдүү массивдерге да колдонууга болот. Кыскача эске салсак, төмөндө 2D массивди кантип инициализация кылуу жана элементке кантип жетүү керектигин көрсөтөбүз:

```js javascript
public static void main(String[] args) { 
    int[][] arr = new int[10][20]; 
    arr[0][0] = 1; 
    System.out.println(arr[0][0]); 
} 
    // 1ди чыгарат
```

Башында түшүнүксүз сезилиши мүмкүн болгон жалгыз татаал бөлүгү — бул 2D массивди кайталоо, бирок бул дагы өтө жөнөкөй. Бир `for` циклинин ордуна, эки `for` циклин колдонобуз. Төмөндө идеяны түшүнүүгө жардам берүү үчүн кыскача мисал келтиребиз.

```js javascript
public static void main(String[] args) { 
    int[][] arr = new int[10][20]; 
    int num = 0;

    // Массивдердин массивинин ичинен кайталоо
    for (int i = 0; i < arr.length; i++) {

        // 2D массивдин ичиндеги жеке массивдерди кайталоо
        for (int j = 0; j < arr[i].length; j++) {

            // Жеке маанилерге жетүү
            arr[i][j] = num;
            num++;
        }
    }
} 
```

Көрүнүп тургандай, биз `arr` аттуу бош массив жараттык. Анда ар бири `20` элементтен турган `10` массив бар. Бардык массивдерди кайталоо үчүн кадимки массивге колдонгон стандарттуу `for` циклин колдонобуз. Бирок, бул жерде өзгөрүү — бул учурда `i`чү массивдин элементтерин кайталап өтүү үчүн экинчи `for` циклин түзүшүбүз керек. Бул мисалда, биз жөн гана `arr[i][j]`га `num`ду коюп, анан `num++` кылабыз.
