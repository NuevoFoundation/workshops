## Тапшырма 1: 2D массивди басып чыгаруу

Төмөндөгү 2D массивде ар түрдүү тамак-аштардын тизмеси бар. Ар бир катар өзүнчө бир түргө таандык. Мисалы, 1-катар негизги тамактардын массиви. 2-катар суусундуктар, ал эми 3-катар десерттер массиви.

```js javascript
String[][] menu = {    
                    { "Гамбургер", "Паста", "Стейк", "Тако" },
                    { "Кола", "Спрайт", "Пепси", "Фанта" },
                    { "Пудинг", "Балмуздак", "Мочи", "Торт" }
                  };
```
Үйрөнгөн нерселериңизди колдонуп, массивди басып чыгарыңыз!
