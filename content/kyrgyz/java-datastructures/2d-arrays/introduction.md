## Эки өлчөмдүү массив деген эмне?

Биз массивдер жөнүндө буга чейин кеңири маалымат алдык. Массив ар кандай типтерди (бүтүн сан, сап, кош сан ж.б.) сактай аларын билебиз, бирок массивдин ичинде массивдерди кармаган массивдер жөнүндө эмне дейсиз?

![image](../img/2darray.png)

Эки өлчөмдүү массивдин тиги сыяктуу типи бар: `int[][]` же `String[][]`, эки жуп квадраттык кашаалар менен. Эки өлчөмдүү массивдин элементтери катарларга жана колонкаларга жайгаштырылат, жана эки өлчөмдүү массивдер үчүн `new` оператору катарлардын жана колонкалардын саны менен белгиленет. Мисалы:

```js javascript
int[][] A;
A = new int[3][4];
```

Бул `int` тибиндеги 3 катар жана 4 колонканын ичинде 12 элементтен турган эки өлчөмдүү массивди түзөт. Массивдер үчүн баштапкы маанилерди пайдаланууга да болот. Мисалы, төмөндө көрсөтүлгөн сүрөттөгүдөй 3x4 өлчөмүндө массив түзгөн билдирмени карап көрүңүз:

```js javascript
int[][] A = {    
                {  1,  0, 12, -1 },
                {  7, -3,  2,  5 },
                { -5, -2,  2, -9 }
            };
```

Эки өлчөмдүү массив үчүн массив баштапкы мааниси `A` массивинин катарларын камап, аларды үтүр менен бөлүп, фигуртук кашааларга камайт. Өз кезегинде, ар бир катар маанилердин тизмегин үтүр менен бөлүп, фигуртук кашааларга камайт. Ошондой эле ушундай синтаксисти төмөндөгүлөрдөй декларациялардан тышкары да колдонууга жол берилет:

```js javascript
A = new int[][] { 
                    {  1,  0, 12, -1 },
                    {  7, -3,  2,  5 },
                    { -5, -2,  2, -9 }
                };
```
                  
Бул нерсе үч өлчөмдүү, төрт өлчөмдүү жана андан да жогорку өлчөмдүү массивдерге табигый түрдө кеңейет.
