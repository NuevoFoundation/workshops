## Өзгөрмөлөр

Бул иш канасын баштаардан мурун, сиз Java өзгөрмөлөрү кантип иштээри жана аларды кантип түзсө болору жөнүндө алдын ала маалыматыңыз болушу керек. [Java негиздери боюнча иш канасын карап чыгуу үчүн бул жерди басыңыз!](https://workshops.nuevofoundation.org/java-basics/) Камсанабаңыз, эгер дагы деле бир аз ишенимиңиз жок болсо! Биз бул темаларды акырындык менен түшүндүрүп кетебиз. Бирок, эгер өзгөрмөлөр эмне экенин такыр билбесеңиз, анда алды менен Java негиздери боюнча иш канасын аяктоону катуу сунуштайбыз.
