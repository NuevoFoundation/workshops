## Replitти Орнотуу!

Бүгүн сиз Java менен маалымат структураларын үйрөнүү үчүн Replitти колдоносуз. Баштоодон мурун Replit аккаунтун түзүшүңүз керек, эгерде сизде аккаунт жок болсо.

Төмөндөгү баскычты басып, Replit аккаунтуна катталыңыз - катталуу үчүн электрондук почта аккаунту керек болот. Эгерде сизде Replit аккаунту бар болсо, анда төмөндөгү баскычты басып аккаунтуңузга кире аласыз.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Replitке Катталуу</a>

<img src="../img/replit-signup.png" height="300" alt="Replit катталуу формасы" />

Андан кийин, бүгүн колдончу Replit консолун ишке киргизүү үчүн төмөндөгү баскычты басыңыз. Экран төмөндөгүдөй көрүнүшү керек.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/HelloWorld" target="_blank">Replitти Ишке Киргизүү</a>

<img src="../img/replit-start-screen.png" height="300" alt="Replit баштапкы экраны" />

Эми Replди fork (көчүрмө) кылып алабыз, бул программаны көчүрүп алуу дегенди билдирет, андан кийин анын ичинде өзгөртүүлөрүбүздү жасай алабыз. Оң жактагы "Fork Repl" баскычын, андан кийин "Fork Repl" баскычын басыңыз.

<img src="../img/replit-fork.png" height="300" alt="Replди көчүрүү" />

Replitти fork кылгандан кийин, сиз төмөндөгүдөй терезени көрөсүз:

<img src="../img/replit-window.png" height="300" alt="Replit терезеси" />

{{% notice warning %}}
Ар бир жолу "Replitти Ишке Киргизүү" деген баскычты көргөнүңүздө, жогорудагы кадамдарды аткарып, replди көчүрүшүңүз керек, андан кийин тапшырманы аткарсаңыз болот. Эгерде replди көчүрүүдө кыйынчылык жаралса, жардам сураңыз!
{{%/notice %}}

Баштоодон мурун, Replit кантип иштей турганын түшүнөлү. `main.java` файлы компьютердин аткаруусу үчүн код же көрсөтмөлөр камтылган. **Run** баскычын басуу менен, сиз компьютерге коддогу көрсөтмөлөрдү аткарууну айтасыз. Коддун иштетүүсүнүн бардык жыйынтыктары төмөнкү ак экранда, **Results** табынын астында көрсөтүлөт.

Маалымат структураларына кандай код жазууну үйрөнүү үчүн, биз Replitти колдонуп көнүгүүлөрдү жасайбыз. **Run** баскычын басып, төмөндөгү тапшырмаларды бүтүрүүгө аракет жасаңыз!

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/introduction" target="_blank">Replitти Ишке Киргизүү</a>
