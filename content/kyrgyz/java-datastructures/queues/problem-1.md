## Тапшырма 1: Жаңы буйрутмалар үчүн кезекти тазалоо

Nuevo Eats'ке жаңы ресторан кошулду! Жаңы буйрутмалар толуп, Кезек буйрутмалар менен толуп кетти! Таколордун популярдуулугу бат эле өсүп, ресторан ашыкча жүктөлүп калды. Ресторанды сактап калуу үчүн бардык элементтерди тазалоо жолун табыңыз!

{{% notice tip %}}
1. Кезекти кантип кыдырып өтсө болот?
2. Кезекти кыдырып жатканда тазалап көрүңүз!
3. Мисалдагы менюну караңыз!
{{% /notice%}}

```js javascript
// Бул тизмени кезекти уюштуруучу катары колдонот.

orders.add("Fish Taco");
orders.add("Beef Taco");
```

## Тапшырма 2: Баалардын минималдуу маанисин табуу үчүн Priority Queue колдонуу

Ресторан буйрутмаларды башкаруу үчүн Priority Queue колдонууда. Ресторан, тамактарды даярдоо үчүн, алардын бааларына жараша буйрутмаларды карагысы келет. Тактап айтканда, алардын тизмесиндеги n-минималдуу бааны табууну каалашат. Алардын буйрутма кезегин карап, n-минималдуу бааны кайтарган функцияны жазыңыз.

{{% notice tip %}}
1. Тизмени тартипке келтирүүнү кантип камсыздайсыз?
2. Минималдуу бааны табууну эмне жеңилдетет?
3. Эгер алар 5-минималдуу (же эң төмөнкү) бааны издеп жатышсачы?
{{% /notice%}}
