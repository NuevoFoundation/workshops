## Үстөмдүк кезек

`PriorityQueue` объекти иштелип чыгышы керек болгон учурда колдонулат. Бул учурда, биз кардар канча убакыт күтүп жаткан болсо, ошого жараша кезекти ирээттөөнү каалайбыз. Кезек биринчи кирген–алгач чыккан алгоритмин карманат, бирок кээде кезектин элементтери үстөмдүккө жараша иштетилиши керек болот; дал ушул учурда `PriorityQueue` колдонулат. Үстөмдүк кезек үстөмдүк кочкору (heap) негизинде түзүлөт. Үстөмдүк кезегинин элементтери табигый иретке жараша ирээттөө же кезек түзүлгөн учурда берилген Comparator'го жараша ирээттөлөт, бул кайсы конструктор колдонулганына көз каранды.  

Кезекти түзүүдөн мурун, биз `PriorityQueue` классын `import` кылышыбыз керек. Жердеги иштерди жеңилдетүү үчүн, биз, `*` белгисин колдонууну тандап, китепканадагы бардык класстарды импорттой алабыз. Бул төмөнкүдөй көрүнөт:

```java
// PriorityQueue жана башка класстарды импорттойт
import java.util.*; 
```
Үстөмдүк кезек үчүн колдонууга болуучу ар кандай ыкмалар бар жана эгерде кызык болсоңуз, ыкмаларды өзүңүз изилдеп көрүңүз. Бирок, биз азыр эң маанилүү ыкмалар тууралуу гана сөз кылмакчыбыз: `add()`, `peek()`, жана `poll()`.

<hr>

## Үстөмдүк кезегин түзүү
    
```java
Queue<Integer> orders = new PriorityQueue<>();
```

Үстөмдүк кезегин ирээттөөнүн бир нече ыкмасы бар жана аны кандай ишке ашырууну өзүңүз чечесиз.

<hr>

## Элементтерди кошуу

Сиз элементтерди `add()` ыкмасы аркылуу кошо аласыз. `PriorityQueue` сиз үчүн автоматтык түрдө элементтерди ирээттейт. Анын демейки маани берүүчү ирээти - бул объекттин табигый ирети болот, бирок сиз аны каалаганыңыздай өзгөртө аласыз.

```java
add(1);
add(2);
add(3);

// [1, 2, 3] элементтер менен кезек түзөт
```

<hr>

## Элементтерди жетүү

`peek()` ыкмасы жогорку элементти алып салбастан кайтарат.

```java
queue.peek();

// 1ди кайтарат
// Кезекте [1, 2, 3] турат
```

<hr>

## Элементтерди алып салуу

`poll()` ыкмасы жогорку элементти кайтарып, аны кезектен өчүрөт.

```java
queue.poll();

// 1ди кайтарат
// Кезекте [2, 3] калат
```

<hr>

Ушул үч ыкмаларды эске алуу менен мисалга өтөлү.

```java
import java.util.*;
 
class PriorityQueueDemo {
   
      // Башкы ыкма
    public static void main(String args[]) {
        // Бош үстөмдүк кезекти түзүү
        PriorityQueue<Integer> pQueue = new PriorityQueue<Integer>();
 
        // Кезекке add() аркылуу элементтерди кошуу
        pQueue.add(60);
        pQueue.add(30);
        pQueue.add(10);
 
        // Үстөмдүк кезектин жогорку элементин басып чыгуу
        System.out.println(pQueue.peek());
 
        // Үстөмдүк кезектин жогорку элементин басып чыгуу
        // жана аны контейнерден өчүрүү
        System.out.println(pQueue.poll());
 
        // Жогорку элементти дагы бир жолу басып чыгуу
        System.out.println(pQueue.peek());
    }
}
```

Бизде күтүү убактысы башкача болгон үч кардар бар: `10`, `30` жана `60`. Компилятор кандай натыйжа көрсөтөт деп ойлойсуз?

Кодду аз убакытка талдап көрөлү. Биринчи сап үчүн биз `pQueue.peek()`ди чакырабыз. `peek()` эмнени кылат? Peek жөн гана жогорку турган элементти кайтарат. Чырмалып жетиштүү болуп, биз табигый ирет менен ирээттелгенде, жогорку элемент бул эң кичинекей элемент, демек `10`.

`pQueue.poll()`чы эмне болот? Ал буга чейин айтылгандай peek менен окшош натыйжа берет, бирок бул жолу кезектеги жогорку элементти өчүрүп салат, демек `10`.

Эгерде дагы `peek()`ди чакырсак эмне болот? Эми `10` жок болгондуктан, бул жолу `30` кайтарып берет.

Акыркы натыйжа төмөнкүчө болот:

```java
10
10
30
```

Токтоңуз? Биз кезектин башында эң узак убакыт күтүп жаткан адамдарды коюуну каалаганбыз, туурабы? Бирок көрүнүп тургандай, кезек эң кичине элементтерди биринчи чыгарат, биз болсо эң чоң элементти каалайбыз. Муну аткаруу үчүн биз кезекти бир аз башкача түзүшүбүз керек. `Collections.reverseOrder()` кезекти жөн эле тескери иреттейт. Мындайча!

```java
PriorityQueue<Integer> pQueue = new PriorityQueue<Integer>(Collections.reverseOrder());
```
Эми биздин ишке ашыруу туруктуураак болот.

```java
import java.util.*;
 
class PriorityQueueDemo {
   
      // Башкы ыкма
    public static void main(String args[]) {
        // Бош үстөмдүк кезекти түзүү
        PriorityQueue<Integer> pQueue = new PriorityQueue<Integer>(Collections.reverseOrder());
 
        // Кезекке add() аркылуу элементтерди кошуу
        pQueue.add(60);
        pQueue.add(30);
        pQueue.add(10);
 
        // Үстөмдүк кезектин жогорку элементин басып чыгуу
        System.out.println(pQueue.peek());
 
        // Үстөмдүк кезектин жогорку элементин басып чыгуу
        // жана аны контейнерден өчүрүү
        System.out.println(pQueue.poll());
 
        // Жогорку элементти дагы бир жолу басып чыгуу
        System.out.println(pQueue.peek());
    }
}
```
