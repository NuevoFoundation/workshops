## Негизги Түшүнүктөр

| Түшүнүк | Python Коду | Окуядагы максаты |
|---------|-------------|------------------|
| Текст чыгарып берүү | `print("text")` | Окуяны окурманга айтуу |
| Колдонуучудан киргизүү алуу | `input("question")` | Окурманга тандоо мүмкүнчүлүгүн берүү |
| Өзгөрмөгө сактоо | `choice = input(...)` | Окурмандын тандоосун эсинде сактоо |
| Чечим кабыл алуу | `if` / `else` | Тандоого жараша окуяны өзгөртүү |

## Нувинин Толук Окуясы

Бул мастер-класстагы Нувинин сүрөттөлмөсүнүн негизинде иштелип чыккан иштеп жаткан мисал:

```python
# Нувинин Өзү Тандаган Окуя Оюну

print("=" * 40)
print("Нувинин Окуясы!")
print("=" * 40)
print()
print("Нуви мектепте робототехника боюнча практиканы жаңы эле бүтүрдү.")
print("Эми үйгө барчу убакыт келди!")
print()

# Тандоо 1: Үйгө кантип баруу керек
choice1 = input("Нуви жөө барабы же велосипед тебеби? 'жөө' же 'велосипед' деп териңиз: ")

if choice1 == "жөө":
    print()
    print("Нуви жөө барууну чечти.")
    print("Жолдо Нуви кооз күчүктү жолуктурат!")
    print("Нуви күчүктү эркелетип, анан жолун улантат.")
    print("Нуви үйүнө бактылуу болуп келип жетет.")
elif choice1 == "велосипед":
    print()
    print("Нуви велосипедге отуруп, үйүнө барат.")
    print("Шамал абдан сонун сезилип жатат! Нуви абдан тез жүрдү.")
    print("Нуви рекорддук убакытта үйүнө жетти!")
else:
    print()
    print("Нуви тандоо кыла албай, жөө бара берди.")

print()
print("Нуви акыры үйүнө келди! Достору сыртта жүрүшөт.")
print()

# Тандоо 2: Достору менен эмне кылуу керек
choice2 = input("Нуви футбол ойнойбу же сүзгөнү барабы? 'футбол' же 'сүзүү' деп териңиз: ")

if choice2 == "футбол":
    print()
    print("Нуви жана достору парктта футбол ойношот!")
    print("Нуви жеңүүчү топту киргизет!")
    print("Баары кол чаап, шыктандырды! Сонун күн!")
elif choice2 == "сүзүү":
    print()
    print("Нуви жана достору талаага сүзүүгө барышат!")
    print("Алар сууда чачыранды болуп, жакшынакай саат өткөрүшөт.")
    print("Нуви чоң секирик жасайт! ЧАК-ЧАК!")
else:
    print()
    print("Нуви жөн гана достору менен убакыт өткөрүүнү чечти.")

print()
print("Кандай сонун күн! Бүтү. ")
```
