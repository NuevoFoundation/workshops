`setTempo()` функциясы жалпы долбоордун темпин коюуга мүмкүнчүлүк берет. Темп — бул музыкалык чыгарманы ойноонун ылдамдыгы. Долбоордун темпин өзгөртүү ар түрдүү музыкалык стилдерди жаратууга мүмкүндүк берет. `setTempo` функциясындагы санды өзгөртүп, эмне болорун байкап көрүңүз! Сиз колдонгон сан 45тен 220га чейин болушуна ынаныңыз. Төмөндө пайдалана турган темптердин айрым сунуштары берилген.

<img src="../img/img-tempo1.png" height="200"/>

Азыр биз темпти коюп бүтүрдүк, үндөрдү кошуу убактысы келди. Муну ишке ашыруу үчүн, биз `fitMedia()` функциясын колдонушубуз керек. Жаңы кодду `setTempo()` функциясынын астына жайгаштырабыз.

## Иш аракет 1

1. Программадагы курсорду `setTempo()` функциясынын астына жайгаштырыңыз.

<img src="../img/screenshot-cursor.png" height="200"/>

2. Код редакторунун сол тарабындагы **API** тизмесин төмөн карай жылдырып, `fitMedia()` функциясын табыңыз.

<img src="../img/screenshot-find-fitmedia.png" height="400"/>

3. `fitMedia()` функциясынын оң четиндеги **Пасте** (Paste) иконкасын басып, функцияны `setTempo` функциясынын астына киргизиңиз.

<img src="../img/icon-paste.png"/>

4. Функцияны пасте кылганда, Earsketch айрым тексттерди орун толтуруучу (placeholder) катары жаратарын байкайсыз. Бул тексттерди кийин алмаштыруу керек болот. Мындай тексттер `параметрлер` деп аталат.

<img src="../img/screenshot-fitmedia.png" />

Төмөндөгү параметрлер үчүн өзүңүздүн маанилериңизди көрсөтө аласыз:

- `sound` - \'Sounds\' панелине кирип, жаккан үндү тандаңыз.
- `track` - Каалаган оң санды трек номери катары тандаңыз.
- `start/end` - Бул параметрлер өлчөмдөр менен эсептелет. Өлчөм — бул белгилүү бир соккулардын саны менен байланышкан убакыт сегменти.

Эгер кайсы маанилерди тандоо керектиги тууралуу белгисиз болсоңуз, төмөнкү вариантты колдонуп көрүңүз:

- `fitMedia(YG_TRAP_ELECTRIC_PIANO_FILTERED_1, 3, 1, 17)`

Сиздин кодуңуз азыр мындай көрүнүшү керек:

```python
from earsketch import *

setTempo(120)
fitMedia(YG_TRAP_ELECTRIC_PIANO_FILTERED_1, 3, 1, 17)
```

{{% notice warning %}}
Функциянын чакыруусунда чоң-кичинесине көңүл буруңуз. Көптөгөн программалоо тилдери, анын ичинде Python, чоң-кичине тамгаларды сезимтал деп эсептейт. Бул туура эмес чакырууларга алып келиши мүмкүн. Мисалы: `fitMedia()` менен `FitMedia()` бирдей эмес.
{{% /notice %}}
