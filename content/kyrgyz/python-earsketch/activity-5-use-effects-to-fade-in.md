Эми сиздин ырыңызда бир эффект кошулган болсо, ырдын кириш бөлүгүн жай көрсөтүүнү аракет кылалы.

Иш-аракет 4тө биз `setEffect` функциясын колдонуп, бир жолу бүтүндөй ырдын узактыгында белгилүү бир трекке эффект кошконбуз, бирок эгер сиз ырдын белгилүү бир бөлүктөрүнө гана эффект кошкуңуз келсе эмне болот? Ошондо, `setEffect` функциясын көбүрөөк параметрлер менен колдонуп көрүңүз!

<img src="../img/screenshot-seteffect2.png" alt="Коду үзүндүсү" width="60%"/>

- `startValue`: Параметрге колдонулган баштапкы мааниси
- `start`: Баштапкы маани коюла турган өлчөм
- `endValue`: Параметрдин аягындагы мааниси
- `end`: Аяктоо маани коюла турган өлчөм

`setEffect`дин бул версиясы ырдын белгилүү бөлүгүнө *автоматташтыруу* жасоого мүмкүндүк берет. Автоматташтыруу эффекттин маани-барктарын убакыттын өтүшү менен өзгөртүү ыкмасы. Автоматташтыруунун бир мисалы - ырды жай илмек менен баштоо (fade in) же аяктатуу (fade out). Бул үчүн, **VOLUME** `type`тагы **GAIN** `parameter`инин үн көлөмүн убакыттын өтүшү менен өзгөртүш керек. Мисалы, эгерде `startValue` -60 db болуп, `endValue` 0 db болсо, ыр убакыттын өтүшү менен жайдык берип башталып жаткандай угулат. Эффекттин баштапкы чекитин жана узактыгын орнотуу үчүн, `start` жана `end` параметрлерин көрсөтүңүз.

![DJ Nuvi](https://media.giphy.com/media/OTk8FTCvQ5WQQfJqVf/giphy.gif)

## Ырыңызга дагы бир setEffect функциясын кошуу

1. Программаңызга дагы бир `setEffect` функциясын кошуп, чакырууда бардык 7 параметрлер киргизилгенине ынануу керек.
2. `type`ти VOLUME деп белгилеңиз.
3. "Ар бир Эффект Толугу менен Түшүндүрүлгөн" маалымдама колдонмосун колдонуп, `VOLUME` үчүн кайсы параметрлер бар экенин караңыз. Аудио клиптин үнүн өзгөртүү үчүн GAIN `parameter`ин тандаңыз.
4. Эгерде бир нерсенин үнү акырындык менен көбөйүп жаткандай болсун десеңиз, үнүн баштапкы минималдуу мааниден баштап, ага 0 децибелге чейин көтөрүп коюу керек. Бул үчүн, effectStartValue параметрин өтө төмөн мааниге, ал эми effectEndValue параметрин жогору мааниге тууралаңыз.

{{% notice tip %}}
*Ишарат:* Үн децибел менен өлчөнөт. Децибелдин саны оң болгондо, үнү катуураак болот. 0 децибелден ашпоого аракет кылыңыз.
{{% /notice %}}

5. Үнүнүн жай башталуу эффектин ишке ашырууну каалаган баштапкы жана аяктоочу чекиттерин көрсөтүү үчүн, `start` жана `end` параметрлерине маани бериңиз.

Программаңыздын коду төмөнкүлөргө окшош болушу керек:

```python
from earsketch import *

setTempo(120)

fitMedia(HOUSE_DEEP_CRYSTALCHORD_001, 3, 1, 5)
fitMedia(HOUSE_DEEP_CRYSTALCHORD_002, 3, 5, 9)

fitMedia(RD_UK_HOUSE__AIRYPAD_1, 1, 1, 9)
fitMedia(HOUSE_MAIN_BEAT_002, 4, 1, 9)
fitMedia(HOUSE_ROADS_BASS_001, 5, 1, 9)

fitMedia(Y37_ORGAN_1, 2, 9, 17)
fitMedia(HOUSE_ROADS_BASS_001, 5, 9, 17)
fitMedia(RD_UK_HOUSE__ARPLEAD_1, 6, 9, 17)

makeBeat(OS_CLAP01, 6, 1, "--0+--0+--0+0+0+")
makeBeat(OS_CLAP01, 6, 2, "--0+--0+--000000")
makeBeat(OS_CLAP01, 6, 3, "0+-0+-0+-0+-0-0-")
makeBeat(OS_CLAP01, 6, 4, "0+-0+-0+-0+-0000")

setEffect(2, DELAY, DELAY_FEEDBACK, -6.0)
setEffect(2, DELAY, DELAY_TIME, 1200.0)
setEffect(0, VOLUME, GAIN, -60, 1, 0, 3)
```
