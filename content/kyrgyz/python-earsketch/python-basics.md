# Python негиздери

Музыка коддоо үчүн бизге кичине Python үйрөнүү керек болот. Кабатыр болбоңуз, ал сизди чакпайт. Python – бул биз адамдар компьютерлерге эмне кылууну айтууда колдоно турган тилдердин бири. Бул тилдер "программалоо тилдери" деп аталат. Биз Python концепцияларын сабактын жүрүшүндө үйрөнөбүз, бирок жөнөкөй print деген сөз менен баштайлы.
