[EarSketch](https://en.wikipedia.org/wiki/EarSketch) — бул Джорджия технологиялык институту тарабынан иштелип чыккан акысыз билим берүү программалоо чөйрөсү. Бүгүн биз EarSketch колдонуп музыка түзөбүз.

1. Музыка түзүү үчүн, төмөнкү баскычты басып, Earsketch'ти жаңы терезеде ачыңыз.

<a class="my-2 mx-4 btn btn-info" href="https://earsketch.gatech.edu/earsketch2/" target="_blank">Earsketch'ти ачуу</a>

2. Веб-баракчаны ачкандан кийин, төмөнкүдөй саламдашуу экранын көрүшүңүз мүмкүн. "Өткөрүп жиберүү" баскычын басып тур көрсөтмөсүн өткөрүп жиберсеңиз болот – керектүү кадамдардын баары төмөндө көрсөтүлөт.

<img src="../img/screenshot-skip-tour.png" height="400"/>

3. Эми баштайлы. Сол меню тилкесиндеги *Scripts* белгисин басып, андан соң *+ New Script* тандоо керек.

<img src="../img/screenshot-new-script.png" height="400"/>

4. Скриптке *myjam* (же каалаган аталыш) атын берип, программалоо тилин *Python* катары калтырып, *Create* баскычын басыңыз. Ошондо сиздин скрипт (код жазылуучу файл) түзүлөт.

## Мугалимдер үчүн сунушталат - EarSketch боюнча жалпы маалымат

Сабакка киришүүдөн мурун, EarSketch боюнча жалпы маалымат менен таанышып чыгыңыз. Колдонуучу интерфейсинде кантип алдыга жана артка өтүү керектигин билүү маанилүү.

Экрандын сол тарабындагы `Content Manager` - бул EarSketch сунуш кылган бардык функцияларды башкаруунун негизги базасы.

1. Навигация тилкесинин биринчи пункту — бул `Sounds` коллекциясы. Бул курал – EarSketch'те алдын ала жүктөлгөн үндөрдүн борбору. Үндөр браузеринде сиз үндөрдү артисттер, жанрлар же аспаптар боюнча чыпкалай аласыз.

<img src="../img/screenshot-navigation-sound-browser.png" height="400"/>

2. Навигация тилкесиндеги кийинки белги — бул `Scripts` панелдери. Бул жерден биз код жазабыз.

<img src="../img/screenshot-navigation-script.png" height="400"/>

3. Навигация тилкелериндеги акыркы белги — бул `API Browser` панелдери. *Колдонмолорду программалоо интерфейси* же *API* бул дароо колдонууга даяр болгон коддордун жыйындысы. Аны ачканда ар бир API боюнча толук түшүндүрмө берилет.

<img src="../img/screenshot-navigation-api-curriculum.png" height="400"/>

Экрандын оң тарабында `Curriculum` колдонмолорун көрүүгө болот. Эгерде EarSketch жөнүндө көбүрөөк билгиңиз келсе, терезенин оң тарабында пайда болгон бөлүмдү изилдей аласыз. Бул көнүгүүдө биз бул бөлүмдү өткөрүп жиберебиз.
