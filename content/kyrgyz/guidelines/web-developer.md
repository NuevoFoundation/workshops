Бул документ **веб-сайт өнүктүрүүчүлөр үчүн гана** [Nuevo Foundation мастер-класстарынын долбоору](https://github.com/nuevoFoundation/workshops) үчүн шаблондорду жана стиль өзгөртүүгө арналган.

## Баштаардан мурун

Веб-сайтты кошоордун же жаңыртаардан мурун, долбоор командасы жана [Долбоордук Баклогдо](https://github.com/NuevoFoundation/workshops/projects/1) катталган учурдагы иштер менен синхрондоштурганыңызды текшериңиз.

## Орнотуу

Git жана Hugoну локалдык долбоорду сынаш үчүн орнотуу боюнча көрсөтмөлөрдү [Башталгыч бет](../getting-started/) баракчасынан караңыз.

## Веб-дизайн стилдери жана структурасы

- **Сүрөттөр:** Веб-сайттын сүрөттөрү `themes/images` папкасында болушу керек.
- **CSS:** SCSS файлдарын пайдалануудан алыс болуңуз жана `/themes/docdock/static/css/` ичиндеги CSS файлдарын колдонуңуз. Киргизе турган CSS файлына шилтемени `/themes/docdock/layouts/partials/flex/head.html` файлындагы `head.html` бөлүмүнө кошконуңузга ынаныңыз.

## Мастер-класс бетин талдоо

- **Толук беттин шаблону:** Беттин бардык компоненттерин, анын ичинде баш, меню, негизги бөлүм, жана тегерекке чыгаруучу бөлүмдөрдү көрүү үчүн `/themes/docdock/layouts/_default/baseof.html` караңыз.  
- **Баш:** Meta, CSS жана JS файлдары `/themes/docdock/layouts/partials/flex/head.html`
- **Үстүңкү/менюлук навигация:** docDock конфигурация файлындагы config.toml маанилерин колдонбоңуз, анын ордуна `/themes/docdock/layouts/partials/flex/body-before-content.html` дарегиндеги HTMLди кошуңуз же оңдоңуз.  
- **Сол жактагы меню:** `/themes/docdock/layouts/partials/flex/menu.html`
- **Төмөнкү навигация:** `/themes/docdock/layouts/partials/flex/body-after-content.html`  
- **Метамаалымат Боксу:** `/themes/docdock/layouts/partials/flex/body-after-content.html`

## Жардам, CSS жоголду

Hugo менен иштөөдөгү бир кыйынчылык – бул куруудагы негизги параметр болуп табылган `baseURL` айнымалысын тууралоо. Мазмун жүктөлгөндө, бирок CSS жок болуп калса, бул, сыягы, `baseURL` жөндөөсүнүн маселеси.

Мазмун кураар маалда конфигурация файлындагы `baseURL`ди өзгөртүүнүн ордуна, аны кол менен өзгөртүп койсоңуз болот. Төмөндөгү мисалда CSS жана JS минималдаштырылат, baseURL өндүрүштөгү .org URLге коюлат жана жыйынтыгындагы мазмун `public` катанасына көчүрүлөт.

`hugo --minify --baseURL "https://workshops.nuevofoundation.org/"`

## Кеңештер жана Трюктар

- **Publicти Эмес Сактаңыз:** Демейки боюнча, эч кандай параметрсиз hugo иштетсеңиз, ал сайтты Public папкасына курат. Public папкасын булак көзөмөлүнө салбаңыз (ал азыр gitignore'до).  
- **Сол Навигация:** Сол жактагы навигациядан мазмунду жашыруу үчүн, файлдын метамаалыматы hidden: true болуп турушу керек (бул мастер-класстын index.md markdown уюмундагыдай!).  
- **Partials:** Баракчанын кайра колдонулуучу компоненттери үчүн, `/themes/docdock/layouts/partials/flex/` папкасында жаңы partial түзүңүз.
