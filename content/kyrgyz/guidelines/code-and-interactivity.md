Семинарлар интерактивдүү болушу маанилүү. Студенттер код жазып, анын натыйжасын көрүп жана эксперимент жүргүзө алышы керек. Бул колдонмодо код редакторлорун жана интерактивдүү элементтерди кантип орнотуу керектиги жөнүндө айтылат.

## Кириштирилген код блоктору

Студенттер окуп, бирок дароо иштетпей турган код үлгүлөрү үчүн стандарттуу маркдаундагы код блокторун тил эскертүүлөрү менен колдонуңуз:

````markdown
```python
print("Салам, Дүйнө!")
```
````

Колдоого алынган тилдер: `python`, `html`, `css`, `javascript`, `csharp`, `java`, `sql`, `bash` жана башка көптөгөн тилдер.

## Орнотулган код редакторлору

Студенттер код жазып, иштете турган тапшырмалар үчүн интерактивдүү редакторлорду киргизиңиз. Биз төмөнкү платформаларды колдонобуз:

### Replit

Python, JavaScript жана жалпы программалоо үчүн эң ылайыктуу. Жаңы орнотмолор үчүн `replit.com` доменин колдонуңуз (эски семинарларда `repl.it` колдонулган, бирок ал дагы эле багытталган).

```html
<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/python-basics" target="_blank">Replitке кирүү</a>
```

Же түз эле орнотуңуз:

```html
<iframe height="600" width="100%" src="https://replit.com/@nuevofoundation/python-basics" title="Код жана интерактивдүүлүк - Replit редактору" scrolling="no" frameborder="no" allowtransparency="true" allowfullscreen="true"></iframe>
```

Эскертүү: эски семинарларда Replit URLдарында `?lite=true` параметрин камтып келген. Бул параметр азыр активдүү эмес жана жаңы орнотмолордо алып салынса болот.

### Codebunga

Жаңы Trinket шилтемелерин же орнотмо саптарын кошпоңуз. Бар болгон Trinket интеграциялары убактылуу камтылган жана анын ордуна жаңы браузердик IDEге өтмөкчү болгончо `TODO-IDE-Replace` катары сакталат.

Мурас үлгүсү:

```html
<iframe src="https://codebunga.com/embed/7s5rkuud" title="Код жана интерактивдүүлүк - Codebunga редактору" width="100%" height="600" frameborder="0" marginwidth="0" marginheight="0" allowfullscreen></iframe>
```

### .NET Fiddle

C# программалары үчүн эң ылайыктуу.

```html
<iframe width="100%" height="475" src="https://dotnetfiddle.net/Widget/abc123" title="Код жана интерактивдүүлүк - .NET Fiddle редактору" frameborder="0"></iframe>
```

### CodePen

HTML/CSS/JavaScript веб долбоорлору үчүн эң ылайыктуу. Бул реподо CodePen негизинен шилтеме баскычы катары колдонулат, бирок түз орнотмо катары колдонулбайт:

```html
<a class="my-2 mx-4 btn btn-info" href="https://codepen.io/Sunny-Dee/pen/exxyYL" target="_blank">Өзүңүз сынап көрүңүз!</a>
```

## Интерактивдүү HTML элементтери

Кол башкара турган интерактивдүүлүктү (тесттер, сүйрөп таштоо, баскычтар) түзүү үчүн, маркдаунда түздөн-түз HTML колдонсоңуз болот (бул сайт үчүн Hugo'нун `unsafe` иштетүү режими активдүү). Же болбосо, `rawhtml` кыска коду менен пайдаланыңыз:

```
{{</* rawhtml */>}}
<button onclick="alert('Туура!')">Маанисин түшүнүү үчүн басыңыз</button>
{{</* /rawhtml */>}}
```

Бул семинарда HTML, CSS жана JavaScriptти каалооңуз боюнча киргизүүгө мүмкүнчүлүк берет.

## Чакырык түзүмү

Жакшы тапшырма төмөнкү тартипти карманып ишке ашат:

1. **Түшүндүрүү:** Концепцияны кыскача сүрөттөө
2. **Көрсөтүү:** Код блоктору менен үлгүнү көрсөтүү
3. **Чакырык:** Студенттен өз алдынча код жазуусун талап кылуу
4. **Кеңеш берүү:** Эскертүү кыска код аркылуу:

```
{{% notice tip %}}
Функцияны чакырганда кашааларды колдонууну унутпаңыз!
{{% /notice %}}
```

## Кеңештер

- Ар дайым студенттер бош редакторго карап отурбашы үчүн **иштеген старттык пункт** менен камсыз кылыңыз.
- Бардык орнотулган шилтемелерди тапшырма берүүдөн мурда текшериңиз.
- Орнотулган редакторлор үчүн **бийиктик="600"** дегенди баштапкы стандарт катары коюп, зарыл учурда оңдоңуз.
- Эгерде орнотмо тосулуп калса, резервдик шилтемени кошуңуз. Мисалы: "Редакторду көрө албай жатасызбы? Аны жаңы терезеде ачыңыз."
- Коддун мисалдарын мүмкүн болушунча кыска жана так бериңиз. Эгерде мисал 20 саптан ашып кетсе, аны этаптарга бөлүп берүү боюнча ойлонуңуз.
