Hugo ар бир markdown файлына алды маалыматтарды (frontmatter metadata) колдонуп, сайттагы барактардын навигацияда кандай көрүнөөрүн башкарууда. Бул колдонмо негизги жөндөөлөрдү камтыйт.

## Барактардын тартибин башкаруу (weight)

`weight` талаасы сол тарабындагы менюда жана мазмун тизмесинде барактардын тартибин аныктайт. Кичирээк сандар биринчи көрүнөт.

```yaml
---
title: "24 мисал: Башталгыч кадамдар"
weight: 3
---
```

**Сунушталган weight схемасы:**

| Барактын түрү | Weight | Мисал |
|---------------|--------|-------|
| `_index.md` (саламдашуу барагы) | 1 | Workshop киришүү |
| Орнотуу/шарттар | 2 | Керектүү шаймандар |
| Иш-чаралар | 3, 4, 5... | Иш-чара 1, 2, 3 |
| Жооп ачкычы | 15+ | Навигациядан жашырылган |

Эгерде кийин барактарды кошууну пландап жатсаңыз, иш-чаралар үчүн weight сандарын аралыкта калтырыңыз (мисалы, 3, 5, 7 колдонуу 3, 4, 5 ордуна).

## Мазмун тизмесин башкаруу

### Мазмун тизмесин чектелген түрдө көрсөтүү (сунушталат)

Workshop'тарда киришүү тапшырма көрүнө турган, ал эми иш-чаралар тизимдери жабылган түрдө ачылышы керек:

```yaml
---
title: "Python: Негиздер"
alwaysopen: false
---
```

`alwaysopen: false` менен, бала барактар сол тарабындагы менюда жыйналган түрдө көрүнөт. Студенттер иш-чараларды жүрүү менен ачышат.

### Толук ачылган мазмун тизмеси 

Эгер workshop'та өтө аз тапшырмалар болсо (3 же андан аз), бардык бөлүктөр көрүнүктүү болушу мүмкүн:

```yaml
---
title: "Кыска Workshop"
alwaysopen: true
---
```

## Барактарды жашыруу

### Жашырылган барактар (сайтта курулат, бирок навигацияда жок)

Сол тараптагы менюда көрүнбөй турган, бирок жеткиликтүү болушу керек барактар үчүн `hidden: true` колдонулат. Студенттер аларга түз байланыш аркылуу кире алышат.

```yaml
---
title: "Жооп ачкычы"
hidden: true
---
```

Көп колдонулуучу учурлар: жооп ачкычы, инструкторлор үчүн белгилер, кошумча мазмун.

### Долбоор баракчалары (продукцияга кошулбайт)

Даяндалып жаткан, сайтка жүктөлбөшү керек барактар үчүн `draft: true` колдонулат:

```yaml
---
title: "Бүткөн эмес Workshop"
draft: true
---
```

Долбоор барактар тек гана `hugo server -D` командасын ишке киргизүүдө көрүнөт (`-D` желеги долбоор барактарды камтыйт).

## Балдар барактарын кыска код менен көрсөтүү

Саламдашуу баракта балдар барактар тизмесин көрсөтүү үчүн, `children` кыскартылган кодду (shortcode) collapsible details элементинин ичинде колдонуңуз:

```html
<details>
<summary>Мазмун тизмеси</summary>
{{% children /%}}
</details>
```

Бул студенттер керек болгондо кеңейтип көрө ала турган кыйла таза жана жыйналма таблица түзөт. Бир катар бар болгон workshop'тар кеңейген стандарт үчүн `<details open>` колдонот.

## Workshop саламдашуу барактын шаблону

Төмөндө толук `_index.md` алды маалыматтын мисалы:

```yaml
---
title: "Python: Негиздер"
description: "Python негиздерин үйрөнүү"
date: 2026-09-16T00:00:00-07:00
language: "python"
topics: ["программалоо-негиздери"]
difficulties: ["башталгыч"]
prereq: "Жок"
draft: false
hidden: false
alwaysopen: false
icon: "fab fa-python"
weight: 1
---
```

## Кеңештер

- Навигация өзгөрүүлөрүн сайтка жүктөө алдында `hugo server -D` менен текшерип алыңыз
- Жооп ачкычтарды `hidden: true` кылып койгула, студенттер көрбөшү үчүн
- Weight сандарын бирдей ырааттуулук менен белгилеңиз
- Эгер барактарды ордун алмаштырсаңыз, бардык weight'ти жаңыртыңыз, бош орун же кайталанма сандардын алдын алуу үчүн
