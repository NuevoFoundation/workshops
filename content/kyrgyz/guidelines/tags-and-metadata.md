Ар бир семинар баракчасы YAML фронтматтерди сайтта кандай көрүнүштө көрсөтүлүшүн башкаруу үчүн колдонот. Бул колдонмо ар бир талааны жана аны качан колдонуу керектигин түшүндүрөт.

## Милдеттүү фронтматтер

Ар бир Markdown файлына эң аз дегенде төмөнкү фронтматтер керек:

```yaml
---
title: "Барактын аталышы"
date: 2026-09-16T00:00:00-07:00
draft: false
---
```

| Талаа | Максаты | Мисал |
|-------|---------|---------|
| `title` | Навигацияда жана баракчанын башындагы аталышы | `"Python: Негиздер"` |
| `date` | Акыркы жаңыртуунун датасы (сайтта көрсөтүлөт) | `2026-09-16T00:00:00-07:00` |
| `draft` | `false` жарыяланган, `true` иштелип жаткан материал үчүн | `false` |

## Семинардын негизги баракчасынын талаалары

Семинар үчүн `_index.md` файлында кошумча талаалар колдонула алат:

```yaml
---
title: "Python: Негиздер"
description: "Пайтондун негиздерин, анын ичинде өзгөрмөлөрдү, циклдерди жана функцияларды үйрөнүңүз"
date: 2026-09-16T00:00:00-07:00
language: "python"
topics: ["программа-негиздери"]
difficulties: ["баштапкы"]
prereq: "Жок"
draft: false
hidden: false
alwaysopen: false
icon: "fab fa-python"
weight: 1
---
```

| Талаа | Максаты | Маани |
|-------|---------|--------|
| `description` | Тизмелерде көрсөтүлгөн кыска маалымат | Эркин текст |
| `language` | Коддоо тилинин фильтри | `data/taxonomy.yaml` файлынан алынган токен |
| `topics` | Теманын фильтри | Бир же бир нече токендер `data/taxonomy.yaml` файлынан алынат |
| `difficulties` | Кыйынчылык деңгээлинин фильтири | Бир же бир нече токендер `data/taxonomy.yaml` файлынан алынат |
| `prereq` | Алдын ала талаптар | `"Жок"` же семинардын аталышы |
| `hidden` | Навигацияда жашыруу | `true` / `false` |
| `alwaysopen` | Мазмундун кеңейүү жүрүм-туруму | `false` (жакшыраак) |
| `icon` | Башкы баракча үчүн Font Awesome иконкасы | Төмөндөгү иконкаларды караңыз |
| `weight` | Навигациядагы ирети | Сандар (аз = биринчи) |

`language`, `topics`, жана `difficulties` талаалары семинарлар "Семинарлар" бөлүмүнүн фильтринде кандай көрүнөөрү аныкталат. Тек гана `data/taxonomy.yaml` файлындагы белгиленген маанилерди колдонуу керек. Белгисиз маанилер жаңы фильтр варианттарын түзбөйт.

Мисал:

```yaml
language: "javascript"
topics: ["оюндар", "веб"]
difficulties: ["баштапкы"]
```

## Дата талаасы

`date` талаа ар бир барактын сайттын төмөнкү бөлүгүндө көрсөтүлөт. Баракчаны маанилүү өзгөрүүлөр киргизилген сайын жаңыртып турсаңыз, мазмундун учурдагы экендигин келүүчүлөр билип турушат.

Формат: `YYYY-MM-DDTHH:MM:SS-07:00` (ISO 8601 + убакыт зонасы) же `YYYY-MM-DD` (тек гана дата).

## YAML кеңештери

- Ар дайым тексттик маанилерде кош өтмөкчөлүү тырмак белгилерин колдонуңуз, эгерде : символун камтылса: `title: "Python: Негиздер"`
- Boolean маанилеринде тырмак белгилер кереги жок: `draft: false`
- TAB басмагыча бербеңиз — YAML боштук боюнча туура индентация талап кылат
- Фронтматтер `---` бөлүнүүчү белгилеринин арасында жана документтин эң башында болушу керек.
