Бул колдонмо идеядан баштап pull request'ке чейин жаңы семинар түзүүнү кадам-кадам кандай жасоону түшүндүрөт. Баштоодон мурун, [Баштапкы кадамдар](../getting-started/) (Git, Hugo, fork) орнотуу жана [Сайт архитектурасы](../site-architecture/) боюнча жалпы маалымат менен таанышып алууну бүтүрүңүз.

## Биздин философия

Nuevo Foundation семинарлары **жолдоштук саякаттардай** сезилиши керек, текстер китеби сыяктуу эмес. Ар бир семинар студенттер өз темпинде окуй турган окуяны көрсөтөт. Эң мыкты семинарлар:

- **Окуяга негизделген**: студенттер каармандын миссиясын аткаруу үчүн окуяны ээрчишет (Бенжи ит үйгө вебсайт керек, Алекс аарыга уя керек, DJ Нуви хит микстейпке муктаж)
- **Персоналдаштырылуучу**: студенттер теманы өз кызыкчылыгына жараша өзгөртө алышат (Бенжи ордуна өз үй жандыгы, Коста-Рика ордуна өз өлкөсү)
- **Өз темпинде**: студенттер өз алдынча иштей ала тургандай ачык-айкын көрсөтмөлөр, мугалим жок болуп кеткенде да
- **Прогрессивдүү**: тапшырмалар бир концепцияны бир убакта үйрөнүү менен үзгүлтүксүз өнүгүп жатат
- **Кызыктуу**: колдоочу тон, маскот-каармандар, визуалдык сыйлыктар жана акырында майрамдоо

## Биздин эң мыкты семинарлардан үйрөнүңүз

Жаңы семинар түзүү алдында төмөнкү эң мыкты үлгү семинарларды изилдеңиз:

### Веб негиздери (HTML/CSS) — [content/english/web-basics/](https://github.com/NuevoFoundation/workshops/tree/master/content/english/web-basics)

- **Тема**: Бенжи итке (Харви тайфуну себептүү ордунан айрылган) үй-бүлө табууга жардам берип, ал үчүн вебсайт түзүү
- **Эмне үчүн иштейт**: эмоционалдык байлоо, ар бир баракта YouTube видеосу, дароо код жазууга мүмкүнчүлүк берүүчү CodePen, 5-тапшырмада студенттер өз сайттарын түзө алышат, GitHub Pages’ке жарыялоо
- **Негизги үлгү**: окуя → концепция → видео → шилтеме таблицасы → практикалык тапшырма

### Python turtle — [content/english/python-turtle/](https://github.com/NuevoFoundation/workshops/tree/master/content/english/python-turtle)

- **Тема**: Алекс аарыга Python чийүү колдонуп түз уяга үйдү курууга жардам берүү
- **Эмне үчүн иштейт**: 11 YouTube видеосу, embed жасалган Codebunga IDE, визуалдык натыйжалар (студенттер коду формаларды кантип чийип жатканын көрүшөт), прогрессивдик татаалдашуулар (сызык → квадрат → алты бурч → уя → мандала гүлү)
- **Негизги үлгү**: окуя контексти → видео → код мисалы → интерактивдүү Codebunga → чакырык

### EarSketch (Python жана JS блоктору) — [content/english/python-earsketch/](https://github.com/NuevoFoundation/workshops/tree/master/content/english/python-earsketch)

- **Тема**: DJ Нувиге код колдонуу менен хит микстейп чыгарууга жардам берүү
- **Эмне үчүн иштейт**: студенттер кодун УККАНДЫктан (музыка!), дароо угулчу кайтарым байланыш, профессионалдык инструмент (Georgia Tech), үн тандоодо чыгармачыл эркиндик
- **Негизги үлгү**: музыка концепциясы → код концепциясы → түзүү → уккан → өзгөртүү

## Copilot менен семинар түзүү

Бул репозиторий GitHub Copilot CLI'дин `workshop-builder` жөндөмүн камтыйт. Жөндөм бул колдонмону окуйт, тиешелүү бар болгон семинарды изилдейди, каркас скриптин колдонот, мазмунду жазат жана жарыялоо текшерүүлөрүн жүргүзөт.

Репозиторийдин түп-тамырынан Copilot CLI’ди ишке киргизиңиз:

```bash
copilot
```

Эгер жөндөм Copilot иштеп жаткан учурда кошулса, долбоор жөндөмдөрүн кайра жүктөңүз:

```text
/skills reload
```

Жөндөм табылганын тастыктаңыз:

```text
/skills info workshop-builder
```

Андан кийин жөндөмдүн атын жана семинар кыска сүрөтүңүздү киргизиңиз:

```text
Use the /workshop-builder skill to create a 45-minute beginner Python 
workshop for ages 10–13. It should run in the browser and teach variables, 
input, and if statements through a robot rescue story.
```

Жөндөм стандарттык суроо формасын колдонуп, семинар жөнүндө бардык маалыматты чогултат: аты, жаш курагы, узактыгы, мурунку код тажрыйбасы, үйрөнүү натыйжалары, коддоочу тил, өткөрүү форматы (онлайн же оффлайн), иш-чаралар саны, окуя жана башка талаптар. Эгерде орнотуу убактыгында сунушталган иш-чаралар саны ашыкчалык кылса, жөндөм бул тууралуу эскертет, бирок колдонуучунун санын сактайт.

Copilot ошондой эле ачык семинар түзүү, оңдоо, же карап чыгуу суроо-талабы ачык-айкын болсо, автоматтык түрдө жөндөмдү тандашы мүмкүн.

## 1-кадам: семинар үчүн каркас түзүү

Семинардын туура түзүмүн жана шаблондорду түзүү үчүн каркас скриптин колдонуңуз. Файлдарды же папкаларды кол менен түзбөңүз — каркас туура Hugo frontmatter, файл ысымын жана папка түзүлүшүн камсыз кылат.

**Талабы:** Python 3.7 же андан жогору
