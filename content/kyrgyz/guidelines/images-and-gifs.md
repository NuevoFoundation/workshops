Сүрөттөр жаш үйрөнчүктөр үчүн мастер-класстарды кызыктуураак кылат. Сүрөттөр жеткиликтүү, туура өлчөмдө жана бардык платформаларда туура иштешин камсыздоо үчүн ушул көрсөтмөлөрдү аткарыңыз.

## Сүрөттүн өлчөмү

Сүрөттөрдү эч качан өлчөмү чектелбеген бойдон калтырбаңыз. Эгерде сүрөттөрдүн кеңдиги аракет кылынып көрсөтүлбөсө, анда алар турган көлөмүндө көрсөтүлөт, бул көбүнчө контент аянты үчүн өтө чоң болот.

| Сүрөт түрү | Максаты кеңдиги | Мисал |
|------------|----------------|-------|
| Толук UI скриншоту (Replit, IDE) | 60% | Replit жүктөө диалог |
| Коддун натыйжасы / терминал | 70% | dotnetfiddle натыйжалары |
| Концепция диаграммалары | 50% | Түс теориясы, маалымат структуралары |
| Фотосүрөт мисалдары | 40-50% | python-pixel мышык сүрөттөрү |
| Кичинекей иконки / значоктор | 15-25% | Таблицалар, кичине диаграммалар |
| Декоративдүү сүрөт искусствосу | 20-30% | Каармандардын сүрөттөрү |
| Каарман сүрөттөрү | 100% | Баштапкы беттин ` _index.md` гана үчүн |

**Пайыздарды, пикселдер эмес, колдонуңуз.** Пайыздык кендиктер мобилди жана планшеттерди эске алат. Пикселдик кендиктер аз кубулуштуу экрандарда көйгөйлүү болушу мүмкүн. 

```markdown
<!-- Жакшы: жооп беруучу -->
<img src="../media/screenshot.png" alt="Replit код редактору" width="60%">

<!-- Болбойт: фикс жайгашкан пиксел кендиги -->
<img src="../media/screenshot.png" alt="Replit код редактору" width="900px">
```

## Сүрөт кошуу

### 1-метод: Markdown синтаксис

```markdown
![Сүрөттүн сүрөттөмөсү](../media/filename.png)
```

### 2-метод: HTML img теги (кендикке көзөмөл керек болгондо)

```html
<img src="../media/filename.png" alt="Сүрөттүн сүрөттөмөсү" width="50%">
```

### 3-метод: Hugo фигурасынын shortcode`су

```
{{</* figure src="../media/filename.png" alt="Сүрөттүн сүрөттөмөсү" width="50%" */>}}
```

`figure` shortсode'у сүрөттөрдү `<figure>` элементине ороп коёт. Белги: Жаңы мастер-класстар көбүнчө жогорудагы markdown же HTML ыкмаларын колдонушат. Эски мастер-класстар `img/` аталышын колдоно алышы мүмкүн, бирок экөө тең бирдей иштешет.

## Жеткиликтүүлүк (alt текст)

Ар бир сүрөттө сөзсүз түрдө түшүндүрүүчү alt текст болушу керек. Бул сөзсүз берилиши керек.

| Андай кыл | Мындай кылба |
|-------------|-------------|
| `alt="Replit код редактору Python hello world программасын көрсөтөт"` | `alt="скриншот"` |
| `alt="RGB түс диаграммасы кызыл, жашыл жана көк чөйрөлөрү кошулган"` | `alt="сүрөт"` |
| `alt=""` (эстетикалык сүрөттөрдө, мис.: бөлгүчтөрдө) | `alt="Сүрөт жүктөлбөй калды"` |

Тилге которулган мастер-класстар үчүн alt эле текст барактын тилинде болушу керек:
- Англисче: `alt="A friendly chatbot welcoming users"`
- Португалча: `alt="Um chatbot amigavel dando boas-vindas aos usuarios"`
- Корейче: `alt="사용자를 환영하는 친근한 챗봇"`

## Файлдын аталышы

- **Кичи тамгаларды** гана колдонуңуз: `.png`, `.jpg`, `.gif` (жок `.PNG`, `.JPG`)
- **Сүрөттөөчү аталыштарды** колдонуңуз: `replit-upload-dialog.png` (жок `img1.png`)
- Сөздөрдү бөлүү үчүн **тире** колдонуңуз: `color-theory-diagram.png` (жок `color_theory_diagram.png`)
- Аталышты кыска, бирок маанилүү кылуу

## Сүрөттүн жайгашкан жери

Жаңы мастер-класстар `media/` директорийин колдонушу керек (скрипт автоматтык түрдө аны түзөт). Эски мастер-класстар `img/` колдонушу мүмкүн — Hugo баяндамачысында экөөндө айырмалар болбойт.

```
content/english/my-workshop/
  _index.md
  activity-1.md
  media/             <-- сүрөттөр бул жерде
    screenshot.png
    diagram.png
```

Сүрөттү барактан салыштырмалуу жол менен көрсөтүңүз. ` _index.md` ичинде `media/image.png`. Файлдардын ичинен жана жооптор барагынан, `../media/image.png` колдонуңуз (бул папка Hugo'до бир деңгээлге тереңирээк жеткиликтүү болот).

{{% notice warning %}}
Hugo салыштырмалуу жолдорду **барактын URLинен** чыгарып табат, файл тутумунун жайгашуусунан эмес. `/workshop/section/activity/` боюнча жайгашкан барак үчүн, `../media/file.png` жолу `/workshop/media/file.png` болуп чыга баштайт. Бул туура модель. Бул `../` жолдорун "уюштурууга" аракет кылбаңыз — алар атайылап жасалган.
{{% /notice %}}
