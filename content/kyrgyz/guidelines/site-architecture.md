# Сайт кандайча курулган

Workshops субдоменинин мазмуну Hugo үчүн [DocDock](https://docdock.netlify.com/) темасын колдонуу менен курулган. [Hugo](https://gohugo.io) бир катар артыкчылыктарга ээ статикалык сайт генератору болуп саналат:

1. **Контент авторлору** markdown колдонуп, контентке көңүл бурушуп, сайттын техникалык ишке ашуусуна же CSS/баракчалардын стилине тынчсызданбашат. Workshops *автоматтык түрдө* сол жактагы мазмун таблицасына жана Workshops башкы барагына кошулат. Hugo локалдык түрдө сонун иштейт (мисалы: учакта), жана Hugo эң ылдам статикалык сайт генератору болуп саналат, бүтүндөй workshop сайтынын түзүлүшү 2 секунддан аз убакытты алат.  
2. **Студенттер** ар кайсы workshopтордо ырааттуу колдонуу интерфейсинен, өзгөртө алган мүмкүнчүлүктөн, мобилдик түзүлүштөрдөн рабочий компьютерге чейин колдоого алган адаптивдик дизайндан, GitHub репозиторийине автоматташтырылган шилтемелерден, жана Azure CDN аркылуу дүйнө жүзү боюнча ылдам сайттын иштөөсүнөн пайда алышат.
3. **Nuevo өнүктүрүү командасы** workshop беттерин жана ошондой эле желе баракчаларынын ыңгайлашкан шаблондорун, [эскертүүлөр, белги, баскычтар, эскертүүлөр ж.б. үчүн курулган бет көзөмөлү](https://workshops.nuevofoundation.org/guidelines/formatting/), ыңгайлаштырылган көзөмөлдөр (мисалы: Nuevo шапкасы), iframe интерактивдүүлүгү, ыңгайлаштырылган метадата, автоматташтырылган баракчалар аралык шилтемелер, бет темалары, автоматташтырылган сайт картасын түзүү, орнотулган иконкалар жана GitHub Actions жана Azure DevOps аркылуу куруу/ишке киргизүү үчүн орнотуу автоматташтыруусу сыяктуу өзгөчөлүктөрдү түзүү жана ыңгайлаштыруу мүмкүнчүлүгүнөн пайдаланышат.
