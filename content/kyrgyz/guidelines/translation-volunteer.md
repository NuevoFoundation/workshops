Дүйнө жүзү боюнча көптөгөн балдар үчүн мастер-класстарды жеткиликтүү кылууга жардам берип жатканыңыз үчүн рахмат! Бул колдонмо учурдагы мастер-классты жаңы тилге кантип которуу керектигин түшүндүрөт.

## Баштаганга чейин

1. Мастер-класс максаттуу тилде бар-жогун текшериңиз. Тилдик папкаларды табуу үчүн `content/` директориясын караңыз:

| Папка | Тил |
|-------|-----|
| `content/english/` | Англисче |
| `content/espanol/` | Испанча |
| `content/brazilian-portuguese/` | Бразилиялык португалча |
| `content/korean/` | Кореяча |
| `content/francais/` | Французча |
| `content/german/` | Немисче |
| `content/simplified-chinese/` | Жөнөкөйлөтүлгөн кытайча |
| `content/traditional-chinese/` | Салттык кытайча |
| `content/kyrgyz/` | Кыргызча |

2. [Котормо суранычы боюнча ишти](https://github.com/NuevoFoundation/workshops/issues/new) GitHub’да ачыңыз, башкалар сиздин буга иштеп жатканыңызды билиши үчүн.

## Котормо кандайча иштейт

Ар бир тилде `content/` ичинде өзүнүн жеке папкасы бар. Ар бир тилдин ичиндеги папка структурасы англис версиясынын түзүлүшүнө дал келет:

```
content/
  english/
    python-basics/
      _index.md
      basics/
        writing-to-console.md
      img/
        screenshot.png
  espanol/
    python-basics/
      _index.md
      basics/
        writing-to-console.md
      img/
        screenshot.png
```

## Кадам-кадам менен

### 1. Англис мастер-классын көчүрүү

Англис мастер-классына тиешелүү папканы максаттуу тилдеги папкага толугу менен көчүрүңүз:

```bash
cp -r content/english/python-basics content/espanol/python-basics
```

### 2. Мазмунду которуу

Ар бир `.md` файлы үчүн:

- Көрүнүктүү текстти **котормоңуз** (аталыштары, тексттер, нускамалар, сунуштар)
- Hugo'нун бардык frontmatter ачкычтарын (төмөнкү: `title`, `date`, `draft`, `weight`, ж.б.) англисче калтырыңыз.
- Frontmatter маанилерин **котормоңуз** (`title: "Python: Conceptos basicos"`)
- Бардык код мисалдарын англисче **калтырыңыз** (код универсалдуу)
- Эгер код комментарийлери бар болсо, аларды **котормоңуз**
- Файлдын жолдорун, сүрөт шилтемелерин жана Hugo'нун шорткоддорун **өзгөртпөңүз**
- Сүрөттүн альтернативдүү текстин максаттуу тилде **котормоңуз**

### 3. Сүрөттөрдү иштеп чыгуу

- **Жалпы сүрөттөр** (код скриншоттору, диаграммалар): Англис тилинде камтылган `img/` же `media/` папкасын которулган папкага көчүрүңүз. Сүрөт файлдары бардык тилдер үчүн бирдей.
- **Текст көп камтылган сүрөттөр** (англис тилинде тексттуу сүрөттөр): Мүмкүн болсо, локалдаштырылган версиясын түзүңүз. Мүмкүн болбосо, англис версиясын калтырыңыз жана аны PRда белгилеңиз.
- **Альтернативдүү текст**: Ар дайым альтернативдүү текстти максаттуу тилге которуңуз. Экран окуучулар беттин тилдик жөндөөсүн колдонушат.

### 4. Локалдык тестирлөө

```bash
hugo server -D
```

Тергөөчүүдө которулган мастер-классты ачып, текшериңиз:
- Бардык барактар катасыз жүктөлүшүн
- Сүрөттөр туура көрүнүшүн
- Навигация иштеп жатканын (TOC, кийинки/мурунку)
- Код мисалдары бузулбаганын

### 5. PR жазыңыз

- Аталышы: `Translation: [мастер-класс аты] to [тил]`
- Түшүндүрмө: Которулган бардык файлдардын тизмеси жана англис тилдүү текстти камтыган сүрөттөр
- **Бардык мастер-классты** толук которгонуңузга ынануу, жөн гана башкы бетти эмес

## Кеңештер

- Мастер-классты студент катары иштеп чыккандай иштеп чыгыңыз. Эгерде котормодо бир нерсе түшүнүксүз болсо, аны кайрадан жазып чыгыңыз.
- Сүйлөмдөрдү кыска жана так кылыңыз. Бул мастер-класстар 8-18 жаштагы балдар үчүн жасалган.
- Техникалык терминдер боюнча шек санап турган учурда, англисче терминди сактап, аны бир аз түшүндүрүү менен коштой аласыз.
- Hugo'нун маршруттоосун сактоо үчүн мастер-класстардын аталыштарын URL же папка аттарында которбоңуз.

## Тилдер боюнча эскертүүлөр

### Испанча

- Кеңири Латын Америкасынын жеткиликтүүлүгү үчүн **tú** этиш формасын колдонуңуз (восео эмес).
- Код комментарийлерин которуңуз, бирок өзгөрмө жана функция аттарын англисче калтырыңыз.
- "string", "loop", "function" сыяктуу техникалык терминдер англисче калып, алгачкы жолу жогорку жааттагы кыска түшүндүрмө менен берилиши мүмкүн.
