## Киришүү: Хакерди кармоону үйрөнүңүз!

<img src="https://github.com/bgrant34/workshops/blob/master/content/english/kusto-kc7/Images/KC7Logo.png?raw=true" alt="лого" height="20%">

### Кош келиңиздер, жаңы Кибер Коргоочулар! 
*--- Коркунуч тууралуу чалгындоо ар бир адам үчүн жарактуу*
Реалдуу коркунуч маалыматтарын колдонуу менен киберкоопсуздукту үйрөнүңүз.
**KC7 - реалдуу дүйнөдөгү киберкоопсуздук көндүмдөрүн үйрөтүүчү оюн**
>KC7 каарман компанияга бир нече кибер коркунуч жаратуучу оюнчулар тарабынан жасалган чабуулду симуляциялап, кибер өлтүрүү чынжырынын жетти фазасында да өзгөчө маалыматыңызды колдонуп, ар кандай аракеттерди аныктоо үчүн үйрөтөт.

Алгачкы иш күнүңүздүн аягына чейин сиз төмөнкүлөрдү жасай аласыз:  
-  Azure Data Explorer (ADX) ичинде маалыматты өзгөртүүнү үйрөнүү үчүн Kusto Query Language (KQL) колдонуу  
-  Ар кандай маалымат топтомдорун колдонуп, максаттуу суроолорго жооп берүү  
-  Электрондук почта, веб-трафик жана сервер журналы сыяктуу журналдардан кибер активдүүлүктү табуу  
-  Татаал Туруктуу Коркунучтарды (APT) көзөмөлдөө үчүн ар кандай ыкмаларды колдонуу  
-  Кол салуучулар жөнүндөгү маалыматтарды ачуу үчүн үчүнчү тараптын маалымат топтомдорун колдонуу  
-  Коркунуч чалгындоо отчетун түзүү  
-  Компаниянын өзүн коргоо үчүн кандай чараларды көрүү керектигин сунуштоо  

Эгер сиз машыктыруучу болсоңуз, анда мастер-класска өтпөстөн мурун, **T3: Тренер үчүн Киришүү** блогунан баштаңыз. Эгер сиз студент болсоңуз, **1-иш-аракет: Кибер чөйрөгө кирүү жана аны орнотуу** бөлүмүнө өтүңүз.
