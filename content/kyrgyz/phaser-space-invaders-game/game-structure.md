Көрүнүп тургандай, биз сиз үчүн бир топ файлдарды түзүп койдук. Оюндун структурасы буга чейин эле түзүлгөн жана сиз ар бир файлды мазмун менен толтурасыз. Ошондуктан, баштоо үчүн, алгач ар бир файл эмне кылаарын жана алардын бири-бири менен кандайча байланыштарын түшүнүү зарыл.

Биринчиден, `phaser.min.js` - бул жөн гана биздин оюндун иштешин камсыз кылган Phaser фреймворкунун коду камтылган JavaScript файлы. Бул файл үчүн көп кабатыр болуунун кажети жок жана аны түзөтпөйсүз.

Андан кийин, `index.html` файлына көз чаптырыңыз. Бул биздин бүт долбоордун негизин түзгөн html файлы жана анын ичинде бардык колдонулган JavaScript файлдарын импорттоо ишке ашырылат.

Андан соң `Game.js` файлы турат. Бул файл, негизинен, биздин оюнду чагылдырат. Анын ичинде оюн коду `Scene1.js` жана `Scene2.js` аркылуу бөлүнөт. Бул сцена файлдары, негизинен, кодуңуздун көпчүлүк бөлүгүн жазуучу жер болуп саналат, жана биз кийинчерээк Phaser сценалары тууралуу кененирээк маалымат беребиз.

`PlayerBullet.js`, `EnemyBullet.js`, жана `Explosion.js` файлары оюбуз үчүн конкреттүү объектилерди түзүүгө арналган.

Акырында, `assets` папкасы биздин оюндун колдонгон бардык сүрөттөрүн камтыйт.
