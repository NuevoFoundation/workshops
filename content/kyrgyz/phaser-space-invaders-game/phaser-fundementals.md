## 1-бөлүк: Config өзгөрмөсү

Келгиле, Phaser'дин негиздерин карап чыгалы — бул HTML жана JavaScript колдонуп веб оюндарды түзүүчү оюн фреймворку! Бул мастер-класста колдонууга үйрөнө турган нерсе ушул.

`game.js` файлын ачыңыз. Ар бир Phaser оюнунда оюн үчүн конфигурацияларды сактаган өзгөрмө (көбүнчө config деп аталат) менен башталат.

```javascript
var config = {
  type: Phaser.AUTO,
  width: 512,
  height: 544,
  backgroundColor: 0x000000,
  scene: [Scene1, Scene2],

	physics: {
        default: 'arcade',
        arcade: {
            gravity: { y: 0 },
            debug: false
        }
    },
};
```

Бул өзгөрмөнүн ичинде сиз оюнубуздун туурасын, бийиктигин жана фон түсүн сыяктуу ар кандай мүнөздөмөлөрүн аныктаганыбызды байкай аласыз. Биз ошондой эле колдонулчу сценаларды аныктадык (сценалар жөнүндө кийинчерээк көбүрөөк маалымат беребиз). Сценаларсыз оюн жаратып, бүт кодду `game.js` файлына жайгаштырсаңыз болот.

Ошондой эле, физиканын жөндөөлөрү Config'те аныктала турганын көрө аласыз. Оюн дизайнында физика — оюндун "сезимдерин" аныктаган эң маанилүү аспекттердин бири. Мисалы, Мариодогу секирген физика аны "Mario сезими" менен өзгөчө кылат. Оюнубуз үчүн биз "arcade" физикасын колдонобуз, бул Phaser'деги жөнөкөй физика түрү. Физика жөндөөлөрүндө, гравитацияны 0 деп аныктайбыз, анткени биздин оюн космос атуу ойуну жана каармандарыбызды ылдый тарта турган гравитация бизге керек эмес.

`game.js` файлынын аягында биз config өзгөрмөсүн оюн өзгөрмөсүнө өткөрүп бергенин көрө аласыз. Бул нерсе Phaser оюнунда дээрлик ар дайым керек.

## 2-бөлүк: Сценалар

Эми, сценалар жөнүндө көбүрөөк сөз кылалы. Сцена — колдонуучу иштеп жаткан оюнунун абалы. Муну мисалдын жардамы менен жакшыраак түшүнүүгө болот:

Покемон аттуу атактуу оюн франшизасын карап көрөлү. Оюнду ойногондо, дүйнөнүн ичинде жүрөсүңүз. Эгер чөптүн арасында тренерге же жапайы покемонго жолуксаңыз, оюн абалын өзгөртүп, башка сценага киресиз, анда сиз салгылашасыз. Салгылашуу бүткөндө, картаңызды ачып, бара турган жерди көрүшүңүз мүмкүн – бул дагы башка сцена ачылат. Бул үч сценар толугу менен башкача иштейт жана ар бири өзүнүн механикасына ээ. Картадан чыккандан кийин, оюн негизги сценага өтүп, дүйнөдө кыдыруучу оюнчунун абалына кайтып келет. Салгылашууга киргенде, оюн салгылашуу сценасына өтөт. Бул үч абалды түзүү толугу менен башкача болушу керек — салгылашуу менюну талап кылат, дүйнөдө 2D мейкиндик жана оюнчу керек, ал эми карта интерактивдүү диаграмма болуп саналат. Биз аларды өз-өзүнчө сценаларга бөлөбүз, анткени бардыгын байланыштыруунун зарылдыгы жок жана алардын коддолушу да бир топ жеңил болот.

Колдонуучуну оюнду ойногондо сценалардын ортосунда кыймылдаган деп элестетсеңиз болот. Алар бир убакта бир гана сценаны колдонушат, ар бири өз алдынча мини-оюн сыяктуу (бирок, негизги оюн адатта "мини" эмес).

{{% notice info %}}

Теория боюнча, бул үч оюн абалын бир сценада колдонсок да болот (ойдун сценаларга бөлүнүшү оюн дизайнердин тандоосу). Бул физикалык жактан мүмкүн. Бирок, өзүнчө сценаларды түзүү программалоону бир топ жеңилдетет (бул учурда, үчөөнү биригип, бир сценага жайгаштырууну элестете албайм, жөн гана биринин үстүнө бирин коюу оңой эмес болуп калмак).
{{% /notice %}}

Сценаларды колдонууга болгон башка көп таралган мисал: титул бет.

![Outliers оюнунун титул бет](../media/title-game.png)

Биринчи сцена жөн гана титул бетти көрсөтөт, анда жөндөөлөр, сакталган файлды ачуу жана башка нерселер камтылган. Оюнчу "ойноо" дегенди басып, оюнга киргенде, бет толук башка сценага өтөт, ал жерде оюн башталат.

Дал ушуну биз жасайбыз. Биринчи сцена титул бетти камтыйт, ал эми экинчи сцена биздин чыныгы оюнду көрсөтөт. Ошентип, экинчи сценанын коддору көп болот жана эң көп иш жасала турган жер болот.

## 3-бөлүк: Чексиз Canvas

Оюнду replit'те баштаганда, экраныңызда бош канвасты көрөсүз, бул жерде кийин нерселерди жайгаштырасыз. Бирок, сиз жалпы канвастын бир бөлүгүн гана көрүп жатасыз — чынында, канвас бардык багыттарда чексиз. Канвас бардык бөлүктөрдө бир эле түрдө иштейт — демек, объекттер колдонуучуга көрүнбөгөн канвастын бөлүгүнө жылып жана жайгаштырыла алат. Бул биздин оюн үчүн маанилүү болот, анткени объекттер экрандан чыгып кетпеши керек. Аларды экрандын ичинде кармап же экрандан чыга турган болсо жок кылышыбыз керек.
