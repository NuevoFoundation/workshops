## Колдонуучунун Киргизүү Каражаттары

Киргизүү каражаттары абдан маанилүү себеби колдонуучу башкаруу элементтери менен нерселерди киргизбей туруп, оюндун чындап оюн болуп калышы мүмкүн эмес. Phaser ар кандай киргизүү мүмкүнчүлүктөрүн колдойт, бирок Space Invaders оюнунда колдонулуучу үч негизги киргизүү каражатын карап чыгабыз.

## Жебе Түстөрү

Баштаардын алдында, эң маанилүү башкаруу каражаттардын бири - жебе түстөрү менен баштайлы. Алгач, оюнчу жебе түстөрүн баскан учурда аны аныктоочу өзгөрмөнү түзөбүз.

```javascript
this.cursors = this.input.keyboard.createCursorKeys();
```

Бул өзгөрмөнү колдонуу үчүн 4 логикалык билдирүүнүн бирин тандооңуз керек.

```javascript
this.cursors.up.isDown
this.cursors.down.isDown
this.cursors.left.isDown
this.cursors.right.isDown
```

Бул логикалык билдирүүлөрдүн ар бири тиешелүү баскыч басылса true, басылбаса false болот.

## Пробел Түймөсү

Пробел түймөсүн кошуу процесси жебе түстөрүнө окшош болот. Биринчиден, пробел басылганын аныктаган өзгөрмөнү түзөбүз.

```javascript
this.spacebar = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.SPACE);
```

Андан кийин киргизүү басылганын текшерүү үчүн логикалык билдирүүнү колдонсок болот.

```javascript
Phaser.Input.Keyboard.JustDown(this.spacebar)
```

## Башкыч Басуу

Ошондой эле жебе жана пробел киргизүүлөрүн кошуу үчүн колдонулган ыкманы колдонуңуз, бирок бул жерде Space Invaders оюнунда көп колдонулган башкача ыкманы карайбыз.

```javascript
this.input.once("pointerdown", this.restart, this);
```

Бул сап оюнчу басканда `this.restart` ыкмасын чакырат. Бирок, бул бир жолу колдонулуучу киргизүү, демек, оюнчу бир жолу баскан соң, кайрадан чакырылганга чейин колдонулбаса, иштебей калат. Көбүнчө бул киргизүүнү `update()` же жардамчы функциялардын ичинде колдонушат.
