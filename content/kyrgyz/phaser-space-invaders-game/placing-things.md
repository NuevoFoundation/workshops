## Текстти жайгаштыруу

Эми Phaser'ге нерселерди кантип жайгаштырышты үйрөнөсүз. Төмөндөгү кодду караңыз.

Биринчиден, текстти кантип жайгаштырса болорун карап көрөлү!

```javascript
message = this.add.text(20, 10, "Hello World!", {
	font: "25px Arial",
	fill: "white"
});
```

Бул код саптары "message" деген өзгөрмөнү түзөт. Бул өзгөрмө "Hello World" деген текстти оюн терезесиндеги (X, Y) (20, 10) координатына жайгаштырат. Код текстти ак түстө, Arial шрифти менен жана 25 px өлчөмү менен көрсөтүүнү аныктайт.

Бул саптарды барактын аягындагы `create()` методго кошуп, оюн терезеңизге жаңы текст пайда болоорун байкаңыз.

{{% notice note %}}

1. Текст түзүүдө өзгөрмө аталышы экранда көрсөтүлгөн текст болбойт, ал цитатада жазылган нерсе болуп саналат.
2. Бул синтакс текстти String өзгөрмөсүндө сакталган текстти жайгаштыруу үчүн да колдонулушу мүмкүн.

{{% /notice %}}

{{% notice warning %}}

### Жардам! Оюн терезем өтө кичинекей!

Капа болбоңуз, ал чындыгында чоң, бирок repl аны стандарт катары кичирейтет. Терезеңиздин көрүү аянтын ортосундагы сызыктарды сүйрөө менен кеңейте аласыз.

{{% /notice %}}

## Фондун (бэкграундду) жайгаштыруу

Тексттер абдан жөнөкөй, бирок, эгер оюн үчүн өзүбүздүн жеке спрайттарды колдонгубуз келсе (бул дээрлик ар дайым болот), анда алгач `preload()` методуна жүктөп алуу керек, андан кийин `create()` методунда анын жайгашуусун аныктайбыз.

Өткөндөй фонд түзүүнү баштайлы. Бул кодду `preload()` методго киргизиңиз:

```javascript
this.load.image('background', 'assets/sky.png');
```

Бул жөн гана сүрөттү оюнга жүктөйт. Андан кийин `create()` менен сүрөттү оюнга кошобуз:

```javascript
this.add.image(400, 300, 'sky');
```

Бул сап сүрөттү (400, 300) координатына жайгаштырат. Сынап көрүңүз, оюнуңуздун кара экраны эми фонд менен капталганын байкоого болот!

{{% notice note %}}

(400, 300) координаты сүрөттүн борбордук пиксели жайгашкан жерди көрсөтөт. Бул сүрөтдүн борборун (400, 300) координатына жайгаштырабыз, анткени фонд экранды толугу менен каптап турушу керек.

{{% /notice %}}

## Каармандарды жайгаштыруу

Андан соң дүйнөдө бир каарманды жайгаштырып көрөлү.

`preload()` функциясына төмөнкү код киргизилет:

```javascript
this.load.spritesheet('dude', 'assets/dude.png', {
    frameWidth: 32,
    frameHeight: 48
});
```

Бул код бир аз көбүрөөк талап кылат, анткени бул жөнөкөй спрайт эмес, ал спрайттардан турган кыркма-sheet (спрайт-шит). Спрайт-шит мындай көрүнөт:
![dude](../media/example-dude.png)
Бул биздин каармандын спрайт-шити. Спрайт-шиттер каармандын же нерсенин ар түрдүү учурларын чагылдырган баяндамалар топтому. Биринин артынан бири ойнотулганда, алар оюн үчүн анимацияны жаратышат (бул жөнүндө кийинки сабакта көбүрөөк маалымат алабыз). Биз үчүн бул көптөгөн окшош каармандар сыяктуу сезилгени менен, компьютер муну өзү эле оңой аныктай албайт. Демек, ар бир каармандын спрайт шитиндеги чен-өлчөмүн (бул учурда 32x48) компьютеге өз алдынча көрсөтүп берүүбүз керек.

Спрайт-шитти `create()` барагында жайгаштыруу синтаксы жөнөкөй сүрөттү жайгаштырууга окшош, бирок физика тегине ээ:

```javascript
dude = this.physics.add.sprite(250, 200, 'dude');
```

Бул сапта "player" деген өзгөрмө түзүлөт, ал спрайт-шиттеги биринчи сүрөттү (250, 200) координатына жайгаштырат. Сүрөт "dude" деген аталышка ээ.

Бул сапта, player - түзүлүп жаткан өзгөрмөнүн аты. 250 жана 200 X жана Y координаттары, демек, спрайт экрандын (250, 200) координатына жайгаштырылат. "dude" спрайттын аты, бирок ал бул сабакта өзгөчө мааниге ээ эмес.

Каарманды кошуп көрүңүз! Экранда каарманыңызды көрдүңүзбү?

{{% notice note %}}

1. Каарманды көрүү үчүн `create()` барагындагы dude өзгөрмөсү Фонддон кийин түзүлүшү КАРЫЗДЫК МАЖБУР. Себеби, компьютер кодду жогору жактан төмөн карай окуйт, эгерде каарман Фонддон мурун жайгаштырылган болсо, компьютер фондду каармандын үстүнө коюп, аны колдонуучудан жаап коёт.
2. Dude сол жакты карап турат, анткени баштапкы жайгашууда спрайт-шит ар дайым биринчи жазылган позициясына ылайык жайгаштырылат, жана биздин dude сол тарапты карап турган сүрөтү биринчи турат.

{{% /notice %}}
