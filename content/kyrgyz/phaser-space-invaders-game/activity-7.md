Эми биз оюнда эң негизги бөлүктөрдүн бирин кошууну каалайбыз - душмандарды атууну! Душмандарды алар менен кагылышканда утулууга болот, бирок кийинчерээк өмүрдү кошконубузда, бул жакшы идея болбой калат. Биз атууну ишке ашыруу үчүн жарык нурунун объектин JavaScript файлынан түзөбүз (жарылуунун объектисин түзгөнүбүзгө окшош).

`Explosion.js` сыякты, `Phaser.GameObjects.Sprite` кеңейтилген жана анын конструкторунда `super()` ачкыч сөзүн колдонот. Конструктордогу кодду толтуруңуз. Бул нурдун анимациясын иштетүү, денени активдештирүү жана нурдун y-илампыны канчалык ылдамдыкта жүрүшүн кааласаңыз, ошончолук ылдамдык коюуну талап кылат.

Нурдун негиздерин бүтүргөндөн кийин, оюнчуга пробел тийгенде атууну мүмкүнчүлүк берели. Оюнчунун кыймылын иштетүү үчүн курсор ачкычтары үчүн өзгөрмөнү түзгөнүбүздөй эле, оюнчу пробелди басканда кармаган өзгөрмөнү жаратабыз:

playerShoot методу пробел басылганбы текшерет жана нур атууну аткарат. "Нур атуу" дегенибиз бул учурда playerBeam объектин түзүп, активдүү оюнчу болсо аны projectiles тобына кошуу.

Эми аны сыноодон өткөрүңүз! Бирок бул жерде эки чоң маселе бар - нур душманга зыян келтирбейт жана нур дагы эле түбөлүккө уланат, анткени phaserдин чексиз холсту бар.
![blast](../media/8/blast-first.gif)

Адегенде, экинчи маселени чечели. Бул маселе түздөн-түз оюнга таасир этпесе да, проблемага айланышы мүмкүн, анткени экрандан чыгып кеткен нур дагы деле бар болсо, компьютер аны менен иштөөгө убакыт коротууга туура келет. Эгерде компьютер караш керек болгон нурлар өтө көп болсо, бул лагга алып келиши мүмкүн! Биз playerBeam.js файлына update функциясын киргизип, нур экрандын сыртында калса, аны жок кылабыз.

Бирок, бул жаңыртуу функциялары иштеши үчүн, аларды Scene 2 ичиндеги update функциясында чакырышыбыз керек:

```javascript
for(var i = 0; i < this.projectiles.getChildren().length; i++) {
    var beam = this.projectiles.getChildren()[i];
    beam.update();
}
```

Код туура иштеп жатабы, нур айтылган бийиктикке жеткенде жоголсо аныктайбыз. Код иштеп жатканын текшергенден кийин, бул маанини экрандын сыртындагы бир нерсеге (мисалы, 10) өзгөртө алабыз.

![blast](../media/8/blast-disappear.gif)

Бул gifден нур белгилүү бир бийиктикке жеткенде жоголуп жатканын көрө аласыңар (50 пайдаланган болчук). Кийин код иштейт деп ишенсеңиз, саны 50ди экрандан бир аз сыртка жайгашкан бир нерсеге (мисалы, 10) өзгөртсөңүз болот, бул код дагы эле иштеп жатканын күбөлөндүрө алат.

Эми, эгерде душман нур менен тийген болсо, аны жок кылалы! Биз муну душмандын жана оюнчунун тийишүүс
