Python тилинде биз функцияны аныктабай эле колдонууга мүмкүн болгон бир топ маанилүү түзүлгөн функцияларды сунуштайт. Бул бөлүмдө биз сандар боюнча математикалык тапшырмаларды аткарууга мүмкүнчүлүк берген айрым түзүлгөн математикалык функцияларды үйрөнөбүз.

`max()` жана `min()` функциялары тизмедеги эң чоң жана эң кичине маанилерди берет:

```python
x = min(20, 10, 50, 25)		#x = 10
print(x)
y = max(20, 10, 50, 25)		#y = 50
print(y)
```

`abs()` функциясы сандык абсолюттук (оң) маанисин берет:

```python
x = abs(-34)		         #x = 34
print(x)
y = abs(90)			         #y = 90
print(y)
```

`pow(a, b)` функциясы `a` санын `b` даражага көтөргөн маанини кайтарат (a<sup>b</sup>):

```python
x = pow(3,4)		        #x = 81
print(x)
```
