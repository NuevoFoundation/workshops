Python тилинде код жазууну жеңилдетүү үчүн колдонула турган көптөгөн киргизилген функциялар бар. Алардын айрымдарын бул жерде талкуулайбыз.

# sort()
Бул функция массивдер жана тизме сыяктуу маалымат структураларындагы маанилерди сорттоо үчүн колдонулат.
```python
arr = [8,5,1,4,6]
arr.sort()
print('Тизилген массив :',arr)
# басып чыгарат Тизилген массив [1,4,5,6,8]
```

# find()
Берилген саптын ичине берилген критерийдин (pattern) биринчи кездешүүсүн кайтарат.
```python
str1 = "Hello World"
index = str1.find("World")
print(index) # басып чыгарат 6
```

# len()
`len()` берилген маалымат структурасынын өлчөмүн табууга жардам берет.
```python
arr = [10,5,4,2,3]
print(len(arr)) # басып чыгарат 5
```

# isdigit()
Бул функция аргумент катары берилген сапта толугу менен сандар бар болсо, `True` кайтаруу менен натыйжасын билдирет, болбосо `False`.
```python
s = "123";  
print(s.isdigit()) # басып чыгарат True

s = "Hello World";
print(s.isdigit()) # басып чыгарат False

s = "123Hello"
print(s.isdigit()) # басып чыгарат False, анткени саптын ичинде сандар менен каттар бар
```

# reverse()
Бул функция массивдин же тизменин мазмунун тескери кылып өзгөртөт.
```python
arr = [5, 6, 7, 8, 9];
arr.reverse();
print(arr) # басып чыгарат [9,8,7,6,5]
```

# replace()
Бул функция берилген сапта биринчи аргументти экинчи аргументке алмаштырат.
```python
initial_str = "My name is Harry. Harry is a good boy."
final_str = initial_str.replace("Harry", "Potter")
print(final_str) # басып чыгарат My name is Potter. Potter is a good boy.
```

# append()
Бул функция ар кандай типтеги санды, символду же башка элементти массивдин же тизменин аягына кошуу үчүн колдонулат.
```python
arr = [1,2,3,4,5];
arr.append(6);
print(arr) # басып чыгарат [1,2,3,4,5,6]

arr = ['Harry','Ram',1,2]
arr.append("Jenifer")
print(arr) # басып чыгарат [Harry,Ram,1,2,Jennifer]
```

# remove()
Бул функция берилген объекттеги аргументтин биринчи кездешүүсүн жок кылат. Эгерде сапта жок элементти өчүрө турган болсоңуз, ал "элемент жок" деген ката берет.
```python
arr = [1,1,2,3,3]  
arr.remove(1)  
print(arr) # басып чыгарат [1,2,3,3]

arr.remove(4) # басып чыгарат ката "элемент тизмеде жок"
```

### Чакырык 1
Массив түзүңүз `arr`

- Ага `[1,2,3,4,5]` маани бериңиз.

- `6` санын массивге кошуп, басып чыгарыңыз.

- Массивди тескери кылып өзгөртүп, басып чыгарыңыз.

- Массивди сорттоп, басып чыгарыңыз.

- Массивдин узундугун басып чыгарыңыз.

- `arr` массивинен 6 элементти алып салып, басып чыгарыңыз.

- Массивдин узундугун басып чыгарыңыз.

#### Күткөн жыйынтык
```Output
    [1,2,3,4,5,6]
    [6,5,4,3,2,1]
    [1,2,3,4,5,6]
    6
    [1,2,3,4,5]
    5
```

### Чакырык 2
- `s` сапына "Hello all.Hello people" мааниси бериңиз.

- `s` сапындагы `Hello` сөзүнүн биринчи кездешүүсүн издеп, басып чыгарыңыз.

- `s` сапындагы маалымат толугу менен сандардан турат бекен текшерип, натыйжасын басып чыгарыңыз.
