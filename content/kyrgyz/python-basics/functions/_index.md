**Функциялар** — бул окшош же кайталанган код бөлүктөрүн уюштуруунун жолу. Бир эле кодду кайра-кайра терүүгө караганда, аны функцияга коюп, керек болгон учурда чакырып колдоно алабыз.

{{% notice info %}}
**Эскертүү:** Функцияларды түзүүнүн максаты программа ичинде кайталануучу коддорду азайтууга жардам берүү.
{{% /notice %}}

## Функция түзүү

### Функцияны аныктоо – аталышы жана параметрлер

Python тилинде функция түзүү үчүн биз `def` ачкыч сөзүн колдонушубуз керек. Бул ачкыч сөз функция кайда аныкталганын код редакторуна билдирет. `def` сөзүнөн кийин функциянын аты жазылат. Функциянын аты программанын башка бөлүктөрүнөн бул функцияны чакыруу үчүн колдонулат. Функцияны жалпылаштыруу үчүн (ошондуктан аны ар кайсы жерлерде колдонсок болот), кээ бир маалыматтарды жөнөтүү зарыл болушу мүмкүн. Бул параметрлерди колдонуу менен ишке ашырылат. Алар функциянын аталышынан кийин тегерек кашаанын (`()`) ичинде жазылат. Эгерде параметрлер керек болбосо, аларды калтырсаңыз болот. Функция аныктамасынын биринчи сабы коше (колонка) белгиси менен аяктайт. Функция чакырылган сайын иштей турган көрсөтмөлөр кийинки саптарда жайгашат. Бул жерде жылдыруу (indentation) абдан маанилүү, андыктан кодуңуз туура түзүлгөндүгүн текшериңиз. Функция аныктамасынын сапынан кийин келген бардык жылдырылган саптар (комментарийлерден сырткары) функция чакырылганда аткарылат.

Мына функциянын кандай көрүнүшү:

```python
def functionName(parameter1, parameter2, ...):
    # кээ бир коддорду жазуу
    # бул функцияны коддун башка жерлеринен
    # functionName деген ат менен чакырууга болот
```

{{% notice warning %}}
Функцияңыздын биринчи сабы ар дайым коше белгиси `:` менен аякташына көз салыңыз.
{{% /notice %}}

### Функциянын негизги бөлүгүн жазуу

Питон тилинде жылдыруу (indentation) функцияга көз каранды болгон кодду аныктайт. Төмөнкү мисалда `sectionA` функциясын чакыруу үчүн сиз 2 параметр — `startMeasure` жана `endMeasure` такташыңыз керек. Эгерде `sectionA` чакырылса, анда 3 `fitMedia` функция сызыгы ишке ашат. Ал эми төмөндө жайгашкан 2 `fitMedia` функциясы болсо `sectionA` функциясынын негизги бөлүгүнөн тышкары.

```python
#Бөлүк A
def sectionA(startMeasure, endMeasure):
    fitMedia(RD_UK_HOUSE__AIRYPAD_1, 1, startMeasure, endMeasure)
    fitMedia(HOUSE_MAIN_BEAT_002, 4, startMeasure, endMeasure)
    fitMedia(HOUSE_ROADS_BASS_001, 5, startMeasure, endMeasure)

 fitMedia(HOUSE_DEEP_CRYSTALCHORD_001, 3, 1, 5)
 fitMedia(HOUSE_DEEP_CRYSTALCHORD_002, 3, 5, 9)   
```

`sectionA` функциясынын астында жылдырылган код — бул ар бир жолу `sectionA` чакырылганда аткарылуучу код.

{{% notice warning %}}
**Эскертүү:** Питон тилинде жылдыруу өтө маанилүү болгондуктан, функциянын негизги бөлүгү ар дайым 2 боштук (spase) менен башталарына көз салыңыз.
{{% /notice %}}

## Маалымат кайтаруу (return)
Көп учурда биз натыйжаларды жөн гана басып чыгаргыбыз келбей, функция аткарган аракеттин жыйынтыгын кайтарышын каалайбыз. Бул үчүн `return` ачкыч сөзү колдонулат. 

```python
def my_function(x):
    return 5 * x

print(my_function(3)) # 15 чыгарылат
print(my_function(5)) # 25 чыгарылат
```

## Функцияны колдонуу – Функцияны чакыруу

Функцияны чакыруу үчүн функциянын атын жана параметрлерин кайсы учурда аткарыш керек болсо, ошол жерге киргизсеңиз болот. Мисалы, `sectionA` функциясын чакыруу үчүн биз төмөнкүчө жазсак болот:

```python
sectionA(1,9)
```

Бул мисалда `sectionA` функциясы `startMeasure = 1` жана `endMeasure = 9` маанилери менен чакырылат.

{{% notice warning %}}
**Сак болуңуз:** Питон тилинде функцияларды түзүүдө аны жана анын мазмунун чакырганга чейин аныктоо керек. Б.а., коддо сиз функция аныктамасын аны чакырган саптын үстүнө жайгаштырышыңыз керек. Болбосо, төмөнкү сүрөттө көрсөтүлгөндөй NameError катасын аласыз. Төмөнкү сүрөттү караңыз:
