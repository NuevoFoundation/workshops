Туупл дагы тизме сыяктуу эле элементтердин иреттелген жыйындысы болуп саналат, бирок тууплдар өзгөрүлбөс болуп эсептелет (immutable). Ошондуктан туупл дайындалгандан кийин анын элементтерин өзгөртө албайсыз (тизмелерден айырмаланып, анда муну кылууга болот). Бул өзгөрүлбөс мүнөздөмө тууплдарды программаны колдонуу учурунда дайындын өзгөрүшүн каалабаган учурда абдан пайдалуу кылат. Мындан тышкары, тууплдар көбүнчө ар түрдүү маалымат түрлөрүнүн элементтерин сактоо үчүн колдонулат. Эгерде тизме төрт бурчтук кашаалар менен аныкталса (`[]`), туупл бардык элементтерди жайгаштыруу жана аларды үтүр менен бөлүү менен тегерек кашааларда `()` түзүлөт.

```python
# String түрүндөгү эки элементтен турган туупл түзүү
my_tuple = ('alma', 'апельсин')
```

{{% notice note %}}

Тууплдарды тегерек кашааларсыз да түзсө болот. Бирок аларды колдонуу жакшы практика болуп эсептелинет.

{{% /notice %}}

Туупл ар түрдүү түрдөгү элементтерди камтышы мүмкүн.

```python
# Ар түрдүү маалымат түрлөрүнүн элементтеринен турган туупл
my_tuple = ('alma', 1, 4.5)
```

### Туупл элементтерине жетүү

Биз туупл элементтерине эки аңгемчил кашаанын ичиндеги индекс аркылуу жетсек болот, бул жагынан тизмелерге окшоштур. Ошондой эле, индекс нөлдөн (`0`) башталат.

```python
# String түрүндөгү үч элементтен турган туупл түзүү
my_tuple = ('alma', 'апельсин', 'манго')

print(my_tuple[0]) ## "alma" деп чыгат
print(my_tuple[2]) ## "манго" деп чыгат
```

### Эки тууплду бириктирүү

Эки тууплду `+` оператору аркылуу бириктирүүгө болот.

```python
fruits = ('alma', 'апельсин', 'манго')
numbers = (1, 2, 3)

# fruits жана numbers тууплдарын бириктирүү
combined_tuple = fruits + numbers

print(combined_tuple) ## ('alma', 'апельсин', 'манго', 1, 2, 3) деп чыгат
```

### Тууплдун узундугу

`len(tuple)` функциясы тууплда канча элемент бар экенин кайтарат.

```python
fruits = ('alma', 'апельсин', 'манго')

print(len(fruits))  ## 3 деп чыгат
```

### Тууплга кайра тапшыруу

Тууплдар өзгөрүлбөгөнү менен, биз анын элементин өзгөртө албайбыз. Мисалы, `fruits[0] = 'лимон'` деген ээрээ, анткени бул учурда биз 'fruits' тууплунун `0` индексиндеги элементти өзгөртүүгө аракет кылып жатабыз. 
Бирок, биз тууплду жаңыдан дайындай алабыз (толугунан алмаштырсак болот).

```python
my_tuple = ('alma', 'апельсин', 'манго')

print(my_tuple)  ## ('alma', 'апельсин', 'манго') деп чыгат

# my_tuple'ге кайра тапшыруу
my_tuple = (1, 2, 3) 

print(my_tuple)  ## (1, 2, 3) деп чыгат
```

### Тууплду жок кылуу

`del` сөзү аркылуу тууплду толугу менен жок кылсак болот.

```python
fruits = ('alma', 'апельсин', 'манго')

print(fruits)  ## ('alma', 'апельсин', 'манго') деп чыгат

# fruits'ти өчүрүү
del fruits 

print(fruits)  ## КАТА чыгат, анткени fruits тууплу жок
```

### Чакырык
Эми келгиле, жогоруда Тизмелер менен жасалган машыктырууну бул жолу Тууплдар менен аракет кылып көрөлү.

Төмөндөгү мөмө-жемиштердин тизмеси менен баштаңыз. Тизменин ичиндеги ар бир мөмөнү басып чыгарып, ар бир мөмө жөнүндө колдонучудан бул жемишти жакшы көрөсүзбү деп сураңыз. Эгер жактырса, сактаңыз. Эгерде жактырбаса, аны тизмеден өчүрүңүз. Анан андан кийин, колдонучудан тизмеде жок бир мөмөнү кошууну сурануу; аны тизмеге кошуп, колдонучу жакшы көргөн мөмө-жемиштердин санын басып чыгарыңыз.

```python
fruits = ['апельсин', 'киви', 'банан', 'alma', 'манго', 'лимон']
```
