Тизмелер объекттердин иреттелген жыйындысы болуп саналат жана аларды төрт бурчтук кашаанын `[]` ичине үтүр менен бөлүнгөн маани катары жазса болот. Цикл жөнүндө сабакта көргөндөй эле, тизмелер ар кандай маалымат түрлөрүндө болушу мүмкүн, мисалы, сап же бүтүн сандар түрүндө.

```python
#5 мөмө-жемиштин тизмесин түзүү
fruits = ['апельсин', 'алма', 'банан', 'алма', 'манго']
```

Эгерде тизменин белгилүү бир элементине кайрылгыңыз келсе, муну төрт бурчтук кашаанын ичинде индекстерди (позицияны) колдонуу менен жасасаңыз болот. Биринчи элемент индекс (позициясы) `0` жана тизме `(тизмедеги элементтердин саны - 1)` чейин болот. Ошентип, 6 элементтен турган тизмеде индекстер 0дөн 5ке чейин болот.

```python
#5 мөмө-жемиштин тизмесин түзүү
fruits = ['апельсин', 'алма', 'банан', 'алма', 'манго']

#2-позициядагы элементти басып чыгаруу
print(fruits[2]) ##бананды басып чыгарат
```

**Индекс** | **Элемент**
-------|-------
0 | апельсин
1 | алма
2 | банан
3 | алма
4 | манго

{{% notice note %}}

Бул мисалдан көрүнүп тургандай, тизмеде кайталанма элементтер болушу мүмкүн.

{{% /notice %}}

Python'da, тизмелер бир эле маалымат түрүндө болууга милдеттүү эмес, ошол себептүү бир эле тизмеде саптар менен сандарды аралаштырып колдонсо болот.

```python
#тиземеде ар кандай маалымат түрлөрү болушу мүмкүн
my_list = ['таттуу', 10, 2.5]
```

### Тизменин узундугу

Тизменин узундугун `len(list)` функциясы аркылуу табууга болот жана тизменин атын параметр катары жиберет.

```python
length = len(fruits)  ##узундук = 5
```

### Тизмеге элемент кошуу

Тизмеге элементти кошуу үчүн `append` функциясын колдонсо болот, `list.append(x)` функциясында `list` тизменин аты жана `x` - кошулуучу элемент болуп саналат. Бул функция элементти тизменин аягына кошот.

```python
#Буга чейин тизме ['апельсин', 'алма', 'банан', 'алма', 'манго']
fruits.append('лимон')
#Эми тизме ['апельсин', 'алма', 'банан', 'алма', 'манго', 'лимон']
```

### Тизмеге элементти белгилүү бир индекс боюнча кошуу

Эгерде жаңы элементти кайсы жерге коюуну көзөмөлдөгүңүз келсе, аны белгилүү бир индекске коюу үчүн `list.insert(i, x)` функциясын колдонсоңуз болот. Бул жерде `list` тизменин аты, `i` - индекси жана `x` - кошула турган элемент. Эскерте кетсек, бул функция `i` позициясынан баштап элементтерди бир позицияга жылдырат.

```python
fruits.insert(1, 'гуява')
#Эми тизме ['апельсин', 'гуява', 'алма', 'банан', 'алма', 'манго', 'лимон']
```

### Тизмеден элементти алып салуу

`list.remove(x)` функциясы тизмеден берилген элементтин биринчи кездешүүсүн таап, аны алып салат.

```python
fruits.remove('алма')
#Эми тизме ['апельсин', 'гуява', 'банан', 'алма', 'манго', 'лимон']
```

{{% notice note %}}

`list.remove(x)` функциясы, эгерде берилген элемент `x` тизмеде жок болсо, ката жиберет.

Ошондой эле, `'алма'` элементтердин экинчи жолу кездешүүсү тизмеде калганын байкаңыз.

{{% /notice %}}


### Белгилүү бир позициядагы элементти алып салуу

`list.pop(i)` функциясы `i` индекси боюнча элементти алып салат.

```python
fruits.pop(0)
#Эми тизме ['гуява', 'банан', 'алма', 'манго', 'лимон']
```

{{% notice note %}}

Көрсөтүлгөн индекси жок болсо, `list.pop()` акыркы элементти алып салат.

{{% /notice %}}


### Тизме элементтерин тескери кылуу

`list.reverse()` функциясы тизмедеги элементтердин иретин тескери кылат.

```python
fruits.reverse()
#Эми тизме ['лимон', 'манго', 'алма', 'банан', 'гуява']
```

### Тизменин минималдуу жана максималдуу элементин алуу

`min(list)` функциясы тизмеден эң минималдуу элементти кайтарып берет, ал эми максималдуу элементти `max(list)` функциясы аркылуу табууга болот. Эгерде тизме сандардан турса, эң кичине же эң чоң маанини көрсөтөт. Эгерде тизме саптардан турса, алфавиттик жактан биринчи же акыркы чыгарылат.

```python

my_list = [4, 1, 2, 5, 3]  ## жаңы тизмени түзүү

print(min(my_list)) ## 1, минималдуу элементти басып чыгарат
print(max(my_list)) ## 5, максималдуу элементти басып чыгарат

```
{{% notice note %}}

Эгерде сиздин тизмеңиз саптар менен сандардын аралашмасынан турса, `min` жана `max` функциялары ката берип, иштебейт.

{{% /notice %}}

### Чакырык

Биз эми өзүбүз аракет кылып көрөлү. Төмөндө берилген жемиштердин тизмесинен баштаңыз. Жемиштердин тизмесин басып чыгарып, ар бир жемиш үчүн колдонуучудан алар аны жактырабы же жокпу сураңыз. Эгерде алар жактырса, ошол жемишти тизмеде калтырыңыз. Эгерде алар жактырбаса, аны тизмеден алып салыңыз. Андан соң, тизмеде жок жемиш
