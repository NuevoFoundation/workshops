Тизме сыяктуу эле, топтом – бул элементтердин жыйындысы. Топтом менен тизмелердин айырмасы – топтомдо кайталанган элементтер болбойт. Ошентип, эгер сизде 5 шоколад бар болсо жана аларды топтомго салсаңыз, кайталанган элементтер өчүрүлүп, кол жазмада 1 гана шоколад калат. 😢

Жогорудагы сүрөттө сол жагы **<font color="#b00020">Ички оюндарды</font>** (шахмат жана үстөл тенниси), ал эми оң жагы **<font color="#2e6b2e">Сырткы оюндарды</font>** (крикет жана футбол) көрсөтөт. Ортодо экөө тең бирдей болгон бөлүгү көрсөтүлгөн. Бул оюндар үйдө да, сыртта да ойнотулуп келет (баскетбол жана бадминтон). Ортонку бөлүгү эки топтомдун кесилиши катары белгилүү.

{{% notice tip %}}
Топтомду түзүү үчүн `set()` функциясын же бардык элементтерди фигуралдык кашаанын ичине жайгаштыруу жетиштүү.
{{% /notice %}}

```python
indoorGames = set(["Chess", "Table Tennis", "Basketball", "Badminton"])
outdoorGames = {"Cricket", "Football", "Basketball", "Badminton"}
print('** Ички оюндар **')
print(indoorGames)
print('** Сырткы оюндар **')
print(outdoorGames)
```

**Жыйынтык**
```
** Ички оюндар **
set(["Chess", "Table Tennis", "Basketball", "Badminton"])
** Сырткы оюндар **
set(["Cricket", "Football", "Basketball", "Badminton"])
```

### Топтомдордун биригүүсү (Union)
Эгерде бизде жогорудагы сыяктуу 2 топтом бар болсо, алардын биригиши (union) эки топтомдогу бардык оюндарды камтыйт. Жыйынтыгында жаңы топтом пайда болот, анда кайталанган элементтер өчүрүлөт.

Биригүү үчүн колдонулган символ `|` болуп саналат.

```python
allGames = indoorGames | outdoorGames
print('** Бардык Оюндар **')
print(allGames)
```

**Жыйынтык**
```
** Бардык Оюндар **
set(["Chess", "Table Tennis", "Basketball", "Badminton", "Cricket", "Football"])
```


### Топтомдордун кесилиши (Intersection)
Эки топтомдун кесилиши (intersection) бир эле учурда ички жана сырткы ойнолгон оюндардын жыйындысын берет.

Кесилиш үчүн колдонулган символ `&`.

```python
commonGames = indoorGames & outdoorGames
print('** Жалпы Оюндар **')
print(commonGames)
```

**Жыйынтык**
```
** Жалпы Оюндар **
set(["Basketball", "Badminton"])
```

### Топтомдордун айырмасы (Difference)
Эки топтомдун айырмасы (difference) бир топтомдон башка топтомдо жок болгон оюндардын жыйындысын көрсөтөт.

Айырма үчүн колдонулган символ `-`.

```python
indoorOnlyGames = indoorGames - outdoorGames
print('** Жалаң Ички Оюндар **')
print(indoorOnlyGames)
```

**Жыйынтык**
```
** Жалаң Ички Оюндар **
set(["Chess", "Table Tennis"])
```

### Топтомдогу элементтерди чыгаруу
Тизмедеги сыяктуу эле, топтомдун элементтерин алардын номерин көрсөтүү менен чыгара албайсыз. Топтом элементтери белгиленген тартипте болбогондуктан, `indoorGames[0]` же `indoorGames[1]` сыяктуу коддор менен иштеп болбойт. Бирок, топтомдун элементтерин `for` цикли аркылуу чыгара аласыз.

```python
for g in indoorGames:
  print(g)
```

**Жыйынтык**
```
Chess
Table Tennis
Basketball
Badminton
```

### Топтомго элемент кошуу
Жаңы оюнду топтомго кошуу үчүн `.add` функциясын колдонобуз. 
```python
indoorGames.add("Carrom")
print('** Ички Оюндар **')
print(indoorGames)
```


**Жыйынтык**
```
** Ички Оюндар **
set(["Chess", "Table Tennis", "Basketball", "Badminton", "Carrom"])
```

### Топтомдон элементти алып салуу
Топтомдон элементти өчүрүү үчүн `.discard` функциясын колдонобуз. 
```python
indoorGames.discard("Chess")
print('** Ички Оюндар **')
print(indoorGames)
```

**Жыйынтык**

```
** Ички Оюндар **
set(["Table Tennis", "Basketball", "Badminton", "Carrom"])
```
{{% notice note %}}
Эгер топтомдо болбогон элементти өчүрсөңүз, эч кандай ката чыкпайт. Ошол эле учурда, эгерде сиз тизмеде жок элементти өчүрүүгө аракет кылсаңыз, анда `ValueError` пайда болот!
{{% /notice %}}

### Тапшырма
Буга чейинки Тизмелер жана Турлер менен жасаган көнүгүүңүздү эми Топтомдорду колдонуп көрөлү.  

Төмөндө берилген жемиштердин тизмесинен баштаңыз. Жемиштердин тизмесин чыгарып, ар бир жемиш боюнча колдонуучудан аны жактыраарын сураңыз. Эгер жактырса, аны тизмеде калтырыңыз. Эгер жактырбаса, аны топтомдон алып салыңыз. Андан кийин, колдонуучудан тизмеде жок бир жемишти кошууну сураңыз. Жемишти тизмеге кошуп, колдонуучу жактырган жемиштердин санын чыгарыңыз.

```python
fruits = ['orange', 'kiwi', 'banana', 'apple', 'mango', 'lemon']
```
