##### Коркпоңуз! Төмөнкү кеңештер жардам бере албай калса, биз менен байланышыңыз, жана биз жардам беребиз.

1.  Индентация (чыгуу деңгээли) Python'до иштөөдө абдан маанилүү. Коддогу боштуктар жана таблар менен этият болуңуз, анткени индентация каталарын таануу кээде өтө кыйын болушу мүмкүн.

    ![IndentationError: expected an indented block](../img/screenshot-indentationerror.png)

    Бирок, жакшы жагы, катаал форматтоо Python кодун абдан таза жана уюшкан кылат. Бардык өзгөрмөлөрүңүз, функцияларыңыз көрсөтүлгөндөй индентацияланганбы?
    
2.  SyntaxError: invalid syntax  
    Сиз колдонгон ачкыч сөздөр туура жазылган жана түзүлүш эреже боюнча аткарылганбы, текшериңиз.

3.  IndentationError: unexpected indent  
    Эгерде бул катаны көрсөңүз, индентацияларды текшериңиз.

4.  NameError: global name '\-\--' is not defined  
    Функция ичинде аныкталган өзгөрмөлөр ошол функция ичинде гана колдонууга мүмкүн. Эгерде сиз бир өзгөрмөнү башка бир функцияда колдонууга аракет кылсаңыз, бул катаны аласыз.  

    Башка функцияларда маалымат жеткиликтүү болушу үчүн, аны `return` оператору менен бир функциядан чыгарып, мүмкүн болсо өзгөрмөгө ыйгарып койсоңуз болот. Андан соң, экинчи функцияга параметр катары өткөрсөңүз болот. Бул тууралуу тереңирээк түшүнүк алуу үчүн менин кол тамгамдагы функциялар сабагына шилтемени көрүңүз.

5.  "Катаны тааный албай жатасыз": жазылыштагы ката?  
    Мындай ката, эреже катары, ачкыч сөздөрдүн жазылышында каталар болгон учурда пайда болот. Бардык ачкыч сөздөрүңүздү текшериңиз.

6.  TypeError: Can't convert 'int' object to str implicitly  
    Сиз бүтүн санды (integer) тексттик аракеттерде колдонууга аракет кылып жаткан жоксузбу, текшериңиз. (Сиз бир текстти жана бүтүн санды бирдей чогулта албайсыз. Бириң санды адегенде текстке айландырышыңыз керек).
