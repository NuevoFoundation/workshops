### Чоң ичке циклдер
*Чоң ичке циклдер*, мурунку көнүгүүдөгү for-цикл жана while циклдеринен үйрөнгөн нерселерди негиз кылат. Улантуудан мурда <a href="../loops/" target="blank">For-цикл жана While-цикл</a> бетин карап чыгууңуз мүмкүн.

Бул бөлүмдө биз бир циклдин ичинде экинчи циклди пайдаланабыз, бул *чоң ичке цикл* деп аталат.
<hr/>

### Ичке while цикли
```python
# Бул чоң ичке while циклинин форматы
while expressionA:
    while expressionB:
        statement(B)
    statement(A)
```
Жогорудагы `while` циклде, expressionA `False` болуп чыкса, бүт блок өткөрүлүп кетет. ExpressionA `True` болгондо, ички while циклге кирип, expressionB текшерилет. Эгер expressionB `True` болсо, statement(B) аткарылат. Эгер expressionB `False` болсо, ички while цикл өткөрүлүп, башка statement(A) аткарылат.

Эгер expressionA `False` болсо, эч бир билдирүү аткарылбайт; statement(A) жана statement(B) экөө тең аткарылат, эгерде expressionA жана expressionB экөө тең `True` болсо гана.

Чоң ичке while циклинин бир мисалын карап көрөлү.
 ```python
 #Бул чоң ичке while циклинин мисалы.
 x = 0
 y = 0
 #Төмөнкү биздин сырткы цикл болот
 while x < 3:
     #Эгер "x < 3" True болсо басып чыгаруу
     print("Сырткы while цикли, x", x, "y", y, sep=" ")
     #Төмөнкү биздин ички цикл болот
     while y < 5:
         #Эгер "y < 5" True болсо басып чыгаруу
         print("Ички while цикли, x", x, "y", y, sep=" ")
         y += 1
     # төмөнкү коддор ички цикл аяктагандан кийин аткарылат.
     x += 1
     y = 0
 ```
Бул мисалдын чыгарылган жыйынтыгы төмөнкүдөй.

 ```output
Сырткы while цикли, x 0 y 0
Ички while цикли, x 0 y 0
Ички while цикли, x 0 y 1
Ички while цикли, x 0 y 2
Ички while цикли, x 0 y 3
Ички while цикли, x 0 y 4
Сырткы while цикли, x 1 y 0
Ички while цикли, x 1 y 0
Ички while цикли, x 1 y 1
Ички while цикли, x 1 y 2
Ички while цикли, x 1 y 3
Ички while цикли, x 1 y 4
Сырткы while цикли, x 2 y 0
Ички while цикли, x 2 y 0
Ички while цикли, x 2 y 1
Ички while цикли, x 2 y 2
Ички while цикли, x 2 y 3
Ички while цикли, x 2 y 4
 ```

#### Суроолор
x жана y маанилери кандай өзгөрүп жатканын байкап, мунун себебин түшүнүүгө аракет кылыңыз.

### Ичке for цикли

```python
# Бул чоң ичке for циклинин форматы
for variableA in rangeA:
   for variableB in rangeB:
      statements(B)
   statements(A)
```
Жогорудагы `for` циклде, variableA rangeA ичинде болбосо, бүт блок өткөрүлүп кетет. Эгер variableA rangeA ичинде болсо, ички for циклге өтөбүз. Эгер variableB rangeB ичинде болсо, statement(B) аткарылат. Эгер variableB rangeB ичинде болбосо, ички цикл өткөрүлүп, сырткы циклге өтөбүз.

Эгер variableA rangeA ичинде болбосо, эч бир билдирүү аткарылбайт; statement(B) жана statement(A) экөө тең аткарылат, эгерде variableA rangeA ичинде жана variableB rangeB ичинде болсо гана.

Бир мисалды карап көрөлү.

```python
#Бул чоң ичке for циклинин мисалы
#Төмөнкү биздин сырткы цикл болот
for n in range(0, 3):
    #Төмөнкү биздин ички цикл болот
    for m in range(0, 3):
        #Эгер m range(0, 3) ичинде болсо басып чыгаруу
        print("(", n, ",", m, ")", end = " ")
    #Эгер n range(0, 3) ичинде болсо басып чыгаруу
    print("")
```
Бул мисалдын чыгарылган жыйынтыгы төмөнкүдөй.

```output
( 0 , 0 ) ( 0 , 1 ) ( 0 , 2 ) 
( 1 , 0 ) ( 1 , 1 ) ( 1 , 2 ) 
( 2 , 0 ) ( 2 , 1 ) ( 2 , 2 ) 
```
