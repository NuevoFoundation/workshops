## Python'да циклдер

Эгерде сиз бир тапшырманы бир нече жолу аткарууну кааласаңыз, анда Python бул үчүн циклдерди колдонуу менен оңой жардам бере алат.  
Python'до негизги эки түрдөгү цикл бар: `for` циклдери жана `while` циклдери.

### For циклдери

For циклдери тизмек боюнча кайталап өтөт. Келгиле, жөнөкөй тапшырманы 5 жолу кайталагыңыз келгенин айталы. Бул жерде аны кандайча аткаруу керектиги көрсөтүлгөн.

Төмөнкү for цикли [1,2,3,4,5] тизмегиндеги ар бир сандын аралап өтүп, x маанисине дайындайт. Андан кийин, for циклдин ичиндеги кодду аткарат.

```python
for x in [1,2,3,4,5]:    
    print("Биз цикл номери",x, "үдөмө турган жердебиз")
```

Эгерде сиз бир тапшырманы 10 жолу кайталоону кааласаңызчы? 100 жолу? Же 1000 жолу??

[1,2,3,4,5,6,..........,998,999,1000] сыяктуу 1000 санды камтыган тизмени жазуу оор болот. Бул тизмени жаратуу үчүн атайын функция бар.

Муну `range` функциясын колдонуп тизмени жаратуунун мисалы:

Төмөндөгү код 1ден башталып, 10 менен бүткөн тизмени жаратат.  
```
range(1,11)
```
Эми жогорудагы мисалдагы [1,2,3,4,5] тизмесин ушул `range` функциясы менен алмаштырууга аракет кылыңыз!

For циклдеги тизмек болгону сандардан эмес, бул баары болушу мүмкүн! Мына дагы бир мисал:  

```python
fruits = ["алма","банан","апельсин"]

for x in fruits:
    print(x)
```

### While циклдери

While циклдери for циклдерине окшош, бирок алар тизмек боюнча кайталоонун ордуна, белгилүү бир шарт аткарылганга чейин кайталашат.  
Мисалы, 5 жолу кайталоочу while циклин түзүп көрөлү.

```python
count = 0

while count < 5:
    print("Учурдагы эсеп", count)
    count += 1  # Бул count = count + 1 дегенди билдирет
```

Көрүп тургандай, while циклдин астындагы бардык код count өзгөрмөсү 5ке жеткенге чейин аткарылат.

Этият болуңуз! Шарт кандайдыр бир учурларда `False` деп өзгөрүшү керек, антпесе цикл түбөлүк созулат.

### Break оператору

Мурда көрүнүп өткөндөй, for циклдери жана while циклдери тизмек аягына жеткенге чейин же шарт аткарылганга чейин кайталап өтөт.

Циклди булардан башка ыкма менен да эрте токтотууга болот.

Муну `break` оператору менен аткара аласыз. Бул оператор for жана while циклдеринен чыгууну камсыз кылат.

Мына `break` оператору while циклинде кантип колдонулганына мисал:

```python
count = 0

while True:  # Бул цикл түбөлүк кайталоону камсыз кылат! эгер циклде кайсы бир жерде break операторы колдонулбаса.
    print("Эсеп", count)
    
    if (count == 10):  # Эгерде count 10го барабар болсо, циклден чык дегенди билдирет.
        print("Циклди токтотуу!")
        break
    
    count += 1  # Бул count = count + 1 дегенди билдирет
```
