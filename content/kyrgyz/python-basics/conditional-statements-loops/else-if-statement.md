Акыркы машыгууда, биз негизги if-else шарттарын билгенбиз. Эгер сизге кыскача эстөө керек болсо, муну <a href="../conditional-statements/"> Шарттуу билдирүүлөр</a> бөлүмүнөн кайра карасаңыз болот.

Бул бөлүмдө, биз жаңы шартты — "elif" шартын тааныштырабыз.

### Elif Шарты

**Elif** ачкычы "else-if" шартын билдирет. Реалдуу дүйнөдөн мисал келтирсек: Эгер мен чынында эле абдан ачка болсом, пирог жейм; эгер мен бир аз гана ачка болсом, алманы жейм; эгер мен такыр ачка болбосом, эч нерсе жебейм. Бул биринчи шарт туура болбосо, башка шартты текшерүүнү каалаганда колдонулат.

```python
# Бул негизги elif синтаксиси
if expression:
    statement(s)
elif expression:
    statement(s)
else:
    statement(s)
```

#### Мисал көрөлү
```python
# Бул мисал
if 1 > 3:
    print('1>3')
elif 1 == 3:
    print('1=3')
else:
    print('1<3')
```
Бул жерде биринчи билдирүү, `1` үчтөн чоң, туура эмес экенин көрөбүз, ал `false` деп бааланат. Ошондуктан бул `if` билдирүүсүнүн ичиндеги код аткарылбайт. Андан кийин `elif` билдирүүсүн баалайбыз: `1` үчкө барабар, бул да `false` деп бааланат. `elif` ичиндеги код дагы аткарылбайт. Ошондуктан `else` ичиндеги нерсе басылат.

### Эскертүү: `elif` менен `if` бири-биринен айырмаланат  
#### Эки мисалды көрөлү
#### Мисал А
```python
# Бул эки if билдирүүсүнүн Мисал А
if 1 == 1:
    print('1=1')
if 3 == 3:
    print('3=3')
else:
    print('туура эмес')
```
Мисал А төмөнкүнү басып чыгарат:

```
1 = 1
3 = 3
```

#### Мисал Б
```python
# Бул elif билдирүүсүнүн Мисалы
if 1 == 1:
    print('1=1')
elif 3 == 3:
    print('3=3')
else:
    print('туура эмес')
```
Мисал Б төмөнкүнү басып чыгарат:

```
1 = 1
```

Мисал Ада биринчи `if` билдирүүсү (`1==1`) туура деп бааланат. Ошентип, биринчи `if` билдирүүсүнүн ичиндеги код аткарылат. Андан кийин экинчи `if` билдирүүсү (`3==3`) да туура деп бааланат. Ошондуктан экинчи `if` билдирүүсүнүн ичиндеги код дагы аткарылат.

Мисал Бда биринчи `if` билдирүүсү (`1==1`) туура деп бааланат. Ошондуктан андан кийин `elif` жана `else` бөлүктөрү бааланбайт, анткени `if` буга чейин туура болгон.
