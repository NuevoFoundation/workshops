Эми биз басып чыгаруу үчүн билдирүүлөр, өзгөрмөлөр жана колдонуучудан киргизүү маалыматтарын окуу негиздерин билгенден кийин – бул укмуштуудай көндүмдөрдү шарттуу билдирүүлөр менен айкалыштыра алабыз. Шарттуу билдирүүлөр компьютерге **мааниде** көрсөтүлгөн баалуулукка негизделип **чечимдерди** кабыл алууга мүмкүндүк берет. Реалдуу жашоодо биз чечим кабыл алууда дайыма шарттуу билдирүүлөрдү колдонобуз! Мисалы, эгерде сыртта жамгыр жаап жатса, анда мен чатыр колдонуп чыгам. Бул мисалда, мен абаны баалап көрдүм, жамгыр жаап жаткандыктан, анан мен чатырды колдонуу чечимин кабыл алдым.

Сиз күнүмдүк жашоодо колдоно турган кандай шарттуу билдирүүлөрдү ойлоп таба аласыз?

# Эгерде билдирүүлөр

Биз эң жөнөкөй формадагы эгерде ("if") билдирүүсүнөн баштайбыз! Реалдуу жашоодогу мисалды карасаңыз, айрым өзгөчө сөздөрдү байкап, алар программисттик билдирүүлөрдө да колдонуларын көрө аласыз. **Эгерде** сыртта жамгыр жаап жатса, анда мен чатыр колдонуп чыгам. `if` бизден чечим кабыл алуу керектигин айтып турат. Сыртта жамгыр жаап жатабы? Бул суроо мааниси - чыгарылган баа. Анан, эгерде чындап эле жамгыр жаап жатса, мен чатыр колдонуп чыгам. Бул мааниси **чындык** болгон учурларда колдонулуучу билдирүү.

```python
if (expr):
    statement
```

Жогоруда көрсөтүлгөндөй, бизде үч башка бөлүк бар:

1. Эгерде – бул компьютерге кашаанын ичиндеги мааниге жараша чечим кабыл ала турганыңызды билдирет.
2. Expr – бул биз баалап жаткан маани. Эгерде маани "чын" болсо, анда компьютер эгерде ("if") билдирүүсүнүн ичине кирип, аны ишке ашырат.
3. Билдирүү – компьютер мааниси "чын" болсо аткара турган иш-аракет.

```python
x = 0
y = 5

if (x<y):       # чын
    print('ооба')
if (y<x):       # жалган
    print('ооба')
if (x == 10):   # жалган
    print('ооба')
```

Келгиле, жогорудагы мисалды бөлүп карап, айрым билдирүүлөрдүн эмне үчүн "чын" же "жалган" экенин чечип көрөлү.

Бизге эки өзгөрмө берилет `x` жана `y`, жана аларга баалуулуктар белгиленген. Биринчи "if" билдирүүсүндө биз `x` маанисинин `y` маанисинен кичине-күчү экенин текшерип жатабыз. Анткени `0` `5`тен кичине, бул чындык! Ошентип, биринчи "if" билдирүүсү **ооба** деп басып чыгарат.

Бирок, биз көрүп турсак, `y` `x`тен кичине эмес, бул жалган деп бааланат. Анан "if" билдирүүсүнүн ичине кирбей калат жана ал аткарылбайт. Ошондой эле, 'x' 10го барабар деп бааланбаганына тиешелүү. Биз көрүп турабыз, `x` 0го барабар, ошондуктан бул маани **жалган**, жана "if" билдирүүсүнүн ичине кирип ишке ашпай калат.

# Башкача билдирүүлөр

Эми биз "if" билдирүүлөрүн бир же бир нече билдирүүлөрдү шарттуу түрдө аткаруу үчүн кантип колдонууну билгенден кийин, "else" менен дагы эмне кыла аларыбызды көрөлү!

Кээде, биз бир нерсенин шартын текшерип, эгерде ал **чын** болсо, ошого жараша иш-аракет кылууга туура келет, бирок ал **жалган** болсо, башкача иштөө керек болот. **Else** билдирүүсүнүн эң жөнөкөй формасы төмөндөгүдөй.

```python
if (expr):
    statement1
else: 
    statement2
```    

Бул чындыгында эле "if" билдирүүсүнө окшош! Бирок, бул жерде, эгерде "if" билдирүүсү жалган болсо (чынчыл эмес), анда программа автоматтык түрдө "else" билдирүүсүндөгү statement2ди аткарат.

Жашоодогу чыныгы мисал, эгерде мен ачка болсом, мен тамактанам. Болбосо (башкача айтканда, мен ачка болбосом), мен тамактанбайм. Python кодунда мындай көрүнөт:

```python
if (hungry):
    eat
else:
    dont_eat
```
