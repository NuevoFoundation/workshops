## Баштап билүү

### Консолго жазуу - 1-тапшырма

```python
print("Салам, дүйнө!")
```

Натыйжа:
```
Салам, дүйнө!
```

### Консолго жазуу - 2-тапшырма

Кошумча текстти камтыган экинчи `print` операторун кошуңуз:

```python
print("Салам, дүйнө!")
print("Мен Python үйрөнүп жатам!")
```

### Өзгөрмөлөр - Тапшырма

`comp = "Computer"` жана `five = 5` өзгөрмөлөрүн колдонуп, төмөнкү натыйжаны чыгарыңыз:

```python
comp = "Computer"
five = 5
print(comp)
print(five)
print(comp + comp)
print(five + five)
print(comp + comp + comp)
print(five + five + five)
```

Натыйжа:
```
Computer
5
ComputerComputer
10
ComputerComputerComputer
15
```

### Консолдон окуу - Тапшырма

```python
print("Кош келиңиз!")
print("Сизге кантип жардам бере алам?")
value = input()
print("Сиз берген суроо: " + value + "?")
print(value + " боюнча менде жооп жок. Кош болуңуз!")
```

Мисалга натыйжа (эгерде колдонуучу "Python деген эмне?" деп жазса):
```
Кош келиңиз!
Сизге кантип жардам бере алам?
Сиз берген суроо: Python деген эмне?
Python деген эмне? боюнча менде жооп жок. Кош болуңуз!
```

## Маалымат түрлөрү

### Сабактар - 1-тапшырма

Атыңызды жана фамилияңызды бириктириңиз:

```python
first = "Nuevo"
last = "Foundation"
print(first + " " + last)
```

Натыйжа:
```
Nuevo Foundation
```

### Сабактар - 2-тапшырма

"Nuevo Foundation" сабын ар биринде эки `+` символу бар үч ыкма менен басып чыгарыңыз:

```python
print("Nuevo" + " " + "Foundation")
print("Nuevo " + "Foun" + "dation")
print("Nue" + "vo Foundati" + "on")
```

Көптөгөн туура чечимдер бар! Каалаган комбинация "Nuevo Foundation" натыйжасын берип, эки гана `+` белгисин колдонсо, ал кабыл алынат.

### Сандардын иштетүүсү - 1-тапшырма

```python
print(2 - 19)
print((3 + 5) * 6)
print((13 + 5 * 8) / (6 - (3 + 7)))
```

Натыйжа:
```
-17
48
-13.25
```

Математикалык чечмелөө үчүнчү операторго:
- Числитель: 13 + (5 * 8) = 13 + 40 = 53
- Знаменатель: 6 - (3 + 7) = 6 - 10 = -4
- Натыйжа: 53 / -4 = -13.25

### Сандардын иштетүүсү - 2-тапшырма

{{% notice warning %}}
Курстун текстинде `"527 time 199 is: __"` деп айтылган — бул текст "times" (көптүк же көбөйтүү) дегенди билдиргенде эле ката болуп калса керек. Төмөндөгү жооп текстин так ошол бойдон ылайыкташтырылды.
{{% /notice %}}

```python
print("527 time 199 is: " + str(527 * 199))
```

Натыйжа:
```
527 time 199 is: 104873
```

Эсиңизде болсун, санды сап менен бириктирүү үчүн аны `str()` менен сапка айлантуу керек.

### Логикалык типтер - 1-тапшырма

{{% notice warning %}}
Экинчи оператордун `if` жана `print` ортосундагы каражат кашаалар туура жайгаштырылган эмес. Төмөнкү жооп `print` ичинде салыштырып, оңдоо менен көрсөтүлгөн.
{{% /notice %}}

```python
print(5 + 8 < 10)
print((3 + 5) * 6 == (65 - 17))
```

Натыйжа:
```
False
True
```

- 5 + 8 = 13, жана 13 < 10 `False`
- (3 + 5) * 6 = 48, жана 65 - 17 = 48, ошондуктан 48 == 48 `True`
