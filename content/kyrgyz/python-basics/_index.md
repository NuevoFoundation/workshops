## Кароо

**Python: Негиздер** курсуна кош келиңиз, бул жерде сиз компьютерге кызыктуу программаларды жаратуу үчүн буйруктарды бере турган кеңири колдонулган, жогорку деңгээлдеги программалоо тилин үйрөнөсүз!

Python программалоо тили 1985-1990-жылдары Гвидо ван Россум тарабынан түзүлгөн.

{{% notice info %}}
Жогорку деңгээлдеги программалоо тили жогорку деңгээл деп аталат, анткени ал компьютердин борбордук иштетүү бөлүмүндө (CPU) иштеген баштапкы коддон бир топ алыс турат. Жогорку деңгээлдеги код адамдар тарабынан колдонуу үчүн жасалган жана төмөнкү деңгээлдеги кодго караганда түшүнүү оңой. Жогорку деңгээлдеги код кийин төмөнкү деңгээлдеги тилге которулат, аны атайын CPU гана иштетип жана түшүнө алат. Код иштеши үчүн, жогорку деңгээлдеги тилде жазылган ар бир сап код компьютер тарабынан аткаруудан мурун машина тилине которулушу керек.
{{% /notice %}}

Бүгүнкү күндө Python дүйнө жүзү боюнча иштеп чыгуучулар тарабынан колдонулат. Өзгөчө, Python веб-сайттарды, программалык компоненттерди жана тиркемелерди иштеп чыгуу үчүн, же маалымат илимдери, жасалма интеллект жана машина менен билим алуу технологиялары менен иштөөдө колдонулат.

Ал эми бул курста биз тилдин бардык негизги функцияларын камтыйбыз.

Эгерде кандайдыр бир учурда кыйынчылыкка туш болсоңуз же көйгөйлөргө кабылсаңыз, [Жардам, мен кыйналып жатам!](help/) баракчасынан жалпы каталарга чечүү жолдорун карап, тез кеңештерди алсаңыз болот.
