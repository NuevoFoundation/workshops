Компьютер математиканы да иштей алат. Математикалык формулалардын жыйынтыктарын басып чыгаруу үчүн `print()` функциясын колдонуңуз. Сандар үчүн ырчы белги керек эмес! Саптардан айырмаланып, сандар менен математика жүргүзсөңүз болот.

```python
print(7-3)  # 4 чыгарат
print(5 * -6 + 7)   # -23 чыгарат
print(24 * (8-3) / 6)   # 20.0 чыгарат
```

{{% notice note %}}
Python 3'те `/` оператору дайыма ондук жыйынтык чыгарат. Бөлүп, бүтүн сан алуу үчүн (калдыкты эсепке албай), `//` колдонсоңуз болот.

Мисалы,

`15 / 4` - `3.75` чыгарат
`15 // 4` - `3` чыгарат

{{% /notice %}}

Сиз да математикалык символдорду колдонуп, өз формулаларыңызды жазып көрүңүз! 

| Символ            | Колдонулушу       | Символ      | Колдонулушу       |
| ------------------ | ---------------- | ----------- | ---------------- |
| `+`               | Кошуу            | `*`         | Көбөйтүү         | 
| `-`               | Алуу             | `/`         | Бөлүү            | 

### Чакырык 1

Python'до төмөнкүлөрдүн жыйынтыктарын эсептеп көрөлү. Жыйынтыгын басып чыгарууну унутпаңыз (<b>каракөздөрдү өткөрүп жибербөөгө аракет кылыңыз</b>):

- 2 - 19
- (3 + 5) * 6
- (13 + 5 * 8) / (6 - (3 + 7))

### Чакырык 2

Бул билдирүүнү басып чыгара аласызбы? `"527 жолу 199: __"`

Боштукка `(527 * 199)` жыйынтыгын толтурасыз. Эгерде сап менен санды бирге басып чыгаргыңыз келсе, санды алгач сапка айлантууга туура келет.

Мисал: <font color="#005a9c">print</font>(`"Салам, дүйнө!"` + str(5))

{{% notice tip %}}

`str(5)` санды `"5"` сапка айландырат. Бир түрдүн башка түргө айланышы "кастинг" деп аталат.

{{% /notice%}}

#### Кызыктуу факты: Кокус Сандар

Бул жерден 1 (ички, кошулган) менен 10 (ички, кошулган) ортосундагы кокус санды басып чыгаруунун жолун көрүүгө мүмкүн:

 ```python 
 # Бул линия талап кылынган китепкананы импорттойт
 from random import randint
 # Бул линия 1 (кошулган) менен 10 (кошулган) ортосунда кокус санды басып чыгарат
 print(randint(1,10))
 ```

Тагыраак билгиңиз келеби? Жардам сураңыз же интернетти жазыңыз! Ар бир программалоочунун эң мыкты досу издөө системасы болот!

Айрыкча, <font color="#005a9c">from</font> жана <font color="#005a9c">import</font> сөздөрүнүн кандай иштээрин түшүнүүгө аракет кылыңыз. Бул сөздөрдү проект учурунда кайра колдонобуз.
