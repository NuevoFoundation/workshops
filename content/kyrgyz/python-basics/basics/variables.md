Мурунку тапшырмада биз `print("")` менен ар түрдүү мазмунду басып чыгарууну үйрөнгөнбүз. Бир санды же сүйлөмдү басып чыгаруу сонун болгону менен, биз аларга эч кандай маанини бере элекпиз. Өзгөрмөлөр – бул саптарды, сандарды жана логикалык маанилерди сактай турган аттар. Төмөндө Python тилинде s аттуу өзгөрмөнү кантип түзсө болорун көрөлү. Биз бул мисалда s – бул `"Hello, World!"` маанисин камтыган сап деп айтып жатабыз.

```python
s = "Hello, World!"
x = 88
happy = True
```
Run баскычын басыңыз.

Эскертүү: өзгөрмөлөр консолдо көрүнбөйт. Анын ордуна, өзгөрмө сапты, санды же логикалык маанини компьютердин эсине сактап калат. Биз бул өзгөрмөлөрдү башка буйруктарда колдонсок болот. Мисалы, төмөнкү код `"Hello Nuevo Foundation"` деп консолго басып чыгарат:

```python
str1 = "Hello"
str2 = "Nuevo Foundation"
print(str1 + " " + str2)
```

Ошондой эле төмөнкүдөй кылып саптарды кошуп, сөздөрдүн ортосуна боштуктарды кошуп басып чыгарсаңыз болот:

```python
str1 = "Hello"
str2 = "Nuevo Foundation"
print(str1, str2)
```

## Түр деген эмне!

Өзгөрмө түзүүнү үйрөнүүдөн мурун биз **түр** деген түшүнүктү билишибиз керек. Түр – бул кутуга эмне сакталганын билдирет.

Python – динамикалуу түргө ээ тил, демек, Java сыяктуу тилдерден айырмаланып, өзгөрмө үчүн сакталуучу маанинин түрүн аныктап айтып коюунун кереги жок. Эгерде кутуда бүтүн сан болсо, анын ордуна сапты койсоңуз, Python муну кабыл алат. Бирок, сиз өзгөрмөнү анын түрүнө жараша колдонушуңуз керек.

{{% notice note %}}
Төмөндө маанилүү маалыматтар түрлөрү келтирилген:

**Түрү** | **Түшүндүрмөсү** | **Мисалдар**
-------- | ----------------- | -------------
`integer` | бүтүн сан | `20`, `30`, `35`
`string` | символдордун ирети | `"Hello"`, `"Bonjour"`, `"Hola"`
`boolean` | мааниси `true` же `false` болот | `true`, `false`
`float` | бөлчөк сандар | `2.0`, `3.14`, `9.33`

{{% /notice %}}

Биринчи мисалда айтылган үч өзгөрмөнү кайра талдап, алардын түрлөрүн аныктайлы: `s` – сап, `x` – бүтүн сан, ал эми `happy` – логикалык мааниде.

### Тапшырма

- Эки жаңы өзгөрмө түзүңүз: `comp` деген өзгөрмө түзүп, ага `"Computer"` сап маанисин сактаңыз.
- `five` деген өзгөрмө түзүп, ага `5` санын сактаңыз.

Андан соң, өзгөрмөлөрдү жана мурдагы тапшырмалардан үйрөнгөн нерселериңизди колдонуп, консолдо төмөнкүлөрдү басып чыгарыңыз. Сөзсүз түрдө өзгөрмөлөрдү **колдонуңуз**!

    Computer
    5
    ComputerComputer
    10
    ComputerComputerComputer
    15

{{% notice tip %}}

Кеңеш: Эгер кыйынчылык жаралса, `+` операторун колдонууну ойлонуп көрүңүз. **comp** жана **five** өзгөрмөлөрүн бир эле саптын ичинде бир нече жолу колдоно аларыңызды унутпаңыз!
