## Кыскача маалымат

Бул бөлүмдө биз бул курс бою колдонулуучу куралды жана Python жана башка программалоо тилдерин үйрөнүү үчүн маанилүү болгон айрым негизги түшүнүктөрдү тааныштырабыз. Экранга кандайча жазуу керектигин, кодуңузга белгилерди кошууну, маалыматтарды сактоону жана программаңыздын колдонуучусунан маалымат алууну үйрөнөсүз.

Келгиле, баштайлы!
