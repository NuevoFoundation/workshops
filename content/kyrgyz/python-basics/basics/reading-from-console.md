Өзгөрмөлөр жөнүндө негиздерди билгенден кийин, биз колдонуучудан киргизүү күтүүгө программа жазсак болот. Төмөнкү сапты колдонуу менен, программа консолдо колдонуучу бир нерсе термейинче күтөт. Андан кийин компьютер консолго жазылган нерсени алып, аны **value** аттуу өзгөрмөгө сактайт.

```python
value = input()
```

Төмөндө колдонуучунун киргизүүсүн кабыл алуу үчүн `input()` кантип колдонулары боюнча мисал келтирилген:

```python
print("Атыңыз ким?")
value = input()
print("Салам " + value + "!")
```

Муну өз жаныңызда сынап көрүңүз! Программаны иштеткениңизде, консолдо төмөндөгү сүрөт азырынча көрүнбөйт.

![Консолдун акыркы символунун скриншоту](../../img/end_symbol.png "консолдун акыркы символунун сүрөтү")

![Консолдо колдонуучунун киргизүүсүн күтүп турган экрандын скриншоту](../../img/console_read_waiting.png "Консол колдонуучунун киргизүүсүн күтүп жатканда экран кандай көрүнөөрү")

Анын себеби программа сиздин бир нерсе теришиңизди күтүп жатат! Консолго атыңызды же 'Nuvi' деп киргизип, Enter баскандан кийин туура чыгарын текшерип алыңыз.

![Колдонуучу киргизгенден кийин жана программа аяктагандан кийин экран](../../img/console_read_input.png "Программа колдонуучудан маалымат окуп бүткөн соң экран кандай көрүнөөрү")

{{% notice note %}}

Эгер биз номер, мисалы, `8` деп киргизсек, анда өзгөрмө **value** текст түрүндө `"8"` болот. Киргизилген өзгөрмөлөрдө математика жүргүзүп жатканыңызда сак болуңуз!

{{% /notice %}}

## Чакырык

Биз консолго төмөнкү тексттерди басып чыгарган программа жазып көрөлү:

    Кош келдиңиздер!
    Бүгүн эмне жардам бере алам?

Андан кийин программа колдонуучудан киргизүүнү күтөт. Колдонуучу консолдо бир нерсе жазып, _Enter_ баскандан кийин программа төмөнкү саптарды басып чыгарат:

    Сиз суранган: [input]?
    Мен [input] боюнча жоопту билбейм. Сау болуңуз!

`[input]` ошол колдонуучу консолдо жазган текст менен алмаштырылышы керек. Мисалы, сиз "Мен канча жаштамын?" деп суроо бергиси келсе, программа бул суроого жоопту билбей турганын басып чыгарат.

{{% notice tip %}}

Бул жогоруда каралган мисалга абдан окшош. Биз берген кодго кичине өзгөртүүлөрдү киргизип көрүңүз.

{{% /notice %}}
