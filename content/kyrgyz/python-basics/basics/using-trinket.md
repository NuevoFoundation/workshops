Бүгүн биз Python программинги тууралуу үйрөнүү үчүн Codebunga колдонобуз. Төмөндө бүгүн пайдалана турган интерактивдүү Codebunga терезеси көрсөтүлгөн.

<iframe title="Codebunga менен баштоо - Codebunga" src="https://codebunga.com/embed/fcrtud9r" width="100%" height="600" frameborder="0" marginwidth="0" marginheight="0" allowfullscreen></iframe>

Баштаардан мурда, терезенин кантип иштээрин түшүнүп алалы. `main.py` файлында компьютерди иштетүү үчүн жазылган код, же көрсөтмөлөр камтылган. Код иштетилгенде чыккан натыйжа оң тарабында көрсөтүлөт. Натыйжаны көрсөтүп турган бул терезе консоль деп аталат.

**Run** баскычын басыңыз да, коддун консолдо кандай иштээрин оң тараптагы экрандан көрүңүз! Төмөнкү мисалда, `print` командасы компьютериңизге жайгаштырылган айлампалардын ичиндеги `()` сөздөрдү консолго, башкача айтканда оң жактагы экранга жаздырып койууга буйрук берет. `print` жөнүндө кийинки сабактардан көбүрөөк маалымат алыңыз.
