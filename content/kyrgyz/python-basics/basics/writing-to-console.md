## Программаңызды сиз менен сүйлөшүүгө аракет кылалы!

**Print** командасы консолго бир нерсе жазуу үчүн пайдаланылат. Консолго *Hello World* жазуу үчүн `print("Hello World")` колдонуңуз. Кийинчерээк print функция экенин жана аны басып чыгаруу ишин аткарууда колдонорубузду түшүнөбүз. Print функциясына эмне нерсе берсеңиз, ал экранда басып чыгарылат. 

Келгиле, `print` командасын колдонуп баштайлы.

Кийинки сабактарда көп жолу print пайдаланабыз, андыктан ушул бөлүмдү толук түшүнүп алыңыз.

### Сынак 1
Баштоо үчүн, төмөнкү текстти Codebunga программасынын `main.py` файлында жазып, "Run" баскычын басыңыз.

```python
print("Hello, World!")
```

Консолго "Hello, World!" болуп жазылганын экрандын оң жагынан байкаңыз! `print` компьютериңизге сөз айкаштарын  жайгаштырылган "()" ичинде болуп, консолго, башкача айтканда оң жактагы экранга басып чыгарууну билдирет.

### Басып чыгарууда " колдонуу

Сиз байкадыңызбы, Hello, World! `"` менен курчалып жазылган? Аны `"` белгисиз колдонуп көрдүңүзбү? Эгерде бул керек болсо, ката кетирген болушуңуз мүмкүн. Бирок `print(123)` колдонуп текшерсеңиз, эч кандай ката кетпегенин байкайсыз. Себеби текст (программалоо тилиндеги Стрингдер) текст экендигин белгилөө үчүн  сөздөрдү " менен курчоо керек. Ал эми сандарды курчоо талап кылынбайт.

Жогорулоого кайтып, ар кандай нерселерди басып чыгарууну колдонуп көрүңүз!
{{% /notice %}}

### Сынак 2

1. Тырмакчаларды алып салбай `"Hello, World"` сөз айкашын башка текстке өзгөртүп көрүңүз. (Мисалы – `"Менин атым – Нуи!"`). **Run** баскычын басып, өзгөрүү бар же жок экенин текшериңиз.
2. Азыркы саптын астына дагы бир `print` командасын кошуп, экинчи текстти биринчи тексттин астында басып чыгарууга аракет кылыңыз.
3. **Run** баскычын басып, канча текст басылганын текшериңиз.

## ЖАРДАМ! Кызыл текст пайда болду!

Эгерде кызыл текст көрүп жатсаңыз, анда сизде каталар бар! Сураныч, жардам сураңыз. Айрыкча Python'до жазууда төмөнкүлөргө көңүл буруңуз:

1. Сиз басып чыгаргыңыз келген текст **тырмакчалар менен курчалганына** жана тексттин **караштуу көрсөтүлүп турган жагдай ичинде** болгондугун текшериңиз.

![Ката кеткен жана туура жазылган print командасынын мисалы (тырмакчасыз - print(Hello, World!) жана тырмакчалуу - print('Hello, World!'))](../../img/redLine.png)

2. Python'до боштуктар маанилүү. Ар бир саптын башында же аягында кошумча боштук же киргизүү белгилери болбошуна кам көрүңүз, анткени бул Python кодун туура окуй албай калышы мүмкүн. Мисалы, `print` алдында боштук болбошу керек, ошондой эле `print("Hello, World!")` командасында акыркы апострофтун артына кошумча боштук салуу болбойт.
