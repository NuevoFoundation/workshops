Python программасын түзүүдө биз түшүндүрмөлөрдү кошуу үчүн `#` символун колдонуу менен бир сапта түшүндүрмөлөрдү жазсак болот. **Түшүндүрмөлөр** - бул коддун программаны өзгөртпөгөн бөлүктөрү. `#` символунан кийинки нерселер түшүндүрмөгө кирип, код тарабынан эске алынбайт. Түшүндүрмөлөр кодду окуп жаткан адамдарга анын эмне кылып жатканын түшүндүрүү үчүн кошулат. Алар кодду тейлөөнү жеңилдетип, каталарды табууга жардам бериши мүмкүн.

Эгер код жазып жатып, ал жөнүндө түшүнүү үчүн эскертмелер жаза турган болсоңуз, `#` символун колдонуп түшүндүрмө түзсөңүз болот.

```python
# Бул коддун менин биринчи сапы
print("Салам, Дүйнө!")
```

Сак болуңуз, эгер сиз `#` символун алып салсаңыз, кодуңуз иштебей калышы мүмкүн!
