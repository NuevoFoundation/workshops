## While loops

`while` цикли аркылуу бир нече код саптарын кайра-кайра аткарууну кайталоого болот, кайра-кайра бир эле сапты жазуунун кереги жок. Мисалы, `Hello World` сапты беш жолу жаздыруу үчүн, төмөнкүдөй кыла аласыз:

```csharp
var counter = 1;
while (counter <= 5)
{
    Console.WriteLine("Hello World");
    counter = counter + 1;
}
```

`if` операторундагыдай эле, `while` сөзүнүн жанындагы `()` ичинде логикалык шартты көрсөтүү зарыл. Эгер шарт `true` болсо, фигуралуу кашаанын `{ }` ичиндеги код аткарылат. Бирок, фигуралуу кашаанын ичиндеги бардык код аткарылып бүткөндөн кийин, кайра `while` циклинин башына кайтып, логикалык шарт кайра текширилет. Эгер логикалык шарт дагы эле `true` болсо, цикл кайра кайталанат.

![alt text height="600px" width="70%"](../media/while-1.png "While 1")

`while` циклинин ичинде `if` операторун да колдонуп, кызыктуу варианттарды жасоо мүмкүн:

```csharp
var counter = 1;
while (counter <= 10)
{
    if (counter < 5)
    {
        Console.WriteLine("Smaller than 5!");
    }
    else
    {
        Console.WriteLine("Greater than or equal to 5!");
    }
    counter = counter + 1;
}
```

![alt text height="600px" width="70%"](../media/while-2.png "While 2")

Төмөндө чексиз циклдин мисалы келтирилген - бул жерде кандай ката бар экенин байкадыңызбы? Бул кодду `Spam!` сапын болгону 100 жолу чыгаруучу кылуу үчүн эмнени өзгөртсөңүз болот?

```csharp
var counter = 100;
while (counter > 0)
{
    Console.WriteLine("Spam!");
}
```
