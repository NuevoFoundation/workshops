## Сандар

Компьютер мектептеги кадимки математика операцияларын дагы аткара алат. Математикалык билдирүүлөрдүн жыйынтыгын чыгаруу үчүн `Console.WriteLine` колдонсоңуз болот. Сандар үчүн кош тырмакчалар керек эмес!

```csharp
Console.WriteLine(5 + 4);
Console.WriteLine(6 * (9 - 7) / 3);
```

![alt text height="600px" width="70%"](../media/numbers-intro.png "Сандарды басып чыгуу")

Көчө математика символдорунун толук тизмеси төмөндө келтирилген:

| Оператор | Түшүндүрмө      | Оператор    | Түшүндүрмө             |
| -------- | --------------- | ----------- | ----------------------- |
| `+`      | Кошуу           | `\`         | Бөлүү                  |
| `-`      | Алууу           | `%`         | Модуло (калдык)        |
| `*`      | Көбөйтүү        | `(`,`)`     | Жаңы муун              |

## Кызыктуу Факт: Компьютердик Бөлүү

Компьютер бөлүүнү сиздин кадимки калькуляторуңуздан башкача жасайт. Компьютердик бөлүү калдыкты же ондук бөлүктөрдү эске албайт. Мисалы, `15 / 4` деп эсептегенде жыйынтык `3` болот, ал эми `3.75` эмес.

{{% /notice %}}

## Чогуу Иштөө

Төмөнкү мисалдардын жоопторун консольго чыгарып көрүңүз. Жаңы муундардын (жөнү) туура колдонуп жатканыңызды текшериңиз. Компьютердин туура жооп чыгарып жаткандыгын текшерүү үчүн калькуляторду (же акыл калчоочу математикасыз) колдонуңуз.

- `2 - 19`
- `(3 + 5) * 6`
- `(13 + 5 * 8) / (6 - (3 + 7))`

## Кызыктуу Факт: Кокус Сандар

Кокус сандарды `1` (камтылган) жана `10` (камтылбаган) аралыгында басып чыгаруунун жолу төмөнкүдөй:

```csharp
Random random = new Random();
Console.WriteLine(random.Next(1, 10));
```

GuessTheWord оюнунда `Random` кайсы жерден колдонулганын издеп көрүңүз! Бирок, бул кандай иштей турганы жөнүндөгү майда-чүйдөсүн түшүндүрүү оор болгондуктан, бул талкууну калтырабыз.
