## Булдар (Booleans)

**Булдар** булар `true` (туура) же `false` (жалган) деген билдирүүлөр. Сандар же саптардан айырмаланып, булдар чындык же жалгандык жөнүндө маалыматты сактайт: айтып жаткан нерсем чынбы же жалганбы? Мисалы, эгер "Сен роботсуңбу?" деп сурасам, бул суроо `true` же `false` деген натыйжаны пайда кылат, муну **Бул** дейбиз. Бул учурда, сен робот эмес болгондуктан (ишенем!), жыйынтык `false` болот.

Математикалык операторлорду да колдонуп бул билдирүүлөрдү түзсө болот. Бул жерде кээ бир мисалдар бар, бирок "барабар" жана "барабар эмес" деген үчүн өзгөчө белгилер колдонуларын байкаңыз:

| Оператор | Сыпаттамасы                 | Оператор | Сыпаттамасы                  |
| -------- | --------------------------- | -------- | ---------------------------- |
| `<`      | Кичирээк                   | `>`      | Чоңураак                    |
| `<=`     | Кичирээк же барабар         | `>=`     | Чоңураак же барабар          |
| `==`     | Барабар                    | `!=`     | Барабар эмес                |

Ар дайымкыдай эле, `Console.WriteLine` колдонуп жыйынтыктарыңызды чыгарып көрүңүз:

```csharp
Console.WriteLine(10 < 8);
Console.WriteLine((3 * 6) == (32 - 14));
```

## Бирге Жумуш

Төмөнкү билдирүүлөрдүн жыйынтыгына алдын ала болжол кылыңыз. `Console.WriteLine` колдонуп, жоопторуңузду текшерип көрүңүз.

- `54 < (10 + 32)`
- `(37 / 5) == 7`
- `"Hello" + "World" == "Hello World"`
- `false == false`
