## Консолдон Окуу

Эми биз өзгөрмөлөр тууралуу негизги маалыматтарды билгенден кийин, колдонуучудан маалымат алууну үйрөнөбүз. Төмөнкү сапты колдонуңуз, бул консольдон колдонуучу бир нерсе жазганга чейин күтүү үчүн колдонулат. Андан кийин, компьютер консольго жазылган нерсени алып, `input` аттуу өзгөрмөгө сактайт.

```csharp
var input = Console.ReadLine();
```

Мына `Console.ReadLine`'ды колдонуучу киргизген маалыматты кабыл алуу үчүн кантип колдонсо болот деген мисал:

```csharp
Console.WriteLine("Бир нерсе жазыңыз:");
var input = Console.ReadLine();
Console.WriteLine("Сиз жаздыңыз: " + input);
```

Колдонуучу **иштетүү** баскычын басканда, төмөнкүдөй программа экранда көрсөтүлөт:

![alt text height="600px" width="70%"](../media/reading-input-1.png "Киргизүү жазыла электеги абал")

Бул учурда, колдонуучу консольго `Салам Дүйнө!` деп жазгандан кийин, программа консольго чыгуу процессин бүтүрөт:

## Биргелешип Иштөө

Консолго  төмөнкү эки сапты чыгарган программа жазыңыз:

```
Кош келдиңиз!
Бүгүн кантип жардам бере алам?
```

Андан кийин, консоль колдонуучунун киришин күтүшү керек. Колдонуучу бир нерсе жазып, Enter баскандан кийин, компьютер төмөнкүнү чыгарат:

```
Сиз суроо узаттыңыз: [input]?
Мен ал суроону билбейм! Кош болуңуз!
```

`[input]` колдонуучу консольго эмне киргизсе, ошону менен алмаштырылышы керек.
