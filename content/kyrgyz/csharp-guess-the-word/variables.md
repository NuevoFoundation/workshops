## Өзгөрмөлөр

Өзгөрмөлөр бул жөн гана саптар, сандар жана бууландар сыяктуу маанилерге берген ысымдарыбыз. Өзгөрмөлөрдү биз компьютер байкоо жүргүзө ала турган маалыматтарды сактоо үчүн колдонобуз.

Төмөндө `str` аттуу өзгөрмөнү кантип жарыялоону көрө аласыз. Биз `str` мааниси `"Hello World"` деп айтабыз. Төмөндө көрсөтүлгөн башка өзгөрмөлөр эмнени билдирерин түшүндүрүп бере аласызбы?

```csharp
var str = "Hello World";
var x = 88;
var happy = true;
```

**аткаруу** баскычынын үстүнө басыңыз. Өзгөрмөлөр консольго басылып чыкпайт. Анын ордуна, өзгөрмөлөр компьютердин эс тутумунда сап же сан же бууланды гана сактап турат.

![alt text height="600px" width="70%"](../media/variables-intro.png "Өзгөрмөлөргө киришүү")

Башка билдирүүдө бул өзгөрмөлөрдү колдонсок деле болот. Мисалы, төмөнкү код консольго `Hello Nuevo Foundation` деп чыгарат:

```csharp
var str1 = "Hello";
var str2 = "Nuevo Foundation";
Console.WriteLine(str1 + " " + str2);
```

![alt text height="600px" width="70%"](../media/variables-strings.png "Саптар менен өзгөрмөлөр")

Өзгөрмөнүн маанисин каалаган убакта кайра өзгөртүп койсо болот, бул үчүн кайрадан `=` операторун колдонуу жетиштүү. Өзгөрмөнүн маанисин өзгөрткөндө, кайрадан `var` сөзүн колдонуу кереги жок. Төмөнкү мисалда, `Hello` ордуна `Hola` басылып чыгат.

```csharp
var str = "Hello";
str = "Hola";
Console.WriteLine(str);
```

![alt text height="600px" width="70%"](../media/variables-replace.png "Маанилерин алмаштыруу менен өзгөрмөлөр")

Бул жерде дагы бир мисал бар: `9` ордуна `10` басылат.

```csharp
var num = 9;
num = num + 1;
Console.WriteLine(num);
```

![alt text height="600px" width="70%"](../media/variables-numbers.png "Сандар менен өзгөрмөлөр")

Эске алыңыз: сиз бир сап өзгөрмөсүн санга же бууланга алмаштыра албайсыз, жана башка түрлөр үчүн да ушундай. Төмөнкү мисал иштебейт:

```csharp
var happy = "Hello";
happy = 9;
```

![alt text height="600px" width="70%"](../media/variables-invalid.png "Иштебеген өзгөрмөлөр")

Өзгөрмөлөрдү жарыялоонун дагы бир жолу - `var` сөзүнүн ордуна жаратып жаткан өзгөрмөнүн тибин көрсөтүү (`string`, `int`, `bool`). Тибин так белгилөө менен, биз жогорудагыдай көйгөйдөн кача алабыз. Мисалы:

```csharp
string str = "Hello World";
int x = 88;
bool happy = true;
```

`var`, `string`, `int`, же `bool` сөздөрү C# тилинде атайын ачкыч сөздөр болгондуктан, сиз бул ысымдарды өзгөрмөлөр үчүн колдоно албайсыз.

{{% notice tip %}}

## Бирге Иштөө

Келиңиз, эки жаңы өзгөрмөнү түзөлү:

- `"Computer"` сапын сактаган `comp` аттуу өзгөрмө.
- `5` деген санды сактаган `five` аттуу өзгөрмө.

Кийинкиде, консолго төмөнкү маанилерди басып чыгаруу үчүн өзгөрмөлөрдү колдонобуз. Бул тапшырманы өзгөрмөлөрдү колдонуу менен аткарып көрөлү!

**_Сунуш:_** Саптарды чогултуу үчүн жана сандарды кошуу үчүн `+` операторун колдонобуз.

```
Computer
5
ComputerComputer
10
ComputerComputerComputer
15
```
