## Логикалык (Boolean) операторлор

Сиз логикалык баяндамаларды `&&` (ЖАНА) жана `||` (ЖЕ) операторлору аркылуу бириктире аласыз. Мисалы, мен сурасам: "Сиз адамсызбы, жана Нуви роботпу?" дегенде, "жана" деген сөз эки чын-жалган суроону бириктирет. Бул учурда, сиздин адам экениңиз чын болсо жана Нуви робот экени да чын болсо, жалпы жыйынтык `true` болот.

Төмөндө логикалык баяндамаларды бириктиргенде эмне болоорун сүрөттөгөн таблица келтирилген:

| Баяндама         | Натыйжа | Баяндама                            | Натыйжа |
| ----------------- | ------- | ----------------------------------- | ------- |
| `true && true`    | `true`  | <code>true &#124;&#124; true</code> | `true`  |
| `true && false`   | `false` | <code>true &#124;&#124; false</code>| `true`  |
| `false && true`   | `false` | <code>false &#124;&#124; true</code>| `true`  |
| `false && false`  | `false` | <code>false &#124;&#124; false</code>| `false` |

Жыйынтыктап айтканда, `&&` эки логикалык баяндаманын тең чын болушун талап кылат, ал эми `||` эки баяндын бирөөсүнүн чындыгын гана талап кылат. Төмөндө дагы башка мисалдар келтирилген:

- `(5 < 8) && (9 != 10)` бул `true` жыйынтыгын чыгарат, анткени `5` чындыгында эле `8`ден аз, жана `9` чындыгында эле `10`го барабар эмес.  
- `(8 <= 2) || ("h" + "e" == "he")` бул `true` жыйынтыгын чыгарат, анткени `"h" + "e"` `"he"`ге барабар, бирок `8` чындыгында эле `2`ге барабар эмес же андан аз.  
- `(6 != 2 * 3) || (8 < 2 * 4)` бул `false` жыйынтыгын чыгарат, анткени `6` чындыгында `2 * 3`ке барабар эмес жана `8` чындыгында `2 * 4тен` аз эмес, булардын баары `false` натыйжа берет.

## Бирге иштөө

Төмөнкү баяндамалардын жоопторун болжоп көрүңүз. Жоопторду чыгаруу үчүн `Console.WriteLine` колдонуп көрүңүз.

- `(9 < 10) && (12 => 11)`
- `(15 - 2 == 11) || (4 % 3 != 2)`
