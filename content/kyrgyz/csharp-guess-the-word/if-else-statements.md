## If-else билдирмелери

Сиз `if` билдирмелерин белгилүү бир шарттар аткарылганда гана **кодду аткаруу** үчүн колдонсоңуз болот. Мисалы:

```csharp
var myNum = (93 + 41) / 12;
if (myNum == 11)
{
    Console.WriteLine("Алар бирдей!");
}
```

`if` менен жакшылыктын ичиндеги `()` ичинде сиз boolean билдирмесин көрсөтүшүңүз керек. Эгерде билдирме `true` болсо, `{ }` ичиндеги код аткарылат. Бул учурда, `myNum` `11`ге барабар болгондуктан, `Алар бирдей!` чыгарылат.

![alt text height="600px" width="70%"](../media/if-true.png "If-else true case")

Эгерде шарт `false` болсо, эч нерсе болбойт! Мисалы, `10` `11`ден чоң болбогондуктан, `Мени чыгар!` экранга көрүнбөйт.

```csharp
var happy = 10;
if (happy > 11)
{
    Console.WriteLine("Мени чыгар!");
}
```

![alt text height="600px" width="70%"](../media/if-false.png "If-else false case")

Шарт жалган болгондо компьютерге эмне кылуу керектигин айтуу үчүн `else` колдонуңуз. Бул мисалда, `Эми менин ордума чыктым!` консольго чыгарылат.

```csharp
var happy = 10;
if (happy > 11)
{
    Console.WriteLine("Мени чыгар!");
}
else
{
    Console.WriteLine("Эми менин ордума чыктым!");
}
```

![alt text height="600px" width="70%"](../media/if-else.png "If-else")

Сиз бир нече учурларды бири-бирине туташтыруу үчүн `else if`ти колдоно аласыз. Белгилей кетсек, `else if` колдонулганда бир гана биринчи учур бааланат. Мисалы, төмөнкү код фрагментинде `Билдирүү` 1 чыгарылат. Андан кийин `sad == 4` текшерүү өткөрүлүп жатат жана `Билдирүү 2` чыгарылбайт, `sad == 4` `true` болгонуна карабастан.

```csharp
var sad = 4;
if (sad < 9)
{
    Console.WriteLine("Билдирүү 1");
}
else if (sad == 4)
{
    Console.WriteLine("Билдирүү 2");
}
else
{
    Console.WriteLine("Билдирүү 3");
}
```

![alt text height="600px" width="70%"](../media/if-three.png "If-else three statements")

Сиз кызыктуу жүрүм-турууну жаратуу үчүн башка `if` билдирмелерин дагы башка бир `if` ичинде жайгаштыра аласыз:

```csharp
var num1 = 10;
var num2 = 20;
if (num1 < num2)
{
    if (num2 < 30)
    {
        Console.WriteLine("Салам!");
    }
    else
    {
        Console.WriteLine("Hola!");
    }
}
```

## Биргеликте Иштөө

Келгиле, алгач консольго төмөнкү сапты чыгарган программаны жазалы:

```
Код жазуу кызыкпы?
```

Андан кийин, консоль колдонуучунун жооп берүүсүн күтөт.

- Эгерде колдонуучу "ооба" деп жооп берсе, компьютер `Ооба, бул сизге жакканынан кубанычтамын!` деген билдирүүнү чыгарат.
- Эгерде колдонуучу "жок" деп жооп берсе, компьютер `Ой жок, бул аябай өкүнүчтүү!` деген билдирүүнү чыгарат.
- Башка нерсе болсо, компьютер: `Сизди түшүнгөн жокмун! Кош болуңуз!` деп чыгарат.

## Кызыктуу факт: Switch билдирмелери

Көптөгөн `if`, `else` билдирмелер узун жана түшүнүксүз болуп калышы мүмкүн. Эгерде бир өзгөрмөнү бир нече мааниге салыштырышыңыз керек болсо, анда `switch` билдирмелерин колдонсоңуз болот. Мисалы, **Биргеликте Иштөө** активдүүлүгүн төмөнкү код кесими менен аткарууга мүмкүн:

```csharp
    var input = Console.ReadLine();
    switch (input)
    {
        case "ооба":
            Console.WriteLine("Ооба, бул сизге жакканынан кубанычтамын!");
            break;
        case "жок":
            Console.WriteLine("Ой жок, бул аябай өкүнүчтүү!");
            break;
        default:
            Console.WriteLine("Сизди түшүнгөн жокмун! Кош болуңуз!");
            break;
    }
```

Ар бир `case` өзгөрмөнүн берилген маанисинин мүмкүнчүлүгүн көрсөтөт. Бул учурда, белгилүү бир татаалдык ишке ашырылгандан кийин `break` билдирмесин колдонууну унутпаңыз.
