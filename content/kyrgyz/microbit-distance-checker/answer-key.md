Бул micro:bit Wireless Social Distancing семинары үчүн мугалимдерге арналган колдонмо. Семинар студенттерди MakeCode Blocks колдонуу менен толук долбоор түзүү процессинен кадам сайын өткөрөт. Бул жооп ачкыч акыркы толук кодду (Blocks сүрөттөлүшүндө жана JavaScriptте) камсыздайт, негизги түшүнүктөрдү түшүндүрөт жана көйгөй чечүү боюнча жетекчиликти камтыйт.

## Толук чечим

### Акыркы код (JavaScript эквиваленти)

Бул программа студенттер семинар иш-аракеттеринин бардык этаптарын бүткөндө курулат:

```javascript
radio.onReceivedNumber(function (receivedNumber) {
    strength = radio.receivedPacket(RadioPacketProperty.SignalStrength)
    if (strength > -67) {
        basic.showIcon(IconNames.Sad)
    } else {
        basic.showIcon(IconNames.Happy)
    }
})
let strength = 0
radio.setGroup(1)
basic.forever(function () {
    radio.sendNumber(0)
})
```

### Акыркы код (Blocks сүрөттөлүшү)

Блоктук көрүнүш менен иштөөнү артык көргөн мугалимдер үчүн:

| Блок жайгашкан жери | Блок | Орнотуулар |
|-----------------|------|-----------|
| **on start** | `radio set group` | Group: `1` |
| **forever** | `radio send number` | Number: `0` |
| **on radio received (receivedNumber)** | `set strength to` | `received packet signal strength` |
| (received block ичинде) | `if strength > -67 then` | Show icon: кайгылуу бет |
| (else ичинде) | `else` | Show icon: бактылуу бет |

**Аткарган иши:** Ар бир micro:bit радиосигналды тынымсыз түзүп берет. Башка micro:bitтен сигнал алган кезде, сигналдын күчүн текшерет. Эгерде сигнал -67 дБмден күчтүү болсо (тагыраак айтканда, micro:bitтер 6 фут / 2 метрден аз аралыкта болсо), кайгылуу бетти көрсөтөт. Эгерде сигнал алсыз болсо (алар жетиштүү алыста), бактылуу бетти көрсөтөт.

## Кадам сайын түшүндүрүү

### Кадам 1: Micro:bit деген эмне? (1-бет)

Бул кириш бет. Код жазылбайт. Негизги пункттар:

- Micro:bitтин өзгөчөлүктөрү: 25 LED, 2 баскыч, IO пиндери, компас, акселерометр, Bluetooth
- Студенттер жабдыктарын ачышат: micro:bit, 2 батарея, USB кабели, батарея кармагыч
- **Симулятор:** Жабдыктары жок студенттер MakeCode симуляторун колдонсо болот. Экранда эки виртуалдык micro:bit туруп, радиотолкун (сары квадрат толкун) сигналдын күчүн көрсөтүү үчүн өзгөртүлүшү мүмкүн.
- Симулятор сигнал күчүнүн босогосу: `strength > -67` кайгылуу бетти иштетет

### Кадам 2: Сигнал берүү (2-бет)

**Бул кадамда кошулган код:**

```javascript
// on start
radio.setGroup(1)

// forever
basic.forever(function () {
    radio.sendNumber(0)
})
```

**Негизги түшүнүктөр:**
- `radio set group 1` "on start" блокко жайгаштырылат, micro:bit күч алган кезде бир эле жолу иштөө үчүн
- Бардык micro:bitтер байланышуу үчүн ошол эле топ номерин колдонууга тийиш
- `radio send number 0` "forever" блокко жайгаштырылат, тынымсыз сигнал берүү үчүн
- Бул долбоордо жөнөтүлгөн сан (0) мааниге ээ эмес; бизге сигналдын күчү гана керек

### Кадам 3: Кабарды алуу (3-бет)

**Бул кадамда кошулган код:**

```javascript
radio.onReceivedNumber(function (receivedNumber) {
    strength = radio.receivedPacket(RadioPacketProperty.SignalStrength)
})
let strength = 0
```

**Негизги түшүнүктөр:**
- `on radio received` блогу ар бир micro:bitден номер келген сайын иштетилет
- **`strength` аттуу өзгөрмө** түзүлөт, ал алынган сигнал күчүн сактайт
- `received packet signal strength` RSSI (Алынган Сигнал Күчүнүн Көрсөткүчү) маанисин берет
- Өзгөрмөлөр бул маалыматты сактоочу ат коюлган контейнерлер, алар кийин кайра колдонулуп же жаңыртыла алат

### Кадам 4: Сигнал күчүн интерпретациялоо (4-бет)

**Бул кадамда кошулган код:**

```javascript
if (strength > -67) {
    // өтө жакын - 6 футтан аз аралыкта
} else {
    // коопсуз аралык - 6 футтан көп аралыкта
}
```

**Негизги түшүнүктөр:**
- -67 дБм micro:bit Bluetooth'унун 6 фут (2 метр) аралыктагы алдын ала өлчөнгөн сигнал күчү
- Сигнал күчү 0го жакын = күчтүү сигнал = жакын аралык
- Сигнал күчү 0дон ары (көп негативдүү) = алсыз сигнал = алысыраак аралык
- `strength > -67` micro:bitтер **6 фут**тан **жакын** дегенди билдирет (тосмодон күчтүү сигнал)

**Студенттердин жалпы суроосу:** "Эмне үчүн -67?" Анткени -67 дБм, эки micro:bit 6 фут аралыкта болгондо, сигнал күчүнүн деңгээли өлчөнгөн. Ар кандай Bluetooth радиолорунда ошондой эле аралыкта ар башка маанилер болушу мүмкүн.

### Кадам 5: Көрүнтүп берүү (5-бет)

**Бул кадамда кошулган код:**

```javascript
if (strength > -67) {

} else {

}
```
