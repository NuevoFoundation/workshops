Биз кодду белгилүү шарттарга жете турган учурда гана иштетүү үчүн `if` операторлорун колдонсок болот.

Мисалы:

```kotlin
if (isRainingOutside == true) {
    takeUmbrella = true;
} else {
    takeUmbrella = false;
}
```

Оюндун негизинде, биз `if` операторлорун колдонуу менен оюнчу 3 вертикалдык, горизонталдык, же диагоналдык дал келүүгө ээ болгонун аныктап алышыбыз керек.

`if` операторунун жанындагы `()` ичине _Булиандык билдирүү_ көрсөтүшүңүз керек. **Булиандар** `true` же `false` мааниси бар билдирүүлөр. Биз муну `if` операторунда колдоно алабыз. Эгерде билдирүү `true` болсо, анда `{ }` ичиндеги код аткарылат. Эгерде билдирүү `false` болсо, анда `else` сөзүнөн кийинки `{ }` ичиндеги код аткарылат.

Мындан тышкары, **Булиандык билдирүүлөрдү** `&&` (ЖАНА) жана `||` (ЖЕ) операторлорунун жардамы менен бириктирсе болот.

`MainActivity.kt` ичиндеги `CheckWinner()` функциясына көз жүгүртүп, бардык байланыштырылган `&&` операторлору эмне иштеп жатканын ойлонуп көрүңүз.
