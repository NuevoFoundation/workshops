Төмөндөгү кадамдарды аткаруу менен Android Studio'ну компьютериңизге орнотуңуз. Эгерде сизде Android Studio мурунтан эле орнотулса, аны ачып, кийинки кадамга өтүңүз!

Бул кадамдар Windows компьютерин орнотуу үчүн мисалдарды камтыйт. Ошондой эле, башка компьютерлер үчүн кадамдар да ушуга окшош.

## Android Studio'ну Жүктөө жана Орнотуу
1. Операциялык системаңызга ылайык [Android Studio'ну жүктөп алыңыз](https://developer.android.com/studio/).
2. [Бул кадамдарды аткарыңыз](https://developer.android.com/studio/install) жана Android Studio'ну орнотуңуз.

## JAVA_HOME чөйрө өзгөрмөсүн орнотуу
Android Studio тиркеменин айрым бөлүкчөлөрүнүн иштөөсү үчүн керек болгон Java версиясы менен бирге келет. Төмөнкү кадамдарды аткарып, компьютериңизге `JAVA_HOME` чөйрө өзгөрмөсүн орнотсоңуз болот, бул колдонмолорго Java кайсы жерде экенин айтат:
1. Экрандын төмөнкү сол бурчундагы издөө кутучасына `env` деп териңиз.
2. "Эң жакшы дал келүү" программасынан `Системалык чөйрө өзгөрмөлөрүн түзөтүү` опциясын тандаңыз.
<img src="../resources/_gen/images/edit_env_variable.png" height="30%" width="30%" title="Системалык чөйрө өзгөрмөлөрүн түзөтүү" alt="Системалык чөйрө өзгөрмөлөрүн түзөтүү"/>
3. `Чөйрө өзгөрмөлөрү...` дегенди басыңыз.
4. 'Колдонуучунун өзгөрмөлөрү' бөлүгүндө `Жаңы...` дегенди чыкылдатыңыз.
5. Өзгөрмө аталышына JAVA_HOME деп жазыңыз.
6. Төмөнкүни өзгөрмөнүн мааниси катары көчүрүңүз:
```
C:\Program Files\Android\Android Studio\jre
```
7. OK дегенди басыңыз.
<img src="../resources/_gen/images/set_java_home.gif" height="40%" width="40%" title="JAVA_HOME орнотуусу" alt="JAVA_HOME чөйрө өзгөрмөсүн орнотуу кадамдарын көрсөтөт"/>

{{% notice tip %}}
Android Studio'ну туура ачуу үчүн азыр компьютериңизди өчүрүп-күйгүзүүнү сунуштайбыз.
{{% /notice %}}

## Android Studio'ну Баштоо
Орнотулгандан кийин Android Studio'ну ачып, колдонмоңузда иштегиле.

{{% notice tip %}}
Windows компьютериңизде Android Studio тиркемесин баштоонун бир нече ыкмасы бар. Мына эки ыкма:
#### 1-ыкма
1. Компьютериңиздин төмөнкү сол тарабындагы Windows иконкасын басыңыз.
2. Тизмеден `Android Studio` папкасына чейин чыгыңыз.
3. `Android Studio` папкасын кеңейтип ачыңыз.
4. Папканын ичинен `Android Studio` тиркемесин басып, Android Studio'ну баштаңыз.

#### 2-ыкма
1. Экрандын төмөнкү сол бурчундагы издөө кутучасына `Android Studio` деп жазыңыз.
2. Натыйжалар терезесинде, эгерде "Эң жакшы дал келүү" опциясы `Android Studio`ну көрсөтсө, анда же `Android Studio` тиркемесин басыңыз же клавиатурада `ENTER` баскычын басыңыз.
{{% /notice %}}

## Долбоор Файлдарын Ачуу
1. Android Studio'нун башкы экранында `Open an Existing Project` дегенди басыңыз.
2. Долбоор файлдары жүктөлгөн жерди издеңиз.
3. Мурда ачып койгон 'TicTacToe' папкасынын ичиндеги 'TicTacToe' папкасын тандаңыз.
   - Тандачу 'TicTacToe' папкасында жашыл Android иконкасы болушу керек, бул анын Android долбоорунун папкасы экенин көрсөтөт.

Android Studio'ну иштетип, долбоорду ачыңыз. Көрүнүшү төмөнкүдөй болушу керек:

## Лицензияларды Кабыл алуу
Кодду иштетүүдөн мурун, Android лицензияларын кабыл алууңуз керек, төмөнкү кадамдарды аткарыңыз:
1. Android Studio терезесинин төмөн жагындагы `Terminal` баскычын басыңыз.
2. Төмөндөгү буйрукту терип жазыңыз, `<USER_NAME>`ди компьютериңиздин колдонуучу аты менен алмаштырыңыз.
```
C:\Users\<USER_NAME>\AppData\Local\Android\Sdk\tools\bin\sdkmanager --licenses
```
3. Лицензияларды кабыл алуу үчүн, 'y' деп терип, андан кийин `ENTER` баскычын басыңыз. Бул бир нече жолу талап кылынат.
