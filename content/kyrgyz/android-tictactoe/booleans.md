Boolean'дор бул туура же калп сүйлөмдөр. Сабакчалар (string) же сандардан айырмаланып, boolean'дор чындык тууралуу билдирүүлөрдү сактайт: мен айтып жаткан нерселер чындыкпы же калппы? Мисалы, эгерде мен "Сен роботсуңбу?" деп сурасам, бул суроо жабык түрдө туура же калп жыйынтык берет, аны биз Boolean деп атайбыз. Бул учурда, силер робот эмес экендигиңерден улам (үмүттөнөм!), жыйынтык "калп" болот. Биз ошондой эле математикалык операторлорду колдонуп, boolean билдирүүлөрдү түзө алабыз. Төмөндөгү мисалдар менен таанышсаңыз болот; бирок, "барабар" жана "барабар эмес" үчүн колдонулган өзгөчө символдорго көңүл буруңуз:

| Оператор | Сүрөттөмө            | Оператор | Сүрөттөмө                 |
| -------- | -------------------- | -------- | ------------------------- |
| `<`      | Кичине               | `>`      | Чоң                      |
| `<=`     | Кичине же барабар    | `>=`     | Чоң же барабар            |
| `==`     | Барабар              | `!=`     | Барабар эмес             |

Буга адаттагыдай эле `System.out.println` колдонуп, жыйынтыктарды басып чыгарсаңыз болот:

```kotlin
System.out.println(10 < 8);
System.out.println((3 * 6) == (32 - 14));
```

{{% notice tip %}}
## Бирге Иштөө

Кодуңуздагы бардык `System.out.println` тексттерин өчүрүңүз. Төмөндөгү билдирүүлөрдүн жоопторун алдын ала билүүгө аракет кылыңыз. Жыйынтыктарды текшерүү үчүн `System.out.println` колдонуңуз.

- 54 < (10 + 32)
- (37 / 5) == 7
- "Hello" + "World" == "Hello World"
- false == false

{{% /notice %}}

## Boolean Операторлор

Boolean билдирүүлөрдү бири-бири менен `&&` (ЖАНА) жана `||` (ЖЕ) операторлору аркылуу байланыштырууга болот. Мисалы, "Сен адамсыңбы жана Нуви роботпу?" деген суроону алалы. Бул жерде "жана" сөзү эки туура-калп суроону байланыштырып турат. Бул учурда, сен адам экениң чын, ал эми Нуви робот экени да чын болгондуктан, жалпы жыйынтык `true` болот. Boolean'дорду бириктиргенде эмне болорун түшүндүргөн диаграмма:

| Билдирүү                   | Жыйынтык | Билдирүү                             | Жыйынтык |
| -------------------------- | -------- | ------------------------------------- | -------- |
| <code>true && true</code>  | `true`   | <code>true &#124;&#124; true</code>   | `true`   |
| <code>true && false</code> | `false`  | <code>true &#124;&#124; false</code>  | `true`   |
| <code>false && true</code> | `false`  | <code>false &#124;&#124; true</code>  | `true`   |
| <code>false && false</code>| `false`  | <code>false &#124;&#124; false</code> | `false`  |

Жыйынтыктап айтканда, `&&` эки Boolean билдирүүнүн тең чын болушун талап кылса, ал эми `||` бир гана Boolean билдирүү чын болушун талап кылат. Ушул ыкмалар менен дагы башка мисалдарды карап чыгууга болот:

- `(5 < 8) && (9 != 10)` жыйынтык катары `true` берет, анткени 5 эң кичине 8 жана 9 барабар эмес 10.
- `(6 != 2 * 3) || (8 < 2 * 4)` жыйынтык катары `false` берет, анткени 6 барабар эмес 2 * 3 жана 8 кичине эмес 2 * 4 экени да `false` чыгат.
