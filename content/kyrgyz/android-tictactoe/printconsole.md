Колдонмону мүчүлүштүктөрдөн тазалоодон тышкары, кабарыңызды чыгаруу үчүн `System.out.println()` колдонсоңуз болот. Кабарыңызды Android Studioнун ылдый жагындагы "logcat" терезесинен көрө аласыз:

## Бирге Иштейли

1. Ыңгайлаштыруу үчүн тырмакча жебелерин өчүрбөй туруп, `"Restarting the Tac-Tic-Toe Game!"` дегенди `"Restarting the Tic-Tac-Toe Game!"` же башка өзүңүз каалаган сүйлөмгө алмаштырыңыз. Өзгөрүүлөрдү көрүү үчүн Run баскычын басыңыз.
2. Азыркы саптын астына дагы бир `System.out.println` кошуп, экинчи сүйлөмдү биринчи сүйлөмдүн астына чыгарыңыз.
3. Run баскычын басып, эки сүйлөмдүн басылып чыкканын караңыз. Эгерде кызыл текст көрсөңүз, жардам сураңыз.

{{% /notice %}}

{{% notice warning %}}
## ЖАРДАМ! Көптөгөн кызыл текст чыкты!

Эгерде кызыл текст чыкса, анда сиз катачылыктарга туш болдуңуз! Сураныч, жардам сураңыз. Android боюнча код жазып жатканда төмөнкү нерселерге көңүл буруңуз:

1. `out` жана `println` кичине тамга менен башталат.
2. `System` чоң тамга менен башталат.
3. Чыгаргыңыз келген сүйлөм тырмакчалардын ичинде болушу керек жана сүйлөм тегерек кашаанын ичинде жайгаштырылган болушу керек.
4. Эч кандай ийилген кашааларды `{` же `}` өчүрбөңүз.

{{% /notice %}}

`System.out.println` кодуңуздагы каталарды оңдоп кетүүгө жардам берет, бирок колдонмону колдонуп жаткан колдонуучу (б.а., колдонмонун колдонуучусу) ушул функция менен чыгарылган текстти көрө албайт. Бирок, биз бул үчүн тостторду колдонсок болот! Тост — бул тез, чакан текст, аны биз колдонуучуга көрсөтө алабыз. Бул жерде тостту кантип түзүү керектиги көрсөтүлгөн:
```kotlin
Toast.makeText(this, "Көрсөтүлө турган текст", Toast.LENGTH_SHORT).show()
```
