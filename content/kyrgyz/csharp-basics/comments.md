## Комментарий Жасоо

C# программасын түзүп жатканда, бир сапка комментарий жазуу үчүн `//` же көп саптуу комментарий үчүн `/*` жана `*/` колдонуп жазмалар кошсоңуз болот (Эскертүү: Мурдагы иш-чаралар боюнча нускамалар комментарий катары жазылган).

Ошондой эле, комментарийлер программаны эч кандай жол менен өзгөртпөйт. Ошондуктан, сиз өз кодуңуздун кантип иштей турганын өз алдынча же башка программалоочулар үчүн документтештирүү максатында коддун ар кайсы жерлерине комментарийлерди кошсоңуз болот.

```c#
     // бир саптык комментарийдин үлгүсү

     /* көп саптуу
      * комментарийдин
      * үлгүсү */
```

{{% notice tip %}}

Кодуңузду комментарийге жазсаңыз, компьютер ал кодду аткарбайт.

```c#
Console.Write("Мен тамак жегенди жакшы көрөм");
// Console.Write("алмаларды.");
```

Бул "Мен тамак жегенди жакшы көрөм" деген сөздү консольго чыгарат, бирок "алмаларды" деген сөздү чыгарбайт.
{{% /notice %}}
