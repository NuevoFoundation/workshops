## Обзор

**C#: Негиздери** курсуна кош келиңиз! Бул жерде сиз компьютерде кызыктуу программаларды жаратуу үчүн колдонулган кеңири таралган, жогорку деңгээлдеги программалоо тилин үйрөнөсүз.

C# программалоо тили Microsoft компаниясынан Андерс Хейлсберг тарабынан 2000-жылы түзүлгөн. Бул курстун түзүлүү учурунда бул тилдин эң акыркы туруктуу версиясы — C# 11.0, ал 2022-жылы чыккан.

{{% notice info %}}
Жогорку деңгээлдеги программалоо тили жогорку деңгээл деп аталат, анткени ал компьютердин Борбордук Ыкчам Эсептөө Бөлүгү (CPU) иштеткен баштапкы коддон бир нече кадам алыс турат. Бул код адамдар үчүн түшүнүктүү жана төмөн деңгээлдеги кодго салыштырмалуу кыйла оңой. Жогорку деңгээлдеги код андан кийин атайын CPU гана түшүнө ала турган төмөн деңгээлдеги тилге которулат. Код иштеши үчүн жогорку деңгээлдеги тилде жазылган ар бир сап төмөн деңгээлдеги тилге (машина тилине) которулуп, анан компьютер тарабынан аткарылат.
{{% /notice %}}

C# дүйнөдөгү эң популярдуу программалоо тилдеринин бири, Java, JavaScript, Python жана башкалар менен катар. C# тили Windows, Mac жана башка бардык Linux операциялык системаларында иштей алат.
