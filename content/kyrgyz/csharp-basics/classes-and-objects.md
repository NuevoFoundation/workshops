## Объект деген эмне жана Класс деген эмне?

Объект - бул белгилүү бир касиеттери бар жана белгилүү бир тапшырмаларды аткара алган нерсе (зат). Класс - бул объектти түзүү үчүн колдонулган үлгү же аныктама.

Мисалы, Адам дегенди караңыз. Адам - бул Класс болуп саналат. Адамга башка адамдардан айырмалай турган белгилүү касиеттерге ээ болуу мүнөздүү. Мисалы, анын көзү көк болушу мүмкүн, курагы 15 жаш болушу мүмкүн ж.б. Мындан тышкары, адам белгилүү бир тапшырмаларды аткара алат - басуу, сүйлөө ж.б.

C# Объект - бул C# Классынын экземпляры. Бул мисалда "Bea" деген "Адам" болуп саналат. "Bea" күрөң көзгө ээ. Бул "Bea" үчүн касиет же маалымат талаасы болуп саналат. "Bea" англисче сүйлөй алат. "Bea" испан тилинде сүйлөй алат. Бул "Bea" аткара ала турган ыкмалар.

## Классты түзүү!

C# тил - бул **объектке багытталган** программалоо тили, демек, C# тармагындагы нерселердин баары **объект** менен **класс** менен байланыштырылган (объекттердин үлгүсү).

Баштоо үчүн, мурунку иш-аракетте колдонулган код саптары ырастала тургандыгын түшүнүңүз, алар, чындыгында, System деген алдын ала аныкталган класстын ыкмасы менен байланышкан!

```csharp
Console.WriteLine("Салам Дүйнө");
```

1. `Console` - бул колдонуучу киргизүүлөрү жана чыгаруулары менен иштешүүчү класс.
2. `WriteLine()` - бул `Console` классында аныкталган ыкма.

Мурунку көнүгүүлөрдө өз ара аракеттенишкен дагы бир алдын ала аныкталган класс - бул `string`. `string` классы символдор тизмегинин кандай иштеши керектиги боюнча эрежелерди аныктайт.

Төмөндөгү код сапары менен, биз `name` деген `string` объектти түздүк, аны `string` классы аныктаган эрежелерди колдонуу менен аткардык:

```csharp
string name = "Патрик";
```

`Console` жана `string` класстары C# тилиндеги алдын ала аныкталган класстар болуп саналат. Бирок биз бул алдын ала аныкталган класстардын чеги менен чектелген эмеспиз жана классты жазуу аркылуу өз алдынча маалымат түрүн түзө алабыз! Бул кодерлерге белгилүү бир касиеттери жана жүрүм-туруму бар объекттерди түзүү үчүн пайдалуу. Бул жекече түрлөргө жетүү уникалдуу программаларды түзүүгө мүмкүнчүлүк берет.

Класстын ар башка бөлүктөрү боюнча маалыматты төмөндө карап чыгалы:

{{% notice note %}}
### Класс
Класс - бул жаңы объект түрүнүн үлгүсү же прототиби. Жалпысынан алганда, класс үч маанилүү бөлүктү камтыйт: 

<img src="../images/class.png" height="400" alt="Объект үчүн Класстын үлгүсү: экземплярдын өзгөрүүлөрү/маалымат талаалары, алар объекттеги маалыматтар/касиеттерди камтыйт; конструктор, ал класстын объектин түзүү ыкмалары; методдор, объект үчүн ыкмалар."/> 

**Элемент** | **Түшүндүрмө** | **Мисал**
---|---|---
**маалымат талаалары/экземпляр өзгөрүштөрү** | Класс объектиндеги өзгөрүүчүлөр, объектти сүрөттөйт | Мисалы, Адам классы көздүн түсү, курагы, бою сыяктуу талааларга ээ болот.
**конструктор** | объект түзүлгөндө автоматтык түрдө чакырылуучу ыкма, конструкторлор класстын аталышы менен бирдей болушу керек | Ар бир класска бир нече конструктор болуусу мүмкүн.
**ыкмалар (методдор)** | Бул объектке белгилүү тапшырмаларды аткарууга мүмкүндүк берүүчү ыкмалар | Мисалы, Адам классы менен сүйлөө жана басуу сыяктуу ыкмалар болушу мүмкүн.

Мисалы:

```csharp
public class Person{
    // (1) маалымат талаалары/экземпляр өзгөрүүлөрү
    private String name; // мисал
    private int age;
    private int height;

    // (2) конструктор - конструкторлордун аталышы класс аты менен бирдей
    public Person()
    {
        name = "Bea";
        age = 29;
        height = 167;
    }

    // (2) конструктор - бул класста бир нече конструктор болушу мүмкүн
    public Person( String nameInput, int ageInput, int heightInput)
    {
        name = nameInput;
        age = ageInput;
        height = heightInput;
    }

    // (3) ыкмалар (методдор)
    public void talk()
    {
        Console.WriteLine($"Салам, мен {name}.");
    }
}
```
