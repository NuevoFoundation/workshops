## Өзгөрмөлөр: Атын койгула!

Биринчи көнүгүүдө, биз `Console.WriteLine()` жана `Console.Write()` аркылуу ар кандай сүйлөмдөрдү басып чыгарууну үйрөндүк.

Бирок сандарды же сүйлөмдөрдү басып чыгарганда аларга мааниси берилген эмес жана эгер ошол сүйлөмдү же санды кайра колдонгуңуз келсе, аны кайрадан жазууга туура келмек.

C# тилинде, маалымат үчүн **өзгөрмө** деген түшүнүк киргизилет. Өзгөрмө маалыматты ысым менен сактайт.

Мисалы, `"Ann"` деген мааниси бар `myName` деген өзгөрмө болушу мүмкүн. Дагы бир өзгөрмө `age` деп аталат жана ага `12` деген сан ыйгарылган.

## Өздүк Түрү Болсун!

Андыктан, C# тилинде маалыматтарды сактоо үчүн бул өзгөрмөлөрдү кантип түзөбүз?

Өзгөрмөлөрдү кантип түзүүнү үйрөнөрдөн мурун, биз C# тилиндеги **маалымат түрү** же жөн эле **түр** түшүнүгүн билип алышыбыз керек. C# тилиндеги түр сакталган маалыматтын кайсы түргө таандык экенин жарыялайт. Эгер сизде сан өзгөрмөсү болсо, ал сөйөмөлөрдү же белгилерди иреттүү сактай албайт. Ар бир өзгөрмөнүн өз түрү бар, бул анын кандай түрдөгүсүн сактай алаарын чечет.

Мисалы, биз `age` деген өзгөрмө түзө алмакпыз жана ал тек гана `12` деген санды сактайт. Эгер `age` өзгөрмөсүнө `"twelve"` сөзүн жазганга аракет кылсаңыз, ката кетет, анткени ал тек гана сандарды кабыл алат.

C# тилинде, бүтүн сандарды сактагыңыз келсе, `int` деген түр колдонулат. Биз `int` деген түрү менен `age` деген өзгөрмөнү жарыялап, ага `3` маалыматты төмөнкү код саптары аркылуу ыйгарабыз:

```
int age = 12;
```
Жалпысынан, өзгөрмөнү жарыялоо үчүн төмөнкү форматта жазабыз: `[маалымат түрү] [өзгөрмө аты] = [маалымат];`.
{{% notice note %}}
Төмөнкү маалымат түрлөрү C# тилинде негизги болуп эсептелет:

**Түр** | **Сүрөттөмө** | **Мисалдар**
--------|----------|----------
`int` | бүтүн сан | `20`, `30`, `35`
`char` | белгилер же жалгыз тамгалар | `'A'`, `'b'`, `'('`, `']'`
`string` | белгилердин жыйындысы | `"Hello"`, `"Bonjour"`, `"Hola"`
`bool` | логикалык, анда `true` же `false` мааниси болот | `true`, `false`
`double` | ондук бөлүкчөлүү сандар | `2.0`, `3.14`, `9.33`

{{% /notice %}}

Жогорудагы мисалга кайрылсак, бул өзгөрмөлөрдү C# тилинде төмөнкүчө жарыялайбыз:

```C#
string name = "Ann";
int age = 12;
boolean loveMusic = true;
```

Акыркы өзгөрмө кызыктуу: ал тек гана `true` же `false` маанисин кармай алат. Бул маалыматтар тренингдин кийинки, кыйла татаал бөлүктөрүндө абдан пайдалуу болорун көрөбүз.

## Өзгөрмөлөр менен иштөө

Эми өзгөрмөлөр менен кандай иштесе болооруна көз чаптырып көрөлү.

Төмөндө берген .NET Fiddle терезесинде Fiddle редакторун ачып, бул саптарды териңиз жана **ишке киргизиңиз**:

```C#
int age = 10;
Console.WriteLine(age); // 10 дегенди басып чыгарат
age = 12; // age өзгөрмөсүнө 12 деген маанини ыйгарып жатабыз
Console.WriteLine(age); // 12 дегенди басып чыгарат
```
Биз өзгөрмөгө маани ыйгарып, аны кайта чакырып жана башка мааниге өзгөртсөк болот.
