## Өзгөрмөлөр жана Маалымат Типтери

### Патрикке Өзгөрмөлөрүн оңдоого жардам бериңиз

Патриктин кодунда ар бир өзгөрмөгө туура эмес маалымат типи берилген. Бул жерде туура жарыялоолор бар:

```csharp
string bestFriend = "Minerva";
int numOfFriends = 4;
double GPA = 3.6;
char meaningOfLife = '$';
bool loveMusic = true;
```

**Түшүндүрмө:** Ар бир өзгөрмө сакталган мааниге туура келген маалымат типине муктаж:

| Өзгөрмө | Туура эмес Тип | Туура Тип | Себеби |
|---------|----------------|-----------|--------|
| `bestFriend` | `int` | `string` | `"Minerva"` бул текст, сан эмес |
| `numOfFriends` | `bool` | `int` | `4` бүтүн сан, true/false эмес |
| `GPA` | `string` | `double` | `3.6` ондук сан, текст эмес |
| `meaningOfLife` | `double` | `char` | `'$'` бир символ, ондук эмес |
| `loveMusic` | `char` | `bool` | `true` бул логикалык мааниси, символ эмес |

Чыгуу:
```
Сиз аны оңдоодуңуз!
```

## Операторлор

### Сынак статистикасы

Баалар берилген: Патрик (88), Том (89), Мэри (95), Крис (84), Жэн (92):

```csharp
// 1. Студенттин баа өзгөрмөлөрүн жарыялоо
int patrickGrade = 88;
int tomGrade = 89;
int maryGrade = 95;
int chrisGrade = 84;
int jenGrade = 92;

// 2. Класстын орточо баасын эсептеңиз
average = (patrickGrade + tomGrade + maryGrade + chrisGrade + jenGrade) / 5.0;

// 3. Салыштыруу операторлорун колдонуу
bool over60 = average > 60;
bool over70 = average > 70;
bool over80 = average > 80;
bool over90 = average > 90;
```

{{% notice tip %}}
Биз `5.0` менен бөлөбүз, себеби ондук натыйжа алуу үчүн. C# тилинде эки сан бүтүн болуп бөлүнсө, бүтүн жыйынтык чыгат (калдыктан кутулат). `5.0` колдонуу так орточо маанини алат.
{{% /notice %}}

## Башкаруу Түзүмдөрү

### Эгерде-Оператору: Патриктин Саламдашуу Сөзү

Патриктин туура убакытка жараша салам айтып турганын камсыз кылуу үчүн логикалык маселелерди жазыңыз:

```csharp
int currentHour = 10; // башка сааттарды текшерүү үчүн муну алмаштырыңыз (0-23)

if (currentHour < 12)
{
    Console.WriteLine("Кутмандуу таң");
}
else if (currentHour < 20)
{
    Console.WriteLine("Кутмандуу күн");
}
else
{
    Console.WriteLine("Кутмандуу түн");
}
```

**Кантип иштейт:**
- Саат 0-11: `currentHour < 12` чын → "Кутмандуу таң" чыгат
- Саат 12-19: `currentHour < 12` калп, бирок `currentHour < 20` чын → "Кутмандуу күн" чыгат
- Саат 20-23: эки шарт тең калп → `else` → "Кутмандуу түн" чыгат

### For-Loop: 1ден 100гө чейинки суммасын алуу

1 + 2 + 3 + ... + 100 суммасын эсептеген while циклин for циклге айлантыңыз:

```csharp
int total = 0;
for (int num = 1; num <= 100; num = num + 1)
{
    total = total + num;
}
Console.WriteLine("Жооп for циклде эсептелди: " + total);
```

Чыгуу:
```
Жооп for циклде эсептелди: 5050
```

{{% notice tip %}}
Жооп 5050. Белгилүү окуя боюнча математик Карл Фридрих Гаусс бала кезинде муну түшүнгөн: 1 + 100 = 101, 2 + 99 = 101, жана ушул сыяктуу — 50 жуп 101, жалпысынан 5050!
{{% /notice %}}

## Методдор

### Пирамидадагы Бисерлерди Саноо

`n` деңгээлдүү квадрат-сан пирамидасындагы жалпы бисерлердин санын эсептеген метод жазыңыз. 1-деңгээлде 1×1 = 1 бисер, 2-деңгээлде 2×2 = 4 бисер, 3-деңгээлде 3×3 = 9 бисер ж.б.

```csharp
public static int pyramidCount(int levels)
{
    int total = 0;
    for (int i = 1; i <= levels; i++)
    {
        total = total + (i * i);
    }
    return total;
}
```
