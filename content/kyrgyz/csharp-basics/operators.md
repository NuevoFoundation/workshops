## Математика жасайлы: Аритметикалык операторлор

Акыркы тапшырмада биз өзгөрмөлөр жөнүндө жана аларга өзгөчө түрдөгү маанилерди кантип дайындоо керектиги жөнүндө үйрөндүк, мисалы:

```C#
int age = 3;  // int түрүндөгү age өзгөрмөсүн түзүү жана ага 3 маанисин дайындоо
age = 4;      // age өзгөрмөсүнө 4 маанисин дайындоо
```

Жогорудагы кодго карап, бул негизинен `age` өзгөрмөсүнүн маанисине 1ди кошот.

C# тилинде биз өзгөрмөлөрдө ишмердүүлүктү түздөн-түз **аритметикалык операторлорду** колдонуу менен аткара алабыз: `+`, `-`, `*`, `/`, `%`. Маселен, биз `age` үчүн `+` кошуу операторун колдонсо болот:

```c#
int age = 3;  // int түрүндөгү age өзгөрмөсүн түзүү жана ага 3 маанисин дайындоо
age = age + 1;// age өзгөрмөсүнө 1ди кошуу
```

{{% notice note %}}
Төмөндө C# тилиндеги аритметикалык операторлор келтирилген:

**Оператор** | **Сүрөттөмө** | **Мисал**
------|------|--------
`+` | кошуу | `1 + 1 = 2`
`-` | кемитүү | `2 - 1 = 1`
`*` | көбөйтүү | `3 * 3 = 9`
`/` | бөлүү | `9 / 3 = 3`
`%` | модул/калдык | `10 % 4 = 2`

**Эскертүү**: Егер бөлүү ишинде эки оператор тең бүтүн сандар болсо, анда жыйынтык дагы бүтүн сан болот. Мисалы, `10 / 4` жыйынтыгы 2 болот, 2.5 эмес, анткени калдык эске алынбай ташылат. Егер операторлордун бири дабл (double) түрүндө болсо, жыйынтык дабл болот.

**Эскертүү**: Модул операциясын (`%`) бөлүүнүн калдыгын аныктайлы.

{{% /notice %}}

{{% notice tip %}}
Кошуу оператору (`+`) Strings үчүн бириктирүүчү оператор аркылуу пайдаланылат. Мисалы:

`String name = "Patric" + "k";` `String name = "Patrick";` менен бирдей.
{{% /notice %}}

## Салыштыруулар: Реляциондук операторлор

Эми, **реляциондук операторлордун** жардамы менен сандарды кантип салыштырууну үйрөнөлү.

Математикада сыяктуу эле, биз сандарды `>`, `<`, `>=`, `<=` аркылуу салыштыра алабыз. Мисалы: `(3 > 2)` бул `true`, бул булеан мааниси.

{{% notice note %}}
Төмөндө C# тилиндеги реляциондук операторлор келтирилген:

**Оператор** | **Сүрөттөмө** | **Мисал**
------| ------| ------
`==` | барабар | `(3 == 3)` бул `true`
`!=` | тең эмес | `(3 != 3)` бул `false`
`>` | чоңураак | `(3 > 2)` бул `true`
`<` | кичине | `(3 < 2)` бул `false`
`>=` | чоңураак же барабар | `(3 >= 2)` бул `true`
`<=` | кичине же барабар | `(2 <= 2)` бул `true`

Эскертүү: `==` жана `!=` операторлору бир эле түрдөгү маалыматтарга колдонулат. Мисалы:
```csharp
int x=3; 
double y=3.0; 
x==y; // Бул туура эмес жыйынтыкты көрсөтөт, анткени x жана y ар башка типте.
```

{{% /notice %}}

{{% notice tip %}}
Бир белгилүү теңдеме ыкмасы менен маанини өзгөрмөгө дайындоо үчүн 1 тең деген белгини (`=`) колдонулат. Эки белгидеги тең экендиги жөнүндө текшерүү үчүн эки тең белги (`==`) колдонулат.

```csharp
age = 3;  // age өзгөрмөсүнө 3ти даярдоо
age == 3; // age мааниси 3кө теңби деп текшерет
```
{{% /notice %}}
