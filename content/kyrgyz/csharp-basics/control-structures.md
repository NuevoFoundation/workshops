## Чечим кабыл алуу: If-Statement

Патрик 🐥 абдан сылык өрдөктүн түрү, ал жолуккан адамдарды учурдагы убакытка жараша "Куттуу тандоо", "Куттуу күн", же "Куттуу түн" деп учурашат.

![Тоо артынан тезден күн чыгуу](https://media.giphy.com/media/hpWrLS1RDBd5pwkgjy/giphy.gif)
<p style="text-align: center;">(сүрөт: National Geographic: giphy.com/natgeochannel)</p>

Мурда үйрөнгөнүбүздөй, биз бул сөздөрдү төмөндөгүдөй басып чыгара алабыз:

```C#
Console.WriteLine("Куттуу тандоо");   // 0:00 - 11:59 аралыгында айтуу
Console.WriteLine("Куттуу күн");     // 12:00 - 19:59 аралыгында айтуу
Console.WriteLine("Куттуу түн");     // 20:00 - 23:59 аралыгында айтуу
```

Бирок, биз Патрик 🐥 бул сөздөрдүн бирин учурдагы убакытка жараша гана айтышы керектигин билебиз.

Башкача айтканда, биз учурдагы шарттарга жараша басып чыгарууну чечүү үчүн код жазышыбыз керек.

C# тилинде чечимди **if statement** же **if...else statement** дегенди колдонуу менен кабыл алабыз. Төмөнкү эскертмелерди карап көрүңүз:

{{% notice note %}}
### If Statement

```
if(boolean expression){
    Аткара турган аракеттер
}
```

**If statement** жогоруда көрсөтүлгөн структурага ылайык келет. Блоктогу аракеттер (утурлар) чыныгы деген boolean туюнтмасы болсо гана аткарылат. Болбосо, boolean туюнтмасы жалган болгон учурда программа блоктон кийинки утурга өтөт.
### If-Else Statement

```
if(boolean expression){
    Аракет(тер) Аны аткаруу
}else{
    Аракет(тер) Бны аткаруу
}
```

**If-else statement** жогоруда көрсөтүлгөн структурага ылайык иштейт. Эгер boolean туюнтмасы чыныгы болсо, анда программа **if-блокто** болгон **Аракет(тер) Аны аткаруу** жазууларын аткарат. Тескерисинче, программа **else-блокто** болгон **Аракет(тер) Бны аткаруу** жазууларын гана аткарат.

### Мисал

```C#
    bool музыкаЖактыруу = true;
    if(музыкаЖактыруу == true) 
    {
        Console.WriteLine("Мен музыка жактырам");
    } 
    else 
    {
        Console.WriteLine("Мен музыка жактырбайм");
    }   
```

Жогорудагы код **"Мен музыка жактырам"** деген текстти басып чыгарат, себеби boolean туюнтмасы, **"музыкаЖактыруу == true"**, чын.

{{% /notice %}}

Жогорудагы саламдашуу мисалын карап чыгып, Патрикке **"Куттуу тандоо," "Куттуу күн," "Куттуу түн"** деп айтуусун чечүүгө жардам берели.

Патрик **Куттуу тандоо** дейт 0:00 - 11:59 аралыгында, **Куттуу күн** дейт 12:00 - 19:59 аралыгында, жана **Куттуу түн** дейт 20:00 - 23:59 аралыгында.

1. Бизде учурдагы саатты сактоочу `currentHour` деген өзгөрмө бар.

3. Натыйжаны текшерүү үчүн `currentHour` өзгөрмөңүздү 0дан 23кө чейинки сандарга таратыңыз:

## Кайра-кайра кайталоо: For-Loop, While-Loop

Математика сабагында Патриктин 🐥 мугалими класска бир математикалык көйгөйдү чечүү сунушун билдирди, жана ал бир аз жардамга муктаж болушу мүмкүн.

Мугалими алардан **1, 2, 3, ..., 100** сандарынын жалпы суммасын табууну талап кылды. Башкача айтканда, **1 + 2 + 3 + 4 ... + 99 + 100** суммасын табуу керек.

Биз калькуляторду колдонуп эсептесек да болот, бирок бул убакытты талап кылат. Сүйүнүчтүү жагы, C# колдонуп, бул суроону 3 сызыктан турган код аркылуу оңой эсептөө мүмкүн.

{{% notice note %}}
**For loops** жана **While loops** C# тилиндеги башкаруунун структуралары болуп саналат, алар алгоритмдерди бир нече жолу иштетүүгө мүмкүндүк берет.

### While Loop

```
while(boolean expression){
    Аткара турган аракеттер
}
```

**While** блоктун ичиндеги **Аткара турган аракеттер** boolean туюнтмасы чын болгондо гана аткарылат.

Төмөндөгү мисал 1ден 10го чейинки сандарды басып чыгарат:

```C#
int саны = 1;
while(саны <= 10){
    Console.WriteLine(саны);
    саны = саны + 1;        // саны көтөрүлөт
}
```

Жогорудагы **while loop** цикли, учурдагы код **саны**нын маанисин басып чыгарат жана аны көтөрөт. Бул процесс **саны <= 10** туюнтмасы чын болгондо ишке ашат, циклдин аягы **саны == 11** болгондо болот.
