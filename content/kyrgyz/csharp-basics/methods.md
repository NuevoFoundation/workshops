## Метод деген эмне?

Азыркыга чейин биз маалыматты өзгөрмөлөрдө сактоо, маалыматтарды жана сүйлөмдөрдү басып чыгаруу, ошондой эле чечим кабыл алуу үчүн `if`-жоопторду, `for`-циклин жана `while`-циклин кандай колдонууну үйрөндүк.

Акыркы практикадан, төмөндөгү код блок 1ден 100гө чейинки сумманы эсептей турганын билебиз:

```C#
int total = 0;
int num = 1;
while(num <= 100){
    total = total + num;
    num = num + 1;
}
Console.WriteLine("Sum: " + total);
```

Бирок 1ден 77ге чейинки сумманы эсептөөнү кааласак эмне кылуу керек? Бул кодду кайрадан толугу менен жазбай кантип ишке ашырабыз?

Биз коддо ар кандай эки сан үчүн эсептөөнү жүргүзө турган ✨ сыйкырдуу кутуну ✨ түзүүнү каалайбыз!

C# тилинде **метод** дегенибиз – бул айрым тапшырмаларды аткарган жана колдонуучунун киргизген маалыматтарын колдоно турган код блогу сыяктуу сыйкырдуу куту.

Методдун 2 негизги бөлүгү бар: кол тамга жана дене:

{{% notice note %}}
### Методдун Кол Тамгасы

Методду аныктоо үчүн адегенде анын **методдун кол тамгасын** жазышыбыз керек. Кол тамга башында төрт негизги бөлүк бар:

```
access_specifier return_type method_name(list_of_parameters)
```

**Бөлүк Аты** | **Түшүндүрмөсү** | **Мисалдар же мүмкүн болгон варианттар**
----|----|----
**access specifier** | методго жеткилик деңгээлин камсыздайт | `public` компьютерге бул методду ар ким колдоно аларын айтып турат. `private` болсо компьютерге методду класстын ичинде гана чакырууга болорун түшүндүрөт. (Биз кийинки бетте класстарды үйрөнөбүз!) `protected` компьютерге бир эле класстын объекттери тарабынан чакырылышы мүмкүн экенин айтууда.
**return type** | метод кайтара турган маалымат тиби, техникалык жактан кайтаруу тиби C# тилинде кол тамганын бөлүгү болуп эсептелбейт | `string` же `int`. Эгер метод эч нерсе кайтарбаса, анда `void` колдонулат.
**method name** | методдун аты, аны чакырууда колдонулат | метод эмне кыла турганына жараша тандалган сүрөттөөчү ат.
**list of parameters** | метод колдонулганда камсыз кылынуучу кириштердин тизмеси | `()` форматында параметр жок болсо, нөл же андан көп параметрлер болушу мүмкүн (`type` `input name`, `type` `input name`, ... ). 

```
// параметр катары сапты кабыл алып, жооп катары башка сапты кайтарып берген мисал
public string artist (string songName)
```
**Эскертүү:** Параметрлердин өзгөрүлмө аттары методго жөнөтүлгөн маалыматтын өзгөрмө аттарына туура келиши милдеттүү эмес.

### Методдун Дене Болугу

Андан кийин, метод менен байланышкан код блогу методдун **дене болугуна**, башкача айтканда, кол тамгадан кийинки `{` жана `}` ортосуна жазылат.

Маалыматты кайтаруу үчүн `return` ачкыч сөздү анын артынан өзгөрмө аты же кайтарылуучу мааниси менен жазуу керек.

**Эскертүү:** Бир жолу `return` жазылгандан кийин, методдо андан кийинки эч нерсе аткарылбайт.

Бул `numA`дан `numB`ге чейинки сандардын суммасын эсептөөчү методду аныктоонун мисалы:

```c#
/* Метод Аты: sumNum
 * Киргизүү/Параметр: int тибиндеги 2 сан
 * Функциясы: numAдан numBге чейинки сандардын суммасын кайтаруу
 */
public int sumNum(int numA, int numB){
    int total = 0;
    int num = numA;      // биз биринчи киргизүүнү numA атынан колдонобуз
    while(num <= numB){  // биз экинчи киргизүүнү numB атынан колдонобуз
        total = total + num;
        num = num + 1;
    }
    return total; // кайтаруу оператору
}
```

### Методду Чакыруу

Акырында, методду коддо аткаруу үчүн биз методду чакыруу (method call) жасашыбыз керек. Методдун атын туура кириштер менен жазабыз.
Мисалы:

```C#
sumNum(1, 3); // sumNum() методун чакан мааниси 6 болгон сан менен чакыруу
```

`sumNum(1, 3)` 1ден 3кө чейинки сумманы кайтарып, `int` кайтаргычты колдонгонун билүү менен, биз төмөнкөнү жасай алабыз:

Методду чакыруу:
```c#
    int sum = 0;
    sum = sumNum(1, 3);
    Console.WriteLine(sum); // 6 деп басып чыгарат
```

Методдордун күчтүүлүгүнүн бир себеби – биз аларды бир нече жолу чакырса болот:
```C#
    int sum = 0;
    sum = sumNum(1, 3);
    Console.WriteLine(sum); // 6 деп басып чыгарат
    sum = sumNum(1, 4);
    Console.WriteLine(sum); // 10 деп басып чыгарат
```

Муну өзгөрмөгө сактабай эле, кайтарылган санды дароо басып чыгаруу үчүн жазсак болот:
```c#
    Console.WriteLine(sumNum(1,3)); // 6 деп басып чыгарат
    Console.WriteLine(sumNum(1,4)); // 10 деп басып чыгарат
```
