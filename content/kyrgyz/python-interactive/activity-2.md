## Менюну Түзүү жана Сактоо Жолу
Сиздин ресторан үчүн баннерди даярдаганыңыздан кийин, эми тамак-аштарыңыз тууралуу маалыматты кантип уюштурууну ойлонууга убакыт келди. Рестораныңызда саткыңыз келген тамак-аштар жана суусундуктарды мурда чечкениңизди эстеңиз. Эми ошол маалыматтын баарын кантип сактап коё турганыбызды билүү керек. Менюңуздагы ар бир нерсенин аталышын, баасын жана сүрөттөмөсүн сакташыбыз керек.
Бул үчүн, биз маалыматты көзөмөлдөп тура турган Python сөздүгүн (dictionary) колдонсок болот.

Биз маанилерин Тизме (List) түрүндө сактаган сөздүк түзөбүз!
Муну менен биз нерсенин баасын жана сүрөттөмөсүн өз алдыбызда сактай алабыз. Эгерде сөздүктөгү ачкычтын маанилери катары тизмени же башка контейнерди колдонсок, анда **иерархиялык сөздүк** алабыз. Баа жана сүрөттөмө маалыматтарын сактоо керек болгондуктан, аларды тизмеге белгилүү бир тартипте жайгаштыруу зарыл.

Мына бул структураны колдонобуз:
{нерсе : [баа, сүрөттөмө]}
Ушул структураны сактап, **иерархиялык сөздүк** түзгөндө, кийин баа жана сүрөттөмөнү оңой эле ала аласыз.

Мына бир үлгү иерархиялык сөздүк! Бирок меню түзгөндө жогорку структураны колдонууга унутпаңыз:
```python
#структура
#{сөз:[мааниси, сүйлөмдүн түрү, айтылышы]}
кичиСөздүк = {'оюнчук':['балдар ойной турган нерсе', 'зат атооч', 'ойунчук'], 'басуу':['туура жана жай темп менен буттарды кезектешип ар бир кадамда көтөрүп жүрүү ыкмасы', 'эт атооч', 'басуу']}
```

Мурда колдонгон `Replit` шилтемесине кайтып, менюңузду `dictMenu` аталышындагы өзгөрмөгө сактоо үчүн код кошуңуз. Эсиңизде болсун, `dictMenu` глобалдык өзгөрмө болушу керек - аны `main()` функциясына койбостон, коддун баш жагына жайгаштырыңыз, ошондо ал каалаган функциядан жеткиликтүү болот.
Кеңеш: Сиздин бааңыз `float` типинде, сүрөттөмөңүз `string`.
