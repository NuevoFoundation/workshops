## Ресторан баннерин түзүү
Рестораныңыздын виртуалдык кассирин орнотууда, алгач рестораныңыздын аталышы камтылган баннерди түзүү керек болот. Анткени биз жөн гана текстти эмес, чыныгы баннер жасагыбыз келет, ASCII искусствосу менен иштейли! ASCII искусствосу `()`, `{}`, `*` сыяктуу атайын символдорду колдонуп сүрөттөрдү жана сөздөрдү жаратат.
Бул иш-чара үчүн текстти ASCII искусствого өзгөртүү үчүн онлайн ресурстан пайдалансаңыз болот.

[Текстти ASCII искусствого өзгөртүүчү](https://onlineasciitools.com/convert-text-to-ascii-art)

Мисалы, "Restaurant" сөзүн ASCII искусствого өзгөртсөк болот. Төмөндөгү кодду карасаңыз!

```python
print("    _   _   _   _   _   _   _   _   _   _  ")
print("   / \ / \ / \ / \ / \ / \ / \ / \ / \ / \ ")
print("  ( r | e | s | t | a | u | r | a | n | t )")   
print("   \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ ")
```

Бул документти ачык кармаңыз, анткени кийинки иш-чараларда ага кайра кайтабыз, ар бир иш-чара мурунку иш-чараларга негизденет. Акырында, рестораныңыз үчүн касса толугу менен ушул документте орнотулат.      
```
