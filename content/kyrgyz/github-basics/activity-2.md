Экинчи бөлмөгө кирсеңиз, абада коддун үзүндүлөрү калкып жүргөнүн көрөсүз. Борбордо турган терминал жалтылдап мындай билдирүү көрсөтүп турат: "Тартипти орнот. Өзгөртүүлөрдү commit кылып, алдыга жыл."

## Сиздин Тапшырмаңыз

1. `solution.md` деген жаңы файлды жергиликтүү репозиторияңызга түзүңүз.
2. 1-Бөлмөдөн алынган сырдуу кодду бул файлга кошуңуз.
3. Өзгөртүүлөрүңүздү stage кылып, commit кылыңыз.

## Нускамалар

1. Терминалыңызда `escape-room` каталогуна өткөнүңүздү текшериңиз.
2. Файлды түзүп, кодду кошуңуз:

```
echo "Secret Code: GITHUB_BASICS_101" > solution.md
```

3. Өзгөртүүлөрдү stage кылып, commit кылуу:

```
git add solution.md
git commit -m "Add solution for Room 1"
```
