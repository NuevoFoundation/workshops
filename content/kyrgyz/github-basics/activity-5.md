# Бөлмө 5: Талаш-тартыш капчыгайы

Сиз терең жараканы бар бөлмөгө киресиз. Эки тараптан көпүрөлөр сунулганы менен, ортосунда бири-бирине тийишпейт. Белгиде мындай деп жазылган: "Конфликттерди чечүү аркылуу гана өтө аласыз."

## Сиздин миссияңыз

1. Баштапкы репозиторийден акыркы өзгөртүүлөрдү тартыңыз.
2. Пайда болгон биригүү кагылышуусун чечиңиз.
3. Чечимди сактап, өзгөртүүлөрдү түртүңүз.

## Нускамалар

1. Баштапкы репозиторийди алыстан туташтырыңыз:

```
git remote add upstream https://github.com/CodeDungeon/escape-room.git
```

2. Өзгөртүүлөрдү тартыңыз жана кошуңуз:

```
git fetch upstream
git merge upstream/main
```

3. Биригүү кагылышуусун көрөсүз. Кагылышуу болгон файлдарды ачып, көйгөйлөрдү чечиңиз.
4. Чечимди бүткөндөн кийин, өзгөртүүлөрдү сактаңыз, коммит жасаңыз жана түртүңүз:
   
```
git add .
git commit -m "Бириктирүү кагылышуусун чечүү"
git push origin main
```
