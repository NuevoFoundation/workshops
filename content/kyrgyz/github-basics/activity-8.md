Сиз калкып жүргөн канбан такталары жана долбоор графиктери менен толгон бөлмөгө киресиз. Жаткан добуш жарыялайт: "Бейтараптуулукту тартипке келтириңиз, качууңузду пландаштырыңыз!"

## Сиздин миссияңыз

1. GitHub репозиторийиңизде жаңы долбоор тактасын түзүңүз.
2. "Аткаруу", "Процессте", жана "Бүткөн" деген колонкаларды кошуңуз.
3. Бир нече көйгөйлөрдү жаратып, аларды долбоор тактасына кошуңуз.
4. Көйгөйлөрдүн бирин ар кандай колонкаларга жылдырыңыз.

## Нускамалар

1. GitHub репозиторийиңизге өтүңүз.
2. "Projects" баскычын басыңыз.
3. "New project" баскычын басып, "Board" шаблонун тандаңыз.
4. Тактаңызга керектүү колонкаларды кошуңуз.
5. Репозиторийиңизде бир нече көйгөйлөр жаратыңыз.
6. Бул көйгөйлөрдү долбоор тактасына кошуңуз.
7. Бир көйгөйдү тактанын ар бир колонкасы аркылуу жылдырыңыз.

{{< notice info >}}
**Кеңеш:** Долбоор такталары жумуш агымын визуализациялоого жана бир нече маселелер же пул сурамдары боюнча жүрүштөрдү көзөмөлдөөгө абдан жакшы жардам берет.
{{< /notice >}}

{{< expand "Долбоор тактасынын процесси" >}}
**Такта түзүү**
1. "Projects" баскычына өтүңүз
2. "New project" баскычын басыңыз
3. "Board" шаблонун тандаңыз
4. Колонкаларды кошуңуз: "Аткаруу", "Процессте", "Бүткөн"

**Көйгөйлөрдү кошуу**
1. "Issues" баскычына өтүңүз
2. Жаңы көйгөйлөрдү түзүңүз
3. Ар бир көйгөйдө "Projects" баскычын басып, жаңы тактага кошуңуз

**Көйгөйлөрдү жылдыруу**
1. Долбоор тактасына кайтыңыз
2. Көйгөйлөрдү колонкалар арасында сүйрөп жылдырыңыз
3. Бул жумуш тапшырмаларынын жүрүшүн кандайча чагылдырып жатканына байкаңыз
{{< /expand >}}
