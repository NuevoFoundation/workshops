Сиз коопсуздук чаралары менен курчалган бөлмөгө киресиз. Кулпулар, калкандар жана коопсуздук мониторлору тегерегиңизде. Катуу үн жарыялайт: "Кодуңузду камсыздаңыз да өтүңүз!"

## Сиздин Миссияңыз

1. Сактоочу жайыңыз үчүн Dependabot эскертмелерин иштетүү.
2. Сактоочу жайга коопсуздук саясатын кошуу.
3. GitHub Actions аркылуу кодду сканерлөө эскертүүсүн иштетүү (эгер сактоочу жериңиз жалпыга ачык болсо).

## Нускамалар

1. Сактоочу жайыңыздын "Settings" (Орнотуулар) бөлүмүнө кириңиз.
2. Сол жактагы каптал тилкеден "Security & analysis" (Коопсуздук жана анализ) бөлүмүн тандаңыз.
3. Dependabot эскертмелерин иштетиңиз.
4. Сактоочу жайыңызда `.github/SECURITY.md` аталышында жаңы файл түзүңүз.
5. Бул файлга негизги коопсуздук нускамаларын кошуңуз.
6. Эгер сактоочу жайыңыз жалпыга ачык болсо, "Security & analysis" бөлүмүнөн кодду сканерлөөнү иштетиңиз.

{{< notice danger >}}
**Маанилүү:** Коопсуздук жөндөөлөрү боюнча иштөөдө ар дайым этият болуңуз. Ар бир өзгөчөлүктү иштетүүдөн мурун ал жөнүндө толук түшүнүүңүз бар экенине көзүңүз жетсин.
{{< /notice >}}

# Коопсуздук Саясаты

## Осалдыкты Кабыл Алдыруу

Эгерде сиз бул долбоордо коопсуздук осалдыгын тапсаңыз, security@example.com дарегине электрондук кат жөнөтүңүз. Бардык коопсуздук осалдыктары тез арада каралат.
