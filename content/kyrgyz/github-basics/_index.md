GitHub Негиздери Семинарына кош келиңиз! Бул семинар сизге GitHub негиздерин качуу бөлмөсү стилиндеги оюн аркылуу үйрөтүүнү көздөйт. Ар бир бөлмө ар башка GitHub түшүнүгүн камтыйт. Ар бир бөлмөдөгү тапшырмаларды аткарып, кийинкисин ачуу мүмкүнчүлүгүнө ээ болосуз. Ийгилик!
