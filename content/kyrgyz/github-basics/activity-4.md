Сиз өзүңүздү полдо татаал лабиринт чийилген бөлмөнүн ичинде табасыз. Жолдор кайчылашып, бөлүнүп турат, бул сиздин жергиликтүү көчүрмөдөн алыстан башкарылып жаткан версияга кодду бириктирүүдөгү кыйынчылыктарды чагылдырат.

## Сиздин Миссияңыз

1. Сиздин pull сурооңузга коюлган комментарийлерди карап чыгыңыз.
2. Керектүү өзгөртүүлөрдү киргизип, pull сурооңузду жаңылаңыз.
3. Кабыл алынгандан кийин, pull сурооңузду бириктириңиз.

## Нускамалар

1. Сиздин pull сурооңуздагы комментарийлерди текшериңиз.
2. Эгер өзгөртүүлөр талап кылынса:
   - Жергиликтүү өзгөртүүлөрдү жасаңыз
   - Өзгөртүүлөрдү commit кылыңыз
   - Өз форкуңузга push жасаңыз
3. Pull суроо автоматтык түрдө жаңыланат.
4. Кабыл алынгандан кийин, GitHub интерфейсинде "Merge pull request" баскычын чыкылдатыңыз.

{{< notice warning >}}
**Маанилүү:** Байланыш негизги ролду ойнойт! Талап кылынган өзгөртүүлөр тууралуу ишенбесеңиз, pull суроо комментарийлеринде түшүндүрмө сураудан тартынбаңыз.
{{< /notice >}}
