Сиз күңүрт жарык бөлмөдө ойгонуп калдыңыз. Борбордо жайгашкан пьедесталда жарык чачкан GitHub логотиби бар. Үн жаңырып чыгат: "Улантуу үчүн, сиз алдыдагы жолду тармакташыңыз керек."

Жол менен, үн GitHub репозиторийин билдирет. Репозиторийди тармактоо (fork) аны сиздин аккаунтуңузга көчүрүп алат жана баштапкы көчүрмөгө таасир этпей эле өзгөртүүлөрдү киргизүүгө жардам берет.

## Тапшырмаңыз

1. GitHub аккаунт түзүңүз (эгер азырынча жок болсо).
2. Төмөнкү репозиторийди тармактаңыз: `https://github.com/VerisimilitudeX/escape-room`
3. Тармакталган репозиторийди өз компьютериңизге клондоңуз.

## Нускама

1. GitHub сайтына барып, катталуу же кирүү ишин жасаңыз.
2. Репозиторийдин URL дарегин таап, оң жактагы "Fork" баскычын басыңыз.
3. Тармактагандан кийин, жашыл "Code" баскычын басыңыз жана URL дарегин көчүрүп алыңыз.
4. Терминалды ачыңыз жана төмөнкү буйрукту ишке ашырыңыз:

   ```pwsh
   git clone <YOUR_FORKED_REPO_URL>
   cd escape-room
   ```

{{< expand "Жардам керекпи?" >}}
Эгер кыйналып жатсаңыз, төмөнкү кадамдарды жасап көрүңүз:

1. GitHub'га киргениңизди текшериңиз.
2. Туура репозиторийдин URL дарегине киргениңизди текшериңиз.
3. Git буйруктары менен көйгөй жаралса, компьютериңизде [git](https://git-scm.com/downloads) орнотулганын текшериңиз.
