Акыркы бөлмөгө киргенде чоң экранда веб-сайт көрсөтүлүп, "Жеткирүү" деген баскычтар абада калкып турганын көрөсүз. Жеңиштүү үн жарыялайт: "Жеңишиңди элге көрсөтүш үчүн жеткир!"

## Сиздин Миссияңыз

1. Репозиториюңуз үчүн GitHub Pagesди иштетүү.
2. Жөнөкөй index.html файлын түзүү.
3. Файлды жүктөп, жеткирилген сайтыңызды караңыз.

## Нускамалар

1. Репозиториюңуздун "Settings" бөлүмүнө өтүңүз.
2. "GitHub Pages" бөлүмүнөн ылдый жылдырыңыз.
3. "Source" бөлүгүндө жеткирүүнү каалаган тутабын тандаңыз (көбүнчө `main`).
4. Жергиликтүү репозиториңизде root каталогдо `index.html` файлын түзүңүз.
5. Файлга HTML код кошуңуз, мисалы:

   ```html
   <!DOCTYPE html>
   <html>
     <head>
       <title>Менин GitHub Pages сайтым</title>
     </head>
     <body>
       <h1>Салам, GitHub Pages!</h1>
       <p>Мен GitHub Adventure оюнун бүтүрдүм!</p>
     </body>
   </html>
    ```

6. Бул файлды репозиторияга жүктөп, өзгөртүүлөрдү жазыңыз.
7. GitHub процессти иштеп чыкканын күтө туруңуз жана сайтыңызга https://<колдонуучуаты>.github.io/<репозиторий-аты> дареги аркылуу кириңиз, бул жерде <колдонуучуаты> сиздин GitHub колдонуучу атыңыз жана <репозиторий-аты> репозиторияңыздын аталышы.
