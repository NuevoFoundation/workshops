Сиздин жолуңузду чоң эшик тосот, үстүндө "Кайтаруу Суроо" деп жазылган. Бир белги "Бул эшикти ачуу үчүн, сиздин өзгөртүүлөрүңүз каралышы керек" дейт.

## Сиздин тапшырмаңыз

1. Жергиликтүү өзгөртүүлөрүңүздү өзуңүздүн клондук репозиторияңызга түртүңүз.
2. Түпкү `CodeDungeon/escape-room` репозиториясына кайтаруу суроосун түзүңүз.

## Нускоолор

1. Өзгөртүүлөрдү түртүңүз:

```
git push origin main
```

2. GitHub'дагы клондук репозиторияңызга өтүңүз.
3. "Contribute" баскычын басып, андан кийин "Open pull request" баскычын басыңыз.
4. Темасын "Solution for Room 2" деп толтуруңуз жана кыскача түшүндүрмө бериңиз.
5. "Create pull request" баскычын басыңыз.

{{< notice info >}}
**Кеңеш:** Кайтаруу сурооңузга көз салыңыз. Үңкүрдүн кайтаруучулары (репозиторияны тейлөөчүлөр) аны карап чыгат жана өзгөртүүлөрдү суранышы мүмкүн!
{{< /notice >}}

{{< expand "Кайтаруу Суроо процесси" >}}

**Өзгөртүүлөрдү түртүү**
Алгач, жергиликтүү өзгөртүүлөрүңүздү алыскы репозиторияңызга түртүңүз:

```
git push origin main
```

**Кайтаруу Суроосун Түзүү**
1. GitHub'дагы клондук репозиторияңызга өтүңүз.
2. "Pull requests" бараччасына өтүңүз.
3. "New pull request" баскычын басыңыз.
4. Түпкү репозитория базасында жана өзүңүздүн клон укуктарыңызды салыштырыңыз.
5. "Create pull request" баскычын басыңыз.

**Кароо күтүү**
Кайтаруу суроосун түзгөндөн кийин:
1. Тейлөөчүлөрдүн өзгөртүүлөрдү карап чыгышын күтүңүз.
2. Алар берген пикирлерге жооп бериңиз.
3. Керек болсо, кайтаруу суроону жаңыртуу үчүн жаңы коммиттерди түртүңүз.
