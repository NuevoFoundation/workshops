Сиз иш-аракетке толгон бөлмөгө кадам таштайсыз. Тиштүү механизмдер айланып, конвейер ленталары кыймылдап, автоматташтырылган процесстерди символдоштурат. Голографиялык экран жанып чыгат: "Жеңишке автоматташтыруу жолу менен жет!"

## Сиздин Миссияңыз

1. Жөнөкөй GitHub Action агымын түзүңүз.
2. Бул агымды репозиторияңызга өзгөртүүлөрдү жүктөө аркылуу ишке киргизиңиз.
3. Автоматташтырылган процессинин жыйынтыктарын көрүңүз.

## Нускамалар

1. Жергиликтүү репозиторияңызда `.github/workflows` деп аталган жаңы каталог түзүңүз.
2. Бул каталогдун ичинен `hello-world.yml` деген файл түзүңүз.
3. Файлга төмөнкү мазмунду кошуңуз:

   ```yaml
   name: Hello World Workflow
   on: [push]
   jobs:
     say-hello:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v2
         - name: Say Hello
           run: echo "Hello, GitHub Actions!"

    ```
4. Бул файлды сактаңыз, commit түзүп, GitHub репозиторияңызга жүктөңүз.
GitHub репозиторияңыздагы "Actions" бөлүмүнө өтүп, агымдын иштөө статусун караңыз.

{{< notice warning >}}
Эскертүү: GitHub Actions автоматташтырууда натыйжалуу курал болушу мүмкүн, бирок бекер аккаунттардагы пайдалануу чектөөлөрүнө көңүл буруңуз.
{{< /notice >}}
