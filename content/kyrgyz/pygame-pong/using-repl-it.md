Оюбуздагы оюнду куруу үчүн биз Pygame китепканасын колдонобуз, ал даяр функциялар топтомун камсыздайт жана аларды Pong жана анын анимацияларын түзүү үчүн колдоно алабыз.

## Replit менен иштөө

Бүгүн биз Pong оюнун курууда Replitти колдонобуз.

Эгерде Replitти кантип колдонуу жөнүндө кайрадан түшүнүк алгыңыз келсе, биздин <a href="https://workshops.nuevofoundation.org/python-basics/repl-it/" target="_blank">Python негиздери боюнча окуу куралын</a> карап чыгыңыз.

Эми, сизге `main.py` файлында берилген кээ бир коддорду карап чыгалы.

{{% notice tip %}}

## Китепканалар жана импорттоо билдирүүлөрү

Коддун эң жогорку бөлүгүн караңыз. Сиз төмөнкү сапты көрөсүз:

```
import pygame
```

Бул билдирүү `pygame` китепканасы камсыз кылган бардык анимация жана объекттерди тартуу функцияларын импорттоого жол ачат. **Китепкана** — бул Python тилинде колдонуу үчүн байланышкан функциялар бир топко чогулган жер. Мисалы, `pygame` китепканасы экранга тик бурчтукту тартуу мүмкүнчүлүгүн камсыз кылат. Бул функцияны Pong оюнунда чек араларды, топту жана ракеткаларды тартуу үчүн колдонсо болот.

## Комментарийлер

`#` менен башталган боз сап **комментарий** деп аталат. Бул код эмне кыларын кадимки англис тилинде түшүндүргөн жазуулар болуп саналат. Комментарийлерди компьютер эске албайт; иштеп чыгуучулар комментарийлерди бири-бири менен байланышуу үчүн колдонушат, айрыкча бир нече иштеп чыгуучулар бирдей коддун үстүндө иштеп жатканда. Комментарийлер кодду карап жаткан адамга деталдаштырган бардык кодду окубай туруп, эмне болуп жатканын жогорку деңгээлде түшүнүүгө жардам берет. `main.py` файлыбызда биз комментарийлерди өзгөртүү киргизүүгө тийиш болгон жерлерди көрсөтүү үчүн колдонобуз.
