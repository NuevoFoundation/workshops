## Класстар жана объектилер

Оюн түзүүдөн мурун, компьютердин экранында ар кандай объектилерди кантип тартууну жана аларды көрүнүшү жана кыймылы боюнча өзгөртүүнү билүүңүз керек.

Объекттерди түзүү үчүн, алар кандай көрүнүштө болушу керектигин, оюнда кандай роль ойной тургандыгын жана оюнчу экранда алардын кыймылын кантип көзөмөлдөй ала тургандыгын чечишиңиз керек. Бул үчүн, экранда болуучу ар бир объект үчүн класс түзүү керек.
Программада объект түзүлгөнгө чейин анын классын аныкташ керек. Класс — ал объект жеке кандай көрүнүшкө ээ болоорун жана кантип ар кандай кадамдарды аткараарын көрсөтөт. Ал объект программаны иштетип жатканда колдоно алган атрибуттарды жана методдорду камтыйт (бул учурда Понг оюну). Классты бир жолу аныктоо жетиштүү, андан кийин аны колдонуп, каалагандай көп объект түзө аласыз.

Классты программада түздөн-түз колдоно албайсыз; класстын программасында колдонулган көрүнүшү болгон объекти болушу керек.
Экранда көргөнүңүз боюнча объекттин бардыгы "атрибуттар" деп аталат. 
Объектти башкарууга тиешелүү бардык элементтер "функциялар" деп аталат. 

Алгач оюнда колдонулуучу таяктык (падл) үчүн классты аныктаңыз. Муну төмөнкү кодду колдонуп аткарса болот:

```python
class Paddle(pygame.Rect):
    def __init__(self, velocity, up_key, down_key, *args, **kwargs):
        self.velocity = velocity
        self.up_key = up_key
        self.down_key = down_key
        super().__init__(*args, **kwargs)

    def move_paddle(self, board_height):
        keys_pressed = pygame.key.get_pressed()

        if keys_pressed[self.up_key]:
            if self.y - self.velocity > 0:
                self.y -= self.velocity

        if keys_pressed[self.down_key]:
            if self.y + self.velocity < board_height - self.height:
                self.y += self.velocity
```

Эми кодду кененирээк түшүнүп көрөлү.

{{% notice tip %}}

### Классты аталыңыз

`class Paddle(pygame.Rect)`

Бул жерде класс `"Paddle"` деп аталды. Эми, `pygame.Rect` дегенди `()` ичинде байкаңыз. Компьютердин экранында таяктык (падл) катары бир тик бурчтукту тартуу керек деп элестеткен чыгарсыз. Аны экранда тик бурчтук кылып өлчөмдөрүн жана ордун аныктоо менен тартасыз. `(pygame.Rect)` билдирүүсү Python компиляторуна объектти тик бурчтук сыяктуу тартыңыз жана `Rectangle` классы сунуштаган бардык атрибуттарды камсыздоо керек экендигин билдирүүгө мүмкүндүк берет. Бул Пугейменин китепканасында бар болгон бардык атрибуттарды колдонууну жеңилдетет. 

### Атрибуттарды кошуу

`def __init__(self, velocity, up_key, down_key, *args, **kwargs):`

`args` жана `kwargs` жөнүндө азырынча кам санабай эле койсоңуз болот — жөн гана `Paddle` классындагы негизги атрибуттарга көңүл буруңуз.

`__init__` функциясы классты объекттеринде көргүңүз келген атрибуттар менен орнотууга мүмкүнчүлүк берет. Бул жерге Сиз башка атрибуттарды кошо аласыз, алар `Rectangle` классынын өзгөчөлүктөрүнөн тышкары. Мисалы, таяктыктын жылыш ылдамдыгын билдирген жана жогору-ылдый кыймылын көзөмөлдөөчү ачкычтарды көрсөтүү үчүн `velocity`, `up_key`, `down_key` аттуу атрибуттарды кошобуз.

```python
class Paddle(pygame.Rect):
    def __init__(self, velocity, up_key, down_key, *args, **kwargs):
        self.velocity = velocity
        self.up_key = up_key
        self.down_key = down_key
        super().__init__(*args, **kwargs)
```

### Методдорду кошуу

`move_paddle()` — бул **метод**. Бул методду таяктыкты кыймылдатыш үчүн колдонобуз. Бул учурда, `move_paddle()` методу таяктыкты басылган баскычка жараша өйдө же ылдый жылдырууга жана белгилүү бир ылдамдыкта жылууга жардам берет.

```python
def move_paddle(self, board_height):
        keys_pressed = pygame.key.get_pressed()
        if keys_pressed[self.up_key]:
            if self.y - self.velocity > 0:
                self.y -= self.velocity
        if keys_pressed[self.down_key]:
            if self.y + self.velocity < board_height - self.height:
                self.y += self.velocity
```

{{% /notice %}}

Эми таяктык кандай көрүнүштө болушу керектигин жана ал кантип жылышы керектигин аныктаганыңыздан кийин, `Ball` жана `Pong` класстарын карап көрүңүз. Кийинки иш-аракеттерде бул класстардын айрым аспектилерин өзгөртүп, Понг оюнун өз каалооңуз боюнча жөндөйсүз.
