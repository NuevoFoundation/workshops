## Чечим кабыл алуу: If-Statement

Патрик 🐥 — өзгөчө сылык өрдөк, ал учурдагы убакытка жараша жолуккан адамдардын баарына "Кутмандуу таң," "Куттуу күн" же "Куттуу түн" деп салам айтканды жакшы көрөт.

![Тоонун артынан бат эле көтөрүлүп келе жаткан күн](https://media.giphy.com/media/hpWrLS1RDBd5pwkgjy/giphy.gif)

Мурда айтылгандай, биз бул саламдашууларды төмөнкүдөй жазып чыгарсак болот:

```java
System.out.println("Кутмандуу таң");   // 0:00 - 11:59 аралыгында айтылат
System.out.println("Куттуу күн");     // 12:00 - 19:59 аралыгында айтылат
System.out.println("Куттуу түн");     // 20:00 - 23:59 аралыгында айтылат
```

Бирок, биз ошондой эле билебиз, Патрик 🐥 учурдагы убакытка жараша ушул билдирүүлөрдүн бирөөсүн гана айтышы керек.

Башкача айтканда, бизге жагдайдын шарттарына (шарттуу түрдө) жараша басып чыгаруу керек болгон нерсени тандаган код жазуу зарыл.

Java тилинде биз чечимди **if оператору** же **if...else оператору** аркылуу кабыл алабыз. Төмөндө айтылган жазууларды окуңуз:

{{% notice note %}}
### If Оператору

```
if(логикалык билдирүү){
    Аталыш(тар)
}
```

**If оператору** жогоруда көрсөтүлгөн түзүлүштү карманат. Блоктогу аталыштар (стейтменттер) логикалык билдирүү `true` болгондо гана ишке ашышат. Болбосо, логикалык билдирүү `false` болсо, программа блоктон кийинки билдирүүгө өтөт.

### If-Else Оператору

```
if(логикалык билдирүү){
    Аталыш(тар) A
}else{
    Аталыш(тар) B
}
```

**If-else оператору** жогоруда көрсөтүлгөн түзүлүштү карманат. Эгер логикалык билдирүү `true` болсо, программа `if` блоктун ичиндеги `Аталыш(тар) A` аткарат. Болбосо, программа `else` блоктун ичиндеги `Аталыш(тар) B` гана аткарат.

### Мисал

```java
boolean музыкаЖакты = true;
if(музыкаЖакты == true) {
    System.out.println("Мен музыка жакшы көрөм");
} else {
    System.out.println("Мен музыка жактырбайм");
}
```

Жогорудагы код `Мен музыка жакшы көрөм` деген билдирүүнү басып чыгарат, анткени логикалык билдирүү `музыкаЖакты == true` туура.
{{% /notice %}}

Эми жогорудагы саламдашуулар мисалына кайтып келели жана Патрикке "Кутмандуу таң", "Куттуу күн" же "Куттуу түн" деп айтуу чечимин кабыл алсак.

## Тапшырманы кайталоо: For-Loop, While-Loop

Математика сабагында, Патриктин 🐥 мугалими класска тапшырма берет. Ал тапшырманы аткарууда Патрикка жардам керек болушу мүмкүн.

Мугалим аларга **1, 2, 3, ...., 100** сандарынын жалпы суммасын табуу тапшырмасын берет. Бул, башкача айтканда, **1 + 2 + 3 + 4 ... + 99 + 100** дегенди билдирет.

Бул нерсени калькулятор аркылуу эсептесек, бир топ убакыт кетет. Бактыга жараша, Java тилинде бул тапшырманы 3 сапта оңой эле аткарсак болот, мында **for loop** же **while loop** жардам берет.

{{% notice note %}}
**For циклдери** жана **While циклдери** — бул Java тилиндеги блоктордун кодун бир нече жолу аткарууга жардам берүүчү башкаруу структуралары.

### While Цикли

```
while(логикалык билдирүү){
    Аталыш(тар)
}
```

While блоктогу `Аталыш(тар)` логикалык билдирүү `true` болгон учурда гана аткарылат. 

Төмөндө 1ден 10го чейинки сандарды басып чыгаруучу мисал келтирилген:

```java
int сан = 1;
while(сан <= 10){
    System.out.println(сан);
    сан = сан + 1;        // санды 1ге жогорулатуу
}
```
