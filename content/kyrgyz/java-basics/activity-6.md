## Объект жана Класс деген эмне?

Объект – бул белгилүү мүнөздөмөлөргө жана иш-аракеттерди аткара ала турган нерсе (зат). Ал эми Класс – бул объекттин схемасы же аныктамасы.

Мисалы, "Адам" деген объектти карасак болот. Адам – бул Класс. Адам башка адамдардан айырмаланган белгилүү сапаттарга ээ боло алат. Анын көк көздөрү болушу мүмкүн, 30 жашта болушу мүмкүн ж.б. Адам айрым иш-аракеттерди да аткара алат. Ал баса алат, сүйлөй алат ж.б.

Javaдагы Объект Java Классынын экземпляры болуп эсептелет. Бул учурда "Жанар" деген "Адам" объектиси десек болот. "Жанар" деген объектинин кара көзү бар. Бул "Жанар" объектине таандык касиет (же маалымат талаасы). "Жанар" англисче сүйлөй алат. "Жанар" испанча да сүйлөй алат. Бул ыкмалар ("методдор") "Жанардын" аткара ала турган иш-аракеттери.

## Класс түзүү!

Java – бул <b>объектке багытталган</b> программалоо тили, демек Java'да бардык нерселер <b>объект</b> жана <b>класс</b> менен байланыштуу (объекттин схемасы).

Башында, биринчи тапшырмадагы билдирүүлөрдү басып чыгаруу үчүн колдонулган коддун саптары иш жүзүндө System деп аталган алдын-ала аныкталган класстын методун чакыруу болгон!

```java
System.out.println("Hello World");
```

1. `System` – бул колдонуучу киргизүүлөрү жана чыгаруулары менен иштеген класс.  
2. `out` – бул `System` классындагы `PrintStream` классынын/type'нын өзгөрмөсү.  
3. `println()` – бул `PrintStream` классында аныкталган ыкма.

<br />

Мурдагы көнүгүүлөрдө биз иштеп чыккан дагы бир класска мисал бул `String`. `String` классы символдордун тизмеси кандай иштеши керек экендигин аныктоо үчүн топтому болуп саналат.

Төмөнкү коддогу сап менен биз `String` классы аркылуу аны аныктаган эрежелерди колдонуу менен `name` аттуу `String` объект түздүк:

```java
String name = "Patrick";
```

<br />

`System`, `PrintStream`, жана `String` Java'дагы алдын-ала аныкталган класстар. Бирок, биз бул класстар менен гана чектелип калбастан, чындыгында, жаңы класстарды жазуу менен өзүлөрүбүздүн маалымат түрлөрүн түзө алабыз! Бул өзгөчө объекттерди белгилүү бир атрибуттарды жана аракеттерди аткаруучу кылып түзүү үчүн программисттерге пайдалуу. Бул колдонуучунун өз алдынча аныкталган типтерине мүмкүнчүлүк берүү түрдүү программаларды түзүүгө жардам берет.

Төмөндө класстын ар кайсы бөлүктөрү тууралуу билип, үйрөнүңүз:

{{% notice note %}}
### Класс
Класс бул жаңы объекттин типинин схемасы же прототиби. Жалпысынан, класс үч маанилүү бөлүктү камтыйт: (1) маалымат талаалары/экземплярдык өзгөрмөлөр (2) конструктор (3) ыкмалар.

<img src="../images/class.png" height="400" alt="Объектинин схемасы катары турган класс маалымат талааларын/экземплярдык мүнөздөмөлөрдү, конструкторлорду жана объект үчүн мүмкүн болгон аракеттерди камтыйт."/> 

**Элемент** | **Сүрөттөлүшү** | **Мисал**
---|---|---
**маалымат талаалары/экземплярдык өзгөрмөлөр** | класс объектинин атрибуттарын сүрөттөө үчүн колдонулган өзгөрмөлөр | Класс Адамда "көздүн түсү", "жашы", "бойу" деген талаалар бар.
**конструктор** | класстын объектисин түзүү үчүн керек болгон ыкма | Класста бир нече конструктор болушу мүмкүн.
**ыкмалар** | класс объектисинин ишке ашыруусу мүмкүн болгон методдор | Класс Адамда "сүйлөүү" жана "басуу" ыкмалары бар.

Мисалы:

```java
public class SampleClass{
    // (1) маалымат талаалары/экземплярдык өзгөрмөлөр
    private String name; // мисал

    // (2) конструктор
    public SampleClass(){
        name = "мисал";
    }
    // (3) ыкмалар
    public sampleMethod(){}
}
```
