## Өзгөрмөлөр: Аты бар болсун!

Акыркы көнүгүүдө `System.out.print()` менен ар кандай билдирүүлөрдү басып чыгара алганыбызды көрдүк.

Бирок, биз санды же сүйлөмдү басып чыгарганыбыз менен, аларга кандайдыр бир маанини бербейбиз.

Java тилинде бир маалыматка ээ болуу үчүн **өзгөрмө** деген түшүнүк бар. Өзгөрмө — бул аталышы бар бир маалыматты сактаган кутуча сыяктуу нерсе.

Мисалы, `"Patrick"` деген маалыматты сактаган `myName` деген өзгөрмө, `true` деген маалыматты сактаган `loveMusic` өзгөрмөсү, жана `3` санын сактаган `age` деген өзгөрмө болушу мүмкүн. Төмөндөгү сүрөттөн буларды көрө аласыз:

## Түрлөрдү түшүнүү!

Демек, кандайча Java тилинде кутучаны же өзгөрмөнү түзүп, маалыматты сактай алабыз?

Өзгөрмөлөрдү кантип түзүүнү билүүдөн мурун, биз Java тилиндеги **түр** деген түшүнүккө токтолуубуз керек. Түр — бул кутуда эмне сакталып жатканын сүрөттөйт. Эгерде сиздин бүтүн сан кутуңуз болсо, анда ал кутуга сүйлөм же символ эмес, бүтүн сандар гана кирет. Ар бир өзгөрмөнүн өзүнүн түрү бар, бул түр ал кандай гана маалыматты сактай аларын чектейт.

Мисалы, `age` деген өзгөрмө 3 деген санды сактагандан бери, ал бүтүн сандарды гана сакташы керек, сүйлөмдөрдү же символдорду сактай албайт.

Java тилинде бүтүн сандарды (integer) сактоо үчүн өзгөчө `int` деген түр колдонулат. Ал эми `int` түрүндөгү өзгөрмөнү түзүү үчүн, мисалы `age` деген өзгөрмөнү 3 деген маалымат менен кошо, бул кодду жазсаңыз болот:

```java
int age = 3;
```

Жалпысынан, өзгөрмө түзүү үчүн төмөнкүдөй форматта жазабыз: `[маалыматтын түрү] [өзгөрмөнүн аты] = [маалымат];`.
{{% notice note %}}
Төмөндө Java тилинде киргизилген маанилүү маалымат түрлөрү берилген:

**Түр** | **Сүрөттөмөсү** | **Мисалдар**
--------|-------------|----------
`int` | бүтүн сан | `20`, `30`, `35`
`char` | символ же бир тамга | `'A'`, `'b'`, `'('`, `']'`
`String` | символдор тизмеги | `"Hello"`, `"Bonjour"`, `"Hola"`
`boolean` | `true` же `false` мааниси бар | `true`, `false`
`double` | бөлчөк сандар | `2.0`, `3.14`, `9.33`

{{% /notice %}}

Эми мурун айтылган үч өзгөрмөнү карап көрөлү жана алардын маалымат түрлөрүн аныктайлы.

<img src="../images/dataType.png" height="200" alt="3 кутуча. Биринчи кутучада ак текст менен myName деген жазылган, ичинде 'Patrick'. Кызыл жебе көрсөтүп турат, String түрү. Экинчи кутучада ак текст менен loveMusic, ичинде true. Кызыл жебе көрсөткөндө boolean түрү. Үчүнчү кутучада ак текст менен age, ичинде 3. Кызыл жебе көрсөтүп int түрү."/> 

Бул өзгөрмөлөрдү Java тилинде төмөнкүдөй жазып чыгарууга болот:

```java
String name = "Patrick";
int age = 10;
boolean loveMusic = true;
```

Маалыматты өзгөрмөлөрдө сактоо менен, аларды кийинчерээк колдонсоңуз болот же ошол эле түрдөгү башка маалымат менен алмаштыра аласыз. Мисалы:

```java
int age = 10;
System.out.println(age); // 10 чыгат
age = 11; // 'age' өзгөрмөсүнө 11 деген маани берет
System.out.println(age); // 11 чыгат
```

## Түрлөрдү түшүнүү — Сандарды текшерүү!

Эми төмөнкү кодду карап көрөлү. Сиздин оюңуз боюнча чыгаруучу натыйжа кандай болот? Өзүңүз өзгөрмөлөрдүн ар биринин маанисин текшериңиз, андан кийин аны аракет кылып, текшерип көрүңүз!

```java
double x = 2.3;
double y = 10.0;
int z = 4;

x = y;
y = x;
z = 0;
z = z;
System.out.println("x: " + x + " y: " + y + " z: " + z );
```
