## Математика кылалы: Арифметикалык операторлор

Өткөн тапшырмада биз өзгөрмөлөр тууралуу жана аларга кандайча маани ыйгара аларыбызды үйрөнгөнбүз, мисалы:

```java
int age = 3;  // int түрүндөгү age аталыштагы өзгөрмөнү 3 маанисинде жарыялоо
age = 4;      // age өзгөрмөсүнө 4тү ыйгаруу
```

Жогорудагы коддон көрүнүп тургандай, `age` өзгөрмөсүнүн маанисине 1 кошулган.

Java тилинде биз арифметикалык операцияларды түздөн-түз **арифметикалык операторлордун** жардамы менен аткара алабыз: `+`, `-`, `*`, `/`, `%`.
Мисалы, биз `+` операторунун жардамында `age` маанисине 1 кошо алабыз:

```java
int age = 3;  // int түрүндөгү age аталыштагы өзгөрмөнү 3 маанисинде жарыялоо
age = age + 1;// age маанисине 1 кошуу
```

{{% notice note %}}
Java тилиндеги арифметикалык операторлор төмөнкүлөр:

**Оператор** | **Сүрөттөлүш** | **Мисал**
------|------|--------
`+` | кошуу | `1 + 1 = 2`
`-` | кемитүү | `2 - 1 = 1`
`*` | көбөйтүү | `3 * 3 = 9`
`/` | бөлүү | `9 / 3 = 3`
`%` | модуль/калдык | `10 % 4 = 2`

**Эскертүү**: Эгер бөлүү операциясындагы эки өзгөрмө тең бүтүн сан болсо, жыйынтык дагы бүтүн сан болот. Мисалы, `10 / 4` 2ди кайтарат, себеби калган бөлүгү эске алынбайт. Эгер өзгөрмөлөрдүн бирөөсү double түрүндө болсо, жыйынтык double болуп чыгат.

**Эскертүү**: Модуль операциясы бөлүүнүн калган бөлүгүн алат.
{{% /notice %}}

{{% notice tip %}}
Кошуу (`+`) оператору String түрүн анын бириктирүү оператору катары колдонулат. Мисалы:

`String name = "Patric" + "k";` бул `String name = "Patrick";` менен бирдей.
{{% /notice %}}

## Салыштыруу: Реляциялык операторлор

Эми сандарды кантип салыштыруу керек экенин үйрөнөбүз. Ал үчүн **реляциялык операторлорду** колдонобуз.

Математикадагыдай эле, биз сандарды `>`, `<`, `>=`, `<=` операторлору менен салыштыра алабыз. Мисалы: `(3 > 2)` бул `true`, бул логикалык маанини билдирет.

{{% notice note %}}
Javaдагы реляциялык операторлор төмөнкүдөй:

**Оператор** | **Сүрөттөлүш** | **Мисал**
------| ------| ------
`==` | барабарбы | `(3 == 3)` бул `true`
`!=` | барабар эмес | `(3 != 3)` бул `false`
`>` | чоң | `(3 > 2)` бул `true`
`<` | кичине | `(3 < 2)` бул `false`
`>=` | чоң же барабар | `(3 >= 2)` бул `true`
`<=` | кичине же барабар | `(2 <= 2)` бул `true`

Эскертүү: `==` жана `!=` операторлору бир эле түрдөгү маалыматтар үчүн гана колдонулат. Мисалы:
```java
int x=3; 
double y=3.0; 
x==y; // Бул ката жаратат, анткени x жана y ар башка түрдө.
```

{{% /notice %}}

{{% notice tip %}}
Бирдей белги (`=`) өзгөрмөгө маани ыйгарат. Эки бирдей белги (`==`) эки элементтин маанилерин салыштырат.

```java
age = 3;  // age өзгөрмөсүнө 3 маанисин ыйгарууну ишке ашырат
age == 3; // age мааниси 3кө барабарбы экенин текшерет
```
{{% /notice %}}
