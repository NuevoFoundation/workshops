## Программа сүйлөсүн!

Келгиле, `System.out.print("Hello World");` деген код сапты жазып, ал `Hello World` деп айткан программа жазып көрөлү.

Программа `System.out.print` скобкасынын ичинде жазылган нерсени чыгарууга жооптуу. Кандай гана код сап болбосун, ал `;` менен аякташы керек.

Андан кийин, жаңы саптарды кошуп, скобканын ичине сандарды (мисалы, `System.out.print(2020)`) же болбосо символдорду жалгыз тырмакчага салып койсоңуз болот `'` (мисалы, `System.out.print('@')`).

{{% notice tip %}}
### Бардык саптарды бир катарга чыгарганын байкадыңызбы?

Кээде жаңы катардан жазууну каалайбыз. Анда, бир аз башкача код жазабыз: `System.out.println();`

(Эсиңизде болсун: жаңы сапты түзүү үчүн `print` ордуна `println` жазабыз.)

Жогорудагыны кайра жасап көрүңүз. Бардык саптарды ар башка катарларга чыгартыңыз!
{{% /notice %}}

{{% notice tip %}}
### Бир сапта бир нече символдорду кантип чыгарса болот?

Символдорду басып чыгаруу үчүн аларды жалгыз тырмакчанын ортосуна койорубузду үйрөндүк, бирок көп символдорду бир сапка кантип чыгарса болот?

Аларды кош тырмакчанын `" "` арасына коюу жетиштүү (мисалы, `System.out.print("@ , - h A #");`).

{{% /notice %}}

{{% notice tip %}}
### !! Маанилүү !! Кээде жөн гана символдорду " " арасына кое албайбыз

`" "` ичинде символдорду жайгаштырганда, кээде компьютерге басып чыгарылчу символдорду түшүнүү кыйын болуп калат.

Мисалы, компьютериңе `" "` басып чыгар деп кантип айтасың?

Эгерде сиз `System.out.print(""");` жазсаңыз, ката аласыз! Анткени компьютер текст кайдан бүтөөрүн түшүнө албай калат!

Анын ордуна, айрым белгилерди басып чыгарууда `\` кошуп <b>качуу керек</b>.

     System.out.print("\"");  // бул чыгарууда "

Java тилинде качыруу керек болгон башка белгилер: `'`, `"`, `\`.
{{% /notice %}}

## Комментарий жазуу

Java программасын түзгөндө, кээ бир белүмдөрдө эстеңиз деп бир нече белгини комментарий катары жаза аласыз. Бир саптуу комментарий үчүн `//`, ал эми бир нече саптуу комментарий үчүн `/*` жана `*/` колдонуңуз. (Эскерте кетели: мурдагы тапшырмалардагы нускамалар комментарий катары жазылган).

Комментарий кошуу программаны эч кандай өзгөртпөйт. Ошентип, комментарий аркылуу каалаган жазууну кошууга болот!

     // бир саптуу комментарийдин мисалы
     /* көп саптуу
      * комментарийдин
      * мисалы */
