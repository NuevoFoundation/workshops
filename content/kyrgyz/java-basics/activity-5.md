## Метод деген эмне?

Азырынча, биз маалыматтарды өзгөрмөлөргө сактоону, маалыматтарды жана сүйлөмдөрдү басып чыгарууну, жана if-оператор, for-цикл жана while-цикл менен чечим кабыл алууну үйрөндүк.

Акыркы практикадан, төмөнкү код блогу 1ден 100гө чейин сумманы эсептей турганын билебиз:

```java
int total = 0;
int num = 1;
while(num <= 100){
    total = total + num;
    num = num + 1;
}
System.out.println("Sum: " + total);
```

Бирок, биз 1ден 77ге чейин сумманы эсептегибиз келсе эмне болот? Кантип ошол эле кодду толугу менен кайра жазбастан жасап алсак болот?

Биз кодду жаза турган бардык учурлар үчүн 2 санды суммалоо иштешин камсыздай турган ✨ сыйкырдуу кутуча ✨ түзгүбүз келет!

Java тилчесинде **метод** – бул кыялдагы сыйкырдуу кутуча сыяктуу иштеп, колдонуучу киргизген маалыматтардын негизинде белгилүү бир тапшырманы аткарган код блогу.

Метод эки бөлүктөн турат: баш жана дене:

{{% notice note %}}
### Методдун Башы

Методду аныктоо үчүн, алгач анын <b>методдун башын</b> жазышыбыз керек. Методдун башы төрт негизги бөлүктөн турат:

**Бөлүктүн аталышы** | **Сүрөттөө** | **Мисалдар же мүмкүнчүлүктөр**
----|----|----
**жеткиликтүүлүк спецификатору** | методго кирүүнү белгилүү деңгээлде берет | `public` методду ар ким колдоно алары жөнүндө айтат. `private` болсо методду класстын ичинде гана колдонсо болорун билдирет. (`protected` жөнүндө кийинки бөлүмдөн билебиз!) `protected` класс объектилерин чакыруу мүмкүндүгүн берет.
**кайтаруу түрү** | метод кайтара турган маалыматтын түрү | эгер метод эч нерсе кайтарбаса, анда `void` колдонуңуз.
**методдун аталышы** | методду чакыруу үчүн колдонулчу ат | методдун аткаруусуна байланыштуу колдонуучу аныктаган.
**параметрлердин тизмеси** | методду колдонгондо камсыздалышы керек болгон киргизме тизмеси | (`түрү` `киргизме аты`, `түрү` `киргизме аты`, ...) форматында.

```
// мисал
public void sing (String songName)
   1.    2.   3.        4.
```
**Эскертүү:** Параметрлердин өзгөрмөлүү аталыштары методго өтүп жаткан маалыматтын өзгөрмөлүү аталышына дал келиши шарт эмес.

<br />

### Методдун Дене бөлүгү

Андан кийин, метод менен байланышкан коддун блогун методдун **денесинде**, башкача айтканда методдун башынан кийин келген `{` жана `}` ортосунда жайгаштырсак болот.

Айрым маалыматтарды кайтарууну кааласак, `return` ачкыч сөзүн жана андан кийин кайтарылчу өзгөрмөнүн аталышын же маанини колдонобуз.  

**Эскертүү:** Жазууда `return` колдонсоңуз, андан соң методдун алдыңкы линиялары иштетилбейт.

Бул төмөндө `numA` дегенден `numB` дегенге чейинки сандарды кошумчалаган методду аныктоонун мисалы:

```java
/* Методдун аты: sumNum
 * Киргизме/Параметр: 2 сан, int түрүндө
 * Иш-функциясы: numAдан баштап numBга чейин сумма кайтарат
 */
public int sumNum(int numA, int numB){
    int total = 0;
    int num = numA;      // биринчи киргизме numA аттуу өзгөрмө менен берилген
    while(num <= numB){  // экинчи киргизме numB аттуу өзгөрмө менен берилген
        total = total + num;
        num = num + 1;
    }
    return total; // кайтаруу оператору
}
```

<br />

### Методду Чакыруу

Акырында, коддун ичинде методду иштетүү үчүн, методду <b>чакыруу</b> керек. Методдун аталышын жана тиешелүү киргизме маалыматтарды жазып кайрылабыз. 
Мисалы:

```java
sumNum(1, 3); // бир сапта sumNum() методун чакырат, 1ден 3кө чейинки сумма кайтарылды, бул 6 болот
```

`sumNum(1, 3)` деген сөздөр, 1ден 3кө чейинки сумманы кайтарат (бул `int` түрүндө), ошол сумманы сактоого мүмкүн:

```java
int sum1to3 = sumNum(1, 3); 
```
