Мурдагы көнүгүүлөрдө биз өзгөрмөлөр бир бөлүк маалыматты сактоо жана ага жетүү үчүн колдонуларын үйрөнгөнбүз. Бирок, эгерде биз окшош маалыматтардын көп бөлүктөрүн сактагыбыз келсе эмне болот? Бир нече өзгөрмөнү жарыялабай эле аларды иреттөөнүн жакшы жолу барбы?

Программалоодо **маалымат структуралары** - бул бирдей түрдөгү көптөгөн маалыматтарды сактоого мүмкүндүк берген элементтерdir. Маалымат структураларын колдонуу - чоң көлөмдөгү маалыматты натыйжалуу сактоонун жана ага жетүүнүн жолу. Бул көнүгүүдө биз Java'да колдонулуучу 2 маалымат структурасы: **массив** жана **ArrayList** менен таанышабыз.

Массивдер - узундугу туруктуу маалымат структурасы, ал эми ArrayList - узундугу өзгөрмөлүү структура жана анын өлчөмүн өзгөртө аласыз. Баштайлы, адегенде массивдерди карап көрөбүз!

## Массив

Айталы, Патриктин 🐥 эң жакшы көргөн 5 киносун сактагыбыз келди. 5 өзгөрмө түзүүнүн ордуна, бул 5 маалымат бөлүгүн массивде, биздин биринчи маалымат структурасында сактоого болот!

Массивде маалыматты сактоо үчүн төмөндөгү кадамдарды аткарабыз:

1. Биринчи кезекте массив жарыялайбыз, анда маалыматтын түрүн жана көлөмүн (канчалык маалымат сакталат) көрсөтөбүз.

```java
String topMovies[] = new String[5]; // 5 көлөмдүү Стринг массив түзүү.
```

2. Массивди кыдырып (бардык маалымат жерлеринен өтүү) жана массивдеги жерлерге маалыматты ыйгарабыз.

Массивдин аты жана индексин (`0` биринчи элементке жетүү үчүн, `1` экинчи элементке ...) колдонуп массивге жетебиз.
```java
topMovies[0] = "Birds Of Prey";
topMovies[1] = "The Birds";
topMovies[2] = "Angry Birds";
topMovies[3] = "Bird Box";
topMovies[4] = "The Secret Life of Pets";
// topMovies массивинде "Birds Of Prey", "The Birds", "Angry Birds", "Bird Box", "The Secret Life of Pets" сакталат.
```
{{% notice info %}}
### Эмне үчүн Java'да массив индекси 0дон башталат?

Массивдин биринчи элементинин индексине жетүү үчүн 1-ден баштоо соблазндуу жана түшүнүктүү болушу мүмкүн.

Бирок, компьютер `arr[1]` кодун окуганда, ал массив `arr`дан биринчи элементти алуу керек деп түшүнбөйт. 

Чындыгында, ал `arr[1]`ди массивдин башынан 1 аралыктагы элементти алуу катары чечмелейт.

Башкача айтканда, индекс чындыгында эс тутумдун офсетин билдирет. Биринчи элементке жетиш үчүн, массивдин башынан `0` офсет индекстеги элементке жетишибиз керек (б.а., `arr[0]`).
{{% /notice %}}

{{% notice tip %}}
### Массив түзүүнүн башка жолу:
Эгерде бардык маалыматты алдын ала билсек, массивди бир гана сапта түзсөк болот, жана аларды `{` жана `}` ортосунда көрсөтсөк.

Мисалы:

```java
String topMovies[] = {"Birds Of Prey", "The Birds", "Angry Birds", "Bird Box", "The Secret Life of Pets"};
```

Элементти индекс менен инициализациялагандай эле, биз ар бир маалыматка анын индекси менен жетүү же өзгөртүү мүмкүнчүлүгүнө ээбиз.

Мисалы:

```java
String movie1 = topMovies[0]; // movie1 мааниси "Birds Of Prey"
```

{{% /notice %}}

Массив түзүлгөндөн кийин анда канча элемент бар экенин билүү пайдалуу (мисалы, массивдеги акыркы элементке жетүү үчүн). Массивадагы элементтердин санын `array_name.length` аркылуу ала алабыз.

Мисалы:

```java
int numOfMovie = topMovies.length; // numOfMovie мааниси 5
```

## ArrayList

ArrayList Java'да кеңири таралган дагы бир маалымат структурасы. `ArrayList` - массивдерди колдонуу аркылуу ишке ашырылган класс. Бул массивге окшош, анткени колдонуучулар маалыматка жетүү, сактоо жана өзгөртүү үчүн индекс колдонушат.

ArrayList түзүү үчүн атын жана `<` жана `>` ортосунда маалыматтын түрүн көрсөтөсүз.
Мисалы:

```java
ArrayList<String> topMoviesList = new ArrayList<String>();
```

Элементтерди кошуу үчүн, биз `add()` деген методду ArrayListке чакырабыз.
Мисалы:

```java
topMoviesList.add("Birds Of Prey");
topMoviesList.add("The Birds");
topMoviesList.add("Angry Birds");
topMoviesList.add("Bird Box");
topMoviesList.add("The Secret Life of Pets");
// ArrayList'те эми "Birds Of Prey", "The Birds", "Angry Birds", "Bird Box", "The Secret Life of Pets" сакталат.
```
