<b>Java: Негиздери</b> курсуна кош келиңиз, бул курста сиз компьютер программаларын түзүү үчүн кеңири колдонулган жогорку деңгээлдеги программалоо тилин үйрөнөсүз!

Java — бул 1995-жылы Жеймс Гослинг жана Sun Microsystems тарабынан Калифорнияда иштелип чыккан жогорку деңгээлдеги программалоо тили.

{{% notice info %}}
Жогорку деңгээлдеги программалоо тили "жогорку деңгээл" деп аталат, анткени ал компьютердин Борбордук Процессорунун (CPU) иштеткен баштапкы кодунан бир топ алыс турат. Жогорку деңгээлдеги код адамдар үчүн иштелип чыккан жана аны төмөнкү деңгээл кодуна караганда түшүнүү оңойураак. Жогорку деңгээлдеги коддун иштөүшү үчүн, ал коддун ар бир саптары кийинчерээк машиналык тилге которулушу керек жана компьютер аны ишке ашыра алат.
{{% /notice %}}

Бүгүнкү күндө Java дүйнө жүзүндөгү иштеп чыгуучулар тарабынан кеңири колдонулуп келет. Тактап айтканда, Java Android мобилдик колдонмолору, десктоп колдонмолору, веб колдонмолору, ойындарды иштеп чыгуу сыяктуу тармактарда колдонулат.
