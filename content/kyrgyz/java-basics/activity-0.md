## Replit колдонуу

Бүгүн сиз Replit платформасын колдонуп, Java тилинде программалоону үйрөнөсүз. Баштаардан мурун Replit аккаунтун түзүү керек болот, эгерде сизде аккаунт жок болсо. 

Төмөнкү баскычты басып, Replit үчүн аккаунт түзүңүз – бул үчүн сизге электрондук почта аккаунту керек. Эгерде сизде мурунтан эле Replit аккаунту бар болсо, төмөнкү баскыч менен аккаунтуңузга кириңиз.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Replit үчүн катталыңыз</a>

<img src="../images/replit-signup.png" height="300" alt="Replit катталуу формасы" />

Андан кийин, бүгүнкү иш колдонуу үчүн Replit консолун баштоо үчүн төмөнкү баскычты басыңыз. Төмөндөгүдөй экранды көрүшүңүз керек.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaBasicsTest" target="_blank">Replit'ти ачуу</a>

<img src="../images/replit-start-screen.png" height="300" alt="Repl'дин баштапкы экраны" />

Эми биз Repl'ди fork кылабыз, бул, жөнөкөй айтканда, программанын көчүрмөсүн түзүп алуу дегенди билдирет, ошондо биз аны өз муктаждыктарыбызга жараша өзгөртө алабыз. Жогорку оң жактагы "Fork Repl" баскычын, андан кийин "Fork Repl" баскычын басыңыз.

<img src="../images/replit-fork.png" height="300" alt="Программанын көчүрмөсүн түзүү үчүн repl'ди fork кылуу" />

Replit'ти fork кылгандан кийин, төмөндөгүдөй терезени көрөсүз:

<img src="../images/replit-window.png" height="300" alt="Replit терезеси" />

{{% notice warning %}}
Ар бир жолу "Replit'ти ачуу" деген баскычты көргөндө, тапшырманы аткаруу үчүн жогорудагы кадамдарды аткарып, repl'ди fork кылуу керек болот. Эгерде repl'ди fork кылууда көйгөйлөр болуп жатса, жардам сураңыз!
{{%/notice %}}

Баштаардан мурун, терезе кандай иштей тургандыгын түшүнүп алалы. `Main.java` файлы компьютер үчүн аткарыла турган кодду же көрсөтмөлөрдү камтыйт. **run** баскычын басуу (рамканын үстү жагындагы ортодо жайгашкан жашыл үч бурчтук баскычы) – бул коддогу көрсөтмөлөрдү аткаруу үчүн компьютерге буйрук берүү. Кодду аткаруунун бардык жыйынтыктары төмөнкү экранда, **Console** табында көрсөтүлөт. 

"Объекттер жана класстар" көнүгүүсүндө сиз `Main.java` файлы менен `Birds.java` файлынын ортосунда которулуп иштешиңиз керек болот. Муну оң жактагы документке окшош иконканы басуу аркылуу ишке ашыра аласыз. Бул Files менюсун ачып, башка файлдарды ачууга мүмкүндүк берет.

**Run** баскычын басып көрүңүз. Эгерде **Let's learn Java!** деген жазууну көргөн болсоңуз, анда сиз даярсыз. Баштадык!
