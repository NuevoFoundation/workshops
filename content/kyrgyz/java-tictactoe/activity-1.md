## Башкы Класс жана Негизги Метод

Баштапкы коддо `Main` деген класс жана `main()` деген метод бар экенине көңүл буруңуз. Программаны баштаганда, төрөткүчкө `Run` баскычы басылганда, бул метод чакырылат.

```java
public class Main {
  public static void main(String[] args) {
  }
}
```

## Print билдирүүлөрү

 `main()` ичинде, оюндун саламдашуу билдирүүсүн жана эрежелерин басып чыгаруу үчүн print билдирүү(лөрү)н жазыңыз!

```
<<<~  Tic  Tac  Toe  ~>>>
* 1ден 9га чейинки сандарды тандап, кадамыңызды коюңуз
* Оюнчу: 'X' Компьютер: 'O'
```

## Өзгөрмөлөр жана Массивдер

Бул оюнда, тактадагы 9 позицияда учурдагы белгилерди көзөмөлдөө керек болот.

   Ошондуктан программада 9 маалымат элементи сакталууга тийиш. Бул үчүн, көлөмү 9 болгон `array` (маалымат түзүмү) колдонулсун.

   Эрежелерге ылайык, оюн тактасында `"X"` оюнчунун кадамы, `"O"` компьютердин кадамы жана `" "` бош орун болуп саналат.

   Бул үчүн, `board` деген массивдик `өзгөрмөнү` жарыялайбыз жана анын бардык 9 позициясы `" "` сап мааниси менен толтурулат (мисалы, `{" ", " ", " ", " ", " ", " ", " ", " ", " "}`).

## Тактаны көрсөтүү

Азыр, биз `board` деген өзгөрмөдө оюн тактасынын учурдагы белгилерин сактайбыз, келгиле, print билдирүүлөрдү колдонуп, бош оюн тактасын басып чыгаралы (төмөндө көрсөтүлгөн).

Ар бир оюн тактасы 5 саптан турат, ошондуктан ар бир көз караш үчүн 5 print билдирүүсүн колдонуу н合理 deutlich.

Тактадын 9 блоктун ар бири 3 узундуктагы `String`, жана орто символу `board` массивинде тиешелүү позицияга сакталган.

Бул кадамды бүткөндөн кийин программа төмөнкүдөй чыгууну бериши керек.

```
<<<~  Tic  Tac  Toe  ~>>>
* 1ден 9га чейинки сандарды тандап, кадамыңызды коюңуз
* Оюнчу: 'X' Компьютер: 'O'

   |   |  
---+---+---
   |   |  
---+---+---
   |   | 
```

## Метолдор

Оюн убагында тактанын учурдагы абалын бир нече жолу басып чыгарышыбыз керек экенин түшүнгөндүктөн, 4-кадамда жазылган кодду метолдун ичине жылдыруу жакшы идея болот.

Бул метод `String[]` киргизүүсүн алып, учурдагы тактаны басып чыгарат. Бул метод `main()` методунун сыртына жазылышы керек.

Төмөнкүдөй баш сөзү бар методу жазыңыз:

```java
public static void printBoard(String[] curBoard);
```

## Методду Чакыруу

`main()` ичинде, `printBoard()` методун чакырыңыз, ошондо тактаны орундардын номерлерин жазып, баштапкы абалда көрсөтө алат. Муну `"1", "2", ..., "9"` мазмунундагы дагы бир `String массивин` түзүү менен жасасаңыз болот.

Кийинки сапта `Кадамыңызды киргизиңиз (1-9): ` деп басып чыгаруу үчүн код жазыңыз.

```
<<<~  Tic  Tac  Toe  ~>>>
* 1ден 9га чейинки сандарды тандап, кадамыңызды коюңуз
* Оюнчу: 'X' Компьютер: 'O'

 1 | 2 | 3 
---+---+---
 4 | 5 | 6 
---+---+---
 7 | 8 | 9 
Кадамыңызды киргизиңиз (1-9): 
```
