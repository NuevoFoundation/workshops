## Пакеттерди Импорттоо

Java тилинде колдонуучунун киргизүүсүн алуунун натыйжалуу ыкмасы – бул `java.util` пакетиндеги `Scanner` классын колдонуу. Бул классты жана анын бардык ыкмаларын колдонуу үчүн, коддун жогору жагына төмөнкү сапты кошуп, классты `import` кылышыбыз керек.

```java
import java.util.Scanner;
```

## Scanner Классын Колдонуу

`main()` ичинде, биз биринчи кезекте анын конструкторун чакырып, `sc` аттуу `Scanner` объект түзүшүбүз керек (төмөндө көрсөтүлгөн).

Киргизүүнү стандарттык киргизүү агымынан окуу үчүн, биз `System.in` (стандарттык киргизүү агымынын объектиси) берүүбүз керек.

```java
// Scanner объектисин түзүү
Scanner sc = new Scanner(System.in);
```

## Колдонуучунун Киргизүүсүн Алуу

Мурдагы аракетте, биз колдонуучуну 1 - 9 сандардын бирин киргизүүсүн сураганбыз. Ошондуктан, киргизүү агымынан `int` күтүлөт.

`Scanner` объектинде сакталган `int` маанини алуу үчүн, биз `sc` объектисинде `nextInt()` ыкмасын чакырабыз.

```java
int input = sc.nextInt();
```

## Программаңызды Тесттен Өткөрүңүз (каалоо боюнча)

Программаңызды текшерүү үчүн, `nextInt()` менен сакталган маанини чыгаруу үчүн алгач басып чыгаруу операторун кошуңуз.

Программаңызды иштетип көрүңүз, кээ бир сандарды терип, `Enter` баскычын басыңыз. Сиз терилген сандын туура басылганын көрүшүңүз керек. Мисалы:

```
<<<~  Tic  Tac  Toe  ~>>>
* 1 - 9 арасындагы санды тандап жүрүшүңүздү коюңуз
* Оюнчу: 'X' Компу: 'О'

 1 | 2 | 3 
---+---+---
 4 | 5 | 6 
---+---+---
 7 | 8 | 9 
Жүрүшүңүздү тандаңыз (1-9): 2                 <------- сиз терген саны
Киргизилген Сан: 2                          <------- Киргизилген сан туурача басылган
```

{{% notice warning %}}
#### Колдонуучу сан эмес нерсени тергенде эмне болот?

Программаларды жазууда, биз колдонуучуларды ар дайым туура маанилерди киргизет деп күтүүгө болбойт, ал тургай бул көрүнүш буйрутмада айтылып турса да.

Биздин программа `int` киргизүүсүн гана күтүп жаткандыктан, эгерде сиз бүтүн сан эмес маанини, мисалы: `hi`, `$`, `20.1` терсеңиз, программа токтоп калат. Ошондой эле төмөнкүдөй ката билдирүүсүн көрө аласыз:

```
Exception in thread "main" java.util.InputMismatchException      <------ бул кайсы ката экенин көрсөтөт
    at java.base/java.util.Scanner.throwFor(Scanner.java:939)
    at java.base/java.util.Scanner.next(Scanner.java:1594)
    at java.base/java.util.Scanner.nextInt(Scanner.java:2258)
    at java.base/java.util.Scanner.nextInt(Scanner.java:2212)
    at Main.main(Main.java:15)                                   <------ ката кайсы сапта болгонун көрсөтөт (Main.java файлынын 15-сапында)
```

Ошондой эле, 1 - 9 диапазонунан чыкпаган сан киргизүүлөр программага ката алып келбейт, бирок булар дагы биз каалаган мазмун эмес.

## Сканнер менен Жараксыз Киргизүүлөрдү Иштетүү

`Scanner` класы жарактуу же жараксыз киргизүүлөрдү текшерген ыкмаларды камсыздайт. Мисалы, `hasNextInt` ыкмасы колдонуучунун киргизүүсү бүтүн сан экендигин текшерип, `true` же `false` маанисин кайтарат. Бул ыкма менен колдонуучунун киргизүүсүнүн тууралыгын текшерсе болот.

Башкаруу түзүмдөрүн колдонуп колдонуучунун киргизүүсүн текшериңиз. Эгерде киргизүү туура эмес болсо, бардык талаптарга жооп берген жаңы киргизүүнү кайра сураңыз.

```java
if(sc.hasNextInt()) { // бүтүн сан киргизилдиби
	move = sc.nextInt(); // бүтүн санды алыңыз
   if (!(move > 0 && move <= 9)) { // сан 1ден 9га чейинки диапазондо болдубу текшерүү
		System.out.print("Жараксыз позиция; кайра аракет кылыңыз (1-9): ");
   }
} else { // бүтүн сан эмес киргизилсе
   sc.next(); // Scanner-ди тазалоо
	System.out.print("Жараксыз киргизүү; кайра аракет кылыңыз (1-9): ");
}
```

## Программаңызды Тесттеңиз (каалоо боюнча)

Программаңызды текшерип көрүңүз. Эгерде сиз туура эмес сандарды киргизсеңиз, мисалы, диапазондон тышкары сандар же текст, сиз:

`Жараксыз позиция; кайра аракет кылыңыз (1-9):` сыяктуу билдирүүнү көрүшүңүз керек.

## Бир нече Киргизүүлөрдү алуу

Эми программабыз бир гана киргизүүнү кабыл алып, аны баалайт. Оюн аяктаганга чейин оюнчуну кайра-кайра киргизүүнү сурангыдай өзгөртүү киргизели.

Колдонуучудан кийинки жүрүштөрүн сурай берүү үчүн, бүтүндөй `hasNextInt` шарттары бар if операторун `while` циклине жайгаштырабыз. Бул цикл аргумент катары `true` маанисин алат, муну менен программага токтобой айланууну көрсөтөт, токтоочу команда берилмейинче.
