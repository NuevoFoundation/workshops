## Колдонуучунун Жүрүшүн Көрсөтүү

`hasNextInt()` текшериүүсүнүн ичинде, `printBoard(board)` ыкмасы чакырылганга чейин, колдонуучунун берген маалыматтарын колдонуп, тиешелүү индекстеги `board` массивин жаңыртыңыз.

Карап көрүңүз, оюнчунун белги катары `"X"` көрсөтүлөрүн тактаны жаңыртууда эске алыңыз.

{{% notice tip %}}
### Эскертүүлөр

- Java 0-индекстөө форматын колдонот, ал эми оюнчу 1ден 9га чейинки сандарды киргизип жатат.
- Массивдин элементин жетүү үчүн индекстөө ыкмасын колдонушуңуз керек: `myVariable[indexNumber]`.
{{% /notice %}}

## Компьютердин Жүрүштөрүн Орнотуу

Учурдагы оюн тактасын параметр катары кабыл алган жана компьютер үчүн 1ден 9га чейинки жарактуу жүрүштү чыгаруучу жаңы `getComputerMove(String[] curBoard)` ыкмасын түзүңүз.

Бул ыкманы ишке ашыруу үчүн кийинки кадамдарды аткарыңыз.

## Компьютердин Жүрүшүн Ишке Ашыртуу

`getComputerMove()` ичинде биз компьютер үчүн 1ден 9га чейин кокустук сан түзөбүз.

Бул үчүн Java'нын `Random` классын колдонобуз, ал кокустан сандарды жаратууда кеңири колдонулат.

Бул классты жана анын бардык ыкмаларын колдонуу үчүн, файлдын жогору жагына төмөнкү коду кошуңуз.

```java
import java.util.Random;
```

`Random()` конструкциясын чакырып, `Random` объектин түзүңүз.

```java
Random rand = new Random();
```

## Кокусунан Сандар Жаратуу

Кокус сандарды жаратуу үчүн түзүлгөн `Random` объектиси аркылуу `int nextInt(int num)` ыкмасын чакырыңыз. Бул компьютер үчүн 1ден 9га чейинки санды чыгарат.

```java
int position = rand.nextInt(9);
```

## Жарактуу Жүрүштү Текшерүү

1ден 9га чейин кокусунан сан алган соң, ошол орун бош экендигин текшерүү керек.

Эгер мурда генерацияланган сан туура келбей калса, жарактуу жүрүш жаратуу үчүн, `while` циклин колдонубуз.

Жарактуу жүрүш табылган учурда, ошол санды кайтарыңыз.

```java
while (!curBoard[position].equals(" ")){
   position = rand.nextInt(9);
}
return position;
```

## Такта Массивин Жаңыртуу

Алгачкы кадамдай эле, `printBoard(board)` ыкмасы чакырылганга чейин компьютер үчүн `board` массивин жаңыртыңыз.

Компьютер үчүн жүрүштү `getComputerMove()` ыкмасын чакырып, кокустан жаратыңыз!

Тактада компьютер `"O"` белгиси менен көрсөтүлөт.

```java
board[getComputerMove(board)] = "O"; // getComputerMove ыкмасы 0-8 арасындагы санды кайтарат, ал массивдеги туура позицияга туура келет
printBoard(board);
```
