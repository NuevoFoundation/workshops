## Replit Менен Колдонуу

Бүгүн сиз Replit колдонуп, Java программалоосун үйрөнөсүз. Баштоодон мурун, эгерде сизде Replit аккаунту жок болсо, анда бир аккаунтка катталып алышыңыз керек. 

Төмөнкү баскычты басып, Replit аккаунтуна катталыңыз - катталуу үчүн сизге электрондук почта дареги керек болот. Эгерде буга чейин Replit аккаунтуңуз бар болсо, төмөнкү баскычты колдонуп аккаунтуңузга кире аласыз. 

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Replit'ке Катталыңыз</a>

<img src="../images/replit-signup.png" height="300" alt="Replit катталуу формасы" />

Андан соң, бүгүн колдонулуучу Replit консолун төмөнкү баскычты басып иштетип алыңыз. Сиз төмөндөгүдөй экранды көрөсүз.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaTicTacToeStarterCode" target="_blank">Replit'ти Ишке Киргизүү</a>

<img src="../images/replit-start-screen.png" height="300" alt="Replit баштоо экраны" />

Эми Repl'ди көчүрүп алабыз, муну менен программадан өз көчүрмөбүздү түзө алабыз жана ага өзгөртүүлөрдү киргизе алабыз. Оң жагындагы "Fork Repl" баскычын басыңыз, андан кийин "Fork Repl" баскычын басыңыз.

<img src="../images/replit-fork.png" height="300" alt="Repl программасын көчүрүп алуу" />

Replit'ти көчүргөндөн кийин, төмөнкүдөй терезени көрөсүз:

<img src="../images/replit-window.png" height="300" alt="Replit терезеси" />

{{% notice warning %}}
Кандай гана учурда "Replit'ти Ишке Киргизүү" баскычын көрсөңүз, жогорудагы кадамдарды аткарып, бардык аракеттерди аткаруу үчүн repl'ди көчүрүп алыңыз. Эгерде repl'дерди көчүрүүдө кыйынчылык жаралып жатса, жардам сураңыз!
{{%/notice %}}

{{% notice info %}}

Баштаардын алдында, биз алгач терезе кантип иштээрин түшүнөлү. `Main.java` файлы компьютер үчүн аткарылып жаткан көрсөтмөлөр же коддор бар файл. **Run** баскычынын жардамы менен, сиз компьютерге бул көрсөтмөлөрдү аткарууну буйрук бере аласыз. Кодду аткаруу натыйжалары төмөнкү экранда, **Console** өтмөгүндө пайда болот.

{{% /notice %}}

`Run` баскычынын жанындагы `open in Replit` деген белгини басыңыз. Бул - сиз TicTacToe программасы үчүн коддорду тере турган терезе болот. Сонун убакыт өткөрүңүз!
