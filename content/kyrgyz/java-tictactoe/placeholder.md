## Киргизүү жана иштетүү

Javaда колдонуучунун киргизүүсүн алуу үчүн эң натыйжалуу ыкма - бул `Scanner` классын колдонуу. Бул класс жана анын бардык ыкмаларын колдонуу үчүн файлдын үстү жагына төмөнкү код сызыгы менен классты `import` кылышыбыз керек.

```java
import java.util.Scanner;
```

## Ката менен иштөө

Javaда потенциалдуу каталарды `try-catch` блоктору аркылуу башкарууга болот.

`try` блокто ката жаратышы мүмкүн болгон код коюлат.

`catch` блокто, эгерде `try` блокту аткаруу учурунда ката пайда болсо, ал ката менен эмне кылуу керектигин аныктаган көрсөтмөлөр жазылат. Бул ыкма программаңызды кырсыктан сактап калууга жардам берет. Мисалы:

```java
try{
   //  Кооптуу код блогу
} catch(Exception e){
   //  Катаны иштетүү блогу
}
```

   Программаңызды иштетип, номер эмес киргизүүлөрдү терип көрүңүз. Эми программаңыз иштен чыкпашы керек!

## Try блок

`try` блокто биз колдонуучудан номер киргизүүсүн алабыз. Бирок, бардык киргизүүлөр жарактуу болбойт, анткени биз тактайчадагы жеткиликтүү орундарды гана кабыл алышыбыз керек.

If турардыгышелт менен киргизилген номердин жарактуу экендигин текшерүү керек. (Кеңеш: киргизүүнүн жарактуулугун текшерүү үчүн `board` массивине кирүү).

Эгер жарактуу эмес болсо, анда «Invalid Position; re-enter your move (1-9):» билдирүүсүн басып чыгарыңыз.

{{% notice hint %}}
#### Эки тексттик сап бирдей экенин кантип текшерем?

Эки тексттик саптын мазмуну бирдей экенин текшерүү үчүн, `equals()` ыкмасын чакырабыз. Мисалы:

```java
String s1 = "hi";
boolean b1 = s1.equals("hi"); // бул true
boolean b2 = s1.equals("HI"); // бул false
```

{{% /notice %}}

## Catch блок

`catch` блокто, колдонуучу номер эмес киргизүү жазганда, биз бул жараксыз киргизүүнү `Scanner`дан жокко чыгарышыбыз керек. Бул үчүн, биз түзгөн `Scanner` объектте `next()` ыкмасын чакырабыз. Андан соң, оюнчуга кайрадан туура билдирүүсүн киргизүүнү талап кылуу үчүн «Invalid Position; re-enter your move (1-9):» билдирүүсүн басып чыгарыш керек.

## (каало боюнча) Программаны тест кылуу

Программаңызды «Run» басуусу менен тест кылыңыз, эгерде сиз номер эмес же 1ден 9га чейинки туура эмес номер киргизген болсоңуз, анда «Invalid Position; re-enter your move (1-9):» билдирүүсүн көрүшүңүз керек.

## Бир нече киргизүү

Азыр биз бир киргизүүнү кабыл алган жана анын жарактуу болушун текшерген программага ээбиз. Оюн аяктаганга чейин оюнчудан кайра киргизүү талап кылууну кааласак.

Колдонуучуну кийинки кадамды киргизүүгө чакыруу үчүн, биз бүт `try-catch` блокту `while loop` ичинде коёбуз. Бул `while loop` аргументинде `true` деп жазылып турат, программанын токтотулмайынча цикл айланып жүрүшү үчүн.

Ар бир кайталануунун аягында `printBoard(board)` жана колдонуучу киргизүүнү сунуштап, аларды баса белгилей турганыңызды эске алыңыз, төмөндө көрсөтүлгөн:

```java
while(true){
    // бул жерге try-catch блокту коюңуз

    printBoard(board);
    System.out.print("Enter your move (1-9): "); 
}
```

## Жараксыз киргизүүлөрдү иштетүү

Колдонуучу жараксыз киргизүү жазганда, программа `printBoard(board)` чакырбашы жана «Enter your move (1-9):» билдирүүсүн басып чыгарбашы керек.

Башкача айтканда, программа `while loop`тогу кийинки итерацияга өтүүнү каалайт.

Кодго `continue;` жазып, программага циклдин баш жагына кайтып, кайрадан аткарууга көрсөтмө бере алабыз.

Бул тапшырманы аяктагандан кийин, сиз кийинки жараксыз киргизүү үчүн кайра текшерүү талап кылган программага ээ болосуз, ал жарактуу киргизүү үчүн «Enter your move (1-9):» менен куру тактайды гана көрсөтөт.
