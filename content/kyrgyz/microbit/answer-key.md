## JavaScript негиздери боюнча колдонмо

### Өзгөрмөлөр жана маалымат түрлөрү

Семинарда беш маалымат түрү киргизилет. Мына алардын кыскача баяны жана мисалдар:

| Маалымат түрү | Сипаттама | Мисал |
|---------------|-----------|-------|
| Бүтүн сан | Бүтүн сандар (ондук болбойт) | `var a = 5;` |
| Ондук сан | Ондукту камтыган сандар | `var x = 0.5;` |
| Тексттик жипчелер | Текст (кош тырмакчада) | `var company = "My company";` |
| Символ | Бир гана белгини камтыйт (жалгыз тырмакчада) | `var letter = 'A';` |
| Булиан | Чын же калп мааниси | `var codingIsCool = true;` |

**Өзгөрмө аттары боюнча негизги эрежелер:**
- Тамгаларды, цифраларды, астынкы сызыктарды, доллар белгилерин камтыса болот
- Боштуктарды камтый албайт
- Тамгадан башталышы керек

### Математикалык операциялар

| Операция | Оператор | Мисал | Натыйжа |
|----------|----------|-------|---------|
| Кошуу | `+` | `var c = 13 + 10;` | `c = 23` |
| Алуучулук | `-` | `var c = 15 - 10;` | `c = 5` |
| Көбөйтүү | `*` | `var c = 2 * 5;` | `c = 10` |
| Бөлүү | `/` | `var c = 20 / 2;` | `c = 10` |
| Калдык | `%` | `var d = 10 % 2;` | `d = 0` |

**Эскертүү:** Семинарда `c = a + b; // c = 25` деп көрсөтүлгөн, бирок 13 + 10 = 23. Бул баштапкы семинардагы типографикалык каталык.

**Кыскартылган операторлор:**
- `c += a;` `a`ны `c`ге кошот
- `c -= a;` `a`ны `c`ден алып салат
- `c *= a;` `c`ни `a`га көбөйтөт
- `c /= a;` `c`ни `a`га бөлөт
- `c++` бирди кошот, `c--` бирди кемитет

**Эскертүү:** Семинарда бөлүү мисалында көрсөтүлгөн комментарийде `c /= a; // c = 5`, ал эми чыныгы натыйжа `0.5` (10ду 20га бөлүү). Мугалимдер бул туура келбестикти билиши керек.

### Басма операторлору

```javascript
// Текшерүү консолунда көрсөтөт (веб-баракта көрүнбөйт)
console.log("Hello!");

// Калкыма терезе түрүндө көрсөтөт
alert("Hello!");

// Жооп кутучасы менен калкыма терезе - колдонуучунун жообун сактайт
var userResponse = prompt("What is your name?");
```

### Шарттуу операторлор

```javascript
var age = 10;
if (age < 18) {
  print("Сиз азырынча чоң кишиге айлана элексиз! :( ");
}
```

**Эскертүү:** Семинарда бул мисал үчүн `print()` колдонулат, ал браузерде стандарттуу JavaScript эмес. MakeCode ичинде, анын эквиваленти `basic.showString()` болуп саналат. Браузерде `console.log()` же `alert()` программасын колдонуу керек. Ошондой эле, семинар булагында комментарий катасы бар: ал "Көрсө, жаш 10дон кичине болсо" деп айтылат, бирок шарт `age < 18`ди текшерет.

### Циклдер

```javascript
// while цикли - 10дон артка санайт
var count = 10;
while (count > 0) {
  alert(count);
  count--;
}

// for цикли - 10дон артка санайт
for (var i = 10; i > 0; i--) {
  alert(i);
}
```

**Маанилүү:** Аяксыз `while (true)` цикли браузерди тоңдурат. Micro:bitте `basic.forever()` үзгүлтүксүз аткаруу үчүн коопсуз эквивалент болуп саналат.

**Кошумча:** `break;` оператору циклди дароо токтотуп, экинчи сапка өтүүгө мүмкүндүк берет.

## Micro:bit орнотулушу

### Аппараттык каражаттардын жалпы көрүнүшү

Micro:Bit төмөнкүлөргө ээ:
- Жеке программаланган 25 диод (5×5 тор)
- 2 программаланган баскыч (A жана B)
- Физикалык байланыш пиндери
- Кыймыл сенсорлору (акселерометр жана компас)
- Зымсыз байланыш (Bluetooth жана радио)
- USB интерфейс

### Компьютерге туташтыруу

1. USB кабел аркылуу Micro:Bitти туташтырыңыз
2. Ал `MICROBIT` аталышындагы диск катары Файл Издөө куралына көрүнөт
3. Программаларды жүктөө үчүн: `.hex` файлдарды MICROBIT дискине көчүрүңүз (же укуктуу баскычы → MICROBITке жөнөтүү)
4. Арткы жагындагы сары диод код жүктөлүп жатканда жанып турат
