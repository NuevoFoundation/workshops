## 1. Python орнотуу
**Python 3.10** (3.10.x версиясы, мисалы, 3.10.14) расмий веб-сайттан орнотуңуз.
- Windows жана macOS: https://www.python.org/downloads/
- (Кээ бир Chromebookтордо Linux режимин колдонуу керек болушу мүмкүн; чоң кишиден же мугалимден сураңыз.)

Эмне үчүн 3.10? Discord жана котормо үчүн колдонулуучу айрым китепканалар азыркы учурда эң жакшы же толугу менен Python 3.10 менен иштейт. Жаңы версиясын (мисалы, 3.11 же 3.12) колдонуу орнотуу катачылыктарын жаратышы мүмкүн.

Сизге `Python 3.10.x` сыяктуу бир нерсе көрүнүшү керек.

## 2. VS Code орнотуу (жана Python куралдарын)

VS Code бул акысыз, студенттерге ыңгайлуу код редактору болуп саналат; ал акылдуу толуктоолорду, ката билдирүүлөрдү жана Python'ды башкаруу үчүн жеңил жолду сунуштайт.

{{<button href="https://code.visualstudio.com" theme="info">}}VS Code жүктөп алыңыз{{< /button >}}

VS Code орнотулгандан кийин, Python куралдарын кошуңуз:
1. VS Code'ду ачып, Extensions көрүнүшүнө өтүңүз. (Жанындагы Activity Barдан кеңейтүүлөр иконкесин чыкылдатыңыз же `Ctrl+Shift+X` басыңыз).
![Extensions жөндөмү иконкасы](../../media/extensions.png)
1. `Python` (Басмачы: Microsoft) терип издеп, Install баскычын басыңыз. Бул семинар учурунда колдонулуучу пайдалуу куралдарды орнотот. ![Python VSCode кеңейтүү баракчасы](../../media/python-extension.png)
1. Эгер сунушталса, `Python Environment Manager` тажрыйбасын орнотуңуз – ал ар бир Python кеңейтүүсүнүн акыркы версияларына кошулган.
1. Эгерде сизден VS Code'ду кайра жүктөө суралса, аны аткарыңыз.

Эми сиз капчыктуу багыттан Python кеңейтүү символун көрүшүңүз керек.
![Python кеңейтүү символу](../../media/python-symbol.png)

## 4. Виртуалдык чөйрөнү түзүү
Виртуалдык чөйрө долбооруңузду башка долбоорлордон бөлүп кармайт жана компьютериңиздеги бардык Python файлдарын уюштурууну жеңилдетет. VS Code'уңуздун Python кеңейтүүсү аны түзүп жана тандоого жардам берет.

<img src="../../media/NF_mascot.jpg" alt="Nuvi комузу" width="70px" style="float:right;margin:0 0 6px 10px;" />

1. Чөйрөнү түзүү үчүн капчыктуу багыттан Python символун издеп табыңыз жана аны чыкылдатыңыз: ![Python VSCode кеңейтүү иконкасы](../../media/sidebar.png)
1. "venv" тизмесинен төмөндө "Чөйрө табылган жок, түзүү үчүн чыкылдатыңыз" деген билдирүү болушу керек. Аны чыкылдатыңыз.
1. Ошондо "Чөйрөнү түзүү режими" деген үстүнкү тизмени көрөсүз. "Тез түзүү" режимин тандаңыз.
![Чөйрө түзүү тизмеси](../../media/create-env.png)
1. Азыр чөйрөнү түзүп жаткандыгын көрсөтүүчү кичинекей жүктөө тизмеси көрүнүшү керек. Бул бир нече минутка созулушу мүмкүн.
![Виртуалдык чөйрөнү түзүү](../../media/loading-env.png)
1. Бүткөн соң, дагы бир жолу айтылган Python символун капчыктуу багыттан тандасаңыз, сиз "venv" тизмесинен "виртуалдык чөйрө түзүлгөн жана тандалганын" көрөсүз.
![Түзүлгөн жана тандалган виртуалдык чөйрө](../../media/venv-created.png)

## 5. Баштапкы файлдарды түзүү
Долбоор папкасынын ичинде төмөнкү файлдарды түзүңүз:
```
bot.py
requirements.txt
```

### bot.py
Бул жерде бардык бот коду болот. Азырынча бул баштапкы кодду кошуңуз:
```python
print("Bot долбоору даяр. Келгенде Discord кодун кошобуз!")
```

### requirements.txt 
Бул учурда боштугунча калат. Кийинчерээк, ботто керек болгон Python китепканалардын аттарын бул файлга кошуп, аларды оңой орнотууга болот.
