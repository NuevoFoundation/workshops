Бул функция текстти бир тилден алып, аны башка тилге өзгөртүү менен которууну ишке ашырат!

## `translate_text()` Функциясы

Мына ушул код магияны ишке ашырат:

```python
def translate_text(text, from_language, to_language):
    """Текстти бир тилден башка тилге LibreTranslate колдонуусу менен которуу."""
    try:
        data = {
            "q": text,
            "source": from_language,
            "target": to_language,
            "format": "text"
        }
        response = requests.post("http://127.0.0.1:5000/translate", json=data, timeout=10)
        result = response.json()
        return result.get("translatedText")
    except:
        return None
```

## Ар бир бөлүгү эмнени билдирет

| Бөлүк | Эмне кылат | Мисал |
|-------|------------|-------|
| `text` | Которула турган текст | `"Hello world"` |
| `from_language` | Азыркы тил коддору | `"en"` (Англисче) |
| `to_language` | Келечектеги тил коддору | `"es"` (Испанча) |

## Кантип иштейт

1. **Маалыматты даярдоо**: Текстти жана тилинин коддорун пакетке салуу
2. **LibreTranslateке жөнөтүү**: Текстти которуусун сураңыз
3. **Которулган текстти алуу**: LibreTranslate которулган текстти жөнөтөт
4. **Эгерде ката кетсе**: `None` кайтаруу (текстти которуу болбоду дегенди билдирет)

## Колдонуу мисалдары

### Авто-которууда
```python
# Кабардын мазмунун аныкталган тилден керектелген тилге которуу
translation = translate_text(message.content, detected_lang, preferred_lang)
if translation:
    # Аларды жөнөтүңүз!
```

### Кол менен колдонуу командасы
```python
# Англисчеден Испанчага которуу
result = translate_text("Hello", "en", "es")  
# Натыйжа: "Hola"

# Испанчадан Англисчеге которуу  
result = translate_text("Gracias", "es", "en")
# Натыйжа: "Thank you"
```

## LibreTranslate кайтарган нерсе

Эгерде иштесе, төмөнкүдөй нерсени аласыз:
```json
{
    "translatedText": "Hola mundo"
}
```

## Эгерде нерселер туура эмес иштесе

Функция төмөнкү учурларда `None` деп жооп берет:
- LibreTranslate иштеп жатпаса
- Интернет байланышы бузулса
- Тилдин туура эмес коддору колдонулган болсо
- Текст өтө узун болсо (10 секунд таймаут)

## Ийгиликке жетүү үчүн кеңештер

1. **Ар дайым текшериңиз**: Функция `None` кайтарбаганына ынануу
2. **Туура коддорду колдонуу**: Англисче үчүн "en", Испанча үчүн "es"
3. **Тексти акылдуулук менен колдонуу**: Абдан узун тексттер көп убакыт талап кылат
4. **Сабырдуу болуу**: Которуу бир аз убакыт алат

## Бот бул функцияны кайда колдонот

Бот бул функцияны эки жерде колдонот:
- **Авто-которуу**: Кимдир бирөө башка тилде билдирүү жазганда
- **Кол менен команда**: Кимдир бирөө `/translate` командасын колдонгондо
