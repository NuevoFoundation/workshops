Nuvi азыр катталган бот идентификациясын алды. Кийинки кадам: аны ишке киргизүү. Долбоор папкасы, виртуалдык чөйрө жана баштапкы файл даяр болгондо, **минималдуу бот базасын** түзө аласыз. Бул биринчи версия байланыштын иштеп жатканын далилдей турган жөнөкөй бот. Ошондой эле ушул кадамда бир уруксатты (`message_content`) иштетебиз, кийинки баракчаларда автоматтык котормо кошулганда кайрадан орнотууга кайрылуунун кереги болбойт.

Бул бөлүктө сиз төмөнкүнү жасайсыз:

1. `discord.py` китепканасын `requirements.txt` файлына кошуу жана орнотуу (VS Code UI — терминал аркылуу жазуу талап кылынбайт)
2. `/hello` slash буйругуна жооп берген жөнөкөй бот жазуу
3. Кабар мазмуну ниетин иштетүү (кийин автоматтык котормо үчүн керек болот)
4. Ботту иштетүү жана тестирлөө

## 1. Discord.py китепканасын кошуу жана орнотуу (Requirements.txt + VS Code UI жардамында)
Адегенде талап кылынган китепкананы жарыялайбыз, анан VS Code аркылуу аны виртуалдык чөйрөгө орнотобуз.

### 1.a Requirements.txt файлына кошуңуз
1. `requirements.txt` файлын долбооруңуздан ачыңыз.
2. Төмөндөгү сабын кошуңуз (файл азырынча ушул сапты камтыса жетиштүү):
```text
discord.py
```
3. Файлды сактаңыз.

### 1.b Environment Manager UI аркылуу орнотуу
1. Python кеңейтүүсүн (бардагы Python иконкасы менен) ачып, туура чөйрөнүн (мисалы, `.venv`) тандалганын тастыктаңыз.
2. «Packages» иконкасын (кассага окшош) тандаңыз, андан кийин "Install project dependencies" дегенди басыңыз.
![Install project dependencies](../../media/dependencies.png)
3. "requirements.txt" чек белгисин тандап, "Ok" басыңыз.
![Select requirements.txt](../../media/requirements.png)
4. `discord.py` орнотулган китепканалар тизмесинде пайда болгонду күтүп туруңуз.
![discord.py installed](../../media/discord-installed.png)

## 2. Бот кодун жазуу
`bot.py` файлын ачыңыз жана кандайдыр бир дайын орунду толтуруу керек болсо, аны төмөнкү код менен алмаштырыңыз. (Бул жерде `user_languages` словар сөздүгү бар экенин байкасаңыз болот — бул “орун толтуруу баракчасы”, аны каттоо жана автоматтык котормо кошулганда колдонобуз.)
```python
import discord
from discord.ext import commands

TOKEN = "<your token here>"

# Бул ар бир колдонуучу кайсы тилди каалаарын эске алуу үчүн
# Бир түрдүү тетиге окшош: user_languages[user_id] = "en" же "es"
user_languages = {}

# Discord'ко биздин бот кабарларды окушу керектигин айтып жатабыз (же буйруктарды гана окуйт эмес)
intents = discord.Intents.default()
intents.message_content = True
bot = commands.Bot(command_prefix="!", intents=intents)

@bot.event
async def on_ready():
    print(f"Бот {bot.user} аты менен онлайн!")
    try:
        synced = await bot.tree.sync()
        print(f"{len(synced)} буйрук синхрондолду.")
    except Exception as e:
        print(f"Ката: {e}")

@bot.tree.command(name="hello", description="Салам айтат!")
async def hello_command(interaction: discord.Interaction):
    await interaction.response.send_message(f"Салам {interaction.user.display_name}! Код жазууда жакшы күн болсун!")

if not TOKEN:
    raise RuntimeError("Бот токен жетишпейт. Файлдын жогору жагындагы TOKEN айнымасына кошуңуз.")

bot.run(TOKEN)
```

### Бул эмне кылат:
- Discord китепканасын импорттойт, андыктан тармактик аракеттерди кайра ойлоп табуу керек болбойт.
- “Ниеттерди” орнотуп, `message_content`ти (келечектеги автоматтык котормо кабарларды окуйт) алдын ала иштетет.
- Ботту түзүп, байланыш башталат.
- `/hello` slash буйругун каттайт, буйруктун синхрондолоорун далилдөө үчүн.
- `user_languages = {}` түзөт, аны биз кийин толтурабыз.
- `/hello` буйругу аткарылганда жеке салам менен жооп берет.
- Коопсуздук текшерүү: токен жок болсо иш токтотулат.

**async / await**: Бул сөздөр Python башка тапшырмаларды аткарып турууга мүмкүнчүлүк берет (мисалы, Discord’un жооп бергенин күтүү) андыктан боттун иши токтоп калбайт.

**Event (@bot.event)**: `@bot.event` сыяктуу декораторлор китепкананы конкреттүү окуя болгон учурда (билдирүү ишке киришкенде) функцияны иштеткендей кылат.

**Slash командалары (`@bot.tree.command`)**: Бул заманбап буйруктарды түзөт жана колдонуучулар Discord'до `/` тергенде көрүнөт. Алар Discord серверлерине катталып, синхрондолгонго бир аз убакыт талап кылынат.

**Interaction**: Slash буйругун колдонгон колдонуучуну билдирет. `interaction.user` адамды берет, ал эми `interaction.response.send_message(...)` жооп созот.

**Bot vs Client**: `commands.Bot` төмөнкү деңгээлдеги Discord кардарына кошумча буйрук өзгөчөлүктөрүн
