<strong>Nuvi кеңеши:</strong> Ботуңузду жандандыруунун убагы келди. Алгач минималдуу буйрук менен баштаңыз, ошондо аны интернетте көрө аласыз—кичине жеңиштер шыктанууну пайда кылат.
{{< /alert >}}

Nuviнин сервери активдүү жана адамдар кошулуп жатышат—бирок котормо жардамчысы али жок. Бул бөлүмдө, сиз эң биринчи курулуш блокту түзөсүз: Python колдонуп, минималдуу Discord бот. Сиз Discord колдонмосун каттайсыз, боттун токенин жаратып, ботту өзүңүз башкарган серверге чакырасыз, жана бардыгы иштеп жатканын текшерүү үчүн биринчи буйрукту ишке ашырасыз. Бул Nuviнин жардамчы өзөгүн күчгө толтуруу процесси катары ойлонуңуз, андан кийин тил өзгөчөлүктөрүн кошо аласыз.

Биз басым жасайбыз:
- Discord тиркемесин жана бот колдонуучусун түзүү
- Бот токенин коопсуз башкаруу
- Минималдуу Python бот жазуу
- Ботту жергиликтүү иштетүү жана байланыштуулукту текшерүү

Кеттик баштайлы!
