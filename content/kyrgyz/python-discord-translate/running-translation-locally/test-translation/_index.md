## Котормону Текшерүү (Кыска Скрипт)
Нуви котормо кыймылдаткычы чындап эле иштеп жатканын далилдеши керек, андан кийин аны ботко туташтыруу алынат. Бул кичинекей скрипт дал ошол далил экенин көрсөтүп берет.

Кыска Python файлынын жардамы менен серверге бир аз текст жөнөтөлү.

`test_translate.py` деп аталган жаңы файл түзүңүз:
```python
import requests

# 1-Тест: Тилди аныктоо
print("Тилди аныктоону текшерүү...")
detect_payload = {"q": "Hello world!"}
detect_resp = requests.post("http://127.0.0.1:5000/detect", json=detect_payload)
print("Тилди аныктоо жыйынтыгы:", detect_resp.json())

# 2-Тест: Котормо
print("\nКотормону текшерүү...")
translate_payload = {
    "q": "Hello world!",
    "source": "en",
    "target": "es",
    "format": "text"
}
translate_resp = requests.post("http://127.0.0.1:5000/translate", json=translate_payload)
print("Котормо жыйынтыгы:", translate_resp.json())
```

Аны иштетүү (LibreTranslate сервери дагы эле иштеп жатканын текшериңиз):
1. `test_translate.py` файлын редактордон ачыңыз.
1. Сол тараптагы Жүрүш жана Ката Издөө иконкасын басыңыз (ойнотуу баскычы жана ката издеген жөргөмүш).
1. Натыйжаны Debug Console / Terminal панелинен караңыз.

Сиз төмөнкүдөй нерсени көрүшүңүз керек: `{'translatedText': '¡Hola Mundo!'}`

### Бул жерде эмне болуп жатат?
**requests китепканасы:** Бул популярдуу Python инструменти вебсайттар же жергиликтүү серверлер менен сүйлөшүүнү жеңилдетет, демек, көп төмөн деңгээлдеги код жазуунун кереги жок.

**Веб сурамы:** Серверге бир нерсе кылууну (мында: текстти которуу) суранып, жооп катары натыйжа кайтарууну сунуштаган программаңыздан жөнөтүлгөн билдирүү.

**Payload (Жүк):** Сураныч менен кошо жөнөтүлгөн маалымат. Бул скриптте `payload` которулуучу текст жана баштапкы/булак тилдер сыяктуу маалыматты JSON катары тейлейт.

**JSON:** Бул маалыматты сактаган жөнөкөй тексттик формат. Сервер өзүнүн жообун JSON катары кайтарат, ошентип, ар кандай программалар жана тилдер аны окуй алат.

**resp.json():** Бул сервердин JSON жоопторун Python түшүнө турган формага айлантат.
