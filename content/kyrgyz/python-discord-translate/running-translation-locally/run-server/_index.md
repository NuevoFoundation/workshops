## 1. Аны requirements.txt файлына кошуу
Сенин долбооруңдун `requirements.txt` файлын ачып, төмөнкү саптарды кош (же бар экенин текшер):
```text
libretranslate
requests
```
Файлды сакта.

### VS Code терминалын колдонуу менен орнотуу
Терминалды ачуу үчүн:
- Менюну колдон: View → Terminal
- ЖЕ клавиатуранын жардамы менен: `Ctrl+`` (апостроф баскычы, адатта Tab баскычынын үстүндө). macOS системасында бул `Cmd+``.
- ЖЕ башкы панелдин ылдыйкы тарабындагы Terminal табчасын/плюс (+) баскычын бас.

1. Виртуалдык чөйрөңүз тандалганын текшериңиз (төмөнкү статус тилкесинде `.venv` көрүнөт). Эгер тандалбаса, аны тандаңыз.
2. VS Code'до жаңы терминал ач (``Ctrl+` ``).
3. Бул буйрукту иштет:
```pwsh
pip install -r requirements.txt
```
4. Орнотуунун ката жок аякташын күтүңүз.
5. (Кошумча) Орнотулган пакеттерди текшерүү үчүн:
```pwsh
pip show libretranslate
```

## 2. LibreTranslateти Жергиликтүү Иштетүү
Серверди терминалда иштете башта (сыноо учурунда бул терезени ачык карма): 

```bash
libretranslate --load-only en,es
```
Бул серверди англисче жана испанча котормолорду колдоо менен иштетет—бул Нуви алгач колдоо көрсөтүүнү каалаган эки тил.

{{< alert theme="info" >}}
<img src="../../media/NF_mascot.jpg" alt="Нуви маскоту" width="70px" style="float:right;margin:0 0 6px 10px;" />
<strong>Нуви кеңеш:</strong> Кийинчерээк көбүрөөк тилдер керекпи? `--load-only` параметринсиз кайра баштаңыз же коду дайындап кошуңуз (мисалы: `--load-only en,es,fr`).
{{< /alert >}}

Биринчи жолу иштетүү тилин жүктөп калышы мүмкүн. Бул бир нече мүнөттү алат.

![LibreTranslate иштөөсү башталып жатат](../../media/libretranslate-starting.png)

Иш аяктагандан кийин, браузерди ачып, төмөнкү дарекке кир:
```
http://127.0.0.1:5000
```
Жөнөкөй баракча көрүшүңүз керек. Сервер аркылуу колдоого алынган тилдерди көрүү үчүн бул дарекке кир:
```
http://127.0.0.1:5000/languages
```

## 3. Проблемаларды Чечүү
| Проблема | Чечүү |
|----------|-------|
| `No module named libretranslate` | Терминалга (.venv) деп жазылганын текшер, жок болсо чоңдордон жардам сура. |
| Сервер башталат да токтойт | Ката текстин оку, кайталап орнот же кайра аракет кыл. |
| 127.0.0.1:5000 ачылбайт | Сервердин иштеп жатканын текшер; брандмауэрди карап көр. |
| Биринчи котормо жай | Моделдер жүктөлүүдө. Бир аз күтө тур. |
| Натыйжа бош же түшүнүксүз | POST методу менен бул ачкычтарды пайдалангандыгыңды текшер: `q`, `source`, `target`, `format`. |
| Порт колдонулуп жатат | Башка портту колдонуңуз: `python -m libretranslate --port 5001` жана URLди жаңыртыңыз. |
