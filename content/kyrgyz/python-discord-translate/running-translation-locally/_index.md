Нувинин боту жооп бере алат, бирок достор бирин-бири түшүнүшүнө жардам бере албайт. Бул бөлүмдө сиз компьютерде *локалдуу* котормо жүргүзө турган программаны орнотосуз—сырттан аккаунт талап кылынбайт—ошондо бот Нуви ойлогон көп тилдүү көпүрөгө айланат.

Бул программанын жардамы менен сиз:
- `/translate` буйрутмасын кол менен сыноо
- Билдирүү англисче же испанча экендигин аныктоо (`/detect` endpoint)
- Катталган колдонуучулар үчүн билдирүүлөрдү автоматтык которуу (`/translate` endpoint)

Келгиле, котормо механизмин орнотуп, ботту ага туташтыралы.

## 1. LibreTranslate деген эмне?
LibreTranslate — бул жамаат тарабынан иштелип чыккан акысыз, ачык булактуу котормо программасы. Аны локалдуу түрдө иштетесиз. Аккаунт жок. Булутка жазылуу жок. Сиз бир тилдеги текстти бересиз, ал экинчи тилде текстти кайтарат.

Бул семинар үчүн эмне үчүн пайдалуу:
- Купуялуулук: текст компьютериңизде калат.
- Башкаруу: сиз тилдерди тандайсыз жана качан жаңыртуу керектигин чечесиз.
- Offline колдонуу: тил маалыматтары биринчи жүктөлгөндөн кийин интернетсиз иштей алат.
- Ачык булак: программанын иштөөсүн көрө аласыз же өзүңүз салым кошо аласыз.

Бул программаны кичинекей жергиликтүү **API** сайтындай элестетиңиз, аны бот төмөнкү эки нерсе үчүн колдонот:
1. Билдирүүнүн тилин аныктоо (`/detect`)
2. Билдирүүнү башка тилге которуу (`/translate`)

Бул автоматтык которуу функциясына негиз болот.

### API деген эмне?
API — бул программадагы меню сыяктуу нерсе. Ал "endpointтерди" (URLдерди) жана алардан эмнени алаарыңызды тизмектейт. Сиз `http://127.0.0.1:5000/translate` дарегине туура маалымат менен киргениңизде, LibreTranslate API которулган текст менен жооп берет. Сиздин ботуңуз **сураныч жөнөтөт** (текст + тил тандоолору) жана **жооп кайтарат** (которолгон текст) — тамак буйрутма берүүдөн жана тамакты алуудан айырмасы жок.
