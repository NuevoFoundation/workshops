### Иш-аракет 1: AND дарбазасы
Күтүлгөн жооп: Чыгуу активдешет (1) эгерде эки киргизүү тең активдүү болсо (1).

Кеңеш: Эки киргизүүнүн бардык мүмкүн болгон айкалыштарын сынап көрүңүз. Чыгуу 1 болуу үчүн, экөө тең 1 болушу керек.

### Иш-аракет 2: OR дарбазасы
Күтүлгөн жооп: Чыгуу активдешет (1) эгерде жок дегенде бир киргизүү активдүү болсо (1).

Кеңеш: Бир же эки киргизүү 1 болгондо, чыгуу 1 болот. Эки киргизүү тең 0 болгондо гана чыгуу 0 болот.

### Иш-аракет 3: NOT дарбазасы
Күтүлгөн жооп: Чыгуу ар дайым киргизүүгө карама-каршы болот.

Кеңеш: Киргизүү 0 болсо, чыгуу 1 болот. Киргизүү 1 болсо, чыгуу 0 болот.

{{< workshop-image filename="media/answer_3.png" alt="Бир киргизүү жана бир чыгышы бар NOT схемасынын визуалдык чечими" width="40%" class="lg-img" >}}

**Эки NOT кыйынчылыгы:**
Эгерде эки NOT дарбазасын катар жайгаштырсаңыз, сигнал эки жолу тескерилет. Б.а.:
- Эгерде киргизүү 0 болсо: биринчи NOT аны 1 кылат, экинчи аны кайрадан 0 кылат.
- Эгерде киргизүү 1 болсо: биринчи NOT аны 0 кылат, экинчи аны кайрадан 1 кылат.

**Жыйынтык:** Катуу жайгашкан эки NOT дарбазасы тескөө эффектин жокко чыгарып, чыгуу баштапкы киргизүүгө барабар болот.

### Иш-аракет 4: AND + NOT (Тескери дарбаза)
Күтүлгөн жооп: Чыгуу 1 болот, эгерде эки киргизүү тең 1 болгон учурдан башка учурда (AND жана андан кийин NOT колдонуу).

Кеңеш: NOT дарбазасы AND жыйынтыгын тескейт. Эки киргизүү тең 1 болсо гана чыгуу 0 болот.

### Иш-аракет 5: OR + NOT (Дым сыяктуу чыгуу)
Күтүлгөн жооп: Чыгуу 1 гана учурда болот, эгерде эки киргизүү тең 0 болсо (OR жана андан кийин NOT колдонуу).

Кеңеш: NOT дарбазасы OR жыйынтыгын тескейт. Эгерде кандайдыр бир киргизүү 1 болсо, чыгуу 0 болот.

### Иш-аракет 6: Дарбазалардын айкалышы (AND, OR, NOT)
Күтүлгөн жооп: Чыгуу активдешет, эгерде B 1 болсо, же A 1 жана C 0 болсо (C'ди NOT менен тескери кылуу керек).

Кеңеш: Белгиленген логикалык шартка ылайык дарбазаларды бириктирип, схеманы түзүңүз. Иш-аракетте сунушталган учурларды сыноодон өткөрүңүз.

1. **Киргизүү жана чыгуу үчүн аныктоо:**
- Киргизүү: A, B, C
- Чыгуу: Чыгуу

2. **C киргизүүсүн NOT менен тескери кылуу:**
- Cни NOT дарбазасына туташтырып, `NOT C` алыңыз.

3. **A жана NOT Cни AND менен бириктирүү:**
- A жана `NOT C` ни AND дарбазасына туташтырып, `A AND NOT C` алыңыз.

4. **Мурунку жыйынтыкты B менен OR аркылуу бириктирүү:**
- `A AND NOT C` жана Bни OR дарбазасына туташтырып, акыркы чыгышты алыңыз: `(A AND NOT C) OR B`.

5. **OR жыйынтыгын Чыгууга туташтырыңыз.**

**Туташуу мисалы:**

{{< workshop-image filename="media/answer_4.png" alt="Үч киргизүү жана бир чыгышы бар AND, OR, NOT дарбазаларынын айкалышынын визуалдык чечими" width="40%" class="lg-img" >}}

**Жетектелген тесттер:**

- A = 1, B = 0, C = 0 → Чыгуу = 1
- A = 1, B = 0, C = 1 → Чыгуу = 0
- A = 0, B = 1, C = 1 → Чыгуу = 1
- A = 0, B = 0, C = 0 → Чыгуу = 0
