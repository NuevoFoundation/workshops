## Киришүү

Дарактын башынан **Кичинекей Маймыл (Monito)** сизге кубаныч менен салам айтат:

> "Сиз көп жолду басып өттүңүз! Сиз буга чейин **AND**, **OR** жана **NOT** жөнүндө билесиз.  
> Эми аларды айкалыштырып, **Токой Сферасына** энергия кайтарууда жардам берүүнүн убагы келди."

Бул иш-аракетте, сиз бардык гейттерди колдонуп кыйынчылыкты чечүү үчүн схеманы түзөсүз.

## Максат

Логикалык схеманы түзүү жана текшерүү:

- **Сфера** күйөт, эгерде:
  - **B** күйүктө болсо, **же**
  - **A** күйүктө, **ал эми** **C** өчө болсо.

Бул схема **NOT**, **AND** жана **OR** гейттерин колдонот.

---

## Керектүү компоненттер

- 3 **Киргизүү**: A, B, C  
- 1 **NOT Гейт**  
- 1 **AND Гейт**  
- 1 **OR Гейт**  
- 1 **Чыгыш**

## Симулятор боюнча көрсөтмөлөр

### 1. Компоненттерди жайгаштыруу
1. **Түзөтүү** режиминдеги экениңизге ынануу.
2. Сол жактагы панелден төмөнкүлөрдү тандап, жайгаштырыңыз:
  - **A**, **B**, **C** (киргизүүлөр) жайгаштырыңыз.  
  - **NOT**, **AND**, **OR** жайгаштырыңыз.  
  - Оң жакка **Чыгышты** жайгаштырыңыз.

### 2. Компоненттерди туташтыруу
1. **C ➔ NOT** туташтырыңыз (бул **NOT C** жаратат).  
2. **A** жана **NOT Cди** **ANDга** туташтырыңыз (бул **A AND NOT C** жаратат).  
3. **(A AND NOT C)** жана **Bни** **ORго** туташтырыңыз.  
4. **ORдон чыккан чыгышты ➔ Чыгышка** туташтырыңыз.

---

## Багытталган тесттер

Бул комбинацияларды сынап, **Чыгышты** текшериңиз:

1. **A = 1, B = 0, C = 0** ➔ `NOT C = 1` ➔ `A AND NOT C = 1` ➔ `Чыгыш = 1`  
2. **A = 1, B = 0, C = 1** ➔ `NOT C = 0` ➔ `A AND NOT C = 0` ➔ `Чыгыш = 0`  
3. **A = 0, B = 1, C = 1** ➔ `B = 1` ➔ `Чыгыш = 1`  
4. **A = 0, B = 0, C = 0** ➔ эки жол тең `0` берет ➔ `Чыгыш = 0`

Эгерде ушул төрт тест дал келсе, Сфера туура күйүп жатат!

## Жалпы каталар жана аларды оңдоо

- **Чыгыш дайыма 0**: **OR** гейттин **эки сигналды** ала тургандыгын текшериңиз: `B` **жана** `A AND NOT C`.  

---

## Эмне үйрөндүңүз?

- Гейттерди айкалыштырып, бир гейт жасай албай турган татаал чечимдерди жаратууга болот.
- NOT сигналды тескери кылууга мүмкүнчүлүк берет; AND бир учурдагы шарттарды айкалыштырат; OR альтернативдик жолдорду бириктирет.
- Акыркы чыгыш гейттердин кантип туташтырылганына жана сигналдардын иштетүү ырааттуулугуна байланыштуу.
