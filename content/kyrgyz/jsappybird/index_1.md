### Өзгөрмөлөр (Variables)

Өзгөрмөлөр - бул тексттерди, сандарды жана логикалык (Boolean) маанилерди сактоо үчүн ысымдар. Алар маалыматты сактоо үчүн колдонулат, ошону менен компьютер аны эске тутуп иштете алат. Өзгөрмөлөрдү `var` деген сөз менен түзүүгө болот жана анын атын койсоңуз болот. Андан кийин, өзгөрмөңызга маалыматты `=` белгеси аркылуу ыйгарып бере аласыз.

Мисалы:

```js
var world = "Салам дүйнө!";
var x = 88;
var happy = true;
```

Өзгөрмөнүн маанисин дагы өзгөртсөңүз болот:

```js
var x = 4;
x = 10;
```

Бул мисалда, `x` аттуу өзгөрмөгө алгач 4 мааниси берилет, андан кийин 10 болуп өзгөртүлөт.

Төмөнкү код жаңы Phaser Game объектисин түзүп, аны оюнубузда колдонуу үчүн өзгөрмөнүн ичинде сактайт:

```js
var game = new Phaser.Game(800, 600);
```

## 1-Активдүүлүк: Boolean жана Boolean ырааттуулукту колдонолу

### Шарттар (Conditionals)

Эгерде белгилүү бир шарттар аткарылса, белгилүү бир код фрагменттерин иштетиш үчүн if билдирүүлөрүн колдонсок болот.

Мисалы:

```js
if (isRainingOutside == true) {
  takeUmbrella = true;
}
```

`if` сөзүнүн жанындагы `()` ичине **логикалык билдирүү** (Boolean expression) жазылышы керек. **Логикалык маанилер** бул `true` же `false` деген билдирүүлөр. Эгерде бул билдирүү `true` болсо, анда `{ }` ичиндеги код аткарылат.

Ошондой эле логикалык билдирүүлөрдү сан белгисизин текшерүү үчүн колдонсо болот:

![Салыштыруучу операторлор](https://imgur.com/F9gGHiI.png)

Логикалык билдирүүлөрдү бириктирүү үчүн `&&` (ЖАНА) жана `||` (ЖЕ) операторлорун колдонсоңуз болот.

![alt text](resources/_gen/images/statements.png "statements")

`&&` оператору логикалык билдирүүлөрдүн экөөсү тең `true` болушун талап кылат, ал эми `||` оператору эки билдирүүдөн жок дегенде бирөөнүн `true` болушун талап кылат.

Мисалы:

```js
// "true" мааниси өндүрүлөт, анткени эки билдирүү тең туура.
(1 < 100 &&
  (5 != 10)(
    // "true", анткени жок дегенде бир билдирүү туура.
    5 == 5
  )) ||
  10 > 20;
```

## 2-Активдүүлүк: Кушту секирүүгө мажбур кылуучу функция кошолу

### Функциялар

**Функцияларды милдет катары элестетсе болот.** Кээ бир милдеттер жөнөкөй жана кыска, мисалы, `1 + 1` кошуу же `"Салам дүйнө!"` билдирүү. Функциялар бирдей милдеттерди көп жолу иштетүүгө ылайыктуу. Бул оюнда функция жазып, кушту "секирүүгө" мажбурлоону карайбыз!

Оюндагы "сепирүү" болгону куштун _y абалын_ өзгөртүү.

#### `Activity 2.js` файлын ачып, `jump` аттуу функция кошолу.

Бул функцияга төмөнкү кодду кошуп, аны оюнда иштетүү мүмкүн:

```js
bird.body.velocity.y = -300;
```

Бул санды секирүү бийиктигине жараша өзгөртсөңүз болот! Санды өзгөртүп, куштун мейкиндик басылганда канчалык бийик секиргенин байкаңыз.

Эми кушка учуу мүмкүнчүлүгүн бердиңиз!

## 3-Активдүүлүк: Тоскоолдуктарды кошолу

Учурда оюндун экранында куш эч кандай тоскоолдуктарга дуушар болбойт, бул оюнду өтө жеңилдетет! Тоскоолдуктарды кошуп, оюнду кыйындатып код жазбасак болбойт! Бул үчүн шарттарды жана циклдерди колдонуу керек болот. Шарттарды мурун карап чыктык, эми цикл тууралуу түшүндүрүү менен таанышалы.
