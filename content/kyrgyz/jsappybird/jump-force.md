Топозго күч кошолу

Төмөнкү буйрукту [Файл: create-game.js] файлына кошуңуз
    bird.body.velocity.y = -350;
    
{{% notice tip %}}

## Биргелешип иштөө

Төмөндөгү Replit терезесинде, биз кодду `bird.body.velocity.y = -350;` деген сап менен баштадык.

![alt text](../img/jump_force.png "канаттын гравитациясына күч кошуучу сүрөт")

Консолуңузда **run** баскычын баскандан кийин күч менен секирген JSappy канатын көрөсүз:

![alt text](../img/jump_output.png "гравитация менен секирген канат")

{{% /notice %}}

## Бонус иш-чара

Кел, канатты өйдө жана алдыга секиртип көрөлү:

Төмөнкү буйрукту [Файл: create-game.js] файлына кошуңуз
    bird.body.velocity.x = 100;

# Канат айлануу менен түшүү

Канатка айлануу кошолу:

Төмөнкү буйрукту [Файл: update-game.js] файлына кошуңуз
    if (bird.angle < 50) {
       bird.angle += 1;
    }

## Комментарийлер:

`If` шарттуу блок болуп, канаттын бурчун текшерип, эгер ал 50ден аз болсо, шартты аткарабыз.
   -bird.angle+=1;

{{% notice tip %}}

## Биргелешип иштөө

Төмөндөгү Replit терезесинде, биз кодду `bird.angle +=1;` деген сап менен баштадык.

![alt text](../img/rotate.png "канатка айлануу кошуучу сүрөт")

Консолуңузда **run** баскычын баскандан кийин бурч менен айланып жаткан Jsappy канатын көрөсүз:

![alt text](../img/rotate_output.png "айланып жаткан канат")

{{% /notice %}}
