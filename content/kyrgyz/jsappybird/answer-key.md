{{% notice note %}}
Бул жооптор ачкычы Flappy Bird оюнун куруу үчүн студенттер кошо турган бардык кодду камтыйт. Ар бир кадам Replit долбоорунда белгилүү бир файлга JavaScript кодунун өзүнчө сабын кошот. Семинар жол көрсөтүүчү түрдө өтөт (студенттерге эмне жазуу керектиги айтылат), бирок бул нерселерди мугалимге карап чыгуу үчүн бириктирет.
{{% /notice %}}

## Кадам-кадам менен код кошуу

### 1. Канаттуунун сүрөтүн жүктөө

**Файл:** `load-sprites.js`

```javascript
game.load.image('bird', 'assets/bird.png');
```

### 2. Баштапкы экрандагы текстти өзгөртүү

**Файл:** `start-screen.js`

```javascript
var text = game.add.text(0, 0, "Press Space to Start", textOptions);
```

### 3. Канаттууну боштук баскычын басканда секирүү

**Файл:** `create-game.js`

```javascript
spaceKey.onDown.add(jump, this);
```

### 4. Гравитация кошуу

**Файл:** `create-game.js`

```javascript
bird.body.gravity.y = 900;
```

### 5. Секирүү күчүн кошуу (ылдамдык)

**Файл:** `create-game.js`

```javascript
bird.body.velocity.y = -350;
```

{{% notice tip %}}
**Студенттердин жалпы суроосу:** "Канаттууну жогору же төмөн секиртүүнү кантип өзгөртсө болот?"

`bird.body.velocity.y` ичиндеги санды өзгөртүңүз. Терс сан канчалык көп болсо, секирик ошончолук бийик болот. Мисалы, кичинекей секирик үчүн `-200`, ал эми чоң секирик үчүн `-500` колдонуп көрүңүз.
{{% /notice %}}

### 6. Канаттуунун түшүп бара жатканда айланышын кошуу

**Файл:** `update-game.js`

```javascript
if (bird.angle < 50) {
    bird.angle += 1;
}
```

### 7. Секирүү үндөрүн кошуу

**Файл:** `create-game.js`

```javascript
jumpSound.play();
```

## Кошумча аракеттер боюнча жооптор

### Канаттууну алдыга секирүү

**Файл:** `create-game.js`

```javascript
bird.body.velocity.x = 100;
```

### Кошумча изилдөө суроолору

| Суроо | Эмне болот |
|-------|------------|
| Гравитацияны күчөтүү? | `bird.body.gravity.y = 1500;` — канаттуу тез-тезирек кулайт, ойноо кыйын болот |
| Гравитацияны терс кылуу? | `bird.body.gravity.y = -900;` — канаттуу түшпөй, көтөрүлүп калат |
| Канаттуунун тез айлануусу? | `bird.angle += 1` кодун `bird.angle += 5` менен өзгөртүңүз |
| Айлануудагы шартты алып салуу? | Канаттуу 50 градустан ашып, тынымсыз айланат |

## Аракет коддору (Өркүндөтүлгөн версия)

Семинарда өзгөрмөлөр, шарттар, функциялар жана циклдерди үйрөткөн үч код жазуу аракеттери камтылган:

### Аракет 1: Канаттууну экранда кармоо (шарттуу)

```javascript
if (bird.y > 0 && bird.y < 490) {
    // канаттуу экранда - кыймылга уруксат
}
```

### Аракет 2: Секирүү функциясы

```javascript
function jump() {
    bird.body.velocity.y = -300;
}
```

### Аракет 3: Бөгөттөрдү боштуктар менен кошуу

```javascript
var hole = Math.floor(Math.random() * 6) + 1;

for (var i = 0; i < 8; i++) {
    if (i != hole) {
        addOnePipe(i);
    }
}
```

**Кантип иштейт:** Цикл 8 түтүк тоскоолдуктарды жаратат. `hole` өзгөрмөсү 1ден 6га чейинки кокустук позицияны тандап алып, аны өткөрүп коёт, канаттуу учуп өтө турган боштук жаратып.
