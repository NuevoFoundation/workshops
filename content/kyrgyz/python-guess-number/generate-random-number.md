Python программалоо тилиндеги `random` китепканасы тасаддуу сандарды түзүүгө жардам берет. Бул китепкананы программаңызда колдонуу үчүн программанын башына `import random` деп жазып, берилиштер диапазонун колдонуп `randint` функциясын иштетсеңиз болот.

Бул 1ден 10го чейин тасаддуу санды түзөт.
```python
    random.randint(1,10)
```

Төмөндөгү кодду бир нече жолу иштетип көрүңүз, кандай сандар пайда болоорун байкаңыз!

{{% notice tip %}}
Тасаддуу сандардын диапазонун өзгөртүп ойноп көрүңүз. Бул көңүлдүү, аракет кылып көрүңүз!
{{% /notice %}}
