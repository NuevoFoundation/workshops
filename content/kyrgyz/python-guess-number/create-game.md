## Колдонуучунун киришин кабыл алуу

Бул оюнда сиз Python негиздери бөлүмүндө үйрөнгөн кээ бир түшүнүктөрдү колдоносуз. Төмөнкү түшүнүктөрдү билишиңиз керек. Эгерде булардын кайсынысы болбосо, аларды кайрадан карап чыгыңыз.
- <a href="../../python-basics/conditional-statements-loops/loops/" target="_blank">While циклдери</a>
- <a href="../../python-basics/basics/writing-to-console/" target="_blank">Консольго жазуу</a>
- <a href="../../python-basics/basics/reading-from-console/" target="_blank">Консолдон окуу</a>
- <a href="../../python-basics/conditional-statements-loops/conditional-statements/" target="_blank">Шарттуу билдирүүлөр</a>
- <a href="/python-guess-number/random/" target="_blank">Кокус сандар</a>

Сиз бул оюнду коддошуңуз керек, ал санды кокусунан жаратат.

Андан кийин, программа консолдон колдонуучунун киргизүү маалыматтарын кайта-кайта сурайт жана сиз бул киргизүүнү кокусунан түзүлгөн санга салыштырууңуз керек болот.

Кайталанма тапшырмаларды жасоо үчүн эң жакшы ыкма кайсы? Туура, циклдер!
Бул тапшырманы ишке ашыруу үчүн `while` циклин колдоно аласыз.

`while` циклинин ичинде шарттууларды колдонуп, оюнчу туура жооп бердиби же жокпу текшере аласыз. Эгер туура эмес болсо, аларга төмөн же жогору болжош керек экенин айткан пайдалуу кеңештерди бере аласыз.

## Өз оюнуңузду түзүүгө аракет кылыңыз!

Комментарийлерди колдонмо катары окууну унутпаңыз; же балким, комментарийлерди өчүрүп, өз алдынча түшүнүүгө аракет кылыңыз. :)
