{{% notice note %}}
Бул JavaScript Блоктор EarSketch семинары үчүн окутуучунун маалымдамасы. Семинарда сүйрөп таштоо блоктору колдонулат, бирок ар бир блоктун астында JavaScript коду жаралат. Бул жооп ачкычы ар бир иш-аракет үчүн барабар JavaScript кодун көрсөтөт, ошону менен окутуучулар студенттердин ишин текшере алышат. Бул чыгармачыл музыка семинары болгондуктан, көптөгөн туура жооптор болушу мүмкүн. Эгер кодуңуз ката кетирбей иштесе жана музыка жаралса, анда ал туура!
{{% /notice %}}

## 1-иш-аракет: Темп коюу жана үн кошуу

`setTempo` блоктун алдына `fitMedia()` блокту сүйрөп таштап, параметрлерин толтуруңуз:

**Барабар JavaScript:**
```javascript
setTempo(120);
fitMedia(YG_TRAP_ELECTRIC_PIANO_FILTERED_1, 1, 1, 9);
```

**Блок параметрлери:**

| Параметр | Баалуулук | Кантип коюлат |
|-----------|-------|--------------|
| Үн | `YG_TRAP_ELECTRIC_PIANO_FILTERED_1` | Блоктогу "sound" басыңыз, анан Sounds панелинен көчүрүп коюңуз |
| Трек | `1` | Төмөндөөнү колдонуу |
| Башталышы | `1` | Башталыш өлчөмү |
| Аяктоосу | `9` | Аяктоо өлчөмү |

## 2-иш-аракет: Ыр түзүү (Бир нече үндөр)

Төрт `fitMedia()` блокту кошуңуз, ар бири башка трекке:

**Барабар JavaScript:**
```javascript
setTempo(120);
fitMedia(RD_TRAP_BELLLEAD_1, 1, 1, 9);
fitMedia(YG_TRAP_STRINGS_2, 2, 1, 17);
fitMedia(YG_TRAP_ELECTRIC_PIANO_FILTERED_1, 3, 1, 17);
fitMedia(YG_TRAP_BASS_9, 4, 1, 9);
```

{{% notice tip %}}
**Студенттер үчүн негизги түшүнүк:** Ар бир `fitMedia()` блок бирдей эмес трек номерин колдонушу керек. Бул үндөрдү иреттөөгө жана ар кандай үндөрдү бир эле учурда ойнотууга мүмкүнчүлүк берет.
{{% /notice %}}

## 3-иш-аракет: Эффекттерди кошуу

`fitMedia()` блоктордун астында 4-параметрдик `setEffect()` блокту сүйрөп таштаңыз:

**Барабар JavaScript:**
```javascript
setTempo(120);
fitMedia(RD_TRAP_BELLLEAD_1, 1, 1, 9);
fitMedia(YG_TRAP_STRINGS_2, 2, 1, 17);
fitMedia(YG_TRAP_ELECTRIC_PIANO_FILTERED_1, 3, 1, 17);
fitMedia(YG_TRAP_BASS_9, 4, 1, 9);
setEffect(2, DELAY, DELAY_FEEDBACK, -6.0);
```

**setEffect параметрлери (4-параметрдик версия):**

| Параметр | Баалуулук | Мааниси |
|-----------|-------|---------|
| Трек | `2` | Кайсы трек (мастер/баардык тректер үчүн `0` колдонуңуз) |
| Эффект түрү | `DELAY` | Төмөндөөнү тандаңыз |
| Параметр | `DELAY_FEEDBACK` | Төмөндөөнү тандаңыз |
| Баалуулук | `-6.0` | Диапазон: -120.0дан -1.0гө чейин |

## 4-иш-аракет: Fade In менен Эффект кошуу

7-параметрдик `setEffect()` блокту кошуп, үн азайтуудан баштоого шарт түзүңүз:

**Барабар JavaScript:**
```javascript
setTempo(120);
fitMedia(RD_TRAP_BELLLEAD_1, 1, 1, 9);
fitMedia(YG_TRAP_STRINGS_2, 2, 1, 17);
fitMedia(YG_TRAP_ELECTRIC_PIANO_FILTERED_1, 3, 1, 17);
fitMedia(YG_TRAP_BASS_9, 4, 1, 9);
setEffect(2, DELAY, DELAY_FEEDBACK, -6.0);
setEffect(0, VOLUME, GAIN, -60, 1, 0, 3);
```

**setEffect параметрлери (7-параметрдик версия):**

| Параметр | Баалуулук | Мааниси |
|-----------|-------|---------|
| Трек | `0` | Мастер трек (баардык үндөр) |
| Эффект түрү | `VOLUME` | Үндүн башкаруусу |
| Параметр | `GAIN` | Үндүн күчү |
| Башкы мааниси | `-60` | Дээрлик унчукпаган (децибелде) |
| Башталыш өлчөмү | `1` | Fade качан башталат |
| Аяккы мааниси | `0` | Нормалдуу үн |
| Аяктоо өлчөмү | `3` | Fade качан бүткөнү |

{{% notice tip %}}
**Fade In иштеши кандай:** Үн 1-өлчөмдө -60 дБден (дээрлик унчукпаган) баштап, 3-өлчөмгө чейин 0 дБго (нормалдуу үн) чейин көбөйөт. Децибелдин саны канчалык терс болсо, үн ошончолук тынч. 0 дБден ашырбаңыз.
{{% /notice %}}
