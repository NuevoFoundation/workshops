Эми модельди машыктырууга даярбыз. Биз аны машыктыруу үчүн 'LinearRegression().fit()' деген функцияны колдонобуз. Бул модель объектинде `score()` деген функция бар, ал моделдин баасын кайтарат, бул прогноздун аныкталуу коэффициенти R^2 болуп саналат. Азырынча бул көрсөткүч канчалык жогору болсо, ошончолук жакшы экенин билишиң керек.

```python
# машыктыруу маалыматтарын даярдоо
x_train = train_data[features]
y_train = train_data[target]

# Линейлик регрессияны колдонуу
# fit() моделди машыктыруу үчүн метод
model = LinearRegression().fit(x_train, y_train)

# Моделдин баасы
print("Баасы: " + str(model.score(x_train, y_train)))
```

    Баасы: 0.9875123836174596
