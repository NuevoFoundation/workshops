Бул убакка чейин биз маалыматтар топтомун импорттоп бүттүк. Чыныгы жашоодо ар бир футболчунун өзүнө тиешелүү позициясы бар. Ар кандай позицияларда ар кандай атрибуттардын күчтүү болушу талап кылынат. Ошондуктан, талдоо чөйрөсүн чабуулчу (striker) менен чектейли.

Биринчи кезекте, бардык позицияларды тизмектейли.
Бул буйрук бир аз узагыраак көрүнүшү мүмкүн, бирок ишти бүтүрөт. `fifa_data['position']` - бул `fifa_data` маалымат топтомундагы позиция мамычасын (колонка) тандап алат, `dropna()` бош уячаларды (клеткаларды) жок кылат, ал эми `unique()` кайталанган элементтерди алып салат.


```python
# канча позиция бар экенин табуу
print(fifa_data['Position'].dropna().unique())
```

Эми биз маалыматтарды "ST" позициясы менен чыпкалай алабыз. Башка позицияларды тандап, алардын айырмачылыктарын көрүүгө чакырабыз.


```python
# оюнчуларды позициясы боюнча тандап алуу
fifa_data_by_pos = fifa_data[fifa_data['Position']=='ST']
```

Эми, биз маалыматтарды эки топко бөлгүбүз келет: биринчиси моделди үйрөтүү үчүн, экинчиси болсо үйрөтүлгөн моделдин сапатын текшерүү үчүн колдонулат.

Сиз, балким, моделди жакшыраак кылыш үчүн мүмкүн болушунча көбүрөөк маалыматты үйрөтүү үчүн колдонушубуз керек деп ойлошуңуз мүмкүн. Албетте, модель үйрөтүүчү маалыматтар топтомуна жакшыраак ыңгайлашат, бирок тест маалыматтарына колдонулганда анын тактыгы төмөндөшү мүмкүн. Бул "ашыкча ылайыкташуу" (overfitting) деп аталат.

Учурда, биз тестирлөө үчүн маалыматтардын 25%ын бөлүп коёбуз.


```python
# маалыматтарды train_data жана test_data катары туш келди бөлүү
# test_size катышын өзгөртүп көрүп, кандай өзгөрүү болоорун байкасаңыз болот
train_data, test_data = train_test_split(fifa_data_by_pos, test_size=0.25)

# train_data жана test_dataдагы оюнчулардын санын басып чыгаруу
# len() оюнчулардын санын сандык форматта берет
# str() сандык маанини текстке айландырат
print("Тренинг маалыматтар саны: " + str(len(train_data)))
print("Тест маалыматтар саны: " + str(len(test_data)))
```
