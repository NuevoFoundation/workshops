Бурроуз-Уилер трансформаты (BWT) - бул маалыматтарды кысуу үчүн колдонулган алгоритм. Ал киргизүү катары сапты алат жана окшош белгилер жыйналып чыккан коддоо түрүндөгү сапты чыгарат.

## Теория

Алгоритм салыштырмалуу жөнөкөй жана түшүнүүгө оңой.

1. Киргизилген сапты алып, анын бардык бурулуш трансформацияларын түзүңүз. (Сүрөттү караңыз).
2. Бурулуштарды лексикографиялык тартипте, өсүш боюнча иреттеңиз.
3. Иреттелген трансформациянын акыркы мамынын алыңыз; бул чыгаруу болуп саналат.

![Бурроуз-Уилер Трансформаты](../resources/e3-01.png "Бурроуз-Уилер трансформациясынын 3 баскычы")

Жогорудагы диаграммада биз `banana` сапты мисал катары колдонуубуз. `\0` бул саптын аягын көрсөткөн белгилер (C тилиндеги нөлдүк терминатор белгиси сыяктуу), бирок лексикографиялык жактан башка белгилерге салыштырмалуу ЭҢ ЧОҢ белгиге жатат.

BWTти ишке ашыруунун эффективдүү жолу «суффикс массив» деп аталган маалымат структурасын колдонуу. Суффикс массив түзүү үчүн, биз алгач киргизилген саптын бардык суффикстерин алып, аларга номерленген аталыш беребиз. Андан соң суффикстерди лексикографиялык тартипте иреттейбиз.

![Суффикс массивдер](../resources/e3-02.png "Суффикс массив түзүү баскычы")

`Nuevo\0` сапын мисал катары колдонуп, биз алгач анын суффикстерин алып, тизмеге кошобуз. Андан соң, аларды лексикографиялык тартипте иреттейбиз, кайрадан `\0` нөлдүк терминатор белгиси эң чоң символ катары иш-аракет кылат. Акырында, ар бир суффикстин биринчи тамгасынын индексин алып, аларды массивге кошобуз. Мисалы, `Nuevo\0` сапындагы `N` тамгасынын индекси `0`, ал эми `e` тамгасынын индекси `2`. Мындай жол менен, эң кичине алфавиттик тамгалар массивдин 0 жана 1 ячейкаларына келет.

Бурроуз-Уилер трансформаты үчүн суффикстерди бурулуш катары ойлонсок болот! Бурулуштарды түзүү үчүн, биз жөн гана «кесилген» префиксти саптын аягына кошобуз. Ошентип, `evo\0` `evo\0Nu` болуп калат, суффиксти бурулуш катары карасак. Андан соң, бардык суффикстерге ушундай кылсак, Бурроуз-Уилер трансформатына керектуу иреттелген бурулуштарды алабыз.

![Суффикстерден бурулуштарга](../resources/e3-03.png "Бурроуз-Уилер трансформаты үчүн суффикстерди иреттүү түрдө бурулуштарга айландыруу")

Бир негизги эскертүү: биз бурулуштарды сактоонун кереги жок, анткени суффикс массивдеги индекс бизге ошол информацияны берет. Эгерде `suffix_array[i] == 0` болсо, анда биз карап жаткан бурулуш `Nuevo\0`. Эгерде `suffix_array[i] == 3` болсо, анда каралып жаткан бурулуш `vo\0Nue`. Мындай учурда, `suffix_array[i] == N` болсо, биз `N` орунга оңго бурулуп карап жатабыз деп ойлоого болот. Көрсөтүлгөн сүрөт муну демонстрация кылат.

Ошентип, бурулуштун акыркы символун ал үчүн, биз жөн гана `suffix_array[i]`ден 1ди алып, андан соң суффикс массивдин жалпы узундугуна модулдук операция жасайбыз. Бул биз издеп жаткан оригинал саптын индекстерин берет. Бул ар кандай сап үчүн Бурроуз-Уилер трансформатын түзүүгө мүмкүндүк берет.

## Ишке ашыруу

Биз жогоруда белгилеген стратегияны колдонууну сунуштайбыз: суффикс массивди түзүү, анан индекстерди алып, 1ди кемитип, ошол эле саптын узундугуна модулдук операция жасоо.

Биз суффикс массивди жана анын жардамы менен Бурроуз-Уилер трансформатын ишке ашырдык. Бирок, иш учурунда бир топ каталарды кетиргенбиз. Бул тапшырма оңой эмес, анткени аны аткарууда индекстер менен иштөөнү жакшы түшүнүү керек. Каталарын оңдоого жардам берүүчү кеңеш катары айта кетсек, көптөгөн каталар суффикс массив жана аны колдонууга байланыштуу.

{{% notice tip %}}
Нөлдүк терминатор белгиси сиздин саптарды басып чыгарууга тоскоол болушу мүмкүн. Бул тапшырмада, сиз трансформацияланган сапты символ менен эле басып чыгарышыңыз керек, анткени нөлдүк терминатор белгиси `printf` функциясын аны тапканда басып чыгарууну токтотууга мажбурлайт. Төмөнкү код `dest` жана `src` колдонгон `bwt` функциясынын жыйынтыгын басып чыгарат; мында **нөлдүк терминаторду** кошкондо статикалык узундугу `STR_LEN` болот.
```c
for(int i = 0; i < STR_LEN; ++i) {
    printf("%c", dest[i]);
}
```
Эске алыңыз, `strlen()` саптын узундугун, нөлдүк терминаторду кошпой, кайтарат.
