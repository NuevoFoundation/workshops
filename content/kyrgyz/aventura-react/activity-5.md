Коста-Рикадагы алсандар өлкөнүн символу катары белгилүү жана алардын эки түрү бар: эки манжалуу алсан (Choleopus hoffmanni) жана үч манжалуу алсан (Bradypus variegatus). Алар жай кыймылдылыгы, чеберчилик менен маскировка кылуусу жана табият менен байланышкан Коста-Риканын улуттук символу катары белгилүү. Алардын изин Манвел Антонио жана Корковадо сыяктуу улуттук парктарда, Ла Фортуна жана Кахуита сыяктуу аймактарда тапса болот.

### Бир компоненттин ичинде башка компонентти колдонуу

Бул иш-аракетте, эки компонент колдонобуз:

- Кичинекей компонент: **Perezoso**
- Чоң компонент: **Perezosos**

Бул деген кичинекей компонент түзүп (мисалы, формочкадай) жана андан кийин аны чоң компоненттин ичинде көп жолу колдонобуз деген маанини түшүндүрөт.
{{% /notice %}}

```jsx
// Кичинекей компонент
function Perezoso() {
  return <p>Мен алсанмын</p>;
}

// Чоң компонент
export default function Perezosos() {
  return (
    <Perezoso />
  );
}
```

{{% notice info %}}
### Props: компонентке берилген маалыматтар

Props бул чоң компоненттен кичинекей компонентке жиберилген маалыматтар.  
Perezoso компоненти төмөнкүнү кабыл алат:

- nombre
- onRescatar
- rescatado
{{% /notice %}}

```jsx
function Perezoso({ nombre, onRescatar, rescatado }) {
  return <p>{nombre}</p>;
}
```

Мына ушундай типов жөнөтүлөт:

```jsx
<Perezoso
  nombre="Marcos"
  onRescatar={rescatar}
  rescatado={false}
/>
```
---

#### **Perezoso** компоненттин ичинде бул код жазылат

```jsx
<div className={`perezoso-card ${rescatado ? "rescatado" : ""}`}>
      <p>
        {rescatado
          ? `${nombre} аман болду!`
          : `${nombre} жардамга муктаж`}
      </p>

      {!rescatado && (
        <button onClick={() => onRescatar(nombre)}>Куткаруу</button>
      )}
    </div>
```

---

{{% notice info %}}
#### 1. Динамикалык класстары бар негизги контейнер  

```jsx
<div className={`perezoso-card ${rescatado ? "rescatado" : ""}`}>
```

- Кайсы учурда болбосун style.css файлынан perezoso-card классын колдонот.
- Эгерде алсан куткарылган болсо (```rescatado === true```), анда ```rescatado``` классын дагы кошот.
- Бул анын абалына жараша стилдерди өзгөртүү үчүн колдонулат.

Бул куткарылганда ага "өзгөчө стикер" бергендей сыяктуу.

**"rescatado"** классы ошол стикер.

---

#### 2. Алсандын абалына жараша өзгөрүүчү текст

```jsx
<p>
  {rescatado
      ? `${nombre} аман болду!`
      : `${nombre} жардамга муктаж`}
</p>

```

- Эгерде rescatado чын болсо, ал куткарылганын билдирген билдирүү көрсөтүлөт.
- Эгерде туура эмес болсо, ал жардам керек экенин билдирген билдирүүнү көрсөтөт.
- ** ```? :``` бул жарым-жартылай түрдө куткарылган → аны көрсөтүү, болбосо → башкасын көрсөтүү дегенди билдирет.**

Бул жарыктандыруучу сыяктуу:

Эгерде жашыл болсо → алсандан аман болду!

Эгерде сары болсо → дагы деле жардамга муктаж.

---

#### 3. Эгерде ал куткарылган эмес болсо гана көрсөтүлүүчү баскыч

```jsx
{!rescatado && (
  <button onClick={() => onRescatar(nombre)}>Куткаруу</button>
)}

```

- !rescatado бул "куткарылган эмес" дегенди түшүндүрөт.
- Эгер бул чын болсо, баскыч көрсөтүлөт.
- Эгерде алсан мурунтан эле куткарылган болсо → баскыч жоголот.
- Баскычты басканда, ```onRescatar(nombre)``` аткарылат.

Бул "жардам бер" баскычы сыяктуу.
Эгерде ал мурунтан эле аман болсо, башка баскыч көрүнө элек болот.

### Компоненттердин тизмесин цикл аркылуу түзүү

```jsx
let listaPerezosos = [];

for (let i = 0; i < perezosos.length; i++) {
  listaPerezosos.push(
    <Perezoso
      key={i}
      nombre={perezosos[i]}
      onRescatar={rescatar}
      rescatado={rescatados.includes(perezosos[i])}
    />
  );
}
```
