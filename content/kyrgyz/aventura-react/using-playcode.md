## Playground колдонуу

Биз React менен биринчи долбоорубузду түзүү үчүн PlayCode инструментин колдонобуз. Бул жерде сиз онлайн режиминде кодду редакциялай аласыз.

Алгач PlayCode же Playground кандай иштээрин билишибиз керек. Сиз коддорду уюштуруу үчүн файлдар жана папкаларды түзө аласыз. Бул код редактору автоматтык түрдө жаңыртылып турат, демек, сиз жазган нерсе жаңыртпастан дароо эле өзгөрөт. Сиз өз прогрессиңизди реалдуу убакыт режиминде көрө аласыз.
