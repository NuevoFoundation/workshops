**Бул колдонмо үчүн CSS код, `"style.css"` файлына көчүрүп, чаптаңыз**

{{% notice info %}}
### CSS эмне кыла алат?
CSS (Каскаддык Стил Барактары) өтүнүчүңүздүн кандай **көрүшүн** көзөмөлдөйт: түстөр, формалар, өлчөмдөр жана анимациялар. CSS жок өтүнүчүңүз мурункудай эле иштейт, бирок жөн гана стилсиз текст түрүндө көрүнөт.

Төмөндөгү бөлүктөр ар бири Коста Рика өтүнүчүңүздүн ар түрдүү компоненттерине стил берет.
{{% /notice %}}
