Ajoutons des sons à l'oiseau lorsqu'il saute.

Ajoutez la commande ci-dessous dans le fichier [File: create-game.js]  
    jumpSound.play();

{{% notice tip %}}

## Travailler ensemble

Dans la fenêtre Replit ci-dessous, nous avons commencé le code avec la ligne `jumpSound.play();`.

![alt text](../img/jump_sound.png "image pour ajouter un son à l'oiseau")

Dans votre console, vous devriez voir un Jsappy bird sauter avec un son après avoir appuyé sur **run**.

{{% /notice %}}
