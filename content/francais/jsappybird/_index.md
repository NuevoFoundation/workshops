## Introduction

Vous connaissez peut-être le jeu Flappy Bird. Cet atelier vous guidera dans la création de votre propre version du jeu en utilisant le langage JavaScript ! Prêt à relever le défi ?

<p style="text-align: center;"><iframe src="https://giphy.com/embed/euuaA2cwLEUuI" title="JS : JSappyBird - Animation Giphy" width="350" height="350" frameBorder="0" class="giphy-embed"></iframe>

Comme vous êtes probablement familier avec le jeu Flappy Bird, cet atelier vous expliquera comment créer votre propre version du jeu et la partager avec vos amis ! Dans ce tutoriel, nous apprendrons à utiliser le langage JavaScript pour aider l'oiseau à évoluer dans le monde que vous allez créer.

## Commencement

L'objectif de l'activité d'aujourd'hui est d'acquérir des compétences en JavaScript et d'intégrer vos nouvelles connaissances pour créer un jeu Flappy Bird ! Commençons par mettre le jeu en place.

Aujourd'hui, vous utiliserez Replit. Avant de commencer, vous devez vous inscrire à un compte Replit, si vous n'en avez pas encore.

Nous allons ignorer certains détails sur cet écran, mais nous allons passer en revue quelques notions de base qui s'affichent. Le fichier `index.html`, ainsi que tous les fichiers se terminant par `.js`, contiennent du code, ou des instructions à exécuter par l'ordinateur. En appuyant sur le bouton **run**, vous demandez à l'ordinateur d'exécuter les instructions du code. Tout résultat de l'exécution du code sera affiché sur la partie droite, appelée la **console**.

Si vous appuyez sur **run** maintenant, vous verrez que rien ne se passe ! Votre mission est d'aider Nuvi à compléter le code de ce jeu !

Toutes les activités sous les sections **Activity** seront effectuées dans cet onglet de navigateur. Vous réaliserez ces activités seul, mais de l'aide sera disponible en cas de blocage.
