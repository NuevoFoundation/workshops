## Utiliser Replit

Aujourd'hui, vous allez utiliser Replit pour apprendre à coder en Java. Avant de commencer, vous devrez créer un compte Replit, si vous n'en avez pas encore. 

Cliquez sur le bouton ci-dessous pour créer un compte Replit - vous aurez besoin d'une adresse e-mail pour vous inscrire. Si vous possédez déjà un compte Replit, vous pouvez également vous connecter à votre compte en utilisant le bouton ci-dessous.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Inscrivez-vous à Replit</a>

<img src="../images/replit-signup.png" height="300" alt="Formulaire d'inscription à Replit" />

Ensuite, lancez la console Replit que nous utiliserons aujourd'hui en cliquant sur le bouton ci-dessous. Vous devriez voir l'écran suivant.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaBasicsTest" target="_blank">Lancer Replit</a>

<img src="../images/replit-start-screen.png" height="300" alt="Écran de démarrage d'un Repl" />

Nous allons maintenant forker le Repl, ce qui signifie simplement que nous faisons une copie du programme, afin que nous puissions y apporter nos propres modifications. Cliquez sur le bouton "Fork Repl" en haut à droite, puis sur le bouton "Fork Repl".

<img src="../images/replit-fork.png" height="300" alt="Forker un Repl pour faire une copie du programme" />

Après avoir forké le Replit, vous verrez une fenêtre similaire à celle ci-dessous :

<img src="../images/replit-window.png" height="300" alt="Fenêtre Replit" />

{{% notice warning %}}
Chaque fois que vous voyez le bouton "Lancer Replit", vous devrez suivre les étapes ci-dessus pour forker le Repl afin de réaliser une activité. Demandez de l'aide si vous avez des difficultés à forker les Repls !
{{%/notice %}}

Avant de commencer, comprenons d'abord comment fonctionne la fenêtre. Le fichier `Main.java` contient du code, ou des instructions pour que l'ordinateur les exécute. En appuyant sur le bouton **run** (le bouton vert avec le triangle au milieu en haut de la fenêtre), vous demandez à l'ordinateur d'exécuter les instructions du code. Tous les résultats de l'exécution du code seront affichés dans la partie inférieure de l'écran, sous l'onglet **Console**.

Dans l'exercice sur les Objets et Classes, vous devrez passer du fichier `Main.java` au fichier `Birds.java`. Vous pouvez le faire en cliquant sur l'icône à droite qui ressemble à un document. Cela ouvrira le menu Fichiers et vous permettra d'accéder aux autres fichiers.

Essayez d'appuyer sur le bouton **run**. Si vous voyez **Let's learn Java!**, cela signifie que vous êtes prêt. Commençons !
