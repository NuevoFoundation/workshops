### Que fait le CSS ?
Le CSS (Cascading Style Sheets) contrôle à quoi ressemble votre application : les couleurs, les formes, les tailles et les animations. Sans CSS, votre application fonctionnerait de la même manière mais ressemblerait à du texte simple sans style.

Chaque section ci-dessous applique un style différent à un composant de votre application Costa Rica.
