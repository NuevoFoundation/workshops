## Utilisation de Playground

Nous allons utiliser l'outil PlayCode pour créer notre premier projet avec React. Ici, vous pouvez éditer du code en ligne.

Tout d'abord, nous devons comprendre le fonctionnement de PlayCode ou Playground. Vous pouvez créer des fichiers et des dossiers pour organiser votre code. C'est un éditeur de code qui se rafraîchit automatiquement, donc tout ce que vous écrivez sera mis à jour sans avoir besoin de recharger. Vous pouvez voir vos progrès en temps réel.
