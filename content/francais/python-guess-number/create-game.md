## Accepter une saisie utilisateur

Ce jeu utilisera certains des concepts que vous avez appris dans la section "Bases de Python".
Vous devrez savoir utiliser les concepts suivants. Si vous n'êtes pas familier avec l'un d'entre eux, veuillez revenir en arrière pour les revoir.
- <a href="../../python-basics/conditional-statements-loops/loops/" target="_blank">Les boucles While</a>
- <a href="../../python-basics/basics/writing-to-console/" target="_blank">Écrire dans la console</a>
- <a href="../../python-basics/basics/reading-from-console/" target="_blank">Lire depuis la console</a>
- <a href="../../python-basics/conditional-statements-loops/conditional-statements/" target="_blank">Les instructions conditionnelles</a>
- <a href="/python-guess-number/random/" target="_blank">Les nombres aléatoires</a>

Vous devrez coder ce jeu pour qu'il génère un nombre aléatoire.

Ensuite, le programme demandera de manière répétée une saisie à l'utilisateur via la console, et vous devrez comparer cette saisie avec le nombre généré aléatoirement.

Quel est le meilleur moyen de réaliser des tâches répétitives ? Vous avez deviné, les boucles !
Vous pouvez utiliser une boucle `while` pour accomplir cette tâche.

À l'intérieur de la boucle `while`, vous pouvez utiliser des instructions conditionnelles pour vérifier si le joueur a deviné correctement. Sinon, vous pouvez leur donner des indices utiles pour leur indiquer s'ils doivent deviner un nombre plus petit ou plus grand.
