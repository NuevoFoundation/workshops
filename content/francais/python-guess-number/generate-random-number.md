Python inclut une bibliothèque appelée `random` qui vous aide à générer des nombres aléatoires. Vous pouvez l'utiliser dans votre programme en écrivant `import random` au début de votre programme et en utilisant la fonction `randint` pour générer un nombre dans une plage donnée.

Cela générerait un nombre aléatoire entre 1 et 10.
```python
    random.randint(1,10)
```

Essayez d'exécuter le code ci-dessous plusieurs fois pour voir ce que vous obtenez !

{{% notice tip %}}
Vous pouvez aussi vous amuser à modifier la plage des nombres aléatoires. C'est amusant, essayez !
{{% /notice %}}
