## Avant Nuevo Eats...

<hr>

Pour commencer votre formation dans Nuevo Eats, vous devez d'abord apprendre quelque chose appelé **les structures de données** ! Ici, vous découvrirez tout ce que vous devez savoir pour vous lancer dans votre première Mission Nuevo Eats ! Commençons par les bases : qu'est-ce que c'est.

<hr>

## Les Structures de Données !

Les structures de données sont géniales et puissantes. Grâce au code, nous pouvons stocker de nombreuses informations dans des catégories organisées pour une utilisation ultérieure !

Stocker des éléments dans ces structures nous permet d'y accéder rapidement et efficacement - parfait pour Nuevo Eats ! Restaurants, aliments, employés et lieux ne sont que quelques exemples où nous pouvons utiliser les Structures de Données à notre avantage.

{{% notice tip %}}

Les structures de données peuvent stocker **n'importe quoi**, bien plus que ce que nous avons mentionné ci-dessus !  
Elles peuvent même contenir d'autres structures de données à l'intérieur de structures de données !

{{% /notice%}}

Il existe de nombreux types de structures de données (par exemple des Tableaux, ArrayLists, Files, Piles et Hashmaps), tout comme il existe de nombreuses façons d'organiser des jouets !

Maintenant que vous avez une petite idée de ce que c'est, appuyez sur Suivant pour découvrir comment vous pouvez utiliser cela pour faire de Nuevo Eats une réussite pour tout le monde !
