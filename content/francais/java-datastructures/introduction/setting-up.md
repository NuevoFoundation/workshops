## Configuration de Replit !

Aujourd'hui, vous utiliserez Replit pour apprendre les structures de données avec Java. Avant de commencer, vous devrez créer un compte Replit, si vous n'en avez pas encore. 

Cliquez sur le bouton ci-dessous pour créer un compte Replit - vous aurez besoin d'une adresse e-mail pour vous inscrire. Si vous avez déjà un compte Replit, vous pouvez vous connecter à votre compte en utilisant également le bouton ci-dessous.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Inscrivez-vous sur Replit</a>

<img src="../img/replit-signup.png" height="300" alt="Formulaire d'inscription Replit" />

Ensuite, lancez la console Replit que nous allons utiliser aujourd'hui en cliquant sur le bouton ci-dessous. Vous devriez voir l'écran ci-dessous.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/HelloWorld" target="_blank">Lancer Replit</a>

<img src="../img/replit-start-screen.png" height="300" alt="L'écran de démarrage d'un repl" />

Nous allons maintenant "forker" le Repl, ce qui signifie simplement faire une copie du programme, afin que nous puissions y apporter nos propres modifications. Cliquez sur le bouton "Fork Repl" en haut à droite, puis sur le bouton "Fork Repl".

<img src="../img/replit-fork.png" height="300" alt="Forker un repl pour en faire une copie" />

Après avoir forké le Replit, vous verrez une fenêtre similaire à celle-ci :

<img src="../img/replit-window.png" height="300" alt="Fenêtre Replit" />

{{% notice warning %}}
Chaque fois que vous voyez le bouton "Lancer Replit", vous devrez suivre les étapes ci-dessus pour forker le repl afin de compléter une activité. Demandez de l'aide si vous avez des difficultés à forker les repls !
{{%/notice %}}

Avant de commencer, comprenons d'abord comment fonctionne Replit. Le fichier `main.java` contient du code, ou des instructions que l'ordinateur doit exécuter. En appuyant sur le bouton **run**, vous demandez à l'ordinateur d'exécuter les instructions du code. Tous les résultats de l'exécution du code apparaîtront sur l'écran blanc en bas, sous l'onglet **result**.

Pour apprendre à coder les structures de données, nous utiliserons Replit pour tester vos compétences. Appuyez sur exécuter (*run*) et essayez de réaliser les tâches suivantes !
