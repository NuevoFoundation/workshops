## Variables

Avant de commencer cet atelier, vous devriez avoir une connaissance préalable du fonctionnement des variables en Java et savoir comment les créer. [Cliquez ici pour réviser l'atelier des bases du Java !](https://workshops.nuevofoundation.org/java-basics/) Ne vous inquiétez pas si vous vous sentez encore un peu incertain ! Nous vous introduirons progressivement aux sujets abordés. Cependant, si vous n'avez aucune idée de ce que sont les variables, nous vous recommandons fortement de terminer l'atelier des bases du Java au préalable.
