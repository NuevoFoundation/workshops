## Tâche 1 : Trouvez le coût moyen !

Supposons que nous avons un tableau contenant les coûts de divers aliments. Trouvez le coût moyen de l'alimentation !

{{% notice tip %}}
1. Vous pouvez utiliser une boucle `for` pour parcourir le tableau !
2. N'oubliez pas, la moyenne d'une liste est le total divisé par le nombre d'éléments.
{{% /notice%}}

## Tâche 2 : Trier un tableau !

Le coût de chaque élément du menu est désordonné ! Aidez-nous à trier le tableau du moindre au plus grand.

{{% notice tip %}}
1. Pensez à une façon de trier le tableau (il y a plusieurs méthodes pour y parvenir) !
2. Regardez l'exemple !
{{% /notice%}}

Si nous disposons du tableau ci-dessous, 
```js javascript
int[] cost = {100,90,50,60,20,1,3};
```

nous devrions obtenir la sortie suivante :
```js javascript
int[] sorted = {1,3,20,50,60,90,100};
```
