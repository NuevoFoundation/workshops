## Visualiser une Pile

Une pile est très similaire à une file d'attente, et de nombreux concepts que vous avez appris sur une file d'attente peuvent être appliqués à une pile. Contrairement à la file d'attente avec la logique FIFO, une pile est différente car elle utilise la logique opposée, LIFO (Dernier Entré, Premier Sorti).

Un exemple courant pour penser à une pile est une pile d'assiettes. Imaginez 5 assiettes empilées les unes sur les autres. Si vous ajoutez une sixième assiette sur le dessus de la pile, votre pile d'assiettes devient une pile de 6. Cependant, que se passe-t-il si vous souhaitez retirer une assiette ? Eh bien, vous ne chercheriez pas à prendre une assiette au bas de la pile ; vous prendriez une assiette sur le dessus.

Cette logique Dernier Entré, Premier Sorti (LIFO) s'applique également aux piles en Java.
