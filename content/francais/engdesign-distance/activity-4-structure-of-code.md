Rappelons que la structure principale de tout code consiste à suivre une série d'étapes pour obtenir une solution. Nos étapes incluent l'intégration de certaines valeurs numériques, la sélection d'un choix parmi un certain nombre d'options, etc. Chaque décision que vous prenez à chaque étape aura des résultats significatifs à la fin du code. Chaque étape sera intégrée dans un calcul, qui fournira ensuite la taille du diamètre en fonction de vos choix. De plus, notre solution consiste à obtenir un diamètre pour notre arbre de transmission et à vérifier ensuite si le diamètre choisi constitue un bon choix de conception.

Un code est déjà fourni pour vous, et votre tâche principale est d'utiliser ce code comme un outil pour déterminer le diamètre de votre arbre de transmission en fonction de toutes les décisions que vous prendrez. Les choix sont divisés en 5 étapes principales.

1) Entrer le facteur de sécurité
2) Sélectionner un matériau pour votre arbre de transmission
3) Déterminer les conditions pour votre arbre
4) Insérer la quantité de charge que votre arbre devra supporter
5) Choisir la géométrie de votre arbre

Ne vous inquiétez pas, toutes ces étapes seront expliquées dans la section suivante.
