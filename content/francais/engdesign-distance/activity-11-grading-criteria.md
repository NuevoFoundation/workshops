Félicitations ! Vous avez réalisé votre première expérience avec MATLAB ! Si vous souhaitez redessiner votre arbre, n'hésitez pas à recommencer et essayez de viser la première place ! Dans la fenêtre de commande, vous pouvez faire un clic droit, puis sélectionner Effacer la fenêtre de commande dans le menu déroulant. Cela effacera tout. Vous pouvez ensuite relancer le code dans l'éditeur comme vous l'avez fait la première fois.
