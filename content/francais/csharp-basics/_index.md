## Vue d'ensemble

Bienvenue dans le cours **C# : Bases**, où vous apprendrez un langage de programmation de haut niveau très répandu, conçu pour donner des instructions aux ordinateurs afin de créer des programmes captivants !

Le langage de programmation C# a été conçu par Anders Hejlsberg de Microsoft en 2000. Au moment où ce cours a été conçu, la version stable la plus récente du langage est C# 11.0, sortie en 2022.

{{% notice info %}}
Un langage de programmation de haut niveau est qualifié de "haut niveau" car il se situe à plusieurs étapes au-dessus du code d'origine exécuté sur l'Unité Centrale de Traitement (CPU) de l'ordinateur. Le code de haut niveau est destiné à être utilisé par les humains et est bien plus facile à comprendre que le code de bas niveau. Ce code est ensuite traduit en un langage de bas niveau, qui peut uniquement être perçu et exécuté par un CPU spécifique. Pour que le code fonctionne, chaque ligne de code écrite dans un langage de haut niveau doit être traduite en langage machine avant d'être exécutée par l'ordinateur.
{{% /notice %}}

C# est l'un des langages de programmation les plus populaires au monde, aux côtés de Java, JavaScript, Python et d'autres. C# peut s'exécuter sur n'importe quel ordinateur, y compris sur Windows, Mac, et les systèmes d'exploitation Linux.
