### Utiliser .NET Fiddle
Aujourd'hui, vous allez utiliser .NET Fiddle pour apprendre à programmer en C#.

Avant de commencer, comprenons d'abord comment fonctionne la fenêtre. Sur le côté gauche, vous avez une liste d'options. Celles-ci ont toutes été configurées pour vous, donc vous n'avez pas besoin de vous en soucier. Au centre de l'écran se trouve le code, ou des instructions pour que l'ordinateur les exécute. En appuyant sur le bouton **Exécuter** (le bouton avec un triangle au milieu, en haut du cadre), vous demandez à l'ordinateur d'exécuter les instructions contenues dans le code. Les résultats de l'exécution du code seront affichés au bas de l'écran.

<img src="../images/donetfiddle-overview.png" height="300" alt="Disposition de la fenêtre .NET Fiddle" />

Passez un peu de temps à vous familiariser avec l'outil ci-dessous.

<iframe width="100%" height="475" src="https://dotnetfiddle.net/Widget/ccWNBp" title="Aperçu interactif de l'éditeur .NET Fiddle" frameborder="0"></iframe>

### Quelques conseils sur le C#

Quelques conseils importants :
1. Chaque ligne de code se termine par un point-virgule `;`
2. Il y aura du code dans les exemples que vous ne comprenez pas. Ce n'est pas grave, ignorez-le pour l'instant et concentrez-vous sur la tâche que vous devez accomplir.

## Sauvegarder votre travail

Si vous souhaitez sauvegarder votre travail tout au long de ces exercices, vous devrez créer un compte .NET Fiddle, si vous n'en avez pas encore un.

Cliquez sur le bouton ci-dessous pour créer un compte .NET Fiddle - vous aurez besoin d'une adresse e-mail pour vous inscrire. Si vous avez déjà un compte .NET Fiddle, vous pouvez vous connecter à votre compte en utilisant le bouton ci-dessous.

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/SignUp" target="_blank">Créer un compte .NET Fiddle</a>

<img src="../images/dotnetfiddle-signup.png" height="300" alt="Formulaire d'inscription .NET Fiddle" />

Ensuite, vous pouvez maintenant *forker* le Fiddle, ce qui signifie simplement créer une copie du programme, afin que nous puissions apporter et sauvegarder nos propres modifications. Cliquez sur le bouton "Fork" en haut.

Après avoir forké le Fiddle, vous verrez une fenêtre similaire à celle ci-dessous :

<img src="../images/dotnetfiddle-window.png" height="300" alt="Fenêtre .NET Fiddle" />
