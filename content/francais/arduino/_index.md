## Introduction - Construire avec Arduino

Les composants électroniques comme les microcontrôleurs, les capteurs, et tous types de circuits sont partout autour de nous ! Certains sont très basiques et fournissent des informations de télémétrie pour les systèmes de trafic. D'autres gèrent les feux de circulation programmés avec une temporisation intégrée.

Aujourd'hui, nous travaillerons sur quelques activités pour montrer les capacités de cette plateforme. Nous commencerons petit et simple pour développer ensuite des projets plus grands et plus complexes. Vous apprendrez toutes les informations de base sur la manière d'utiliser la carte contrôleur Arduino, les capteurs, et les composants. Après avoir complété chaque activité, n'hésitez pas à modifier certains éléments pour constater les différences et approfondir votre compréhension.

## Les Composants

Les composants que nous utiliserons pour le projet sont présentés ci-dessous. Assurez-vous d'avoir tous ces composants avant de commencer :

![Texte alternatif : Photo du kit de démarrage Elegoo UNO](img/Elegoo-starter-kit.png)

Le kit de projet `Elegoo` UNO Super Starter avec tutoriel pour Arduino inclut tout le matériel (à l'exception de l'ordinateur).

* Composants principaux nécessaires pour toutes les activités :
  * Arduino UNO R3
  * Câble USB A vers B
  * PC Windows 10
  * Logiciel Arduino IDE (téléchargement)

* Composants additionnels nécessaires pour des activités spécifiques :
  * (5) LEDs (de n'importe quelle couleur)
![Texte alternatif : Photo de LEDs aux couleurs de l'arc-en-ciel](img/colorful_LEDs.jpg)
  * (5) [résistances de 220 ohms](https://somanytech.com/220-ohm-resistor-color-code)
![Photo des bandes de couleur sur une résistance de 220 Ohms](img/220OhmResistor.jfif)
  * Câbles de connexion (jumper wires)
![Texte alternatif : Image d'un stock de câbles de connexion pour breadboard](img/jumperWires.png)
  * Câble de type femelle-vers-mâle
![Texte alternatif : Image d'un câble](img/DupontWire.png)
  * Écran LCD + résistance de 5K ohms
  * Batterie 9V (optionnelle)
