## Lancez le Jeu
Appuyez sur le bouton de lecture (►) en haut d'Android Studio pour démarrer le jeu.
<img src="../resources/_gen/images/run_app.png" height="30%" width="30%" title="Bouton pour exécuter l'application" alt="Bouton pour exécuter l'application"/>

Vous verrez que le titre en haut de l'application indique Toe-Tac-Tic (cela ne semble pas correct !) ; modifions-le pour afficher Tic-Tac-Toe.

## Résolvez l'Énigme
Double-cliquez sur le fichier `strings.xml` sous app &rarr; res &rarr; values :
<img src="../resources/_gen/images/open_strings_file.gif" height="30%" width="30%" title="Emplacement du fichier Strings.xml" alt="Montre comment naviguer vers strings.xml dans Android Studio"/>
