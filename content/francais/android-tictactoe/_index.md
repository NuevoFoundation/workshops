## Pour bien commencer

## Qu'est-ce qu'Android ?

Android est actuellement le système d'exploitation mobile le plus utilisé au monde ! Android Studio vous permet de créer des applications utilisables sur ces appareils Android. En fait, si vous avez un téléphone Android, vous pouvez même télécharger l'application que vous créez aujourd'hui directement sur votre téléphone !

## À propos de ce projet

Dans ce projet, nous vous proposons une application Android presque fonctionnelle qui est un jeu de Tic-Tac-Toe. Elle a besoin de votre aide pour résoudre certains problèmes et ajouter quelques éléments pour en faire un excellent jeu !

## Téléchargez les fichiers du projet
Pour commencer, téléchargez les fichiers du projet en suivant les étapes ci-dessous :
1. [Téléchargez les fichiers du projet](resources/_gen/files/TicTacToe.zip) pour votre jeu.
2. Trouvez le fichier TicTacToe.zip dans votre dossier de téléchargements.
3. Décompressez le fichier.
   - Sur Windows : Cliquez avec le bouton droit sur TicTacToe.zip et sélectionnez `Extraire tout...`. Un dossier nommé 'TicTacToe' sera créé, contenant le code du projet.

Dans cette aventure, vous devrez résoudre les énigmes marquées par des étiquettes `PUZZLE` pour compléter le jeu !
