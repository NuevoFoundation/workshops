Bien joué ! Vous l'avez fait !

Ensuite, vous pouvez expérimenter un peu avec ce jeu de données.

- Essayez de sélectionner des joueurs à une autre position, par exemple, gardien de but ("GK"). Quelles caractéristiques seront les plus corrélées ? Quelles caractéristiques allez-vous sélectionner ?
- Modifiez les caractéristiques que vous avez sélectionnées, cela changera-t-il les résultats de la prédiction du modèle ?
- Changez le ratio des données d'entraînement/de test, observez ce qui se passe.
- Modifiez la variable cible, par exemple 'Valeur' ou 'Salaire'. Essayez de comprendre comment convertir le contenu en valeur numérique.
  - indice : 50k = 50 * 1000, 10M = 10 * 1000 * 1000.

Dans le cours d'aujourd'hui, vous avez appris à entraîner un modèle de régression linéaire afin d'estimer les notes globales d'un joueur de football. Nous espérons que vous avez apprécié et que cela vous a un peu inspiré.

Désormais, vous pouvez explorer le site [kaggle](http://kaggle.com), essayer de trouver un autre jeu de données à explorer. Appliquez la régression linéaire pour prédire/estimer les résultats. Vous serez étonné par ce que vous pouvez accomplir. 👏🏽👏🏽👏🏽
