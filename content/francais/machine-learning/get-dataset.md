FIFA 2019 est un jeu vidéo de football. Tous les joueurs de ce jeu ont une note globale, ainsi que de nombreuses caractéristiques telles que les passes, les frappes, etc.

Nous nous dirigeons vers le site appelé kaggle.com pour obtenir notre jeu de données.

[Jeu de données FIFA19](https://www.kaggle.com/karangadiya/fifa19/)

<br>
 *Remarque : il se peut que vous deviez vous inscrire pour obtenir le lien de téléchargement*.
<br>

Sur cette page, vous pouvez trouver de nombreuses informations sur ce jeu de données. Prenez un peu de temps pour les parcourir et vous familiariser avec le jeu de données.
![kaggle_fifa_dataset.png](../images/kaggle_fifa_dataset.png)

Une fois que vous l'avez téléchargé, extrayez le fichier zip dans un dossier, disons `C:\fifa_dataset\`.
