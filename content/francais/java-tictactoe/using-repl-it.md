## Utilisation de Replit

Aujourd'hui, vous allez utiliser Replit pour apprendre à coder en Java. Avant de commencer, vous devrez vous inscrire à un compte Replit si vous n'en avez pas déjà un. 

Cliquez sur le bouton ci-dessous pour vous inscrire à un compte Replit - vous aurez besoin d'une adresse e-mail pour vous inscrire. Si vous avez déjà un compte Replit, vous pouvez vous connecter à votre compte en utilisant également le bouton ci-dessous.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Inscrivez-vous à Replit</a>

<img src="../images/replit-signup.png" height="300" alt="Formulaire d'inscription Replit" />

Ensuite, lancez la console Replit que nous allons utiliser aujourd'hui en cliquant sur le bouton ci-dessous. Vous devriez voir l'écran suivant.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaTicTacToeStarterCode" target="_blank">Lancer Replit</a>

<img src="../images/replit-start-screen.png" height="300" alt="Écran de démarrage d'un repl" />

Nous allons maintenant dupliquer le Repl, ce qui signifie simplement faire une copie du programme, afin que nous puissions y apporter nos propres modifications. Cliquez sur le bouton "Fork Repl" en haut à droite, puis sur le bouton "Fork Repl".

<img src="../images/replit-fork.png" height="300" alt="Duplication d'un repl pour faire une copie du programme" />

Après avoir dupliqué le Repl, vous verrez une fenêtre similaire à celle ci-dessous :

<img src="../images/replit-window.png" height="300" alt="Fenêtre Replit" />

{{% notice warning %}}
Chaque fois que vous voyez le bouton "Lancer Replit", vous devrez suivre les étapes ci-dessus pour dupliquer le repl afin de compléter une activité. Demandez de l'aide si vous rencontrez des difficultés pour dupliquer les repls !
{{%/notice %}}

{{% notice info %}}

Avant de commencer, comprenons d'abord comment fonctionne cette fenêtre. Le fichier `Main.java` contient le code, ou les instructions que l'ordinateur doit exécuter. En appuyant sur le bouton **run**, vous demandez à l'ordinateur de suivre les instructions du code. Tous les résultats de l'exécution du code s'afficheront sur l'écran du bas, sous l'onglet **Console**.

{{% /notice %}}

Cliquez sur l'icône à côté du bouton `Run` qui indique `open in Replit`. Ce sera la fenêtre où vous taperez tout le code pour le programme TicTacToe. Amusez-vous bien !
