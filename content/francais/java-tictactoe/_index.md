## Aperçu

Dans ce workshop, vous apprendrez à créer un programme de Tic-Tac-Toe en Java, de A à Z !

Vous aurez besoin des notions de base en Java des ateliers [Java : Bases](../java-basics) car nous supposerons que vous connaissez les variables, opérateurs, classes et tableaux pendant les exercices.

Il y aura également des liens vers les sujets pertinents sur Java à chaque page si vous souhaitez réviser un concept spécifique !
