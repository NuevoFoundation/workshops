Bienvenue dans le Canyon des Conflits, intrépide développeur ! Ce terrain périlleux est le refuge des conflits de fusion, prêts à défier même les programmeurs les plus chevronnés. Mais ne craignez rien, car avec les bons outils et les connaissances adéquates, vous naviguerez parmi ces obstacles avec aisance.

### Le défi des conflits de fusion

Imaginez que vous travaillez sur un projet avec votre équipe. Vous avez pour mission de mettre à jour le site web du projet, mais lorsque vous essayez de pousser vos modifications, vous vous heurtez à un conflit de fusion. C'est ici que vos compétences seront mises à l'épreuve !

### Comprendre les Issues GitHub

Avant de plonger dans la résolution des conflits, explorons un outil crucial dans le codage collaboratif : les Issues GitHub. Ceux-ci ne sont pas simplement des rapports de bogues ; ce sont un centre de communication pour votre projet.

### Quiz : Quel est le but des étiquettes dans les Issues GitHub ?

Prenez un moment pour examiner les options suivantes :

1. Attribuer des issues aux membres de l'équipe  
2. Fixer des dates d'échéance pour les issues  
3. Catégoriser et filtrer les issues  

Réfléchissez à la manière dont vous avez utilisé GitHub dans vos projets. Laquelle de ces fonctions semble la plus alignée avec l'objectif des étiquettes ?

Lorsque vous êtes prêt, choisissez votre réponse. N'oubliez pas, il n'y a qu'une seule option correcte !

**La bonne réponse est : 3. Catégoriser et filtrer les issues**

Les étiquettes dans les Issues GitHub sont des outils puissants pour organiser votre projet. Elles permettent d'identifier rapidement le type d'issue (bogue, amélioration, question), sa priorité, ou la partie du projet qu'elle concerne. Cette catégorisation facilite la gestion des grands projets comprenant de nombreuses issues.

### Activité pratique : Créer une issue

Maintenant que vous comprenez l'intérêt des étiquettes, mettons cette connaissance en pratique :

1. Accédez au dépôt GitHub d'un de vos projets.  
2. Allez dans l'onglet "Issues".  
3. Cliquez sur "New Issue".  
4. Donnez à votre issue un titre lié à une fonctionnalité que vous aimeriez ajouter ou à un bogue que vous avez remarqué.  
5. Dans la description, fournissez des détails sur l'issue. Rappelez-vous d'être clair et concis !  
6. Sur le côté droit, vous verrez des options pour ajouter des étiquettes. Choisissez au moins une étiquette adaptée pour votre issue.  
7. Soumettez l'issue.
