Vous entrez dans une salle remplie de tableaux kanban flottants et de chronologies de projets. Une voix apaisante annonce : "Apportez de l'ordre au chaos, planifiez votre évasion !"

## Votre mission

1. Créez un nouveau tableau de projet dans votre repository GitHub.
2. Ajoutez des colonnes pour "À faire", "En cours" et "Terminé".
3. Créez quelques issues et ajoutez-les à votre tableau de projet.
4. Déplacez une issue entre les différentes colonnes.

## Instructions

1. Accédez à votre repository GitHub.
2. Cliquez sur l'onglet "Projets".
3. Cliquez sur "Nouveau projet" et choisissez "Tableau" comme modèle.
4. Ajoutez les colonnes nécessaires à votre tableau.
5. Créez quelques issues dans votre repository.
6. Ajoutez ces issues à votre tableau de projet.
7. Déplacez une issue dans chaque colonne de votre tableau.

{{< notice info >}}
**Astuce :** Les tableaux de projet sont excellents pour visualiser votre flux de travail et suivre l'avancement de multiples issues ou pull requests.
{{< /notice >}}

{{< expand "Processus du tableau de projet" >}}
**Créer un tableau**
1. Accédez à l'onglet "Projets"
2. Cliquez sur "Nouveau projet"
3. Choisissez le modèle "Tableau"
4. Ajoutez les colonnes : "À faire", "En cours", "Terminé"

**Ajouter des issues**
1. Accédez à l'onglet "Issues"
2. Créez de nouvelles issues
3. Dans chaque issue, cliquez sur "Projets" et ajoutez-les à votre nouveau tableau

**Déplacer les issues**
1. Retournez à votre tableau de projet
2. Glissez-déposez les issues entre les colonnes
3. Observez comment cela reflète la progression de vos tâches
