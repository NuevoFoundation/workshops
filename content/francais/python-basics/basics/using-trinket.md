Avant de commencer, comprenons d'abord comment fonctionne la fenêtre. Le fichier `main.py` contient du code, ou des instructions pour que l'ordinateur les exécute. Tout ce qui résulte de l'exécution du code sera affiché sur le côté droit. Cette fenêtre qui affiche le résultat est appelée la console.

Appuyez sur **exécuter** et regardez votre console exécuter votre code sur l'écran à droite ! Dans l'exemple ci-dessous, `print` demande à l'ordinateur d'afficher la phrase entre les parenthèses `()` dans la console, ou sur l'écran à droite. Apprenez-en davantage sur `print` dans les leçons suivantes.
