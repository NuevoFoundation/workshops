Lors de la création d'un programme Python, nous pouvons ajouter des notes en utilisant des commentaires sur une seule ligne avec `#`. **Les commentaires** sont des parties du code qui n'affectent pas le programme. Tout ce qui se trouve après le symbole `#` fait partie du commentaire et est ignoré par votre code. Les commentaires sont introduits dans le code pour expliquer aux lecteurs ce que fait le code. Ils peuvent faciliter la maintenance du code et également aider à trouver des bugs.

Si à tout moment, en écrivant du code, vous souhaitez noter des indications pour mieux comprendre le code, utilisez le symbole `#` pour créer un commentaire.

```python
# C'est ma première ligne de code
print("Bonjour, le monde !")
```

![Capture d'écran montrant le commentaire C'est ma première ligne de code.](../../img/comments.png "une image illustrant comment écrire des commentaires en python")

Attention, si vous retirez le symbole `#`, votre code ne fonctionnera pas !

![Capture d'écran montrant la suppression du # avant le commentaire, entraînant une erreur d'exécution du code](../../img/comments_wrong.png "une image d'un commentaire incorrect") 

Essayez d'ajouter un commentaire au-dessus de votre première ligne de code et appuyez sur exécuter. Vous verrez que l'ordinateur ignorera votre commentaire.
