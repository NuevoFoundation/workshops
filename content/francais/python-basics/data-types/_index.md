## Aperçu

En programmation, les types de données sont un concept important. Les variables peuvent stocker des données de différents types, et chaque type peut effectuer différentes actions.

Python possède les types de données suivants intégrés par défaut, classés dans ces catégories :

**Type** | **Exemple**
---------|-------------
Texte |	str
Numérique | int, float, complex
Séquence | list, tuple, range
Mappage | dict
Ensemble | set, frozenset
Booléen | bool
Binaire | bytes, bytearray, memoryview
Aucun | NoneType

Dans cette section, nous allons nous concentrer sur les chaînes de caractères, les nombres et les booléens. C'est parti !
