## Vue d'Ensemble

Dans la section précédente, vous avez appris les instructions conditionnelles et les boucles. Dans cette section, nous allons introduire différentes structures de données. Une structure de données est une méthode d'organisation et de stockage des données et informations de manière à ce qu'un utilisateur puisse les utiliser efficacement. En Python, il existe trois principales structures de données que nous allons explorer et utiliser tout au long de cette section : Listes, Tuples et Ensembles.
