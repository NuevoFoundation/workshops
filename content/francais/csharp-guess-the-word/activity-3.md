## Activité 3

Cette activité est divisée en 2 parties et testera vos connaissances sur les variables. Avant de commencer, cherchez `HINT (ACTIVITY 3)` dans le code, où nous déclarons une variable appelée `lives` qui stocke le nombre de vies qu'il reste au joueur, et utilisez cette variable pour afficher le nombre de vies dont dispose le joueur au début du jeu. Cela devrait vous donner une idée pour compléter les deux parties suivantes.

### Activité 3.1

Au début du jeu, nous devons informer le joueur du nombre de lettres contenues dans le mot à deviner. Par exemple, si le mot à deviner est `"Hello"`, nous devons dire au joueur : `Le mot contient 5 lettres`. Si le mot à deviner est `"Foundation"`, nous devons dire au joueur : `Le mot contient 10 lettres`. Nous avons déjà stocké le nombre de lettres dans la variable `numberOfLetters`, donc utilisez-la pour compléter cette activité.

Pour vérifier si vous avez correctement terminé cette activité, appuyez sur **run**, et assurez-vous de voir `Le mot contient 5 lettres` (ou un autre nombre différent de 5) dans la console.

### Activité 3.2

Il y a deux autres informations que nous devons demander à l'ordinateur de stocker :

- Le nombre de lettres que le joueur a correctement devinées jusqu'à présent.
- Si oui ou non le joueur a gagné la partie.

Nous allons déclarer deux variables pour représenter ces informations. Appuyez sur **run** pour vérifier qu'aucune erreur n'apparaît dans la console. N'oubliez pas que les variables ne produisent pas de sortie dans la console, donc pour cette partie, nous vérifions uniquement l'absence d'erreurs.
