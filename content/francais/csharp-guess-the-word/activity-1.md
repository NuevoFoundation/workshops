## Instructions

Accédez au code du jeu [GuessTheWord](https://dotnetfiddle.net/lMl7j4). Appuyez sur **Exécuter**. Remarquez que `Appuyez sur 'Exécuter' en haut de l'écran pour jouer à nouveau.` est la seule chose qui s'affiche sur la console. Ajoutons un message de bienvenue pour que le joueur sache qu'il joue au jeu Guess the Word.

Trouvez `// TODO (ACTIVITY 1)` dans le code. Ajoutez une ligne de code pour afficher Bienvenue dans C# GuessTheWord sur la console. Si vous avez correctement effectué cette étape, `Bienvenue dans C# GuessTheWord` s'affichera sur la console après avoir appuyé sur **Exécuter**.
