## Mise en Route

L'objectif de l'activité d'aujourd'hui est d'apprendre des compétences en C# et d'incorporer vos nouvelles connaissances pour créer un jeu "Devine le Mot" ! Préparons le jeu.

Aujourd'hui, vous utiliserez .NET Fiddle, un outil en ligne conçu pour vous aider à apprendre, construire et exécuter du code C#.

{{% notice tip %}}
Avant de commencer, vous pouvez choisir de créer un compte .NET Fiddle, si vous n'en avez pas encore et si vous souhaitez sauvegarder votre travail plus tard.

Cliquez sur le bouton ci-dessous pour créer un compte .NET Fiddle - vous aurez besoin d'un compte email pour vous inscrire. Si vous avez déjà un compte .NET Fiddle, vous pouvez vous connecter à l'aide du bouton ci-dessous également.

{{% /notice %}}

Ensuite, lancez la console .NET Fiddle que nous utiliserons aujourd'hui en cliquant sur le bouton ci-dessous. Vous devriez voir l'écran suivant.

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/lMl7j4" target="_blank">Lancer .NET Fiddle</a>

Si vous êtes connecté, vous pouvez dupliquer le Fiddle, ce qui signifie simplement faire une copie du programme, afin que nous puissions y apporter nos propres modifications et l'enregistrer. Cliquez sur le bouton "Fork" en haut.

<img src="./media/dotnetfiddle-fork.png" height="300" alt="Dupliquer un fiddle pour faire une copie du programme" />

Après avoir dupliqué le Fiddle, vous verrez une fenêtre semblable à celle ci-dessous :

<img src="./media/guessTheWordActivity-fork.png" height="300" alt="Fenêtre .NET Fiddle" />

{{% /notice %}}

Nous ignorerons certains détails sur cet écran, mais nous passerons en revue quelques notions de base qui y apparaissent. Le fichier `main.cs` contient du code, ou des instructions pour que l'ordinateur les exécute. En appuyant sur le bouton **run**, vous dites à l'ordinateur d'exécuter les instructions du code. Tous les résultats de l'exécution du code seront affichés sur la droite, appelée la **console**.

Si vous appuyez sur **run** maintenant, vous verrez que rien ne se passe ! Votre tâche est d'aider Nuvi à compléter le code pour ce jeu !

Toutes les activités sous les sections **Activity** seront réalisées dans cet onglet du navigateur. Vous effectuerez ces activités par vous-même, mais de l'aide est disponible si vous êtes bloqué.
