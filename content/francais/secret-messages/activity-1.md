Nous devons d'abord entrer un message pour que notre programme puisse créer des messages secrets.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/activity-1-english" target="_blank">Lancer Replit</a>

Pour ce faire, nous allons commencer par dire à l’ordinateur d’afficher dans la console à qui est destiné ce message. Voici la commande que nous allons utiliser.

```
cout << "Hello Developer!" << endl;
```

Apprenons-en davantage sur cette ligne de code, d'accord ?

{{% notice tip %}}

### Chaînes de caractères

Tout ce qui est entouré de guillemets (`""`) est appelé des **chaînes**. Une chaîne est une séquence de caractères, de chiffres, de lettres ou de symboles.

Dans la ligne de code que nous avons écrite précédemment, `"Hello Developer!"` est une chaîne. `"123"`, `"abc!"` ou `"Hello"` sont également des exemples de chaînes. Cependant, `123`, `abc!` ou `Hello!` ne sont pas des chaînes car ils ne sont pas entourés de guillemets.

### Afficher dans la console

Pour afficher dans la console, nous utilisons `cout`. Chaque `cout` sera suivi de `<<`, tandis que `endl` signifie que nous avons atteint la fin de la ligne. Tout ce qui est enveloppé par `<<` sera imprimé dans la console. Dans notre cas, si nous cliquons sur **Exécuter**, la chaîne `Hello Developer!` sera imprimée dans la console.

{{% /notice %}}

Copiez la ligne ci-dessus et collez-la dans le fichier `main.cpp` que nous avions au départ. **Exécutez** le programme et voyez ce qu’il se passe. Essayez de changer la chaîne par `"Hello world!"` ou `"Pour la reine"`.
