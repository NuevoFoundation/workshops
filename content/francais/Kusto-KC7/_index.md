## Introduction : Apprenez à Attraper le Hacker !

<img src="https://github.com/bgrant34/workshops/blob/master/content/english/kusto-kc7/Images/KC7Logo.png?raw=true" alt="logo" height="20%">

### Bienvenue, nouveaux Défenseurs Cyber ! 
*--- Le renseignement sur les menaces est pour tout le monde*
Apprenez la Cybersécurité en utilisant des données réelles sur les menaces.
**KC7 est un jeu qui vous enseigne des compétences réelles en cybersécurité**
>KC7 simule une intrusion par plusieurs acteurs de menaces cybernétiques contre une entreprise fictive et vous apprend à identifier les activités des adversaires à travers les sept phases de la Cyber Kill Chain en utilisant des données réalistes.

À la fin de votre première journée de travail, vous devriez être capable de : 
-  Utiliser le langage de requête Kusto (KQL) pour manipuler les données dans Azure Data Explorer (ADX)  
-  Utiliser plusieurs ensembles de données pour répondre à des questions ciblées  
-  Détecter des activités cybernétiques dans les journaux, y compris : emails, trafic web et journaux de serveurs  
-  Utiliser plusieurs techniques pour suivre l'activité des APTs ( menaces persistantes avancées)  
-  Utiliser des ensembles de données tiers pour découvrir des informations sur vos attaquants   
-  Construire un rapport d'intelligence sur les menaces    
-  Faire des recommandations sur les actions qu'une entreprise peut prendre pour se protéger    

Si vous êtes un formateur, veuillez commencer par le bloc **T3 : Introduction au Programme de Formation des Formateurs** avant de participer à l'atelier. Si vous êtes un élève, passez directement à **Activité 1 : Connexion et Configuration de l'Environnement Cyber**

{{% notice warning %}}
Veuillez ne pas utiliser le navigateur Firefox pour cet atelier.
{{% /notice%}}


{{% notice warning %}}
Notez que le KQL, comme la plupart des langages de programmation, est sensible à la casse. Gardez cela à l'esprit lorsque vous travaillez dans Azure Data Explorer (ADX). Cependant, le tableau de score du jeu Cyber Defender n'est PAS sensible à la casse.
{{% /notice%}}
