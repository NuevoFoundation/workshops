[EarSketch](https://en.wikipedia.org/wiki/EarSketch) est un environnement de programmation éducatif gratuit développé par le Georgia Institute of Technology. Nous allons composer de la musique avec EarSketch aujourd'hui.

1. Pour créer de la musique, cliquez sur le bouton ci-dessous pour ouvrir Earsketch dans un nouvel onglet.

<a class="my-2 mx-4 btn btn-info" href="https://earsketch.gatech.edu/earsketch2/" target="_blank">Lancer Earsketch</a>

2. Après avoir ouvert la page web, vous pourriez voir l'écran de bienvenue suivant. Appuyez sur "skip" pour passer le tour - nous couvrirons toutes les étapes nécessaires ci-dessous.

<img src="../img/screenshot-skip-tour.png" height="400"/>

3. Passons maintenant à l'action. Cliquez sur l'icône *Scripts* dans la barre de menu à gauche et sélectionnez *+ New Script*.

<img src="../img/screenshot-new-script.png" height="400"/>

4. Entrez *myjam* (ou un autre nom de votre choix) comme nom de votre script et gardez le langage de programmation comme *Python*. Cliquez sur le bouton *Create* pour créer votre script (le fichier où votre code sera placé).

<img src="../img/screenshot-new-myjam.png" height="200"/>

## Recommandé pour les enseignants - Vue d'ensemble d'EarSketch

Veuillez consulter la vue d'ensemble d'EarSketch avant de commencer avec la classe. Il est important de savoir comment naviguer dans l'interface utilisateur.

Le `Content Manager` sur le côté gauche de l'écran est votre point de départ pour parcourir tout ce que EarSketch offre.

1. Le premier élément de la barre de navigation est la collection `Sounds`. C'est l'emplacement central pour tous les sons préchargés que propose EarSketch. Dans le navigateur de sons, vous pouvez filtrer les sons affichés en fonction des artistes, des genres ou des instruments.

<img src="../img/screenshot-navigation-sound-browser.png" height="400"/>

2. La prochaine icône de la barre de navigation est le volet `Scripts`. C'est ici que nous écrirons notre code.

<img src="../img/screenshot-navigation-script.png" height="400"/>

3. La dernière icône sur la barre de navigation est le volet `API Browser`. Une *Application Programming Interface* ou *API* est un ensemble de code prêt à être utilisé immédiatement ! Lorsque vous cliquez dessus, une explication détaillée de chaque API est fournie.

<img src="../img/screenshot-navigation-api-curriculum.png" height="400"/>

Sur le côté droit, vous verrez le guide de `Curriculum`. Si vous souhaitez en savoir plus sur EarSketch, vous pouvez explorer la section qui apparaît sur le côté droit de la fenêtre lorsque vous cliquez dessus. Nous passerons cette section pour cet exercice.
