# Notions de Base en Python

Pour coder de la musique, nous devons apprendre un peu de Python. Ne vous inquiétez pas, il ne vous mordra pas. Python est l'un des langages que nous, les humains, utilisons pour dire aux ordinateurs quoi faire. Ces langages sont appelés "langages de programmation". Nous allons apprendre des concepts Python tout au long du cours, mais commençons par une simple instruction print.
