[EarSketch](https://en.wikipedia.org/wiki/EarSketch) est un environnement de programmation éducatif gratuit développé à l'Institut de Technologie de Georgia. Aujourd'hui, nous allons composer de la musique avec EarSketch.

1. Pour créer de la musique, cliquez sur le bouton ci-dessous pour ouvrir EarSketch dans un nouvel onglet.

<a class="my-2 mx-4 btn btn-info" href="https://earsketch.gatech.edu/earsketch2/" target="_blank">Lancer Earsketch</a>

2. Après avoir ouvert la page web, vous devriez voir l'écran de bienvenue suivant. Appuyez sur "skip" pour passer le tour - nous couvrirons toutes les étapes nécessaires ci-dessous.

<img src="../img/screenshot-skip-tour.png" height="400"/>

3. Maintenant, commençons. Cliquez sur l'icône *Scripts* dans la barre de menu à gauche et sélectionnez *+ New Script*.

<img src="../img/screenshot-new-script.png" height="400"/>

4. Entrez *myjam* (ou tout autre nom de votre choix) comme nom de votre script, et changez le langage de programmation en *JavaScript*. Cliquez sur le bouton *Create* pour créer votre script (le fichier dans lequel votre code sera placé). 

<img src="../img/screenshot-new-myjam.png" height="200"/>
 
5. Enfin, cliquez sur l'icône de roue dentée, et sélectionnez "Blocks mode". Votre écran devrait maintenant ressembler à ceci.

<img src="../img/screenshot-setup-complete.png" height="400"/>

## Recommandé pour les enseignants - Vue d'ensemble de EarSketch

Veuillez jeter un œil à la vue d'ensemble de EarSketch avant de commencer avec la classe. Il est important de savoir comment naviguer dans l'interface utilisateur.

Le `Content Manager` sur le côté gauche de l'écran est votre point de départ pour naviguer à travers tout ce qu'EarSketch a à offrir.

1. Le premier élément de la barre de navigation est la collection de `Sounds`. Il s'agit du lieu central pour tous les sons préchargés que propose EarSketch. Dans le navigateur de sons, vous pouvez filtrer les sons affichés en fonction des artistes, des genres ou des instruments.

<img src="../img/screenshot-navigation-sound-browser.png" height="400"/>

2. La prochaine icône de la barre de navigation est le panneau `Scripts`. C'est ici que nous écrirons notre code.

<img src="../img/screenshot-navigation-script.png" height="400"/>

3. La dernière icône de la barre de navigation est le panneau `API Browser`. Une *Application Programming Interface* ou *API* est un ensemble de code prêt à être utilisé immédiatement ! Lors de son ouverture, une explication détaillée de chaque API est fournie.

<img src="../img/screenshot-navigation-api-curriculum.png" height="400"/>

Sur le côté droit, vous verrez le guide du `Curriculum`. Si vous souhaitez en savoir plus sur EarSketch, vous pouvez explorer la section qui apparaît sur la partie droite de la fenêtre en cliquant dessus. Nous sauterons cette section pour cet exercice.
