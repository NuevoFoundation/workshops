## Démarrage

Aujourd'hui, vous utiliserez Replit pour apprendre à coder votre jeu Space Invaders. Avant de commencer, vous devrez créer un compte Replit si vous n'en avez pas encore un.

Cliquez sur le bouton ci-dessous pour créer un compte Replit - vous aurez besoin d'une adresse e-mail pour vous inscrire. Si vous avez déjà un compte Replit, vous pouvez également vous connecter à votre compte en utilisant le bouton ci-dessous.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Inscrivez-vous à Replit</a>

<img src="../media/replit-signup.png" height="300" alt="Formulaire d'inscription Replit" />

Ensuite, lancez la console Replit que nous allons utiliser aujourd'hui en cliquant sur le bouton ci-dessous. Vous devriez voir l'écran suivant.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/Phaser-Space-Invaders" target="_blank">Lancez Replit</a>

<img src="../media/replit-start-screen.png" height="300" alt="Écran de démarrage d'un repl" />

Nous allons maintenant "forker" le Repl, ce qui signifie simplement en faire une copie afin que nous puissions y apporter nos propres modifications. Cliquez sur le bouton "Fork Repl" en haut à droite, puis sur le bouton "Fork Repl".

<img src="../media/replit-fork.png" height="300" alt="Forker un repl pour en faire une copie" />

Après avoir forké le Replit, vous verrez une fenêtre similaire à celle-ci :

<img src="../media/replit-window.png" height="300" alt="Fenêtre Replit" />

Pour l'instant, nous allons ignorer le contenu du projet (le code) et nous allons plutôt voir les bases de l'utilisation du site web. Sur le côté gauche de l'écran, vous verrez une liste de fichiers contenant du code, ou des instructions pour que l'ordinateur les exécute. En appuyant sur le bouton "run" (exécuter), vous demandez à l'ordinateur de réaliser les instructions du code. Tous les résultats de l'exécution du code seront affichés sur le côté droit, appelé la console.

Si vous appuyez sur exécuter maintenant, vous ne verrez qu'un écran noir. Cela est dû au fait que le code n'est pas encore terminé - ce sera votre travail ! Toutes les activités sous les sections d'activité seront réalisées dans cet onglet de navigateur - gardez-le à portée de main !
