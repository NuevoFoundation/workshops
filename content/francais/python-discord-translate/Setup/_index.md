Nuvi vient de lancer un nouveau hub Discord mondial où des amis de différents pays se retrouvent— mais les premières conversations commencent déjà à se diviser en bulles linguistiques. Avant de pouvoir aider Nuvi à créer le bot traducteur qui connectera tout le monde, vous devez disposer d'un environnement de développement fiable pour écrire et exécuter du code. Dans cette section, vous allez préparer votre environnement de développement pour créer un bot Discord avec des fonctionnalités de traduction. Vous installerez les outils nécessaires, configurerez ou sélectionnerez une version de Python, et organiserez un dossier de projet propre pour garder les informations confidentielles en sécurité et le code modulaire. Pensez à cela comme à la construction de l'atelier du robot avant d'assembler les pièces du traducteur.

Nous allons nous concentrer sur :
- Les prérequis (version de Python, pip, environnement virtuel)
- L'installation des dépendances principales (bibliothèques)
- Les bases de la structure du dossier de projet
