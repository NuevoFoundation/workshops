<strong>Astuce Nuvi :</strong> Il est temps de donner vie à votre bot. Commencez par une commande minimale pour le mettre en ligne—les petites victoires alimentent l'élan.

Le serveur de Nuvi est en ligne et les gens commencent à rejoindre—mais l'assistant de traduction n'existe pas encore. Dans cette section, vous allez créer la toute première base : un bot Discord minimal utilisant Python. Vous enregistrerez une application Discord, générerez un token de bot, inviterez le bot sur un serveur que vous contrôlez, et implémenterez une première commande pour vérifier que tout fonctionne. Pensez à cela comme l'allumage du cœur de l'assistant de Nuvi avant d’ajouter des fonctionnalités linguistiques.

Nous allons nous concentrer sur :
- Créer une application Discord et un utilisateur bot
- Gérer votre token de bot en toute sécurité
- Écrire un bot Python minimal
- Exécuter le bot localement et valider la connectivité

C'est parti !
