## Découvrez Visual Studio Code

Visual Studio Code est un éditeur de code avec une interface utilisateur et une disposition similaires à de nombreux autres éditeurs de code. Sur le côté gauche de l'interface se trouve une barre latérale que vous utiliserez pour accéder aux fichiers et dossiers de votre projet de code. Sur le côté droit se trouve une zone d'édition qui affiche le contenu des fichiers de l'application.

### Comprendre les principales zones de l'interface utilisateur

Le diagramme suivant montre les six sections principales incluses dans l'interface utilisateur de Visual Studio Code.

<img src="../media/visual-studio-code-user-interface-labels.png" alt="Capture d'écran montrant les 5 zones de l'interface utilisateur de VS Code" />

A - La **Barre d'activités** est la barre verticale étroite située tout à gauche de la fenêtre. La barre d'activités vous permet de basculer entre les vues (comme l'Explorateur ou les Extensions) et offre d'autres indicateurs spécifiques au contexte.

B - La **Barre latérale** contient des vues qui fournissent des outils et ressources. Les vues de la barre latérale (comme l'EXPLORATEUR) sont très utiles lorsque vous travaillez sur un projet de code.

C - L'**Éditeur** est la zone utilisée pour éditer vos fichiers. Vous pouvez ouvrir autant d'éditeurs que vous le souhaitez côte à côte, à la fois verticalement et horizontalement.

D - La zone du **Panneau** est utilisée pour afficher différents panneaux sous la région de l'éditeur pour des informations de sortie ou de débogage, des erreurs et avertissements, ou un terminal intégré.

E - La **Barre d'état** est la barre horizontale en bas de la fenêtre qui affiche des informations sur le projet ouvert et les fichiers que vous éditez.

F - Le **Menu principal** est l'interface du menu située en haut de la fenêtre de l'application. Les options du menu vous permettent de sauvegarder, modifier et exécuter votre code (et bien plus encore).
