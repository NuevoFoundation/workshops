## Instructions

### Configurer les Extensions de Visual Studio Code
Maintenant que vous êtes familier avec l'interface utilisateur de Visual Studio Code, votre prochaine étape est de configurer Visual Studio Code pour coder en C#.

1. Assurez-vous que Visual Studio Code est ouvert.

2. Dans la **Barre d’activités**, sélectionnez **Extensions**.

3. Dans la zone de saisie **Rechercher des extensions sur le Marketplace**, entrez **C#**.

    En tapant "C#", vous filtrez la liste des extensions pour afficher uniquement celles qui concernent le codage en C#.

4. Dans la liste filtrée des extensions disponibles, sélectionnez l'extension intitulée "C# Dev Kit - Official C# extension from Microsoft" publiée par Microsoft.

<img src="../media/visual-studio-code-csharp-extension-microsoft.png" alt="Capture d'écran montrant l'extension C# Dev Kit pour Visual Studio Code publiée par Microsoft." />

Il y a beaucoup d'informations sur l'extension C# que vous pouvez lire. Pour l'instant, l'important est de savoir que cette extension vous aide à développer, éditer et déboguer du code C# dans Visual Studio Code. Vous pourrez revenir plus tard lire ces détails si vous le souhaitez.

5. Pour installer l'extension, sélectionnez **Installer**.

    Le bouton Installer se changera en Installation en cours. Cette extension devrait s'installer rapidement.

6. Fermez la page du C# Dev Kit dans l'Éditeur.

7. Dans la vue EXTENSIONS, effacez le texte **C#** de la zone de recherche.

    La vue EXTENSIONS se mettra à jour pour afficher toutes les extensions **INSTALLÉES** en haut de la liste. Les extensions populaires et recommandées s'afficheront en dessous des extensions installées.

8. Remarquez qu'installer le C# Dev Kit installe également les extensions suivantes :

* **C# Dev Kit** - Extension officielle C# de Microsoft. 
* **C#** - Support de base pour le langage C#.
* **IntelliCode for C#** - Développement assisté par IA pour le C# Dev Kit.
* **.NET Runtime Install Tool**.

    Ces quatre extensions sont les seules dont vous avez besoin pour le moment.
