## Instructions

### Ouvrez Visual Studio Code et examinez la page d'accueil
1. Utilisez le menu Démarrer de Windows pour ouvrir Visual Studio Code.

    Si vous ouvrez le menu Démarrer de Windows, vous devriez voir Visual Studio Code listé comme une application récemment ajoutée. Vous pouvez également faire défiler vers le bas pour trouver Visual Studio Code.

    Une autre option consiste à taper Visual Studio Code dans la barre de recherche Windows située sur la barre de lancement en bas de l'écran.

2. Remarquez que Visual Studio Code s'ouvre sur une page "Bienvenue" qui inclut des liens et autres informations.

    La première fois que vous ouvrez Visual Studio Code, la page d'accueil affiche des parcours utiles, comme le contenu "Get Started with VS Code". Vous pouvez examiner ces informations à votre convenance ultérieurement.

3. Pour fermer la page "Bienvenue", sélectionnez le bouton Fermer (représenté par un X dans l'interface).

    Chaque page ouverte dans l'Éditeur inclut un bouton Fermer (X) situé à droite du titre de la page. L'onglet de la page "Bienvenue" est affiché dans la partie supérieure gauche de la fenêtre Visual Studio Code, sous le menu principal. Si vous survolez le X avec le pointeur de la souris, le mot "Fermer" apparaît.

### Examinez la barre d'activité et la barre latérale

1. Remarquez que la barre latérale à droite de la barre d'activité est réduite.

    Vous vous souvenez peut-être que la barre d'activité est une liste verticale d'icônes située à l'extrême gauche de la fenêtre Visual Studio Code. Le contenu de la barre latérale dépend de ce qui est actuellement sélectionné dans la barre d'activité.

2. Positionnez le pointeur de votre souris sur la barre d'activité, puis survolez chaque icône pour afficher les étiquettes.

    Une étiquette apparaît lorsque vous survolez les icônes. Vous devriez voir les boutons de la barre d'activité comme illustré dans l'image suivante :

<img src="../media/visual-studio-code-activity-bar-icons.png" alt="Capture d'écran montrant la barre d'activité de Visual Studio Code avec des icônes étiquetées." />

De haut en bas, les icônes de la barre d'activité sont : Explorateur, Recherche, Contrôle de source, Exécuter et déboguer, Extensions, Comptes, et Gérer.

3. Dans la barre d'activité, sélectionnez Explorateur.

    La barre latérale devrait s'ouvrir et afficher des informations contextuelles.

4. Remarquez que la barre latérale est maintenant étiquetée EXPLORATEUR.

    La vue EXPLORATEUR est utilisée pour accéder/explorer les dossiers de projet et les fichiers de code.

    Visual Studio Code se souvient de votre historique de travail et ouvre les fichiers de projet récents lorsqu'il s'ouvre. Étant donné qu'il s'agit de la première fois que vous ouvrez Visual Studio Code, aucun dossier de projet n'est ouvert.

5. Dans la barre d'activité, sélectionnez Extensions.

6. Remarquez que la barre latérale est maintenant étiquetée EXTENSIONS.

7. Prenez un moment pour examiner les informations affichées dans la vue EXTENSIONS.

    Les extensions de Visual Studio Code vous permettent d'ajouter des langages de codage, des débogueurs et d'autres outils à l'environnement afin de soutenir votre flux de travail de développement. Vous installerez une extension C# plus tard dans cet atelier.

8. Dans la barre d'activité, pour fermer la barre latérale EXTENSIONS, sélectionnez Extensions.

### Examinez les options du menu supérieur

1. Pour afficher les options du menu Fichier, sélectionnez Fichier.

2. Remarquez les options Nouveau, Ouvrir, Sauvegarder, et Fermer listées dans le menu Fichier.

3. Prenez une minute pour examiner les options du menu Édition, puis celles des autres éléments du menu supérieur.

4. Remarquez que plusieurs des menus incluent des options pour interagir avec votre code.

Par exemple :

* Le menu Édition inclut des options pour chercher, remplacer, et basculer les commentaires de code, ainsi que les actions standards comme couper, copier, coller, annuler et refaire.
* Le menu Sélection inclut des options pour sélectionner et manipuler des lignes de code.
* Le menu Exécuter inclut des options pour exécuter et déboguer votre application.

5. Dans le menu Terminal, sélectionnez Nouveau terminal.

6. Prenez un moment pour examiner le contenu du panneau Terminal.

    Vous pouvez basculer entre les onglets (PROBLÈMES, SORTIE, CONSOLE DE DÉBOGAGE, et TERMINAL) et survoler les boutons (en haut à droite) pour afficher les étiquettes des boutons.

7. Remarquez que le panneau Terminal inclut une invite de commande.

    Le panneau Terminal peut être utilisé pour exécuter des commandes via l'interface de ligne de commande (CLI).

8. Dans le coin supérieur droit du panneau Terminal, sélectionnez X (Fermer le panneau).

9. Dans le menu Affichage, sélectionnez Palette de commandes.

    La palette de commandes peut être utilisée pour trouver et exécuter toutes sortes de commandes utiles. Vous n'avez ni le temps, ni le besoin de les examiner en détail maintenant, mais c'est bon de savoir où trouver la palette de commandes.

10. À l'invite de la palette de commandes, tapez extensions.

    Remarquez que la liste des commandes est filtrée selon votre saisie.

11. Pour mettre à jour la liste filtrée des commandes, remplacez extensions par aide.

12. Dans la liste des options de commande, sélectionnez Aide : Terrain de jeu interactif de l'éditeur.

    Le document qui s'ouvre dans l'éditeur inclut une liste d'activités interactives.

13. Dans la liste à puces des activités interactives, sélectionnez Mise en forme.

14. Prenez une minute pour lire les options de mise en forme.

15. Fermez le document Terrain de jeu de l'éditeur.
