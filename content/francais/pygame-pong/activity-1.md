Vous pouvez ajuster les limites du jeu Pong en modifiant la hauteur et la largeur du rectangle qui représente les limites.

Accédez au <a href="https://replit.com/@nuevofoundation/PongLessonStudent?v=1" target="_blank">code</a> contenant le jeu Pong. Appuyez sur **run**. Vous remarquerez que les limites du jeu ne semblent pas correctes - voir l'image ci-dessous. Corrigeons cela dans cette activité, afin que les limites du jeu soient plus esthétiques.

![Jeu Pong avec des limites incorrectes](../media/width-highlight.png)

Trouvez `# TODO (ACTIVITY 1)` dans le code. Suivez les instructions à cet endroit pour modifier l'attribut `WIDTH` de la classe `Pong`. Si vous avez correctement effectué cette modification, le problème des limites sera corrigé. Appuyez sur **run** pour observer le résultat.

{{% notice tip %}}

Essayez de modifier les valeurs de hauteur et de largeur pour voir les effets de différentes valeurs sur les limites du jeu.

{{% /notice %}}
