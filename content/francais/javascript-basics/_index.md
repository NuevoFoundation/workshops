## Les bases du JavaScript
Bonjour ! Si vous lisez ceci, cela signifie probablement que vous êtes là pour apprendre le JavaScript 😁🥳. Que ce soit votre première fois en programmation ou que vous souhaitiez apprendre rapidement un nouveau langage - vous êtes au bon endroit ! Préparez-vous à découvrir la puissance de la programmation et à vous amuser.

## Qu'est-ce que le code ?

Nous ne pouvons pas apprendre à coder sans d'abord comprendre ce qu'est exactement le code. Pensez à votre site web préféré, si vous n'en avez pas en tête, prenons comme exemple NuevoFoundation.org. En tant qu'utilisateur, tout ce que vous avez à faire est de taper l'adresse web dans votre navigateur et, avant même de vous en rendre compte - ta da ! - le site web apparaît, avec toutes ses jolies couleurs et ses images de Nuvi.

Facile, non ? Pas exactement. Derrière ce qui semble être une interaction simple, il existe des centaines - sinon des milliers ! - de lignes de code pour que tout fonctionne. Prenons une seule étape de cette interaction : rechercher et accéder au site web de Nuevo Foundation. Il existe des milliards de sites web (1,7 milliard la dernière fois que j'ai vérifié), comment votre navigateur parvient-il à accéder au site que vous voulez si rapidement ? Réfléchissez à cela un instant...

Il y a des personnes qui ont codé cela, des personnes qui ont codé votre navigateur, le site web de Nuvi, ce plan d'apprentissage que vous lisez, et ... eh bien, vous voyez l'idée. Le code est la manière dont nous, les humains, concevons et construisons des choses comme des sites web, des applications et des jeux. C'est le langage que nous utilisons pour dire à un ordinateur ce qu'il doit faire.

## Qu'est-ce que le JavaScript et à quoi sert-il ?

Tout comme il existe une multitude de langues humaines, il existe aussi une multitude de langages de programmation. Peut-être en avez-vous déjà entendu parler, comme Python ou Java. Chaque langage de programmation possède ses caractéristiques et ses objectifs spécifiques - par exemple, CSS est utilisé pour styliser les sites web, Python est particulièrement efficace pour la science des données, etc.

Le JavaScript est parfois appelé le "langage du web". Pratiquement tous les sites web que vous pouvez imaginer utilisent le JavaScript d'une manière ou d'une autre. Le JavaScript est particulièrement efficace pour gérer le comportement des sites web, par exemple, contrôler ce qui se passe lorsque vous cliquez sur un bouton ou transférer des données entre les pages.

La bonne nouvelle, c'est qu'une fois que vous maîtrisez un langage, vous pouvez en apprendre un autre assez rapidement, car les bases ont tendance à rester les mêmes.

## Configurer l'environnement

Un environnement ? Je pensais que c'était un atelier de codage ?

Un environnement, c'est simplement le terme que les programmeurs utilisent pour désigner leur configuration de codage. Vous savez comment vous utilisez des applications comme Microsoft Word ou Google Docs pour rédiger des essais ? Vous pouvez considérer cela comme votre "environnement de rédaction d'essais".

Pour les programmeurs, il existe des applications appelées IDE, qui signifient Environnement de Développement Intégré (Integrated Development Environment en anglais). Ces applications nous permettent d'écrire et d'exécuter du code.

Pour cet atelier, nous utiliserons playcode.io.

Une fois que vous avez ouvert playcode.io, voici quelques étapes que vous devez suivre avant de commencer :
* Fermez tous les fichiers en haut à gauche, sauf __script.js__.
* Supprimez tout ce qui se trouve dans le fichier __script.js__.
* Désactivez __live__ en cliquant une fois sur le bouton __live__ en haut à droite.

Si vous avez effectué correctement toutes les étapes ci-dessus, votre écran devrait ressembler à ceci :
