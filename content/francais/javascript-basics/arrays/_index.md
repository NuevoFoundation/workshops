## Qu'est-ce qu'un tableau ?

Un tableau est simplement une collection de valeurs. C'est une variable spéciale qui peut contenir plusieurs valeurs à la fois.

Par exemple, considérez un tableau appelé fruits, qui contiendrait des valeurs comme pomme, orange, mangue, etc., toutes ensemble dans une seule variable.   

## Comment en créer un

Les instructions suivantes montrent comment créer des tableaux de deux manières différentes, mais le résultat final est le même.

<b>Syntaxe :</b>
```javascript
var arrayName = new Array(element0, element1, ..., elementN);
var arrayName = Array(element0, element1, ..., elementN);
var arrayName = [element0, element1, ..., elementN];
```
