Un **système d'exploitation** (OS) est un logiciel qui agit comme une interface entre vous et le matériel de votre ordinateur. Chaque ordinateur doit avoir au moins un OS pour exécuter d'autres programmes, comme votre navigateur ! L'OS vous aide à communiquer avec votre ordinateur sans avoir besoin de connaître le langage de celui-ci.

Microsoft Windows est probablement le système d'exploitation que vous connaissez le mieux chez vous. Un autre que vous avez peut-être vu est Apple macOS. Linux est encore un autre système d'exploitation ! Il est largement préféré par les développeurs pour sa polyvalence. Il existe de nombreuses options, mais aujourd'hui, nous allons utiliser un système d'exploitation basé sur Linux, appelé Kali Linux. C'est un système d'exploitation populaire parmi les experts en sécurité et les hackers !

Les principales différences entre Windows, macOS et Linux résident dans ce pour quoi ils sont les meilleurs. Windows est parfait pour le multimédia et les jeux ! macOS se situe quelque part entre Windows et Linux. Bien qu'il soit également excellent pour le multimédia, il ne prend pas en charge tous les jeux. Linux est généralement meilleur pour la programmation et l'hébergement des serveurs.
