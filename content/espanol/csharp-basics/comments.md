## Hacer un Comentario

Al crear un programa en C#, podemos tomar notas añadiendo un comentario de una sola línea con `//` o un comentario de varias líneas usando `/*` y `*/` (Nota: Las instrucciones en las actividades previas estaban escritas como comentarios).

Además, agregar comentarios no afectará en absoluto el programa. Por lo tanto, puedes añadir comentarios en todo tu código para documentar cómo funciona, para ti y otros programadores.

```c#
     // ejemplo de comentario de una sola línea

     /* ejemplo de un
      * comentario de varias
      * líneas */
```

{{% notice tip %}}

Puedes comentar tu código para que la computadora no lo ejecute.

```c#
Console.Write("Me gusta comer");
// Console.Write("manzanas.");
```

Esto escribirá "Me gusta comer" en la consola, pero no escribirá "manzanas".
