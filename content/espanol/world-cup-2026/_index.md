## Tu misión en el campeonato

Nuvi United ha alcanzado el partido final de un campeonato mundial de fútbol imaginario. El estadio está lleno, el marcador está listo y el equipo necesita que **tú** construyas un programa en Python para el partido.

A lo largo de tres actividades, tu programa presentará a los equipos, mostrará actualizaciones del partido y decidirá quién levanta la copa. Puedes personalizar el equipo, el capitán, los colores, el contrincante y el marcador.

Esta es una historia de programación ficticia. No utiliza equipos, logotipos ni resultados oficiales de torneos.
{{% /notice %}}

## Qué aprenderás

Al final del partido, serás capaz de:

- crear variables que almacenen información del equipo y los puntajes;
- usar cadenas formateadas para construir anuncios del partido; y
- usar una decisión `if`/`else` para elegir un mensaje de ganador.

## Qué necesitas

- Python 3 instalado en tu computadora
- Un editor de texto, como Visual Studio Code, IDLE o Notepad
- Aproximadamente 45 minutos

Debes saber cómo guardar un archivo y ejecutar un programa Python simple. No se requiere cuenta en línea ni servicio de codificación externo.

Como ya tienes algo de conocimiento previo de Python, la Actividad 1 será un repaso rápido en lugar de una primera introducción. Se revisan variables para que todos comiencen con la misma información del equipo antes de que la Actividad 2 use esas variables en mensajes formateados del partido y la Actividad 3 compare las variables de los puntajes para decidir al ganador.

## Crea tu archivo de partido

1. Abre tu editor de texto.
2. Crea un archivo llamado `world_cup_2026.py`.
3. Guárdalo en un lugar fácil de encontrar.
4. Abre una terminal en esa carpeta.
5. Ejecuta el programa después de cada cambio:

```text
python world_cup_2026.py
```

En algunas computadoras, el comando es `python3 world_cup_2026.py`.

{{% notice tip %}}
Para un taller presencial, trabaja en equipo con un compañero. Después de cada actividad, cambien de roles: una persona ejecuta el código mientras la otra revisa el anuncio del partido.
{{% /notice %}}
