## Introducción - Construyendo con Arduino

¡La electrónica como los microcontroladores, sensores y todo tipo de circuitos están a nuestro alrededor! Algunos son muy básicos y proporcionan información de telemetría para los sistemas de tráfico. Otros controlan semáforos programados con tiempos establecidos.

Hoy trabajaremos en algunas actividades para mostrarte algunas de las capacidades de esta plataforma. Comenzaremos con algo pequeño y simple, y avanzaremos hacia cosas más grandes y complejas. Aprenderás toda la información básica sobre cómo usar la placa controladora Arduino, sensores y componentes. Después de realizar cada actividad, siéntete libre de cambiar algunas cosas para ver qué es diferente y obtener una comprensión más profunda.

## Los Componentes

Los componentes que usaremos para el proyecto se muestran a continuación. Asegúrate de tener todos estos componentes antes de comenzar:

![Texto Alt: Imagen del kit de inicio Elegoo UNO](img/Elegoo-starter-kit.png)

El `Elegoo` UNO Project Super Starter Kit con tutorial para Arduino incluye todo el hardware (excepto la computadora).

* Componentes básicos necesarios para todas las actividades:
  * Arduino UNO R3
  * Cable USB A a B
  * PC con Windows 10
  * Software de Arduino IDE (descargar)
