## Tarea 2: ¡Ordenando un array!

¡El costo de cada artículo en el menú está desordenado! Ayúdanos a ordenar el array de menor a mayor.

{{% notice tip %}}
1. Piensa en una forma de ordenar el array (¡existen muchas maneras de hacerlo)!
2. ¡Mira el ejemplo!
{{% /notice%}}

Si nos dan este array: 
```js javascript
int[] cost = {100,90,50,60,20,1,3};
```

deberíamos obtener el siguiente resultado: 
```js javascript
int[] sorted = {1,3,20,50,60,90,100};
```
