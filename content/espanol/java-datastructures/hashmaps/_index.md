Ahora que los restaurantes han terminado de preparar el pedido, un conductor necesita recogerlo y entregarlo al cliente. Pero, ¿a dónde debe ir el conductor? De alguna manera necesita una dirección. Queremos vincular el nombre y el pedido de un cliente con su dirección respectiva. Podemos lograr esto utilizando un `HashMap`.
