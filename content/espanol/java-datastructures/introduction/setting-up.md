## ¡Configuración de Replit!

Hoy utilizarás Replit para aprender sobre estructuras de datos con Java. Antes de comenzar, deberás registrarte en una cuenta de Replit, si aún no tienes una.

Haz clic en el botón de abajo para registrarte en una cuenta de Replit; necesitarás una cuenta de correo electrónico para registrarte. Si ya tienes una cuenta de Replit, puedes iniciar sesión usando también el botón de abajo.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Regístrate en Replit</a>

<img src="../img/replit-signup.png" height="300" alt="Formulario de registro de Replit" />

A continuación, lanza la consola de Replit que usaremos hoy haciendo clic en el botón de abajo. Deberías ver la siguiente pantalla.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/HelloWorld" target="_blank">Abrir Replit</a>

<img src="../img/replit-start-screen.png" height="300" alt="La pantalla inicial de un Repl" />

Ahora haremos un fork del Repl, lo que simplemente significa hacer una copia del programa, para que podamos hacer nuestros propios cambios. Haz clic en el botón "Fork Repl" en la parte superior derecha, y luego en el botón "Fork Repl".

<img src="../img/replit-fork.png" height="300" alt="Haciendo fork de un Repl para crear una copia del programa" />

Después de hacer fork del Replit, verás una ventana similar a la siguiente:

<img src="../img/replit-window.png" height="300" alt="Ventana de Replit" />

{{% notice warning %}}
Cada vez que veas el botón "Abrir Replit", deberás seguir los pasos anteriores para hacer un fork del Repl y completar una actividad. ¡Pide ayuda si tienes problemas para hacer fork de los Repls!
{{%/notice %}}

Antes de empezar, primero entendamos cómo funciona Replit. El archivo `main.java` contiene código, o instrucciones para que la computadora las ejecute. Al presionar el botón **run**, le dices a la computadora que realice las instrucciones del código. Cualquier resultado después de ejecutar el código se mostrará en la pantalla blanca inferior, bajo la pestaña **result**.

Para aprender a programar las estructuras de datos, utilizaremos Replit para poner a prueba tus habilidades. ¡Presiona run e intenta completar las siguientes tareas!
