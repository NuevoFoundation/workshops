## Variables

Antes de comenzar este taller, debes tener un conocimiento previo sobre cómo funcionan las variables en Java y cómo puedes crearlas. [¡Haz clic aquí para revisar el taller de Conceptos Básicos de Java!](https://workshops.nuevofoundation.org/java-basics/) No te preocupes si todavía te sientes un poco inseguro. Introduciremos estos temas paso a paso. Sin embargo, si no tienes idea de lo que son las variables, te recomendamos encarecidamente que completes el taller de conceptos básicos de Java antes de continuar.
