## Antes de Nuevo Eats...

<hr> 

Para comenzar tu entrenamiento en Nuevo Eats, primero debes aprender algo llamado **estructuras de datos**. ¡Aquí aprenderás todo lo que necesitas saber para completar tu primera misión en Nuevo Eats! Empecemos con lo básico y veamos qué son.

<hr>

## ¡Estructuras de Datos!

Las estructuras de datos son increíbles y poderosas. Al usar código, podemos almacenar mucha información en categorías organizadas para usarla más tarde.

Almacenar elementos en estas estructuras nos permite acceder a todo de manera rápida y eficiente, ¡perfecto para Nuevo Eats! Restaurantes, comidas, empleados y ubicaciones son solo algunos ejemplos de cómo podemos usar las estructuras de datos a nuestro favor.

{{% notice tip %}}

Las estructuras de datos pueden almacenar **cualquier cosa**, ¡mucho más de lo que mencionamos arriba!
¡Incluso pueden almacenar diferentes estructuras de datos dentro de otras estructuras de datos!

{{% /notice%}}

Existen muchos tipos diferentes de estructuras de datos (por ejemplo, Arrays, ArrayList, Colas, Pilas y Hashmaps), al igual que hay muchas formas de organizar juguetes.

Ahora que tienes una idea de lo que son, presiona "siguiente" para descubrir cómo puedes usar esto para ayudar a hacer que Nuevo Eats sea para todos.
