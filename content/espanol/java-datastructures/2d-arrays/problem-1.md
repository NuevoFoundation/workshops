## Tarea 1: Imprimir el arreglo 2D

En el arreglo 2D a continuación tenemos una lista de diferentes alimentos. Cada fila representa el mismo tipo. Por ejemplo, la fila 1 es un arreglo de platos principales. La fila 2 es un arreglo de bebidas y la fila 3 es un arreglo de postres.

```js javascript
String[][] menu = {    
                    { "Hamburger", "Pasta", "Steak", "Tacos" },
                    { "Cola", "Sprite", "Pepsi", "Fanta" },
                    { "Pudding", "Ice Cream", "Mochi", "Cake" }
                  };
```
