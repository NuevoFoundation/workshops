Ahora que los clientes tienen acceso a todos los elementos del menú, es hora de que realicen sus pedidos. Un cliente puede querer agregar un artículo a su pedido, eliminar un artículo, cambiar un artículo o acceder a un artículo. Después de finalizar el pedido, querrás devolver un recibo que contenga la cantidad de artículos que el cliente ordenó, así como cada artículo en una lista para que el cliente pueda revisarlo. Lograremos todas estas tareas utilizando un `ArrayList`.
