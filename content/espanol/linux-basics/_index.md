Un **Sistema Operativo** (SO) es un software que actúa como interfaz entre tú y el hardware de tu computadora. Cada computadora debe tener al menos un SO para ejecutar otros programas, como tu navegador. El SO te ayuda a comunicarte con tu computadora sin necesidad de saber cómo hablar su lenguaje.

Microsoft Windows es el SO con el que probablemente estés más familiarizado en tu hogar. Otro común que podrías haber visto es Apple macOS. ¡Linux es otro SO más! Es ampliamente preferido por los desarrolladores por su versatilidad. Hay muchas opciones disponibles, pero hoy usaremos un SO basado en Linux, llamado Kali Linux. ¡Es un SO popular entre expertos en seguridad y hackers!

Las mayores diferencias entre Windows, macOS y Linux son para qué sirven mejor. ¡Windows es perfecto para multimedia y juegos! macOS se encuentra en algún lugar entre Windows y Linux. Aunque también es excelente para multimedia, no soporta todos los juegos. Linux usualmente es mejor para programar y alojar servidores.
