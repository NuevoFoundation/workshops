## Instrucciones

### Abre Visual Studio Code y examina la página de Bienvenida
1. Usa el menú de Inicio de Windows para abrir Visual Studio Code.

    Si abres el menú de Inicio de Windows, deberías ver Visual Studio Code listado como una aplicación agregada recientemente. También puedes desplazarte hacia abajo para encontrar Visual Studio Code.

    Otra opción es escribir Visual Studio Code en la barra de búsqueda de Windows en la parte inferior de la pantalla.

2. Observa que Visual Studio Code se abre en una página de "Bienvenida" que incluye algunos enlaces y otra información.

    La primera vez que abras Visual Studio Code, la página de Bienvenida mostrará algunos tutoriales útiles, como el contenido de Introducción a VS Code. Puedes examinar esta información con calma en otro momento.

3. Para cerrar la página de Bienvenida, selecciona el botón de cerrar (mostrado como una X en la interfaz).

    Cada página que está abierta en el Editor incluye un botón de cerrar (X) ubicado a la derecha del título de la página. La pestaña de la página de Bienvenida se muestra en la parte superior izquierda de la ventana de Visual Studio Code, debajo del Menú Principal. Si pasas el cursor del ratón sobre la X, aparecerá la palabra Cerrar.

### Examina la barra de Actividades y la barra Lateral

1. Observa que la barra Lateral a la derecha de la barra de Actividades está colapsada.

    Tal vez recuerdes que la barra de Actividades es la lista vertical de íconos en el extremo izquierdo de la ventana de Visual Studio Code. El contenido de la barra Lateral depende de lo que esté seleccionado actualmente en la barra de Actividades.

2. Sitúa el cursor del ratón sobre la barra de Actividades y luego pásalo sobre cada uno de los íconos para mostrar las etiquetas.

    Aparecerá una etiqueta cuando pases el cursor sobre los íconos. Deberías ver los botones de la barra de Actividades mostrados en la siguiente imagen:

<img src="../media/visual-studio-code-activity-bar-icons.png" alt="Captura de pantalla que muestra la barra de Actividades de Visual Studio Code con los íconos etiquetados." />

De arriba hacia abajo, los íconos de la barra de Actividades son: Explorador, Buscar, Control de Fuente, Ejecutar y Depurar, Extensiones, Cuentas y Administrar.

3. En la barra de Actividades, selecciona Explorador.

    La barra Lateral debería abrirse y mostrar información contextual.

4. Observa que la barra Lateral ahora está etiquetada como EXPLORADOR.

    La vista EXPLORADOR se utiliza para acceder/explorar carpetas de proyectos y archivos de código.

    Visual Studio Code recordará tu historial de trabajo y abrirá los archivos de proyecto más recientes al iniciarse. Dado que esta es la primera vez que abres Visual Studio Code, ninguna carpeta de proyecto se abrirá.

5. En la barra de Actividades, selecciona Extensiones.

6. Observa que la barra Lateral ahora está etiquetada como EXTENSIONES.

7. Tómate un momento para examinar la información que se muestra en la vista de EXTENSIONES.

    Las extensiones de Visual Studio Code te permiten agregar lenguajes de programación, depuradores y otras herramientas al entorno en apoyo de tu flujo de trabajo de desarrollo. Más adelante en este taller, instalarás una extensión de C#.

8. En la barra de Actividades, para cerrar la barra Lateral de EXTENSIONES, selecciona Extensiones.

### Examina las opciones del menú superior

1. Para ver las opciones del menú Archivo, selecciona Archivo.

2. Observa las opciones Nuevo, Abrir, Guardar y Cerrar que se listan en el menú Archivo.

3. Dedica un minuto a examinar las opciones del menú Editar y luego las de los demás elementos del menú principal.

4. Observa que varios de los menús incluyen opciones para interactuar con tu código.

Por ejemplo:  

* El menú Editar incluye opciones para buscar, reemplazar y alternar comentarios de código, además de las acciones estándar cortar, copiar, pegar, deshacer y rehacer.
* El menú Selección incluye opciones para seleccionar y manipular líneas de código.
* El menú Ejecutar incluye opciones para ejecutar y depurar tu aplicación.

5. En el menú Terminal, selecciona Nueva Terminal.

6. Tómate un momento para examinar el contenido del panel Terminal.

    Puedes cambiar entre las pestañas (PROBLEMAS, SALIDA, CONSOLA DE DEPURACIÓN y TERMINAL) y pasar el cursor del ratón sobre los botones (arriba a la derecha) para mostrar las etiquetas de los botones.

7. Observa que el panel Terminal incluye un símbolo del sistema.

    El panel Terminal puede usarse para ejecutar comandos de una interfaz de línea de comandos (CLI).

8. En la esquina superior derecha del panel Terminal, selecciona X (Cerrar Panel).

9. En el menú Ver, selecciona Paleta de Comandos.

    La paleta de comandos puede usarse para encontrar y ejecutar todo tipo de comandos útiles. No tienes tiempo (ni necesidad) de examinarlos en detalle ahora, pero es bueno saber dónde encontrar la paleta de comandos.

10. En el aviso de la paleta de comandos, escribe extensiones.

    Observa que la lista de comandos se filtra según tu entrada.

11. Para actualizar la lista filtrada de comandos, cambia extensiones por ayuda.

12. Desde la lista de opciones de comandos, selecciona Ayuda: Interactive Editor Playground.

    El documento del Editor Playground que se abre en el Editor incluye una lista de actividades interactivas.

13. Desde la lista con viñetas de actividades interactivas, selecciona Formateo.

14. Dedica un minuto a leer sobre las opciones de formateo.

15. Cierra el documento del Editor Playground.
