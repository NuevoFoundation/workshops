## Instrucciones

### Configurar Extensiones de Visual Studio Code
Ahora que estás familiarizado con la interfaz de usuario de Visual Studio Code, el siguiente paso es configurarlo para la programación en C#.

1. Asegúrate de tener abierto Visual Studio Code.

2. En la **Barra de Actividades**, selecciona **Extensiones**.

3. En el cuadro de texto **Buscar Extensiones en el Marketplace**, ingresa **C#**

    Al ingresar "C#", se filtra la lista de extensiones para mostrar solo aquellas relacionadas con la programación en C#.

4. En la lista filtrada de extensiones disponibles, selecciona la extensión etiquetada como "C# Dev Kit - Official C# extension from Microsoft" publicada por Microsoft.

<img src="../media/visual-studio-code-csharp-extension-microsoft.png" alt="Captura de pantalla que muestra la extensión C# Dev Kit de Visual Studio Code publicada por Microsoft." />

Hay mucha información sobre la extensión de C# que podrías leer. Por ahora, lo importante es saber que esta extensión te ayuda a desarrollar, editar y depurar código C# en Visual Studio Code. Puedes regresar más tarde para leer más sobre la extensión si lo deseas.

5. Para instalar la extensión, selecciona Instalar.

    El botón Instalar cambiará a Instalando. Esta extensión debería instalarse rápidamente.

6. Cierra la página del C# Dev Kit en el Editor.

7. En la vista EXTENSIONES, limpia el texto C# del cuadro de búsqueda.

    La vista EXTENSIONES se actualizará para mostrar todas las extensiones INSTALADAS en la parte superior de la lista. Las extensiones populares y recomendadas se listarán debajo de las extensiones instaladas.

8. Observa que al instalar el C# Dev Kit también se instalan las siguientes extensiones:

* C# Dev Kit - Extensión oficial de C# de Microsoft.
* C# - Soporte básico para el lenguaje C#.
* IntelliCode para C# - Desarrollo asistido por IA para C# Dev Kit.
* Herramienta de Instalación de .NET Runtime.

    Estas cuatro extensiones son las únicas que necesitas por ahora.
