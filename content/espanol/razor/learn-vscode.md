## Conozca Visual Studio Code

Visual Studio Code es un editor de código, con una interfaz de usuario y diseño similar a muchos otros editores de código. En el lado izquierdo de la interfaz hay una barra lateral que usarás para acceder a los archivos y carpetas de tu proyecto de código. En el lado derecho se encuentra un área de editor que muestra el contenido de los archivos de la aplicación.

### Comprenda las áreas principales de la interfaz de usuario

El siguiente diagrama muestra las seis secciones principales incluidas en la interfaz de usuario de Visual Studio Code.

<img src="../media/visual-studio-code-user-interface-labels.png" alt="Captura de pantalla que muestra 5 áreas de la interfaz de usuario de VS Code" />

A - La **Barra de Actividad** es la barra vertical estrecha ubicada en el extremo izquierdo de la ventana. La Barra de Actividad te permite cambiar entre vistas (como Explorador o Extensiones) y te proporciona otros indicadores específicos según el contexto.

B - La **Barra Lateral** contiene vistas que proporcionan herramientas y recursos. Las vistas de la Barra Lateral (como EXPLORADOR) son muy útiles cuando estás trabajando en un proyecto de código.

C - El **Editor** es el área utilizada para editar tus archivos. Puedes abrir tantos editores como desees, uno al lado del otro, de manera vertical y horizontal.

D - El área del **Panel** se usa para mostrar diferentes paneles debajo de la región del editor, como información de salida o depuración, errores y advertencias, o un terminal integrado.

E - La **Barra de Estado** es la barra horizontal en la parte inferior de la ventana que muestra información sobre el proyecto abierto y los archivos que editas.

F - El **Menú Principal** es la interfaz de menú ubicada en la parte superior de la ventana de la aplicación. Las opciones del menú te permiten guardar, editar y ejecutar tu código (y mucho más).
