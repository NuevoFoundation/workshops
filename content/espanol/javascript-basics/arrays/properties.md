Las propiedades o características de un array son una forma de describir los atributos del array. Ejemplos incluyen: el número total de elementos, el valor en un índice particular, etc...

Aquí hay una lista de las propiedades del objeto Array junto con su descripción.

## Constructor()

Devuelve una referencia a la función del array que creó el objeto.

**Sintaxis:**
```javascript
arrayName.constructor;
```

**Ejemplo:**
![#No se encuentra la imagen](../../img/constructor.png)

## Index()

La propiedad representa el índice basado en cero de la coincidencia en la cadena. Index proporciona una forma de acceder o modificar elementos según su posición en el array.

### Acceder a un elemento del array por índice:

**Sintaxis:**
```javascript
var value = arrayName[index];
```

**Ejemplo:**
![#No se encuentra la imagen](../../img/indexaccess.png)

### Modificar un elemento del array por índice:

**Sintaxis:**
```javascript
arrayName[index] = newValue;
```

**Ejemplo:**
![#No se encuentra la imagen](../../img/indexmodify.png)

## Length() 
Refleja el número de elementos en un array.

**Sintaxis:**
```javascript
var length = arrayName.length;
```
