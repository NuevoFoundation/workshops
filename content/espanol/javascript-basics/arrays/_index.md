## ¿Qué es un Array?

Un array es simplemente una colección de valores. Es una variable especial que puede contener más de un valor al mismo tiempo.

Por ejemplo, considera un array llamado frutas, que podría contener valores como manzana, naranja, mango, etc., todos juntos en una sola variable.

## Cómo crear uno

Las siguientes declaraciones muestran cómo crear arrays de dos maneras diferentes, pero el resultado final es el mismo.

<b>Sintaxis:</b>
```javascript
var arrayName = new Array(element0, element1, ..., elementN);
var arrayName = Array(element0, element1, ..., elementN);
var arrayName = [element0, element1, ..., elementN];
```
