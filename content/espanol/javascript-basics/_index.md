## Fundamentos de JavaScript

¡Hola! Si estás leyendo esto, espero que signifique que estás aquí para aprender JavaScript 😁🥳. Ya sea que esta sea tu primera vez programando o que quieras aprender rápidamente un nuevo lenguaje, ¡estás en el lugar correcto! Prepárate para descubrir el poder de la programación y divertirte.

## ¿Qué es el código?

No podemos aprender a programar sin antes entender qué es exactamente el código. Piensa en tu sitio web favorito, y si no se te ocurre uno, tomemos como ejemplo NuevoFoundation.org. Como usuario, todo lo que tienes que hacer es escribir la dirección web en tu navegador y, antes de que te des cuenta, ¡voilá!, ¡el sitio web aparece con todos sus bonitos colores e imágenes de Nuvi!

¿Fácil, verdad? No exactamente. Detrás de lo que parece una interacción sencilla, existen cientos, ¡si no miles!, de líneas de código para que todo funcione. Tomemos solo un paso de esta interacción: buscar e ir al sitio web de Nuevo Foundation. Existen miles de millones de sitios web (1.7 mil millones la última vez que revisé), ¿cómo consigue tu navegador llegar al sitio web que quieres tan rápido? Piensa en eso por un momento...

Hay personas que codificaron eso, personas que codificaron tu navegador, el sitio web de Nuvi, este contenido que estás leyendo y... bueno, ya entiendes la idea. El código es la manera en que los humanos diseñamos y construimos cosas como sitios web, aplicaciones y juegos. Es el lenguaje que usamos para decirles a las computadoras qué hacer.

## ¿Qué es JavaScript y para qué se utiliza?

Así como existen un montón de lenguajes humanos, también existen un montón de lenguajes de programación. Tal vez has oído hablar de algunos de ellos, como Python o Java. Cada lenguaje de programación tiene sus fortalezas y propósitos: por ejemplo, CSS se usa para estilizar páginas web, Python es muy bueno para la ciencia de datos, y así sucesivamente.

A menudo se dice que JavaScript es el "lenguaje de la web." Prácticamente cualquier sitio web que se te ocurra utiliza JavaScript de alguna forma. JavaScript es especialmente adecuado para controlar el comportamiento de los sitios web, por ejemplo, controlar qué pasa cuando haces clic en un botón o transferir datos entre páginas.

Lo bueno es que, una vez que aprendes un lenguaje, puedes aprender otro bastante rápido, ya que los fundamentos suelen ser similares.

## Configuración del entorno

¿Entorno? ¿No se suponía que esto era un taller de programación?

"Entorno" es solo el término que los programadores usan para llamar a su configuración de trabajo para programar. ¿Sabes cómo usas cosas como Microsoft Word o Google Docs para escribir ensayos? Puedes pensar en ellos como tu entorno para "escribir ensayos".

Para los programadores, existen aplicaciones llamadas IDEs, que significa Entorno de Desarrollo Integrado (Integrated Development Environment, por sus siglas en inglés). Este tipo de aplicaciones nos permiten escribir y ejecutar código.

Para este taller, utilizaremos playcode.io.

Una vez que abras playcode.io, hay algunas cosas que debes hacer antes de empezar:
* Cierra todos los archivos en la parte superior izquierda excepto __script.js__.
* Elimina todo el contenido del archivo __script.js__.
* Apaga la función __live__ haciendo clic una vez en el botón __live__ en la parte superior derecha.
