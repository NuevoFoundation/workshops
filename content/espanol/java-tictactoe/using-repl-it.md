## Usando Replit

Hoy usarás Replit para aprender a programar en Java. Antes de comenzar, necesitarás registrarte para obtener una cuenta de Replit si aún no tienes una.

Haz clic en el botón de abajo para registrarte en Replit; necesitarás una cuenta de correo electrónico para registrarte. Si ya tienes una cuenta de Replit, puedes iniciar sesión en tu cuenta usando el botón de abajo también.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">Regístrate en Replit</a>

<img src="../images/replit-signup.png" height="300" alt="Formulario de registro de Replit" />

A continuación, lanza la consola de Replit que usaremos hoy haciendo clic en el botón de abajo. Deberías ver la siguiente pantalla.

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaTicTacToeStarterCode" target="_blank">Lanzar Replit</a>

<img src="../images/replit-start-screen.png" height="300" alt="La pantalla de inicio de un repl" />

Ahora haremos un fork del Repl, lo que simplemente significa hacer una copia del programa, para que podamos realizar nuestros propios cambios en él. Haz clic en el botón "Fork Repl" en la parte superior derecha, y luego en el botón "Fork Repl".

<img src="../images/replit-fork.png" height="300" alt="Haciendo fork de un repl para crear una copia del programa" />

Después de hacer fork al Replit, verás una ventana similar a la siguiente:

<img src="../images/replit-window.png" height="300" alt="Ventana de Replit" />

{{% notice warning %}}
Cada vez que veas el botón "Lanzar Replit", necesitarás seguir los pasos anteriores para hacer fork al repl y completar una actividad. ¡Pide ayuda si tienes problemas para hacer fork a los repls!
{{%/notice %}}

{{% notice info %}}

Antes de empezar, primero entendamos cómo funciona la ventana. El archivo `Main.java` contiene el código, o las instrucciones que el ordenador debe ejecutar. Al presionar el botón **run**, le dices al ordenador que realice las instrucciones del código. Cualquier resultado de ejecutar el código se mostrará en la pantalla inferior, bajo la pestaña **Console**.

{{% /notice %}}

Haz clic en el ícono al lado del botón `Run` que dice `open in Replit`. Esta será la ventana donde escribirás todo el código para el programa TicTacToe. ¡Diviértete!
