## Crea el Banner de tu Restaurante
Cuando configuremos la caja registradora virtual de tu restaurante, primero tendremos que asegurarnos de tener un banner con el nombre de tu restaurante. Dado que queremos un banner real, no solo texto simple para el nombre, ¡usaremos arte ASCII! El arte ASCII utiliza símbolos especiales como `()`, `{}`, `*` y otras teclas para crear imágenes y palabras.  
Para esta actividad, podemos usar este recurso en línea para convertir texto en arte ASCII.

[Convertidor de Texto a ASCII](https://onlineasciitools.com/convert-text-to-ascii-art)

Por ejemplo, podemos convertir la palabra "Restaurant" en arte ASCII. ¡Mira el siguiente código!

```python
print("    _   _   _   _   _   _   _   _   _   _  ")
print("   / \ / \ / \ / \ / \ / \ / \ / \ / \ / \ ")
print("  ( r | e | s | t | a | u | r | a | n | t )")   
print("   \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ ")
```

Recuerda mantener este documento abierto, ya que volveremos a él en actividades posteriores, ya que cada actividad se basa en las anteriores. Eventualmente, toda la caja registradora para el restaurante estará configurada en este documento.
