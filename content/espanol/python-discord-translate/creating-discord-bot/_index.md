El servidor de Nuvi está en línea y la gente se está uniendo, pero el asistente de traducción aún no existe. En esta sección, crearás el primer bloque fundamental: un bot de Discord mínimo utilizando Python. Registrarás una aplicación de Discord, generarás un token para el bot, invitarás al bot a un servidor bajo tu control y pondrás en marcha un primer comando para asegurarte de que todo funciona. Piensa en esto como encender el núcleo asistente de Nuvi antes de agregar características de idioma.

Nos centraremos en:
- Crear una aplicación de Discord y un usuario bot
- Gestionar de manera segura tu token de bot
- Escribir un bot en Python básico
- Ejecutar el bot localmente y validar la conectividad

¡Comencemos!
