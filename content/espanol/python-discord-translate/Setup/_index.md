Nuvi acaba de lanzar un nuevo centro global de Discord donde amigos de diferentes países se están uniendo, pero las primeras conversaciones ya se están dividiendo en burbujas de idiomas. Antes de que puedas ayudar a Nuvi a construir el bot traductor que conectará a todos, necesitas un lugar confiable para escribir y ejecutar código. En esta sección, prepararás tu entorno de desarrollo para construir un bot de Discord con funcionalidades de traducción. Instalarás las herramientas necesarias, crearás o seleccionarás un entorno de Python y organizarás una carpeta de proyecto limpia para mantener seguros los secretos y el código modular. Piensa en esto como construir el taller de robots antes de ensamblar las piezas del traductor.

Nos enfocaremos en:
- Requisitos previos (versión de Python, pip, entorno virtual)
- Instalación de dependencias principales (bibliotecas)
- Fundamentos de la estructura de carpetas del proyecto
