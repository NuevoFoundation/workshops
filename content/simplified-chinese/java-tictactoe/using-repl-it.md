## 使用 Replit

今天，您将使用 Replit 学习如何用 Java 编程。在开始之前，如果您尚未注册 Replit 账户，则需要先注册一个账户。

点击下方按钮注册 Replit 账户 - 您需要一个电子邮件地址才能注册。如果您已经有 Replit 账户，您也可以使用下面的按钮登录到您的账户。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">注册 Replit</a>

<img src="../images/replit-signup.png" height="300" alt="Replit 注册表单" />

接下来，点击下方的按钮启动我们今天将使用的 Replit 控制台。您应该会看到以下屏幕。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaTicTacToeStarterCode" target="_blank">启动 Replit</a>

<img src="../images/replit-start-screen.png" height="300" alt="repl 的起始屏幕" />

现在，我们将“Fork”这个 Repl，也就是简单地复制这个程序，以便我们可以在其基础上进行更改。点击右上方的“Fork Repl”按钮，然后点击“Fork Repl”按钮。

<img src="../images/replit-fork.png" height="300" alt="Fork 一个 repl 以复制该程序" />

在 Fork 这个 Replit 后，您会看到如下所示的窗口：

<img src="../images/replit-window.png" height="300" alt="Replit 窗口" />

{{% notice warning %}}
每次看到“启动 Replit”按钮时，您需要按照上述步骤 Fork 该 Repl，以完成活动。如果在 Fork Repls 过程中遇到困难，请寻求帮助！
{{%/notice %}}

{{% notice info %}}

在我们开始之前，让我们先了解窗口的工作原理。`Main.java` 文件包含代码，也就是计算机运行的指令。通过按下 **运行** 按钮，您告知计算机执行代码中的指令。运行代码的任何结果都将显示在底部屏幕的 **Console** 标签中。

{{% /notice %}}

点击 `Run` 按钮旁边写有 `open in Replit` 的图标。这将是您为井字棋程序输入所有代码的窗口。玩得开心！
