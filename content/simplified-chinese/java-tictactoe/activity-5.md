### 让计算机思考起来

之前，我们使用了一个 `Random` 对象来随机生成计算机的移动。因此，计算机的竞争性相对较低。

在这个练习中，我们希望通过为计算机做出最佳决策来提高游戏的难度。

我们将通过使用 **极大极小** 算法（一种定义明确的程序，允许计算机解决问题）将人工智能引入我们的程序。

### 极大极小算法

极大极小是一种用于两位玩家游戏的算法，可以为玩家做出最佳决策。

- 两位玩家分别被称为<b>最大化者</b>和<b>最小化者</b>。最大化者希望尽量提升自己的获胜机会，而最小化者则试图尽量减少自己的损失。
- 该算法基于当前游戏棋盘，假设最大化者和最小化者都会选择对自己最有利的移动，从而检查所有可能的未来游戏状态。
- 在我们的案例中，我们让计算机成为最大化者，让玩家成为最小化者。我们将通过最大化计算机的获胜机会来为计算机做出最佳决策！

### 极大极小算法在井字棋中的工作原理

- 我们检查 `"X"` 和 `"O"` 的所有可能移动，并对出现赢家或平局的棋盘赋予一个分数。
- 由于我们希望计算机以最少的步数获胜，我们设计棋盘的分数规则如下：

- 如果计算机获胜，使用公式 `1 * (棋盘上可用位置数 + 1)` 计算分数。
- 如果玩家获胜，使用公式 `-1 * (棋盘上可用位置数 + 1)` 计算分数。
- 如果是平局，分数为 `0`。
- 注意：通过为计算机能够以更少的步数获胜的棋盘赋予更高分数，我们教会了代码为计算机选择最佳移动。

1. 在第一行，我们考虑了计算机 `"O"`（最大化者）的三个可能移动。
2. 我们检查所有游戏状态，直到所有移动都导致计算机获胜、玩家获胜或平局。然后为它们赋予相应的分数。

    例如，在第一行的第二个棋盘中，计算机通过在第8个位置放置 `"O"` 获胜。该状态将被赋予分数 `1 * (棋盘上可用位置数 + 1)` = `1 * (2+1)` = `3`。

3. 对于没有赢家或平局的游戏状态，最小化轮次（当 `"X"` 做移动）时选择最小分数，最大化轮次（当 `"O"` 做移动）时选择最大分数。

- 这是在数据结构中查找最大值的一种有效方法。例如：

```java
public int getLargestNum() {
    // 以下代码在数组 "nums" 中找到最大值
    int[] nums = {3, 5, -2, 10};
    int largestNum = Integer.MIN_VALUE;
    for(int i = 0; i < nums.length; i++){
        if(nums[i] > largestNum){
            largestNum = nums[i];
        }
    }
    return largestNum;
}
```
