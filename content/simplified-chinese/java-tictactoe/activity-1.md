在这个活动中，我们将编写一个程序来打印出游戏棋盘和游戏提示，如下输出所示：

```
<<<~  Tic  Tac  Toe  ~>>>
* 选择数字 1 - 9 以放置你的棋子
* 玩家: 'X' 电脑: 'O'

 1 | 2 | 3 
---+---+---
 4 | 5 | 6 
---+---+---
 7 | 8 | 9 
输入你的棋子位置 (1-9): 2
 O | X |   
---+---+---
   |   |   
---+---+---
   |   |   
输入你的棋子位置 (1-9): 
```

## 主类和主方法

注意，在起始代码中，我们有一个类 `Main` 和一个 `main()` 方法。`main()` 方法是程序开始执行的地方，无论何时点击 “运行” 按钮，程序将从这里开始。

```java
public class Main {
  public static void main(String[] args) {
  }
}
```

## 打印语句

在 `main()` 方法中，使用打印语句来输出欢迎语和游戏规则！

```
<<<~  Tic  Tac  Toe  ~>>>
* 选择数字 1 - 9 以放置你的棋子
* 玩家: 'X' 电脑: 'O'
```

## 变量和数组

在游戏中，我们需要跟踪棋盘上每个位置的当前符号。

因此，我们需要在程序中存储这 9 个位置的数据。我们可以使用大小为 9 的 `数组`（一种数据结构）来存储这些数据。

根据游戏规则，游戏棋盘上的 `"X"` 是玩家的棋子，`"O"` 是电脑的棋子，`" "` 是一个可用的位置。

为此，我们在程序中声明一个名为 `board` 的数组变量，其值为包含 `" "` 字符串的 9 个位置（即 `{" ", " ", " ", " ", " ", " ", " ", " ", " "}`）。

## 显示棋盘

现在我们有变量 `board` 来存储棋盘上当前的符号，让我们尝试使用打印语句输出一个空的游戏棋盘（如下所示）。

注意，每个棋盘由 5 行组成，因此合理的做法是有 5 个打印语句来打印每行棋盘。

每个棋盘块是长度为 3 的 `String`，其中中间字符是存储在 `board` 中对应位置的当前符号。

完成此步骤后，程序应输出以下内容：

```
<<<~  Tic  Tac  Toe  ~>>>
* 选择数字 1 - 9 以放置你的棋子
* 玩家: 'X' 电脑: 'O'

   |   |  
---+---+---
   |   |  
---+---+---
   |   | 
```

## 方法

我们知道在游戏中我们将需要多次打印当前的游戏棋盘，因此将第 4 步中编写的代码移动到一个方法中会是个好主意。

该方法应接受一个 `String[]` 输入，并打印当前棋盘。注意，这个方法应该写在 `main()` 外部。

让我们编写一个方法，具有以下声明：

```java
public static void printBoard(String[] curBoard);
```

## 调用方法

在 `main()` 中调用 `printBoard()`，使其打印初始的标记棋盘。你可以通过创建一个内容为 `"1", "2", ..., "9"` 的另一个 `String` 数组来实现这一点。
