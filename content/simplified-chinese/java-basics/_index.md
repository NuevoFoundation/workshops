Java 是一种高级编程语言，由 James Gosling 和 Sun Microsystems 于 1995 年在加利福尼亚开发。

<img src="images/logo.png" height="150" alt="Java 的标志：冒着热气的咖啡杯，下方写有 Java" />

{{% notice info %}}
高级编程语言之所以被称为高级，是因为它与计算机中央处理器（CPU）运行的原始代码相差较远。高级代码是为人类使用而设计的，比低级代码更容易理解。高级代码稍后会被翻译成低级语言，而低级语言只能被特定的 CPU 理解和运行。为了让代码正常工作，每一行用高级语言编写的代码都必须在被计算机执行之前转换为机器语言。
{{% /notice %}}

如今，Java 被世界各地的开发人员广泛使用。具体来说，Java 常被用于开发 Android 移动应用程序、桌面应用程序、Web 应用程序以及游戏。

在本课程中，我们将涵盖 Java 语言的所有基础功能。
