## 使用 Replit

今天，你将使用 Replit 学习如何用 Java 编码。在开始之前，如果你还没有 Replit 账户，则需要注册一个。

点击下面的按钮注册一个 Replit 账户——你需要一个邮箱来注册。如果你已经有一个 Replit 账户，可以使用下面的按钮登录你的账户。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">注册 Replit</a>

<img src="../images/replit-signup.png" height="300" alt="Replit 注册表单" />

接下来，点击下面的按钮启动我们今天将要使用的 Replit 控制台。你应该会看到下面的屏幕。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JavaBasicsTest" target="_blank">启动 Replit</a>

<img src="../images/replit-start-screen.png" height="300" alt="Repl 的启动屏幕" />

现在，我们将要 fork 这个 Repl。这只是意味着为程序创建一份副本，以便我们可以对其进行更改。点击右上角的 "Fork Repl" 按钮，接着点击 "Fork Repl"。

<img src="../images/replit-fork.png" height="300" alt="Fork 一个 repl 以创建程序的副本" />

在 fork Replit 后，你将看到类似下面的窗口：

<img src="../images/replit-window.png" height="300" alt="Replit 窗口" />

{{% notice warning %}}
每次你看到“启动 Replit”按钮时，需要按照上述步骤 fork Repl，以完成活动。如果在 fork Repl 时有困难，请随时寻求帮助！
{{%/notice %}}

在开始之前，让我们先了解一下这个窗口如何运作。`Main.java` 文件包含代码，也就是让计算机运行的指令。通过按下 **运行** 按钮（位于框架顶部中间的绿色三角形按钮），你可以告诉计算机执行代码中的指令。运行代码的任何结果都将在底部屏幕的 **Console** 标签下显示。

在“对象和类”练习中，你需要在 `Main.java` 文件和 `Birds.java` 文件之间切换。你可以通过点击右侧看起来像文档的图标来执行此操作。这将打开文件菜单，并允许你访问其他文件。

尝试按下 **运行** 按钮。如果你看到 **Let's learn Java!**，说明你已经准备好了。让我们开始吧！
