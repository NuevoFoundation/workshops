<strong>Nuvi 说：</strong> Discord 看似只是一个聊天应用，但它实际上非常适合我们的机器人项目！这是数百万用户线上聚集的地方——从玩家到学习小组。最酷的是，Discord 允许我们添加机器人来让这些社区变得更棒。
{{< /alert >}}

Nuvi 的新社区驻扎在 Discord 上——一个让人们可以创建社区（称为 **服务器**）的平台，用户能够通过文字、语音或视频聊天。你可以将一个服务器想象成一个俱乐部、游戏、课堂或朋友群的组。每个服务器内都有 **频道**，频道可以帮助整理对话。例如，一个频道可能用于作业帮助，另一个频道可以用来谈论视频游戏。

### 核心概念
- **服务器：** 人们为群组或主题创建的空间。
- **频道：** 服务器内部的房间（文本或语音）用于不同的讨论。
- **用户：** 拥有账号的人，可以加入服务器（有时需要通过邀请）。
- **机器人：** 计算机程序（例如你将要创建的机器人！），可以帮助完成任务，比如聊天管理、消息翻译或播放音乐。

Discord 最初在玩家中很流行，但现在也被学习小组、兴趣社区和课堂广泛使用。这使得它成为 Nuvi 的国际朋友们的完美聚集地——如果每个人都能阅读彼此的信息就更好了。

{{< alert theme="warning" >}}
<img src="../../media/NF_mascot.jpg" alt="Nuvi mascot" width="70px" style="float:right;margin:0 0 6px 10px;" />
<strong>警告：</strong> 线上要保持聪明！永远不要与不认识的陌生人分享你的个人信息，比如你的真实姓名、地址或学校。一定要保守你的机器人令牌秘密——这相当于机器人的密码。
{{< /alert >}}

### 安全提示
永远不要向陌生人分享你的个人信息（姓名、地址、电话、学校）。同时要保护好你的机器人令牌（密码），防止别人利用它来控制你的机器人。

## 为你的机器人创建一个测试服务器
在邀请你的机器人之前，最好先有一个私人服务器，在这里你可以安全地进行实验。

{{< alert theme="success" >}}
<img src="../../media/NF_mascot.jpg" alt="Nuvi mascot" width="70px" style="float:right;margin:0 0 6px 10px;" />
<strong>Nuvi 提示：</strong> 创建自己的服务器就像拥有一个实验室，你可以在这里安全地进行测试。我总是在一个私人“机器人操练场”服务器中测试新功能。
{{< /alert >}}

1. 打开 Discord 应用（或通过浏览器访问 https://discord.com/app 并登录）。
1. 看屏幕最左侧的侧边栏（服务器图标的列）。点击加号按钮。
![创建服务器按钮](../../media/add-server.png)
1. 选择 `创建我的服务器`（无需模板）。
![选择模板](../../media/create-my-own.png)
1. 选择 `为我和我的朋友们`。
![为我和我的朋友们](../../media/friends.png)
1. 给服务器起一个名字，例如 `机器人测试实验室` 或 `翻译机器人开发`。
1. 点击 `创建`。

现在你有了一个空白服务器，其中包含一些默认的频道（例如 `#general`）。稍后你将邀请机器人到这里，以便测试机器人命令。

### 保持私人化
在你学习时，只邀请你信任的人。等你的机器人稳定后，你可以创建一个“真实”的服务器。
