Nuvi的机器人可以进行回应，但目前还不能帮助朋友们互相理解。在这一部分中，您将安装一个可以*本地*运行翻译的程序——不需要任何外部账户——这样机器人就能成为Nuvi想象中的多语言桥梁。

您将使用它来：
- 手动测试`/translate`命令
- 检测消息是英语还是西班牙语（`/detect`端点）
- 为注册用户自动翻译消息（`/translate`端点）

现在让我们设置翻译引擎，以便机器人可以与之连接。

---

## 1. 什么是LibreTranslate？
LibreTranslate是一个免费的开源翻译程序（由社区创建），它可以在本地运行。无需账户，无需云订阅。您输入一种语言的文本，它会返回另一种语言的翻译。

为什么它对这个工作坊有帮助：
- 隐私：您的文本保存在您的设备上。
- 控制：您选择语言并决定何时更新。
- 离线使用：下载语言数据后，它可以在没有互联网的情况下工作。
- 开源：您可以查看它的工作原理，甚至参与到开发中。

可以将它想象成一个微型的本地网站，它有一个**API**，您的机器人将调用API执行两项任务：
1. 检测消息使用的语言（`/detect`）
2. 将消息翻译成另一种语言（`/translate`）

这为后面的自动翻译功能提供了动力。

### 什么是API？
API就像是程序的菜单。它列出了可以调用的“端点”（URLs）以及返回的内容。当您访问 `http://127.0.0.1:5000/translate` 并带上正确的数据时，LibreTranslate 的 API 会返回翻译后的文本。您的机器人将**发送请求**（您的文本 + 语言选择），然后**接收响应**（翻译后的文本）——就像点餐后得到食物一样。
