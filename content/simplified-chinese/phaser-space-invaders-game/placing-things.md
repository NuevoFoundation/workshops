## 放置文本

现在，您将学习如何将元素放置在 Phaser 中。请查看下面的 repl。

首先我们来看如何放置文本！

```javascript
message = this.add.text(20, 10, "Hello World!", {
	font: "25px Arial",
	fill: "white"
});
```

这几行代码创建了一个名为 "message" 的变量。这个变量在游戏窗口的 (X, Y) 坐标 (20, 10) 处添加了 "Hello World" 的文本。这段代码还指定了文本的颜色为白色，字体为 Arial，字体大小为 25 px。

将这一行代码放入页面底部的 `create()` 方法中，看看它是否会弹出显示在游戏窗口中。

{{% notice note %}}

1. 创建文本时，变量名称不是屏幕上显示的文本内容，而是您放置在引号中的内容。
2. 此语法也可用于放置存储在字符串变量中的文本。

{{% /notice %}}

{{% notice warning %}}

### 帮助！我的游戏窗口太小了！

别担心，它实际上相对较大，但 repl 默认情况下会进行最小化。您可以通过拖动中间的分隔条来扩展窗口视图。

{{% /notice %}}

## 放置背景

文本非常简单，但当我们希望为游戏使用自己的自定义精灵时(您几乎总是会使用)，需要先在 `preload()` 中加载精灵，然后再在 `create()` 中指定其位置。

我们从创建背景开始。将以下代码放入您的 `preload()` 方法中：

```javascript
this.load.image('background', 'assets/sky.png');
```

这只是将图像加载到游戏中。接下来，让我们用 `create()` 将这个图像添加到游戏中：

```javascript
this.add.image(400, 300, 'sky');
```

这行代码简单地将图像放置在 (400, 300) 的坐标上。试试看，您的背景是否已经不再是一个黑屏！

{{% notice note %}}

坐标 (400, 300) 是我们放置图像中心像素的位置。这意味着 (400, 300) 将是图像的中心。我们在此处放置图像，是为了让它覆盖整个屏幕，像一个背景一样。

{{% /notice %}}

## 放置角色

接下来，让我们在我们的世界中放置一个角色。

需要放入 `preload()` 方法的代码如下：

```javascript
this.load.spritesheet('dude', 'assets/dude.png', {
    frameWidth: 32,
    frameHeight: 48
});
```

由于这是一个精灵表而不是简单的精灵，因此它需要更多的代码。精灵表看起来是这样的：
![dude](../media/example-dude.png)
这是我们角色的精灵表。精灵表本质上是同一个角色或物体的多个位置的精灵集合。将这些图像连续播放时，它们将在游戏中创建动画(我们将在下一课中详细介绍)。虽然我们很容易看出这是一个角色的图像集合，但计算机无法自行轻松检测这一点。所以我们需要更多的语法告诉计算机精灵表中每个精灵的大小(在本例中为 32x48)。

在 `create()` 中放置精灵表的语法与图像非常相似，但需添加一个物理标记：

```javascript
dude = this.physics.add.sprite(250, 200, 'dude');
```

在这一行代码中，我们创建了名为 "player" 的变量，并在坐标 (250, 200) 处添加了精灵表的第一张图片。该图片还被赋予名称 "dude"。

在这一行代码中，player 是我们创建的变量名称。250 和 200 是我们放置精灵的 X 和 Y 坐标，因此它会被放置在屏幕上的 (250, 200) 坐标处。"dude" 是我们精灵的名称，但在本课程中，它不会起主要作用。

尝试着将角色添加进来吧！您是否看到屏幕上的角色了？

{{% notice note %}}

1. 为了看到角色，`create()` 中的 dude 变量必须在背景之后创建。这是因为计算机会从上到下读取代码，因此如果角色在背景之前放置，那么计算机会将背景覆盖在角色上，导致用户无法看到角色。
2. 成熟的角色应该朝左看，因为精灵表在初始放置时总是会显示表中的第一个条目，而我们的角色在第一个条目中正朝左看。

{{% /notice %}}
