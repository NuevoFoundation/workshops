## 学习一些机器学习知识来评估 FIFA 视频游戏中球员的整体评分

机器学习是研究*算法*和*模型*的科学，它使计算机能够识别事物、做出决策，甚至在没有明确指令的情况下预测结果。例如，当与手机语音助手（如 Siri 或 Cortana）对话时，机器学习会帮助将你的语音转换为文本，并进一步理解你的请求。是不是很神奇？

今天，我们将逐步演示如何*教会*计算机根据球员的属性评估球员的总体评分。

让我们开始吧！

## 一点背景知识

假设有一个公式可以计算 EA Sports（FIFA 2019 的开发商）为足球运动员设定的“总体”评分。有了这个公式，即使是游戏中没有的球员，我们也可以轻松计算出他们的总体评分。问题是，我们不知道这个公式到底是什么样子的。<br>
我们知道*输入*，即球员的属性，以及*输出*，即总体评分。因此，我们可以使用一种称为“回归”的方法，根据输入和输出来“估算”这个公式。

今天，我们将使用一种简单的模型，称为线性回归。  
假设用于计算足球运动员总体评分的公式 \( y = f(x)\) 是
\[
    f(x) = ax + b
\]
线性回归的目标是找出 \(a\) 和 \(b\)。公式 \(f(x)\) 在机器学习中称为“模型”，求解/估计模型的过程称为“训练”模型。一旦我们训练好了模型，就可以用它来预测新数据的目标值 \(y\)。

回到我们的故事，如果我们只有一个变量 \(x\)，估算 \(f(x)\) 应该很容易。每个人都应该能够用一支笔和一张纸解决它。然而，当 \(x\) 是足球运动员的一长串属性时，比如速度、力量、传球、抢断等，就变得复杂起来。公式需要改写为
\[
    f(x_1, x_2, ..., x_n) = a_1 * x_1 + a_2 * x_2 + ... + a_n * x_n + b
\]
然后我们需要向模型提供大量高质量数据，以使模型尽可能接近“真实”公式。让我们开始吧！
