## 介绍

从树顶上的**小猴子（Monito）**兴奋地向你打招呼：

> “你已经走了很远的路！你已经了解了**与门（AND）**、**或门（OR）**和**非门（NOT）**。
> 现在是时候**把它们组合起来**为**森林球体**恢复能量了。”

在这个活动中，你将构建一个使用**所有**逻辑门来解决挑战的电路。

---

<img src="../media/pattern.webp" alt="逻辑工作坊装饰图案" width="100%" />

## 目标

构建并验证逻辑电路：

- **球体**会亮起，如果：
  - **B**是打开的，或者
  - **A**是打开的且**C**是关闭的。

这个电路使用了**非门（NOT）**、**与门（AND）**和**或门（OR）**。

---

## 所需组件

- 3个**输入**: A, B, C  
- 1个**非门（NOT）**  
- 1个**与门（AND）**  
- 1个**或门（OR）**  
- 1个**输出**

<img src="../media/actividad_4.png" alt="结合与门、或门和非门的电路示例，三个输入和一个输出" width="20%" class="lg-img"/>

## 模拟器说明

### 1. 放置组件
1. 确保处于**编辑模式**。
2. 在左侧栏中选择并放置：
  - 放置**A**、**B**、**C**（输入）。
  - 放置**非门（NOT）**、**与门（AND）**、**或门（OR）**。
  - 在右侧放置一个**输出**。

### 2. 连接组件
1. 将**C ➔ 非门**连接起来（这将得到**非C**）。  
2. 将**A**和**非C**连接到**与门**（这将得到**A与非C**）。  
3. 将**(A与非C)**和**B**连接到**或门**。  
4. 将**或门输出 ➔ 输出**连接起来。

---

## 指导测试

尝试以下组合并验证**输出**：

1. **A = 1, B = 0, C = 0** ➔ `非C = 1` ➔ `A与非C = 1` ➔ `输出 = 1`  
2. **A = 1, B = 0, C = 1** ➔ `非C = 0` ➔ `A与非C = 0` ➔ `输出 = 0`  
3. **A = 0, B = 1, C = 1** ➔ `B = 1` ➔ `输出 = 1`  
4. **A = 0, B = 0, C = 0** ➔ 两条路径都是`0` ➔ `输出 = 0`  

如果以上四个匹配，球体就会正确亮起！

## 常见错误及解决方法

- **输出始终为0**：检查**或门（OR）**是否接收了**两个信号**：`B`**和**`A与非C`。  

---

## 你学到了什么？

- 逻辑门可以组合起来，创造比单一逻辑门更复杂的决策。
- **非门（NOT）**可以反转信号；**与门（AND）**可以组合同时满足的条件；**或门（OR）**可以连接不同的路径。
- 最终输出取决于逻辑门如何连接以及信号的处理顺序。
