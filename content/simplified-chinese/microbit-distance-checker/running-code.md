现在我们已经写好了代码，是时候试一试了。首先，我们需要将 micro:bit 与电脑配对。找到你的 USB 数据线，将较小的一端连接到 micro:bit 顶部的银色 USB 接口，另一端连接到电脑上的 USB 接口。在 MakeCode 工作空间中，点击下载按钮旁边的省略号 (...)，会出现一个小菜单。从菜单中点击“配对设备”。

在弹出的新窗口中，点击右下角的紫色“配对设备”按钮。最后，又会弹出一个窗口。点击“BBC micro:bit CMSIS-DAP”，然后点击底部的“连接”按钮。现在我们已经连接好了，可以下载代码了。你通常只需要进行一次配对。

![下载按钮选项已展开并选择了“配对设备”](../img/pairDevice.png)
![弹出窗口指示用户连接他们的 micro:bit 并配对设备](../img/pairModal.png)
![浏览器的已连接设备列表](../img/connectToDevice.png)

现在再次点击紫色下载按钮旁边的省略号 (...)。这次，选择“下载到 micro:bit”选项。当下载按钮停止旋转后，寻找“下载完成”提示气泡：这意味着我们已经完成了！尝试远离其他处于相同无线电频道的 micro:bit，看看 micro:bit 上的眉头是否会皱成笑脸！

![显示下载完成提示气泡](../img/downloadComplete.png)
