现在我们的 micro:bit 已经知道接收到的信号强度，我们需要利用它来判断我们之间的距离。点击“逻辑”部分并抓取“如果 true 则 / 否则”块。将其拖到“收到无线电”块内放到设置信号强度变量的下方。返回到“逻辑”部分，并将 0 = 0 的比较块拖到“如果 true 则”语句的 true 位置上。此时，你的代码应如下所示：

![添加了 if/then/else 语句的工作区](../img/addedLogic.png)

接下来，我们将告诉 micro:bit 如何判断我们是否相距 6 英尺（2 米）。打开变量菜单，选择名为“strength”的气泡，将其拖到 if 语句中第一个零的顶部，使其显示为 `if strength = 0 then`。现在，点击等号 (=) 符号以显示不同符号的列表。选择大于 (>) 符号。最后，点击 if 语句中最后一个零，将其替换为 `-67`。现在你的粉色“当收到无线电信号”块应如下所示：

![添加了 if/then/else 语句的工作区](../img/completedCondition.png)

你可能会疑惑：“为什么是 -67？这看起来像是一个随机的数字。” -67 dBm（这是分贝毫瓦）恰好是我们提前测量两块 micro:bit 相距 6 英尺时的功率水平。不同的蓝牙设备，比如你的手机，在相同距离下的信号强度可能不同。当信号强度越接近 0 时，信号就越强，说明你离另一台设备也越近。而信号强度越远离 0，则信号越弱，这意味着你可能离设备也更远。

这意味着如果接收到的信号强度强于 -67 dBm（`strength > -67`），那么我们的 micro:bit 无线电之间的距离小于 6 英尺。但如果信号比这个值更弱，那么我们的无线电之间的距离就大于 6 英尺。
