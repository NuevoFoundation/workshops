## 任务 1: 打印二维数组

在下面的二维数组中，我们有一个不同食物的列表。每一行都是同一类型。例如，第一行是主菜的数组，第二行是饮料的数组，第三行是甜点的数组。

```js javascript
String[][] menu = {    
                    { "Hamburger", "Pasta", "Steak", "Tacos" },
                    { "Cola", "Sprite", "Pepsi", "Fanta" },
                    { "Pudding", "Ice Cream", "Mochi", "Cake" }
                  };
```
运用你所学的知识，打印这个数组！
