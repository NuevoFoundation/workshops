## 可视化栈

栈与队列非常相似，许多关于队列的概念同样适用于栈。不同的是，栈并不像队列那样遵循先进先出（FIFO）的逻辑，而是使用相反的逻辑：后进先出（LIFO，Last In, First Out）。

一个常见的例子是把栈想象成一叠盘子。假设有5个盘子堆叠在一起，如果你在上面再放一个第六个盘子，那么这叠盘子现在就是6个盘子的栈了。然而，如果你想移除一个盘子呢？你不会去拿栈底的盘子，而是从栈顶拿一个盘子。

这种后进先出（LIFO）的逻辑也适用于 Java 中的栈。
