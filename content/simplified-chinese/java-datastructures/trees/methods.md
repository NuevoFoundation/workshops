## 二叉树

树是一种特殊的 数据结构，因为它由通过边连接的节点集合组成。与我们之前看到的其他数据结构不同，没有一个一站式的初始化器来创建一个新的通用树。为了简化，我们将具体查看**二叉树 (Binary Trees)**，这是一种具有严格规则的特定类型的树，规定每个节点应该放置在哪里。

二叉树的规则是：
* 每个节点恰好有两个边，一个左节点和一个右节点
* 左边的节点小于当前节点
* 右边的节点大于当前节点

我们之前看到的树是二叉树的一个例子。检查每个节点并自行确认它们是否遵循这些规则！

## 搜索元素

在我们查看如何用代码实现搜索之前，先看看二叉树是如何搜索元素的。当我们检查树中的元素时，总是从根节点开始，在二叉树中，根节点应该大致位于数据的中间。

一旦我们从根节点开始，就检查其值并问自己：“我们要找的值是小于、等于还是大于这个值？” 如果值相等，太好了！我们找到了答案。如果我们要找的值小于当前的值，那么我们前往左边的节点并再次问自己同样的问题。如果我们要找的值大于当前的值，那么我们前往右边的节点并再次问自己同样的问题。

## 遍历元素

既然我们在概念上理解了搜索元素，我们可以看到，搜索元素其实只是不断重复同样的操作。这意味着只要程序正确地执行该操作，整个搜索算法就完成了。

假设我们的节点定义如下：
```js javascript
class Node {
    int value;
    Node left;
    Node right;
}
```

现在，我们可以将上一节中讨论的查找正确元素的逻辑应用于以下代码片段：
```js javascript
Node current = root;
if (current.value < desired) {
    current = root.right;
} else if (current.value > desired) {
    current = root.left;
}
```
我们可以看到，这个逻辑可以让我们从一个步骤转到下一个步骤，然后可以在一个 `for` 循环中使用这个逻辑，直到找到我们想要的值。
