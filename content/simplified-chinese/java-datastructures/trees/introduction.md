树由两个组件组成：**边** 和 **节点**。让我们更详细地了解一下这两个组件。

### 边

你可以将边想象成连接两个节点的线。边总是恰好连接两个节点。边可以携带一些信息，但也可以不携带。

### 节点

节点就是树上的点，表示某些数据。一棵树至少需要一个节点，每个节点可以有任意多的边，只要它与另一个不同的节点相连。

### 为什么是树？

树是一种非常简单的数据结构，可以存储大量数据，同时仍然允许快速查找。许多依赖寻找最佳匹配的算法在搜索之前会将数据组织成树，以优化速度。以下是一些树在现实世界中的应用例子：
* <a href="https://en.wikipedia.org/wiki/Spanning_Tree_Protocol" target="_blank">生成树协议</a> - 使用互联网的基础协议，
* <a href="https://en.wikipedia.org/wiki/Binary_search_algorithm" target="_blank">二分搜索</a> - 搜索已排序数据集最有效的算法之一，
* <a href="https://docs.oracle.com/javase/8/docs/api/java/util/TreeMap.html" target="_blank">TreeMaps</a> - Java 中 HashMap 数据结构的姐妹结构，用树来组织数据。

有些树有更具体的规则，规定如何向其中添加数据以及如何维护其内部的数据。这意味着几乎总有一种树可以满足任何场景的需求。

## 可视化树

树有一个被称为 **根节点** 的节点，这是其余树直接或间接连接的地方。我们称这种数据结构为树，因为节点从根节点分支出来。当你看到树的图形表示时，通常会将根节点放在顶部，但并非总是如此！
