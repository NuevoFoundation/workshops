数组是一种数据结构，其中每个元素按数字顺序排列，每项都可以通过其位置编号进行引用。在 Java 中，每个元素都是一种类型（`String`、`int`、`double` 等），并且使用零索引，这意味着数组中的第一个元素的索引为 `0`，第二个元素的索引为 `1`，依此类推。

![image](../img/array.png)

在我们进一步讨论数组之前，请了解以下一些重要术语：

- 数组中的项目数量称为数组的 **长度**。
- 数组中每个项目的类型称为数组的 **基本类型**。
- 数组中某个项目的位置编号称为该项目的 **索引**。

在本实例中，我们想要创建一个数组来存储应用中所有的餐厅。假设我们的程序需要处理一千家不同餐厅的名称，我们需要一种方法来方便地整理和处理所有数据。如果没有数组这样的数据结构，我们可能需要为每家餐厅创建一个变量，并且如果我们想执行一个简单的操作，比如打印出每家餐厅的名称，就需要写1000个打印语句。完成这样的工作将会是一项巨大的挑战。

相反，数组可以使我们用一个步骤完成同样的操作。数组只是一个单一变量，但它包含1000家餐厅的信息。

![image](../img/array2.png)

数组的 **长度** 是1000，因为其中包含1000个独立的名称。数组的 **基本类型** 是 `String`，因为数组中的项目是字符串类型。第一个名称在数组中的 **索引** 为 `0`，第二个名称的索引为 `1`，依此类推，直到第1000个名称，其索引为 `999`。
