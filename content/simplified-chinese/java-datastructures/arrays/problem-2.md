## 任务2：排序数组！

菜单上各项的成本分布不规律！请帮助我们将数组从小到大排序。

{{% notice tip %}}
1. 想一想如何给数组排序（有很多不同的排序方法可以使用）！
2. 看一下下面的示例！
{{% /notice%}}

如果我们有下面的数组，
```js javascript
int[] cost = {100,90,50,60,20,1,3};
```

我们应该得到如下输出：
```js javascript
int[] sorted = {1,3,20,50,60,90,100};
```
