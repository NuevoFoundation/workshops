## 可视化队列

想象一下，你正在为一家企业（比如麦当劳）设计 NuevoEats。

我们希望以最有效的方式为我们的大型企业服务新潜在客户；一次一个。当客户在 NuevoEats 应用上提交外卖订单时，这几乎就像他们在餐厅门前排起了一条整齐的队伍，新客户从队伍的后方加入。客户在提交订单时应该本质上“排队”，而我们则按照从前到后的顺序为这些客户服务。

Java 中的 `Queue`（队列）以类似的方式工作。在声明 `Queue` 后，我们可以将新的元素添加到队列的尾部，并从队列的头部移除元素。

实际上，在 Java 中，我们遇到的大多数队列都遵循这种先进先出（First In, First Out，FIFO）方式。
