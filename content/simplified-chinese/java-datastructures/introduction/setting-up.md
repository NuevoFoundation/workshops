## 设置 Replit！

今天您将使用 Replit 学习与 Java 相关的数据结构。在开始之前，如果您尚未拥有 Replit 账户，则需要注册一个账户。

点击下方按钮注册一个 Replit 账户——您将需要一个电子邮件账户来完成注册。如果您已经有了一个 Replit 账户，可以使用下方按钮登录您的账户。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">注册 Replit</a>

<img src="../img/replit-signup.png" height="300" alt="Replit 注册表单" />

接下来，点击下方的按钮启动今天将使用的 Replit 控制台。您应该会看到以下屏幕。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/HelloWorld" target="_blank">启动 Replit</a>

<img src="../img/replit-start-screen.png" height="300" alt="Repl 的起始屏幕" />

现在我们需要 fork 这个 Repl，简单来说就是创建这个程序的副本，这样我们就可以对它进行修改。点击右上角的 "Fork Repl" 按钮，然后再点击 "Fork Repl" 按钮。

<img src="../img/replit-fork.png" height="300" alt="fork 一个 repl 以创建程序副本" />

在 fork Replit 后，您将会看到如下所示的窗口：

<img src="../img/replit-window.png" height="300" alt="Replit 窗口" />

{{% notice warning %}}
每次看到 "启动 Replit" 按钮时，您需要按照上述步骤 fork repl 才能完成活动。如果您在 fork repl 时遇到问题，请随时寻求帮助！
{{%/notice %}}

在开始之前，让我们先理解 Replit 是如何工作的。`main.java` 文件包含代码，或者说是提供给计算机运行的指令。按下 **run** 按钮，您就是在告诉计算机执行代码中的指令。运行代码的任何结果都将显示在底部的白色屏幕上，**result** 标签下。

为了学习如何编码数据结构，我们将使用 Replit 来测试您的技能。按下运行并尝试完成以下任务！

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/introduction" target="_blank">启动 Replit</a>
