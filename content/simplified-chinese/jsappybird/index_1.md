### 变量

变量只是我们可以命名的值，例如字符串、数字和布尔值。我们使用变量来存储信息，以便计算机可以跟踪这些信息。变量通过使用 `var` 关键字和变量名称来创建。然后，您可以使用 `=` 符号后面的信息将该变量与您想要存储的信息关联起来。

例如：

```js
var world = "Hello World";
var x = 88;
var happy = true;
```

您还可以更改变量名所引用的值，如下所示：

```js
var x = 4;
x = 10;
```

在此示例中，变量 `x` 首先被赋值为 4，然后重新赋值为 10。

以下代码创建了一个新的 Phaser 游戏对象并将其存储在一个变量中以供游戏使用。

```js
var game = new Phaser.Game(800, 600);
```

## 活动 1：让我们利用布尔值和布尔表达式

### 条件语句

我们可以使用 if 语句仅在某些条件得到满足时运行一段代码。

例如：

```js
if (isRainingOutside == true) {
  takeUmbrella = true;
}
```

在 `if` 后的小括号 `()` 中，您应该指定一个 _布尔表达式_。**布尔值**是 `true` 或 `false`（真或假）语句。我们可以在 if 语句中利用它。如果表达式为 `true`，则执行 `{ }` 内的代码。

我们还可以使用布尔表达式来检查一个数字是否在特定范围内：

![Comparison Operators](https://imgur.com/F9gGHiI.png)

您还可以使用 `&&`（与）和 `||`（或）运算符连接**布尔表达式**。

![alt text](resources/_gen/images/statements.png "statements")

`&&` 要求两个 _布尔表达式_ 都为 `true`，而 `||` 只需要其中一个 _布尔表达式_ 为 `true` 即可。

例如：

```js
// 由于 5 小于 8 并且 9 不等于 10 ，因此结果为 true。

(1 < 100 &&
  (5 != 10)(
    // 由于至少一个表达式的结果为 true，因此结果为 true
    5 == 5
  )) ||
  10 > 20;
```

### 循环

循环用于多次运行一段代码。有很多类型的循环，但您将在此项目中使用的是 for 循环。

for 循环的格式如下：

```js
for (statement 1; statement 2; statement 3) {
  // 要执行的代码块
}
```

- 语句 1 在运行 `{ }` 中的代码之前仅运行一次。
- 语句 2 用于定义循环停止运行的条件。
- 语句 3 在每次循环迭代时运行。

例如：

```js
var sum = 0;
for (var i = 0; i < 7; i += 1) {
  sum = sum + 1;
}
```

运行此代码后，`sum` 将为 6。这是因为循环将变量每次加 1，共加了 6 次。  
您会注意到我们在 for 循环的第一个语句中创建了一个变量 `i`。然后，该变量用于跟踪循环应该运行的时间。每次循环执行时，我们都会检查 `i` 是否仍小于 7，如果是，我们运行括号内的代码，然后将 `i` 加 1。

这一过程会一直重复，直到 `i < 7` 为假。

我们还可以在括号中的代码中使用 `i`：

```js
var sum = 0;
for (var i = 0; i < 7; i += 1) {
  sum = i + 1;
}
```
