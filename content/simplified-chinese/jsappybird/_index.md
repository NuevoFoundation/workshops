## 介绍

你可能对 Flappy Bird 游戏很熟悉。本次工作坊将指导你用 JavaScript 语言制作你自己的游戏版本！准备好接受挑战了吗？

<p style="text-align: center;"><iframe src="https://giphy.com/embed/euuaA2cwLEUuI" title="JS: JSappyBird - Giphy 动画" width="350" height="350" frameBorder="0" class="giphy-embed"></iframe>

正如你可能已经熟悉 Flappy Bird 游戏一样，这次工作坊将指导你如何制作自己的游戏版本，并让你的朋友也来尝试！在本教程中，我们将学习如何使用 JavaScript 语言，帮助小鸟在你创建的世界中畅玩。

## 开始

今天活动的目标是学习 JavaScript 技能，并结合你的新知识创建一个 Flappy Bird 游戏！让我们开始设置游戏吧。

今天你将使用 Replit。在开始之前，如果你还没有 Replit 账户，你需要先注册一个。

点击下面的按钮注册一个 Replit 账户——你需要一个电子邮件账户才能注册。如果你已经有一个 Replit 账户，也可以使用下面的按钮登录你的账户。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/signup" target="_blank">注册 Replit</a>

<img src="./img/replit-signup.png" height="300" alt="Replit 注册表单" />

接下来，通过点击下面的按钮启动我们今天要使用的 Replit 控制台。你应该会看到如下屏幕。

<a class="my-2 mx-4 btn btn-info" href="https://replit.com/@nuevofoundation/JSappyBird-CSWeek" target="_blank">启动 Replit</a>

<img src="./img/replit-start-screen.png" height="300" alt="Repl 的起始屏幕" />

现在我们将分叉这个 Repl，也就是创建这个程序的一个副本，以便我们能对其进行自己的更改。点击右上角的“Fork Repl”按钮，然后再点击“Fork Repl”按钮。

<img src="./img/replit-fork.png" height="300" alt="分叉一个 repl 以创建程序副本" />

分叉 Replit 后，你会看到如下类似的窗口：

<img src="./img/replit-window.png" height="300" alt="Replit 窗口" />

我们将忽略此屏幕上的部分细节，但我们会介绍一些重要的基础知识。本地的 `index.html` 文件以及所有以 `.js` 结尾的文件都包含了代码或是供计算机运行的指令。按下 **运行** 按钮后，你会告诉计算机执行代码中的指令。运行代码的任何结果都将显示在右侧的 **控制台**。

如果你现在按下 **运行**，你会发现什么也没有发生！你的任务是帮助 Nuvi 完成这个游戏的代码！

所有位于 **活动** 部分下的活动都将在此浏览器选项卡中完成。你将独立完成这些活动，但如果遇到困难可以寻求帮助。
