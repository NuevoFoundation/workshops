一道巨大的门挡住了你的去路，上方写着“拉取请求”。旁边的牌子上写着：“要打开这扇门，必须对您的更改进行审核。”

## 你的任务

1. 将你的本地更改推送到你分叉的代码仓库。
2. 创建一个拉取请求，提交到原始 `CodeDungeon/escape-room` 仓库。

## 指令

1. 推送你的更改：

```
git push origin main
```

2. 前往你在 GitHub 上的分叉仓库。
3. 点击“贡献”，然后选择“打开拉取请求”。
4. 在标题中填写“解决方案 for Room 2”，并提供一个简短的描述。
5. 点击“创建拉取请求”。

{{< notice info >}}
**提示：** 密切关注你的拉取请求。地牢的守卫（仓库维护人员）会对其进行审核，并可能要求做出更改！
{{< /notice >}}

{{< expand "拉取请求流程" >}}

**推送更改**
首先，将你的本地更改推送到你的远程仓库：

```
git push origin main
```

**创建拉取请求**
1. 前往 GitHub 上你的分叉仓库
2. 点击“拉取请求”标签页
3. 点击“新建拉取请求”
4. 确保基础仓库为原始仓库，头部仓库为你的分叉仓库
5. 点击“创建拉取请求”

**等待审核**
创建拉取请求后：
1. 等待维护人员对你的更改进行审核
2. 解决他们提供的任何反馈
3. 推送新提交以更新拉取请求（如果需要）

{{< /expand >}}
