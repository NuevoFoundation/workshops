你进入一个充满安全措施的房间。锁具、护盾和安全监控将你包围。一道严肃的声音宣告：“保护你的代码，才能继续前进！”

## 你的任务

1. 为你的仓库启用 Dependabot 警报。
2. 为你的仓库添加安全策略。
3. 如果你的仓库是公开的，请使用 GitHub Actions 运行代码扫描警报。

## 操作指南

1. 进入你的仓库的“设置”选项卡。
2. 点击左侧边栏中的“安全与分析”。
3. 启用 Dependabot 警报。
4. 在你的仓库中创建一个新文件 `.github/SECURITY.md`。
5. 在该文件中添加基本的安全指南。
6. 如果你的仓库是公开的，请在“安全与分析”设置中启用代码扫描。

{{< notice danger >}}
**重要提示：** 在处理安全设置时始终保持谨慎。确保你在启用每项功能前理解其作用。
{{< /notice >}}
