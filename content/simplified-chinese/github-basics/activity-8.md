你进入一个充满浮动看板和项目时间线的房间，一个舒缓的声音宣布：“将混乱变为秩序，规划你的逃生路线！”

## 你的任务

1. 在你的 GitHub 仓库中创建一个新的项目板。
2. 添加 "待办事项"、"进行中" 和 "已完成" 栏目。
3. 创建几个问题并将它们添加到你的项目板。
4. 将一个问题移到不同的栏目中。

## 指导步骤

1. 进入你的 GitHub 仓库。
2. 点击 "Projects" 标签。
3. 点击 "New project" 并选择 "Board" 作为模板。
4. 向你的项目板添加所需的栏目。
5. 在仓库中创建几个问题。
6. 将这些问题添加到你的项目板。
7. 将一个问题通过每个项目栏移动。

{{< notice info >}}
**提示:** 项目板非常适合可视化你的工作流，跟踪多个问题或拉取请求的进度。
{{< /notice >}}

{{< expand "项目板操作过程" >}}
**创建项目板**
1. 转到 "Projects" 标签
2. 点击 "New project"
3. 选择 "Board" 模板
4. 添加栏目: "待办事项"、"进行中"、"已完成"

**添加问题**
1. 转到 "Issues" 标签
2. 创建新的问题
3. 在每个问题内点击 "Projects" 并添加到你的新项目板

**移动问题**
1. 返回你的项目板
2. 在栏目间拖动问题
3. 观察如何更新任务的进度
{{< /expand >}}
