## 添加注释

在创建 C# 程序时，我们可以通过使用 `//` 添加单行注释，或者使用 `/*` 和 `*/` 添加多行注释来记录一些笔记。（注意：之前活动中的说明是作为注释写的）。

此外，添加注释对程序的运行没有任何影响。因此，你可以在代码中添加注释来记录代码的工作原理，方便自己和其他程序员阅读。

```c#
     // 示例单行注释

     /* 示例
      * 多行
      * 注释 */
```

{{% notice tip %}}

你可以通过注释代码来让计算机不运行它。

```c#
Console.Write("我喜欢吃");
// Console.Write("苹果。");
```

上述代码将在控制台输出“我喜欢吃”，但不会输出“苹果”。
