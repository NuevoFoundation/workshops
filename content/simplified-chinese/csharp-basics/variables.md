## 变量：给它命名！

在第一个练习中，我们学习了如何使用 `Console.WriteLine()` 和 `Console.Write()` 打印不同的语句。

虽然打印一个数字或一句话很不错，但它们没有具体的意义。如果我们想要重复使用这段话或数字，就不得不再次手动输入。

在 C# 中，我们引入了**变量**的概念来存储数据。变量是用一个名称存储数据的一段内容。

例如，可以有一个名为 `myName` 的变量，它被赋值为 `"Ann"`。另一个变量可能叫做 `age`，它被赋值为数字 `12`。

## 什么是类型！

那么我们如何在 C# 中创建这些变量来存储数据呢？

在学习如何创建变量之前，我们需要首先了解 C# 中的一个**数据类型**概念，简称为**类型**。C# 中的类型描述了存储的内容。如果你有一个数字变量，它只能包含数字，不能包含句子或符号。每个变量都有其专属的类型，这决定了它能存放什么样的数据。

例如，我们可以有一个名为 `age` 的变量来存储数字 `12`。如果你尝试在 `age` 中存储词语 `"twelve"`，则会生成错误，因为此变量只接受数字。

在 C# 中，要存储整数值的变量，可以使用 `int` 类型。我们使用如下代码声明一个 `int` 类型的变量 `age` 并赋值为 `12`：

```
int age = 12;
```

通常声明变量的格式为：`[数据类型] [变量名] = [数据];`。

{{% notice note %}}
以下是 C# 中一些重要的内置数据类型：

**类型** | **描述**         | **例子**
---------|-----------------|----------
`int`    | 整数              | `20`, `30`, `35`
`char`   | 字符，如单个符号或字母  | `'A'`, `'b'`, `'('`, `']'`
`string` | 字符串（字符序列）   | `"Hello"`, `"Bonjour"`, `"Hola"`
`bool`   | 布尔值，值只能是 `true` 或 `false` | `true`, `false`
`double` | 浮点数              | `2.0`, `3.14`, `9.33`

{{% /notice %}}

继续之前的例子，在 C# 中声明这些变量可以这么写：

```C#
string name = "Ann";
int age = 12;
boolean loveMusic = true;
```

最后一个变量是一个有趣的例子。它只能接受 `true` 或 `false` 两个值。在本课程的高级部分，我们会看到它如何大有用处。
