## 让我们做数学运算：算术运算符

在上一个练习中，我们学习了变量以及如何将值分配给特定类型的变量，例如：

```C#
int age = 3;  // 声明类型为 int 的变量 age，并赋值为 3
age = 4;      // 将 4 赋值给变量 age
```

查看上面的代码，本质上等同于将 1 添加到变量 `age` 的值上。

在 C# 中，我们可以直接使用 **算术运算符** `+`、`-`、`*`、`/` 和 `%` 对变量进行数学运算。例如，我们可以使用加法运算符 `+` 将 1 添加到 `age`：

```c#
int age = 3;  // 声明类型为 int 的变量 age，并赋值为 3
age = age + 1;// 将 1 加到 age
```

{{% notice note %}}
以下是 C# 中的算术运算符：

**运算符** | **描述** | **示例**
------|------|--------
`+` | 加法 | `1 + 1 = 2`
`-` | 减法 | `2 - 1 = 1`
`*` | 乘法 | `3 * 3 = 9`
`/` | 除法 | `9 / 3 = 3`
`%` | 模运算/取余数 | `10 % 4 = 2`

**注意**：如果除法的两个操作数都是整数，结果也将是整数。例如，`10 / 4` 返回 2 而不是 2.5，因为余数被丢弃。如果任一操作数是 double，则结果将是 double。

**注意**：使用模运算符（`%`）可以获得除法操作的余数。

{{% /notice %}}

{{% notice tip %}}
加号（`+`）运算符可以用于字符串的拼接。例如：

`String name = "Patric" + "k";` 等价于 `String name = "Patrick";`
{{% /notice %}}

## 比较：关系运算符

接下来，让我们学习如何使用 **关系运算符** 来比较数字。

就像数学中一样，我们可以使用 `>`、`<`、`>=`、`<=` 来比较数字。例如：`(3 > 2)` 的结果是 `true`，一个布尔值。

{{% notice note %}}
以下是 C# 中的关系运算符：

**运算符** | **描述** | **示例**
------| ------| ------
`==` | 等于 | `(3 == 3)` 是 `true`
`!=` | 不等于 | `(3 != 3)` 是 `false`
`>` | 大于 | `(3 > 2)` 是 `true`
`<` | 小于 | `(3 < 2)` 是 `false`
`>=` | 大于或等于 | `(3 >= 2)` 是 `true`
`<=` | 小于或等于 | `(2 <= 2)` 是 `true`

注意：`==` 和 `!=` 只能用于同类型的数据。例如：
```csharp
int x=3; 
double y=3.0; 
x==y; // 这会产生错误，因为 x 和 y 类型不同。
```

{{% /notice %}}

{{% notice tip %}}
使用一个等号赋值一个值给变量，而使用两个等号比较两个元素的值。

```csharp
age = 3;  // 将值 3 设置给变量 age
age == 3; // 检查 age 的值是否为 3
```
{{% /notice %}}
