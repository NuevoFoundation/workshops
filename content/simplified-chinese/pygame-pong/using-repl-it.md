## 库和导入语句

查看代码的顶部，你会看到以下这一行：

```
import pygame
```

这个语句允许我们导入 `pygame` 库提供的所有动画和对象绘制功能。**库**是一个将相关功能组合在一起供 Python 语言使用的地方。例如，`pygame` 库提供了一种在屏幕上绘制矩形的方法，我们可以用它来绘制边界、球和乒乓游戏中使用的球拍。

## 注释

以 `#` 开头的灰色行称为**注释**。这些是代码中的说明，用普通的英语解释代码的作用。注释会被计算机忽略；开发人员使用注释来相互交流，尤其是当多个开发人员共同合作开发同一段代码时。注释还允许查看代码的人无需阅读所有代码即可对发生的事情有一个大致概览。
在 `main.py` 中，我们在整个代码中使用注释，指示需要对代码进行更改的位置。
