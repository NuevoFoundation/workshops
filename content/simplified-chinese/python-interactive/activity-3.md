## 欢迎顾客光临餐厅并展示菜单
现在我们已经有了展示给顾客的餐厅横幅，并在您的 Python 程序中存储了菜单，接下来我们将向顾客展示菜单并欢迎他们。在这个活动中，我们将编写两个辅助函数来完成这项任务。

{{% notice info %}}
## 辅助函数
辅助函数是在一个运行该程序所有代码的主函数中被调用的函数。每个辅助函数都旨在完成一个简单的目标。
{{% /notice %}}

我们将编写的第一个辅助函数是 `printMenu()`，这是一个会遍历 `dictMenu` 字典的函数，并生成一个如下例子所示的菜单。由于 `dictMenu` 的值都是列表，其中第一个元素是商品的价格，第二个元素是商品的描述，因此我们要确保在打印每个商品的信息时，通过索引来访问该列表的每个元素。  
提示：商品的描述与商品名称和商品价格分布在不同的行，这告诉了你什么？  
再提示：菜单中的每个商品之间都有一个空行，如何实现这个效果呢？

菜单示例：

-----菜单-----

奶油香蒜意面 ------ $15.99

意面搭配浓郁香蒜奶油酱，上面点缀了黑橄榄和晒干的番茄

春卷 ------ $8.0

将卷心菜、胡萝卜等蔬菜切丝拌炒，与粉丝和薄条炸豆腐混合，然后用酥脆的外皮包裹起来。

我们将编写的第二个辅助函数是 `orderFromRestaurantYN()`，在这个函数中，我们将获取用户的输入，询问他们是否想从菜单中点单。记得为用户提供一个他们应该输入的示例。不管是输入 Y 表示 Yes，N 表示 No，还是输入 yes/no，或 Yes/No，y/n；都需要明确告知用户有效的响应格式。

在你编写完这些函数后，在 `main()` 函数中调用它们，并将其放在打印餐厅横幅之后的部分。在 `main()` 中调用这些函数时，记住，只要用户没有输入 `orderFromRestaurantYN()` 要求的有效答案，我们必须告知他们输入的格式无效，同时再次向他们展示菜单，并再次提示他们输入答案。
