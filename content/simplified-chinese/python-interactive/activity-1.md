## 创建你的餐厅横幅
在设置你的餐厅虚拟收银机时，我们首先需要确保有餐厅的横幅，上面写有你的餐厅名字。由于我们需要的是一个实际的横幅，而不仅仅是名字的普通文字，让我们使用 ASCII 艺术来完成吧！ASCII 艺术使用特殊符号，例如 `()`, `{}`, `*` 等来创建图像和文字。  
在本次活动中，我们可以利用一个在线资源将文本转换为 ASCII 艺术。

[文本转 ASCII 转换器](https://onlineasciitools.com/convert-text-to-ascii-art)

例如，我们可以将单词 "Restaurant" 转换为 ASCII 艺术。看看下面的代码示例！

```python
print("    _   _   _   _   _   _   _   _   _   _  ")
print("   / \ / \ / \ / \ / \ / \ / \ / \ / \ / \ ")
print("  ( r | e | s | t | a | u | r | a | n | t )")   
print("   \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ \_/ ")
```

记得将此文档保持打开状态，因为我们将在稍后的活动中再次使用它，因为每个活动都建立在之前的基础上。最终，你的整个餐厅收银机系统将在此文档中完成设置。
