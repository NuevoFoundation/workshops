## 如何创建和存储菜单
现在我们已经为你的餐厅设计了一个横幅，让我们开始考虑如何组织有关菜品的信息。还记得之前你决定在餐厅销售哪些食物和饮料吗？那么现在我们需要确定如何存储这些信息。我们需要存储菜单中每个项目的名称、价格和描述。
为了实现这个目标，我们可以使用一种称为 Python 字典的数据结构来记录这些信息。

我们将创建一个字典，其中的值是列表！
这样，我们可以轻松获取项目的价格和描述。当我们在字典的键对应的值中使用列表或其他容器时，我们就获得了一个**嵌套字典**。由于我们需要同时存储价格和描述信息，因此我们需要以特定的顺序将这些信息存储在列表中。

这是我们将使用的结构：
{项目名 : [价格, 描述]}
通过在创建**嵌套字典**时确保遵循这种结构，我们可以确保随后访问价格和描述变得简单。

以下是一个示例嵌套字典，但在制作你的菜单时，请记得遵循以上结构！
```python
#结构
#{单词:[定义, 词性, 发音]}
smallDictionary = {'toy':['孩子们玩耍的物品', '名词', 'toi'], 'walk':['一种以规律、缓慢速度移动的方法，一只脚抬起后接另一只脚，循环进行', '动词', 'wok']}
```
