## 接受用户输入

这个游戏将使用您在 Python 基础部分中学到的一些概念。
您需要了解如何使用以下概念。如果您对其中任何概念不熟悉，请返回重新学习。
- <a href="../../python-basics/conditional-statements-loops/loops/" target="_blank">While 循环</a>
- <a href="../../python-basics/basics/writing-to-console/" target="_blank">写入到控制台</a>
- <a href="../../python-basics/basics/reading-from-console/" target="_blank">从控制台读取</a>
- <a href="../../python-basics/conditional-statements-loops/conditional-statements/" target="_blank">条件语句</a>
- <a href="/python-guess-number/random/" target="_blank">随机数</a>

您需要编写代码让这个游戏随机生成一个数字。

然后程序会反复要求用户从控制台输入内容，同时您需要将该输入与随机生成的数字进行比较。

完成重复任务的最佳方法是什么？没错，就是使用循环！
您可以使用 `while` 循环来实现这一任务。

在 `while` 循环中，您可以使用条件语句检查玩家是否猜对了。如果没有猜对，可以给他们一些有帮助的提示，比如告诉他们应该尝试猜更低或者更高。
