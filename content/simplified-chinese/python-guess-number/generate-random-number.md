Python 包含一个名为 `random` 的库，它可以帮助你生成随机数。通过在程序顶部写入 `import random` 并使用 `randint` 函数生成一个指定范围内的数字，你可以在程序中使用该库。

以下代码会生成一个 1 到 10 之间的随机数。
```python
    random.randint(1,10)
```

尝试运行以下代码几次，看看你得到的结果！
