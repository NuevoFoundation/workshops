[EarSketch](https://en.wikipedia.org/wiki/EarSketch) 是由乔治亚理工学院开发的一个免费的教育编程环境。今天我们将使用 EarSketch 来创作音乐。

1. 要制作音乐，请点击下方按钮，在新标签页中打开 Earsketch。

<a class="my-2 mx-4 btn btn-info" href="https://earsketch.gatech.edu/earsketch2/" target="_blank">启动 Earsketch</a>

2. 打开网页后，您可能会看到如下欢迎屏幕。点击“skip”（跳过）跳过教程——我们将在下文详细介绍所有必要的步骤。

<img src="../img/screenshot-skip-tour.png" height="400"/>

3. 现在让我们开始吧。点击左侧菜单栏上的 *Scripts*（脚本）图标，然后选择 *+ New Script*（新建脚本）。

<img src="../img/screenshot-new-script.png" height="400"/>

4. 将脚本命名为 *myjam*（或您喜欢的其他名字），并将编程语言更改为 *JavaScript*。点击 *Create*（创建）按钮创建脚本（即放置代码的文件）。

<img src="../img/screenshot-new-myjam.png" height="200"/>
 
5. 最后，点击齿轮图标并选择 "Blocks mode"（块模式）。您的屏幕现在应该如下所示。

<img src="../img/screenshot-setup-complete.png" height="400"/>

## 推荐教师参考 - EarSketch 概览

在开始上课之前，请先了解一下 EarSketch 的概览。熟悉如何在用户界面中导航非常重要。

屏幕左侧的 `Content Manager`（内容管理器）是导航 EarSketch 功能的主入口。

1. 导航栏的第一个项目是 `Sounds`（声音）集合。这是所有预加载声音的中心位置。在声音浏览器中，您可以根据艺术家、流派或乐器筛选显示的声音。

<img src="../img/screenshot-navigation-sound-browser.png" height="400"/>

2. 导航栏的下一个图标是 `Scripts`（脚本）面板。这是我们编写代码的地方。

<img src="../img/screenshot-navigation-script.png" height="400"/>

3. 导航栏的最后一个图标是 `API Browser`（API 浏览器）面板。*API*（应用程序编程接口）是一组可以直接使用的代码！点击打开后，每个 API 都提供了详细的解释。

<img src="../img/screenshot-navigation-api-curriculum.png" height="400"/>

在右侧，您可以看到 `Curriculum`（课程指南）。如果您想了解更多关于 EarSketch 的内容，可以查看点击后出现在窗口右侧的部分。对于本次练习，我们将跳过这个部分。
