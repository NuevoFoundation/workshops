## 开始

今天活动的目标是学习 C# 技能，并将新学到的知识融入到创建一个猜词游戏中！让我们开始设置游戏吧。

今天你将使用 .NET Fiddle，这是一个旨在帮助你学习、构建和运行 C# 代码的在线工具。

{{% notice tip %}}
在开始之前，你可以选择注册一个 .NET Fiddle 账户，如果你还没有注册且希望以后保存你的工作。

点击下面的按钮注册一个 .NET Fiddle 账户——你需要一个电子邮件账户才能注册。如果你已经有一个 .NET Fiddle 账户，你可以使用下面的按钮登录你的账户。

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/SignUp" target="_blank">注册 .NET Fiddle</a>

<img src="./media/dotnetfiddle-signup.png" height="300" alt=".NET Fiddle 注册表单" />

{{% /notice %}}

接下来，启动我们今天将使用的 .NET Fiddle 控制台，点击下面的按钮。你应该会看到以下界面。

<a class="my-2 mx-4 btn btn-info" href="https://dotnetfiddle.net/lMl7j4" target="_blank">启动 .NET Fiddle</a>

<img src="./media/guessTheWordActivity-start.png" height="300" alt="活动起始界面" />

{{% notice tip %}}
如果你已登录，可以对代码进行 fork，fork 就是简单地复制程序，这样我们就可以对其进行自己的修改并保存。点击顶部的 "Fork" 按钮。

<img src="./media/dotnetfiddle-fork.png" height="300" alt="Fork 一个代码文件以复制程序" />

Fork 成功后，你将看到如下类似的窗口：

<img src="./media/guessTheWordActivity-fork.png" height="300" alt=".NET Fiddle 窗口" />

{{% /notice %}}

我们会跳过这部分界面的一些细节，但会介绍一些基础内容。`main.cs` 文件包含代码，代码是计算机运行的指令。通过按下 **运行** 按钮，你告诉计算机执行代码中的指令。代码运行的任何结果都会显示在右侧，称为 **控制台**。

如果你现在按下 **运行**，你会发现什么都不会发生！你的任务是帮助 Nuvi 完成这个游戏的代码！

任何在 **活动** 部分的内容都将在该浏览器标签页下完成。你将自己完成这些活动，但如果遇到困难会有帮助提供。
