## 注释

开发人员经常需要与其他开发者协作。注释是开发者在代码中写下备注并与他人交流的一种简单方式。计算机会忽略注释；因此，它们也是告诉计算机不要运行某些代码行的一种简单方式。有两种方式创建注释：

1. 若需注释掉一行代码，请在代码行前面加上`//`。例如：

```csharp
// 这是一条单行注释。
```

2. 若需一次性注释掉多行代码，请用`/*`表示注释的开始，用`*/`表示注释的结束。例如：

```csharp
/* 这是一段多行注释。
   这一行也是注释的一部分。 */
```

若需删除注释（或取消注释），只需删除单行注释的`//`，或者多行注释的`/*`和`*/`。

{{% notice tip %}}

## 一起练习

1. 在 `Console.WriteLine("Hello World");` 前加上`//`。按下**运行**后，检查确保`Hello World`未打印到控制台。
2. 删除`//`，改用 `/*` 和 `*/` 包围 `Console.WriteLine("Hello World");`。按下**运行**后，检查`Hello World`仍未打印到控制台。
3. 删除`/*`和`*/`，然后按下**运行**。此时`Hello World`应会打印到控制台。
