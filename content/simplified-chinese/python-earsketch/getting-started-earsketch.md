[EarSketch](https://en.wikipedia.org/wiki/EarSketch) 是由乔治亚理工学院开发的免费教育编程环境。今天我们将使用 EarSketch 来创作音乐。

1. 要制作音乐，请点击以下按钮在新标签页中打开 Earsketch。

<a class="my-2 mx-4 btn btn-info" href="https://earsketch.gatech.edu/earsketch2/" target="_blank">启动 Earsketch</a>

2. 打开网页后，您可能会看到以下欢迎屏幕。点击“跳过”跳过教程——我们将在下面详述所有必要步骤。

<img src="../img/screenshot-skip-tour.png" height="400"/>

3. 现在，让我们开始。点击左侧菜单栏上的 *Scripts* 图标，然后选择 *+ New Script*。

<img src="../img/screenshot-new-script.png" height="400"/>

4. 输入 *myjam*（或您希望的任何名称）作为脚本的名称，并将编程语言保持为 *Python*。点击 *Create* 按钮创建您的脚本（即您代码将被放置的文件）。

<img src="../img/screenshot-new-myjam.png" height="200"/>

{{% notice info %}} 

## 推荐给教师的内容 - EarSketch 概述

在课堂开始之前，请先查看 EarSketch 的概览。熟悉用户界面的导航是非常重要的。

屏幕左侧的 `Content Manager` 是您浏览 EarSketch 所有功能的主页。

1. 导航栏的第一个项目是 `Sounds` 集合。这是 Earsketch 提供的所有预加载声音的中心位置。在声音浏览器中，您可以根据艺术家、流派或乐器筛选显示的声音。

<img src="../img/screenshot-navigation-sound-browser.png" height="400"/>

2. 导航栏上的下一个图标是 `Scripts` 面板。这是我们将编写代码的地方。

<img src="../img/screenshot-navigation-script.png" height="400"/>

3. 导航栏上的最后一个图标是 `API Browser` 面板。*应用程序编程接口*（API）是一组可以直接使用的代码！点击打开后，将提供每个 API 的详细说明。

<img src="../img/screenshot-navigation-api-curriculum.png" height="400"/>

屏幕右侧，您会看到 `Curriculum` 指南。如果您想了解更多关于 EarSketch 的信息，可以探索单击时出现在窗口右侧的内容。本次练习中我们将跳过此部分。
