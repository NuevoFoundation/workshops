## 日程安排
{{< /alert >}}

*[前置步骤, 10 分钟] 获得集群访问权限并将其添加到 ADX*

### 第1部分：了解环境 [1.5 小时]

[5 分钟] 威胁情报简介    
   - 简要提及归因工具和技术     
   - 钻石模型     
   - 杀伤链     

[20 分钟] Kusto 查询语言 (KQL) 入门     
   - 在 ADX 浏览器中介绍 KQL 的表格、命令和语法  
     - where（has, contains, has_any, == 等）    
     - count     
     - take     
     - let     

[10 分钟] 如何对观察到的对手活动进行聚类  
 - 如何决定下一步是否与您的行为体相关？ 
 - 将对行为体的知识映射到钻石模型 
 - 如何判断工作已经完成？ 
 - 聚类的注意事项（错误归因）    

[45 分钟] 场景 1：网络调查简介
 - 调查恶意活动（例如，电子邮件威胁）
 - 使用 Azure Data Explorer (ADX) 分析安全日志数据
 - 运用 KQL 基础知识，通过数据回答针对性问题
 - 在多个数据集中切换和深入分析

[10 分钟] 复盘 
 - 快速回顾如何推导出答案

## 后勤支持
{{< /alert >}}

### 清单

**以下是学生需要准备的物品：**   
* 一台电脑或笔记本电脑（性能不必特别强大）   
* 稳定的互联网连接   
* 一个 Microsoft 账户   
    * 可以是个人的 hotmail 或 outlook 账户    
    * 学校提供的 Office365 账户    
    * *注意：如果学校或组织不允许通过其租户访问 Azure 数据，可能需要准备一个活动专用账户供学生使用*     

**您可能还需要准备以下物品：**   
* 打印好的培训指南纸质版（我们的经验表明，参与者使用纸质指南会表现得更好）    
* 能展示问题和方案的投影仪或智能白板    
* 小吃或零食 - 人人都离不开它们 :)    

### 设置计分面板

要访问 KC7 计分面板，请访问此网站：https://kc7.azurewebsites.net。
 您需要使用填写主持课程表单后收到的登录凭据登录。如果您不是主持人，您也可以创建一个账户登录。

如果您正在管理一个课程，您的课程信息应该已经添加到对应的游戏会话中。登录后，您将在仪表盘上看到它。要参与课程，只需点击“加入此游戏”按钮即可。

您还需要为游戏参与者添加问题或挑战以供得分。添加方法如下：

* 确保您是以管理员身份登录到您的课程会话中
* 找到与您使用的培训指南相匹配的问题清单
* 从下拉菜单中选择问题集
