### 了解您的“为什么”  
为了有效地教授这门课程，了解您的“为什么”是非常重要的。对我们来说，我们知道在我们几人有机会接触威胁狩猎并将其作为一个可行的职业选择的过程中，运气占了很大一部分。因为有些人向我们介绍了网络安全并打开了大门，我们得以掌握了找到威胁狩猎工作所需的技能。世界上有很多和我们一样有潜力的人却没有机会接触这个领域，我们希望改变这一现状。  

随着网络攻击的数量和复杂性不断增加，网络安全已经成为一个越来越重要的职业领域。根据美国劳工统计局的数据，从2021年到2031年，信息安全分析师的就业预计将增长35%，这远远快于所有职业的平均增长率（5%）。  

威胁情报（TI）是网络安全的一个分支，专注于跟踪和理解对网络攻击负责的对手。由于它需要非常特定的技能，威胁情报传统上对学生和入门级专业人士不太开放。这些技能很难通过实践以外的方法来培养，而没有相关行业的工作往往很难接触到网络安全数据。  

KC7 为学生提供了接触现实网络安全数据的机会，并为其提供所需的培训，从而培养关键的网络安全与威胁情报技能。  

### 什么是 KC7?  
KC7 是一个沉浸式的网络安全分析模拟游戏，由微软威胁情报中心的安全专家开发。这个团队专注于追踪世界上最复杂的网络攻击行为者。KC7 为参与者提供了一个学习和应用网络威胁分析技能的机会，他们可以在模拟环境中保护一家虚拟公司免受黑客攻击。参与者将学习并应用微软安全分析师每天使用的分析技能。  

### 作为培训师，通过本课程您将学到什么？  
完成 KC7 后，您将能够：  
- 使用 Kusto 查询语言（KQL）在 Azure Data Explorer（ADX）中处理数据    
- 在多个数据集中跨域“转移”以回答针对性的问题    
- 在审计日志中识别恶意网络活动，包括：电子邮件、认证、网页流量和终端设备日志  
- 使用多种“转移”技术跟踪一个或多个高级持续威胁（APT）行为者的活动  
- 利用第三方数据集（如 PassiveDNS），基于已知的行为者指标（如域名和 IP 地址）发现未知的行为者基础设施  
- 分析关于 APT 行为者及其基础设施与能力的第三方报告  
- 验证威胁行为者的技术、策略和程序（TTPs）  
- 使用钻石模型和其他威胁分析框架对威胁活动进行聚类  
- 利用培训材料培训他人  

### KC7 适合谁使用？   
KC7 适合任何人！这个项目的目标是为那些可能从未把网络安全当作一个可能的职业选择的学生创造机会。我们鼓励任何背景的学生尝试 KC7，看看是否对网络安全充满热情。  

由于 KC7 中介绍的许多概念相当高级，我们认为它最适合高中及以上年级的学生。目前，我们正在开发适合低年级学生的内容。  

### 开始需要什么？  
- 网络连接    

学生将使用托管在 Microsoft 的云端数据分析平台 Azure Data Explorer 中的数据来玩 KC7。整个 KC7 的体验都在网页浏览器中进行，这意味着任何可以运行浏览器的台式机或笔记本电脑都可以支持学生参与游戏。学生只需要一个 Microsoft 账户即可开始。如果他们还没有账户，可以免费创建一个。    

Microsoft 的志愿者将与您的学校合作，安排并举办使用 KC7 的活动。我们建议安排全天的时间，让学生深入学习 KC7 的内容，并从体验中获得最大收获。Microsoft 的志愿者将通过虚拟方式或亲临学校与学生一起参与活动，引导您的学生完成整个体验。    

学生将获得一个培训包，以帮助他们完成全部体验。该指南将帮助学生学习并练习关键的网络安全概念。
