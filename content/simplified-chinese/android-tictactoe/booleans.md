布尔值是真假陈述。与字符串或数字不同，布尔值存储的是关于真理的陈述：我所说的是对的还是错的？例如，如果我问，“你是机器人吗？”，这个问题会产生真假结果，我们称之为布尔值。在这种情况下，因为你不是机器人（希望如此！），我们会返回`false`。我们也可以使用数学运算符来创建布尔表达式。以下是一些示例，但请注意“等于”和“不等于”的特殊符号：

| 运算符   | 描述                  | 运算符   | 描述                      |
| -------- | --------------------- | -------- | ------------------------ |
| `<`      | 小于                  | `>`      | 大于                      |
| `<=`     | 小于或等于            | `>=`     | 大于或等于                |
| `==`     | 等于                  | `!=`     | 不等于                    |

和往常一样，使用 `System.out.println` 来输出你的结果：

```kotlin
System.out.println(10 < 8);
System.out.println((3 * 6) == (32 - 14));
```

## 布尔运算符

你还可以使用 `&&`（与）和 `||`（或）运算符将布尔表达式连接在一起。例如，假设我问：“你是人类，Nuvi是机器人吗？”单词“与”（AND）将两个真假问题连接在一起。这种情况下，因为你是人类为真，并且Nuvi是机器人也为真，那么整体结果为 `true`。以下是一个描述如何连接布尔表达式的表格：  

| 表达式                        | 结果     | 表达式                                | 结果    |
| ----------------------------- | -------- | ------------------------------------- | ------- |
| <code>true && true</code>     | `true`   | <code>true &#124;&#124; true</code>   | `true`  |
| <code>true && false</code>    | `false`  | <code>true &#124;&#124; false</code>  | `true`  |
| <code>false && true</code>    | `false`  | <code>false &#124;&#124; true</code>  | `true`  |
| <code>false && false</code>   | `false`  | <code>false &#124;&#124; false</code> | `false` | 

总结来说，`&&`要求两个布尔表达式都为真，而 `||` 只需要其中一个布尔表达式为真。以下是一些示例：

- `(5 < 8) && (9 != 10)` 返回 `true`，因为 5 小于 8 且 9 不等于 10 都为真。
- `(6 != 2 * 3) || (8 < 2 * 4)` 返回 `false`，因为 6 不等于 2 * 3 和 8 不小于 2 * 4 均为假。
