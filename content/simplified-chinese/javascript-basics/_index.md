## 什么是代码？

在学习编程之前，我们首先需要了解究竟什么是代码。想想你最喜欢的网站，如果你一时想不出任何网站，那就想想 NuevoFoundation.org 这个网站吧。当一个用户使用这个网站时，只需要在浏览器中输入网址，不一会儿——哇哦！——整个网站就加载出来了，展示出漂亮的颜色和 Nuvi 的图片。

很简单对吧？其实不然。在看似简单的操作背后，可能有几百甚至几千行代码在支持其运作。让我们分析这次互动的其中一步：在浏览器中搜索并访问 Nuevo Foundation 网站。世界上有数十亿个网站（根据我最后一次查的结果，大约有17亿个），你的浏览器是如何如此迅速地找到你想去的网站的呢？仔细想一下这个问题...

是程序员编写了这些代码，还有人开发了你的浏览器、Nuvi 的网站，以及你正在阅读的这份课程... 好吧，你懂我的意思了。代码是我们人类用来设计和构建网站、应用程序和游戏等东西的方式。它是我们用来告诉计算机该做什么的语言。

## 什么是 JavaScript， 它有什么用途？

就像世界上有许多人类的语言一样，也存在许多种编程语言。也许你听说过一些，比如 Python 或 Java。每种编程语言都有它的优点和用途——例如 CSS 用于为网站设计样式，Python 在数据科学方面非常强大，等等。

JavaScript 有时被称为 "Web 的语言"。几乎你能想到的任何网站都以某种形式使用了 JavaScript。JavaScript 在控制网站行为方面非常擅长，例如，控制点击按钮时会发生什么，或者在页面之间传输数据。

好消息是，一旦你掌握了一种语言，学习另一种语言就会变得很容易，因为编程的基础知识通常是相通的。

## 环境设置

环境？我以为这是一个编程工作坊？

"环境" 是程序员用来描述他们编写代码设置的术语。你知道你会用 Microsoft Word 或 Google Docs 写文章吧？可以把它们想象成你的 "写文章" 环境。

对于程序员来说，有一种称为 IDE 的应用程序，IDE 是 Integrated Development Environment（集成开发环境）的缩写。这是允许我们编写和运行代码的工具。

在这个工作坊中，我们将使用 playcode.io 平台。

当你打开 playcode.io 后，在开始之前你需要完成几个步骤：
* 关闭左上角除 __script.js__ 外的所有文件。
* 删除 __script.js__ 文件中的所有内容。
* 点击右上角的 __live__ 按钮一次，关闭 __live__ 功能。
