## 使用 Playground

我们将使用 PlayCode 工具来构建我们的第一个 React 项目。在这里，你可以在线编辑代码。

首先，我们需要了解 PlayCode 或 Playground 的工作方式。你可以创建文件和文件夹来组织代码，这是一个自动刷新的代码编辑器，因此无论你写什么内容，都会在不手动刷新的情况下更新。你可以实时查看自己的进展。
