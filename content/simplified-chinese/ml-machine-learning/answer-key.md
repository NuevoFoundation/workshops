## 第一部分：什么是回归？

### 练习 1 答案

**问题 1:** 你能根据面积判断图形的类型吗？

**答案:** 不行。一个正方形（3x3 = 9）和一个三角形（底边 6、高度 3、面积 = 6x3/2 = 9）可以有相同的面积，但形状不同。

**问题 2:** 哪种关系决定了图形的类型？

**答案:** 边的数量。这是一个直接的线性关系：3 条边 = 三角形，4 条边 = 正方形，5 条边 = 五边形，等等。

## 第二部分：简单线性回归

### 关键公式

线性回归方程：

```
y = ax + b + ε
```

其中：
- `x` = 自变量（工作年限）
- `y` = 因变量（薪资）
- `a` = 斜率/系数（y 随 x 每增加一个单位的变化量）
- `b` = 截距（当 x = 0 时的 y 值）
- `ε` = 误差项

### 练习 1：使用 Scikit-learn 进行操作

加载并可视化数据集：

```python
import pandas as pd
from sklearn import linear_model

dataset = pd.read_csv("Experience_vs_Salary.csv")
x = dataset.iloc[:, :-1].values  # 工作经验列
y = dataset.iloc[:, 1].values     # 薪资列

model = linear_model.LinearRegression()
model.fit(x, y)
```

### 练习 2：求斜率和截距

**答案:**
- **截距 (b):** 25,792.20
- **系数/斜率 (a):** 9,449.96
- **方程:** 薪资 = 9,449.96 × （工作经验）+ 25,792.20 + ε

**解释:**
- 工龄为 0 年的员工平均收入约为 $25,792
- 每多 1 年工龄，薪资大约增加 $9,450

## 第三部分：置信区间

### 关键公式

```
系数范围 = 系数 ± 2 × 标准误差
```

### 练习 2：求标准误差

**答案:** 标准误差 = **409.40**

### 置信区间计算

```
系数范围 = 9,449.96 ± 2 × 409.40
系数范围 = 9,449.96 ± 818.80
系数范围 = [8,631.16 , 10,268.76]
```

**解释:** 我们有 95% 的把握认为每年的工作经验将使薪资增加在 $8,631.16 到 $10,268.76 之间。

### 练习 1：检查更多样本

**问题:** 为什么每次运行时截距和系数值会不同？

**答案:** 每次运行时，系统从 10,000 多条数据中随机选取 30 条记录，因此不同的样本会产生略有不同的结果，但这些结果通常会落在置信区间内。

### 练习 3：正态分布

从多个样本中生成的斜率值的直方图形成一个钟形曲线（正态分布）。这表明这些值聚集在真实系数周围，大多数值位于置信区间内。

## 第四部分：模型拟合

### 练习 1：计算 R²

**答案:** R² = **0.973**

**解释:** 我们有 97.3% 的把握认为工作年限与员工薪资存在关系。模型可以解释 97.3% 的薪资变动。
