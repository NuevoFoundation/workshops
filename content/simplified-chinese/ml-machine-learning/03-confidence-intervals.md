# 置信区间

之前的示例告诉我们，当你从更大的数据集中使用随机样本时，**截距**和**系数**的值分布在一个区间内。我们知道真实值必须在两个值之间，但我们不知道具体是什么！这被称为[置信区间](https://www.geeksforgeeks.org/confidence-intervals-for-machine-learning/)。

当你多次运行**练习 1**的代码时，可以看到**系数**的值每次都会发生变化，但注意它很少低于9000或高于10000。我们可以得到的所有可能**系数**之间的差异是多少？这个值是什么？这就是所谓的**标准误差**。

**[标准误差](https://www.statology.org/standard-error-regression/)** - 值到回归线的平均距离。

# 示例 3：正态分布

让我们退一步思考，从“练习 2”中看到的系数或斜率，这些值在其他样本中重复出现的可能性有多大？

机器学习使用了大量的统计知识来确定我们获得的这些值。在统计学中，有一种图表用于测量数据中某个值出现的“可能性”。这就是所谓的`正态分布`或`钟形曲线`，它看起来是这样的：

|![Normal Distribution](../resources/normal_distribution.png)|
|:--:|
|图示 #: 正态分布或钟形曲线|

举个例子，看到一个身高非常矮的人有多可能？看到一个身高非常高的人有多可能？

如果我们用钟形曲线表示这个关系，你会得到这样的图像：

|![Normal Distribution](../resources/normal_distribution_height.png)|
|:--:|
|图示 #: 正态分布或含有身高的人群分布曲线。|

正如你所见，看到一个非常矮或非常高的人是不太可能的。但看到一个平均身高的人却是很正常的。当然，这可能因国家而异，但你明白我的意思。

如果你运行下面的 Replit，你会看到生成的直方图类似于钟形曲线。程序创建了一个[直方图](https://corporatefinanceinstitute.com/resources/excel/histogram/)，它显示某个值在数据集中出现的次数，也就是有多少员工拥有相同的薪资。

当这种情况发生时，我们可以使用标准误差和以下公式来表示：“我们有 95% 的信心系数的值会在这个范围内。”但这个范围是什么？这个范围就是我们的**置信区间**。

<h3>
\[
    系数范围 = 系数 \pm2 * (标准误差)
\]
</h3>
