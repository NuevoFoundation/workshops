# 什么是简单线性回归？

简单线性回归旨在找到两个变量之间的相关性，并推导出解释一个因变量和一个自变量之间关系的数学方程。总体来说，使用简单线性回归我们想要得出如下结论：

1. 我们的变量之间是否存在**关系**？

    你可以确定收入和消费、经验和薪水、或湿度和温度之间的关系。但例如，一个学生的身高和他们的考试成绩之间则没有关系。

2. 我们是否能**预测**值？

    通过回归，我们可以训练模型并确定我们是否能够准确预测值。我们是否可以利用已知的关系预测新的值？
    
    例如：明天的温度会是多少？我的面包房今年比去年能卖多少？如果我有5年的经验，我的薪水会是多少？

# 变量的角色

在简单线性回归中，变量可以扮演以下两种角色之一。

1. **因变量**

    我们想要预测或推测其值的变量。称其为**因变量**是因为它的值依赖于其他因素。我们将这个变量称为**y**。

2. **自变量**

    我们可以控制或更改的变量，以影响因变量的值。我们将这个变量称为**x**。

    示例：如果一个苹果的价格是 $1.00 且你买了10个苹果，总成本将是 $10.00。在这里，`总成本`是因变量，而你想买的苹果数是自变量。

# 简单线性方程的数学模型

使用简单线性回归时，我们称其为**线性**是因为数学模型表示的是二维平面中的一条直线。让我们来思考一下。

直线的数学方程是什么？

{{% expand "**点击显示答案**" %}}

这个方程可能对你非常熟悉。如果是，它就是直线的一般方程。

<h1>
\[
    y = ax + b
\]
</h1>

- **x** 是自变量。
- **y** 是因变量。
- **a** 是直线的斜率。
- **b** 是截距，即当 **x = 0** 时的 **y** 值。

根据这个方程，我们将详细说明简单线性回归数学模型如何计算和预测新值。

# 实际应用案例

在现实中，数据有时不是线性的，并且表现可能与我们的预期有所不同。乍一看，数据可能似乎毫无关联。而对于简单线性回归，你需要寻找的是那些某种程度上遵循线性模式的数据。

假设你是某公司人力资源部门的一名`数据分析师`，该公司员工超过10,000人。你的老板想知道员工的工作经验是否与他们的薪水有关。当然，作为一名`数据分析师`，你可以检查员工数据库并迅速验证以下内容：

1. 他们当前的薪水是多少？
2. 此人有多少年的工作经验？

正如你所见，这条线没有穿过**所有**点，但它靠近大部分点。这意味着什么？为什么在某些情况下点会靠近或远离我们的假想线？

到目前为止，我们已知：

1. 数据整体上表现出某种程度的**线性**趋势。
2. 数据有2个重要变量 **薪水** 和 **工作经验**。这意味着我们可以像线性方程一样开始**建模**。

**问题：** 我们知道 **薪水** 和 **工作经验** 是我们的变量，但是哪个是因变量，哪个是自变量？
{{% expand "**点击显示答案**" %}}

- **工作经验 (XP)** 是我们的自变量。
- **薪水** 是我们的因变量。

如果我们将它们代入我们的线性方程，将得到如下形式。

<h1>
\[
    SALARY = a(XP) + b
\]
</h1>

用一个这样的方程，我们表示：“工作经验对员工的薪水有直接影响”。
