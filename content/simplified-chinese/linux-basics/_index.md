**操作系统** (OS) 是一种软件，它充当你与电脑硬件之间的接口。每台电脑必须至少有一个操作系统才能运行其他程序，比如你的浏览器！操作系统帮助你与电脑进行沟通，而无需掌握计算机的语言。

你可能在家最熟悉使用的操作系统是 Microsoft Windows。你可能还见过另一款常见的操作系统——Apple macOS。而 Linux 是另一种操作系统！由于其多功能性，它在开发者中非常受欢迎。在众多选项中，今天我们将使用基于 Linux 的操作系统，名为 Kali Linux。它是安全专家和黑客中非常流行的操作系统！

Windows、macOS 和 Linux 之间最大的区别在于它们各自的最佳用途。Windows 非常适合多媒体和游戏！macOS 则介于 Windows 和 Linux 之间。虽然 macOS 也非常适合多媒体，但它不支持所有游戏。而 Linux 通常更适合编程和托管服务器。
