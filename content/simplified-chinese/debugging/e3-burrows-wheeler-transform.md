Burrows-Wheeler 变换（BWT）是一种用于数据压缩的算法。它将输入字符串转换为一个编码字符串，该字符串通常将类似的字符聚集在一起。

## 原理

该算法相对简单且易于理解。

1. 获取输入字符串，并提取其所有旋转形式。（参见图片）。
2. 按照字典顺序升序排序这些旋转字符串。
3. 取排序后的最后一列，作为输出。

![Burrows-Wheeler 变换](../resources/e3-01.png "Burrows-Wheeler 变换的 3 步骤")

在上图中，我们使用字符串 `banana` 作为示例。`\0` 是一个符号，用来表示字符串结束（类似 C 语言中的空终止符号），但按字典顺序比较，它是比其他字符更大的。

一种实现 BWT 的有效方法是使用一种称为后缀数组的数据结构。为了创建后缀数组，我们首先取输入字符串的所有后缀，并为其赋予编号标记。然后按照字典顺序对这些后缀进行排序。

![后缀数组](../resources/e3-02.png "创建后缀数组的步骤")

使用字符串 `Nuevo\0` 作为示例，我们首先取它的所有后缀并列出它们。然后按字典顺序进行排序，其中 `\0` 是前面提到的空终止符，并充当最大的字符。最后，我们取每个后缀中第一个字符的索引，并将它们放入一个数组中。例如，字符串 `Nuevo\0` 中字母 `N` 的索引是 `0`，而字母 `e` 的索引是 `2`。由于它们在字母表中是最小的，分别放入数组的第 0 和第 1 个位置。

我们可以将后缀视为 Burrows-Wheeler 变换的旋转形式！我们只需要将被“截断”的前缀附加到字符串的末尾即可。因此，`evo\0` 在我们将后缀视为旋转时会变成 `evo\0Nu`。然后，如果我们对所有后缀执行此操作，我们就得到了 Burrows-Wheeler 变换所需的排序旋转。

![后缀到旋转](../resources/e3-03.png "通过后缀排序为 Burrows-Wheeler 变换创建旋转的表格")

一个关键点是，我们实际上不需要存储旋转数据，因为后缀数组中的索引已经提供了这些信息。如果 `suffix_array[i] == 0`，那么我们知道正在查看的旋转是 `Nuevo\0`。如果 `suffix_array[i] == 3`，那么正在查看的旋转是 `vo\0Nue`。可以将其理解为我们将 `N` 向右旋转了 N 个位置，前提是 `suffix_array[i] == N`。上图对此进行了说明。

所以，有了这些理解，我们可以通过简单地将 `suffix_array[i]` 减去 1，然后对后缀数组的总长度取模来获取旋转的最后一个字符，从而得到我们对任何给定字符串的 Burrows-Wheeler 变换。

## 实现

我们采用了上述策略进行实现：构造后缀数组，获取索引，执行减法操作，然后进行对字符串长度（包括空终止符）的取模操作。

我们已经实现了后缀数组以及 Burrows-Wheeler 变换。但由于当时编写代码时精力不济，遗留了许多问题。这个练习比较棘手，因为涉及到很多索引，并需要巧妙地解决这些问题。有关修复错误的提示，大部分问题都集中在后缀数组及其使用上。

{{% notice tip %}}
空终止符可能会影响你打印字符串的方式。在此练习中，你需要逐字符打印出转换后的字符串，因为空终止符会使 `printf` 函数在遇到它时停止打印。以下代码将打印出调用 `bwt(dest, src)` 的结果，其中 `STR_LEN` 是字符串的静态长度 **包括空终止符**。

```c
for(int i = 0; i < STR_LEN; ++i) {
    printf("%c", dest[i]);
}
```

请注意，`strlen()` 返回字符串的长度，不包括空终止符。

最后一点提示：在 C 语言中 `%` 不是**取模操作符**！它是**取余操作符**。这可能是某些索引错误的原因...
{{% /notice %}}
